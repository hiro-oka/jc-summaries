🏥 聖路加ICUでの実践への示唆

聖路加ICUでの実践

病棟プロトコルへの落とし込み

  • 輸液戦略の判断を「長期転帰」で決着させる根拠は無い。CLASSIC は90日死亡に続き1年死亡・QOL・認知機能でも群間差を検出しなかった。当院で「制限したほうが後々よい」「入れたほうが後々よい」と長期予後を理由に主張するのは、現時点では根拠を欠く。
  • ただし「差が出なかった」を「同等」と読み替えない。1年死亡の99%信頼区間は −4.8〜+7.8%ポイントで、死亡率50%の集団で7.8%ポイントの害（NNH 約13）まで否定できていない。制限戦略を「安全が証明された」と言い切る資料には使えない。
  • 家族面談の参照値として使う：ICUで敗血症性ショックと診断された成人の1年死亡は約50%（90日で約42%）。90日以降も緩やかに死亡が増え続ける（Kaplan-Meier曲線が1年まで下降を続ける）。「山を越えれば元通り」という説明はこの数字と合わない。
  • 生存者の到達点を具体的な数字で語れる：1年生存者の EQ-5D-5L 指数中央値 0.83／0.81、EQ VAS 中央値 70、Mini MoCA 中央値 22/30（原版MoCAの軽度認知障害カットオフは26未満）。生存しても認知機能は低下域に留まる患者が多数派である。当院の退室後フォロー（Hotel ICU の退室後訪問）で認知面のスクリーニングを議題に載せる根拠になる。
  • 長期アウトカムを電話で測る運用は実行可能：認定スタッフによる母語での電話面接で、死亡 97.9%・HRQoL 91.3%・認知機能 86.3% の追跡率を達成している。当院で長期転帰研究を組む際、EQ-5D-5L は代諾者版が使えるがMini MoCA は代諾不可という制約を最初から設計に織り込む必要がある（本研究で認知機能の欠測が最も多かった直接の原因）。
  • 当院プロトコルの変更は不要。この論文単独で輸液戦略を変える理由にはならない。既存の「反応性を見て入れ、うっ血が出たら引く」運用を維持する。

📌 全体要約

要旨

ひとことで 敗血症性ショック1554例のCLASSIC試験を1年追跡したところ、輸液制限群と標準輸液群で死亡（51.3% vs 49.9%）・HRQoL・認知機能のすべてに差は検出されなかった。ただし99%信頼区間は臨床的に重要な差を除外できていない。

  • 対象：ヨーロッパ8か国31 ICU、2018年11月〜2021年11月に登録された Sepsis-3 基準の敗血症性ショック成人 1554例。うち同意撤回5例を除く 1549例が解析集団（制限群767／標準群782）。
  • 介入：静脈内輸液の制限 vs 標準輸液（介入の詳細は主論文に既報。本論文は1年転帰のみを扱う）。
  • アウトカム（すべて事前規定の副次アウトカム）：①全死因死亡 ②HRQoL（EQ-5D-5L 指数値・EQ VAS） ③認知機能（Mini Montreal Cognitive Assessment）。いずれもランダム化から1年時点。
  • 追跡率：死亡 97.9%、EQ-5D-5L 指数値 91.3%（1414例）、EQ VAS 91.0%（1409例）、Mini MoCA 86.3%（1337例）。
  • 1年死亡：制限群 385例（51.3%） vs 標準群 383例（49.9%）。調整絶対リスク差 1.5%ポイント（99%CI −4.8 〜 7.8）、調整相対リスク 1.03（99%CI 0.91–1.17）、P=0.55。
  • HRQoL（全例・死亡者にゼロを割り当て）：EQ-5D-5L 指数値の中央値 0（IQR 0–0.82） vs 0（IQR 0–0.81）、平均差 0.00（99%CI −0.06 〜 0.05）、P=0.81。EQ VAS 中央値 0（IQR 0–70）が両群、平均差 −0.65（99%CI −5.40 〜 4.08）、P=0.80。
  • 認知機能（全例）：Mini MoCA 中央値 0（IQR 0–22）が両群、平均差 −0.14（99%CI −1.59 〜 1.31）、P=0.82。
  • 生存者限定（post hoc）：EQ-5D-5L 指数値 0.83（IQR 0.58–0.93） vs 0.81（IQR 0.58–0.93）、平均差 0.01（99%CI −0.05 〜 0.07）、P=0.61。EQ VAS 70（IQR 50–80）が両群、平均差 −0.05（99%CI −5.29 〜 5.25）、P=0.63。Mini MoCA 22（IQR 17.5–25） vs 22（IQR 18–24.5）、平均差 0.16（99%CI −0.96 〜 1.39）、P=0.59。
  • 結論：1年時点の生存・HRQoL・認知機能はいずれも「similar（同様）」だが、臨床的に重要な差は除外できない。

📖 詳細

1. まず前提 — この病態・治療の基礎（初めての人にも）🧩

要旨

5分で背景を掴む 敗血症性ショック（Sepsis-3 基準）とは、感染に対する制御不能な宿主反応（敗血症）に、①適切な輸液蘇生をしても平均動脈圧65 mmHg以上の維持に昇圧薬を要し、かつ②血清乳酸値が2 mmol/L超、という循環・代謝異常が重なった状態を指す。院内死亡はおおむね30〜50%と高い。

輸液（IVフルイド）の位置づけ：敗血症性ショックでは血管拡張と血管透過性亢進で有効循環血液量が減るため、輸液は昇圧薬と並ぶ第一選択治療として Surviving Sepsis Campaign ガイドラインに位置づけられている。しかし輸液は「入れれば入れるほど良い」ものではなく、過剰輸液は肺水腫・腸管浮腫・腎うっ血・腹腔内圧上昇を招く。そこで「どこまで入れるか」を検証したのがCLASSIC試験（Conservative vs Liberal Approach to Fluid Therapy of Septic Shock in Intensive Care）である。CLASSIC 本体（NEJM 2022）は、ICU滞在中の輸液量に明確な差をつけた（中央値 1798 mL vs 3811 mL）にもかかわらず、90日死亡に差を認めなかった。

本論文が測ったもの：本論文はCLASSICの1年後の姿を測っている。使う道具は3つ。

  • EQ-5D-5L：EuroQol が開発した汎用の健康関連QOL（HRQoL）尺度。移動の程度／身の回りの管理／ふだんの活動／痛み・不快感／不安・ふさぎ込み の5次元を、それぞれ「問題なし／少しあり／中程度／かなり／極度」の5段階で答える。これを国ごとの一般人口の選好に基づく value set で1つの指数値に変換する。1.0が完全な健康、0が「死と等価な健康状態」、0未満は「死より悪いと評価される健康状態」。デンマークの value set での最低値は −0.76。
  • EQ VAS：同じ質問票に含まれる視覚アナログスケール。「今日のあなたの健康状態」を 100（想像できる最良）〜 0（想像できる最悪）で自己申告する。電話で実施する際は、EuroQol のインタビューガイドの推奨に従い「体温計のような目盛りを思い浮かべてください」と教示した。
  • Mini MoCA：認知機能スクリーニングである MoCA（Montreal Cognitive Assessment）の短縮版で、電話実施用に妥当性が検証されている。4領域＝注意（5単語の即時再生）／遂行機能・言語（1分間の語想起流暢性）／見当識（日付と地理の6項目）／記憶（5単語の遅延再生と再認）。合計0〜30点、低いほど悪い。教育歴の影響を補正するため、教育年数12年以下の参加者には1点を加算し、上限30点で打ち切る。原版MoCAでは26点未満が軽度認知障害のカットオフとされる。

「死亡者にゼロを割り当てる」という設計：死亡率が高い集団でQOLを測ると、死亡した人の値が「欠測」になる。生存者だけを比べると、群間で死亡した人の重症度分布が違ったときに結論が歪む（生存者バイアス）。そこで本研究は EuroQol の推奨に従い、死亡者の EQ-5D-5L 指数値を0（死と等価）、EQ VAS と Mini MoCA も最悪値である0として解析に含めた。この設計を理解していないと、後述の「中央値が両群とも0」という一見奇妙な結果が読めない。

2. 背景と目的 🫁

著者らは Background で次の順に論を立てている。

  1. 敗血症性ショックは毎年数百万人の死亡をもたらし、生存者は身体的・心理的・認知的・社会的な長期の後遺症を抱える。
  2. 輸液は第一選択治療である。少ない輸液量と多い輸液量では短期転帰は同等かもしれないが、敗血症性ショック患者において、異なる輸液量を比較したランダム化試験で長期HRQoLや90日を超えるアウトカムを報告したものは存在しない。
  3. 急性肺傷害では、FACTT（Fluid and Catheter Treatment Trial）の1年追跡で、保存的 vs リベラルな輸液管理への割付が長期の認知障害と遂行機能低下に関連する可能性が示された。一方でQOLは同様だった。ただし439名の生存者のうち1年評価の対象になったのは75名のみという規模の制約があった。
  4. CLASSIC本体は90日時点で死亡その他のアウトカムに差を認めなかった。
  5. 本報告は CLASSIC の事前計画された1年時点の死亡・HRQoL・認知機能の評価結果である。

仮説：著者らは「輸液制限が長期転帰を改善する」と仮説を立てていた（原文 "We hypothesized that fluid restriction would improve long-term outcomes."）。結果はこの仮説を支持しなかった。

3. 方法（Methods）📐

  • デザイン：ヨーロッパ、研究者主導、層別化、並行群間、オープンラベルのランダム化比較試験（CLASSIC）の、事前計画された1年転帰解析。試験プロトコル・統計解析計画・主要結果はいずれも既刊。1年アウトカム用の統計解析計画も別途公表済み。プロトコル・解析計画からの逸脱は根拠とともに ESM1 に記載。報告は CONSORT 2010 Statement に準拠（チェックリストは ESM2）。
  • 施設・期間：デンマーク、スウェーデン、ノルウェー、スイス、イタリア、チェコ、英国、ベルギーの 31 ICU。2018年11月〜2021年11月に登録。患者本人または法的代諾者からの文書同意（各国規定に従う）を得て組み入れ。
  • 対象（組み入れ）：Sepsis-3 基準による敗血症性ショックの成人ICU患者で、直近24時間に1L以上の静脈内輸液を受けており、ショック発症からスクリーニングまで12時間以内。詳細な組み入れ・除外基準は ESM1 および既報。
  • 介入・比較：輸液制限 vs 標準輸液。本論文は介入の詳細を再掲せず、主論文（NEJM 2022）に委ねている。ICU内輸液量の実測差も本論文には記載が無い。
  • アウトカム（すべて事前規定の副次アウトカム、ランダム化1年後）
  • 全死因死亡
  • HRQoL：EQ-5D-5L 指数値、EQ VAS
  • 認知機能：Mini MoCA
  • データ取得の運用
  • 追跡率を上げ、データ収集を均一にするため、全患者共通の標準業務手順書（SOP）を作成（ESM1に収載）。
  • 試験スタッフは1年到達日から少なくとも4週間は追跡データ取得を試み続けた。プロセスはデンマークの統括センターが中央モニタリングし、各施設の回答取得を支援した。
  • 生存状況は診療録から取得。生存者には介入に盲検化された認定試験スタッフが母語で電話面接した。
  • 一部の症例では家族が生存状況を提供し、必要に応じてHRQoLを代諾者版で本人に代わって回答した。認知機能検査は家族による代行が不可能（この制約が後述の通り、Mini MoCA の欠測が最も多くなった直接の原因）。
  • EQ-5D-5L の value set（国別）
  • 国別 value set を使用：デンマーク、スウェーデン、イングランド、イタリア。
  • 専用 value set が無い国は、担当国の研究者と協議して文化・医療制度が近い国のものを採用：スイス→ドイツ、ノルウェー→デンマーク、チェコ→ポーランド。
  • 推奨に従い、全患者にデンマークの value set を当てた追加解析も実施（登録の大半がデンマークだったため）。
  • 解析（統計）
  • 解析集団：全ランダム化例1554例から、全データの使用に同意を撤回した5例を除いた 1549例。
  • 記述統計：連続変数は中央値と四分位範囲（IQR）、カテゴリ変数は実数と割合。ベースラインは割付だけでなく、生存/回答状況の層別でも提示。
  • 欠測の扱い：EQ-5D-5L 指数値 8.8%、EQ VAS 9.2%、Mini MoCA 13.8% と5%を超えたため Little's test を実施したところ、完全ランダム欠測ではない（P<0.001）と示された。したがってこれらのアウトカムの主要解析は多重代入後に行った。代入は predictive mean matching 法で、各治療群で別々に50データセットを代入。代入モデルには層別化変数（試験施設、転移性がんまたは血液悪性腫瘍）、ベースライン値、全アウトカムを含めた。各代入データセットで解析し、結果を適切にプールした。
  • 感度分析：best–worst／worst–best case の代入（生存者は完全回答者の平均±1SD、生存状況欠測例は全利用可能データの平均±1SD を使用）、および complete case 解析。死亡アウトカムは欠測が2.1%と限定的だったため complete case 解析も併用。
  • 主要解析は層別化変数で調整し、副次解析は未調整。
  • 死亡：調整ロジスティック回帰モデルに基づく G-computation と 50,000回のブートストラップ再標本化（主要解析）。未調整の副次解析は二項誤差分布・log/identity リンクの一般化線形モデル。結果は平均（非条件付き）リスク差（RD）と相対リスク（RR）を99%CI付きで提示し、Kaplan-Meier 生存曲線を添えた。
  • 連続アウトカム：明らかに非正規分布だったため、P値は Kryger Jensen and Lange 検定で算出。線形回帰モデルで死亡と同様の手順により、平均差（MD）と比（ratio of means）を99%CI付きで提示。主要解析では1年時点で死亡していた患者をスコア0として含めた。
  • 生存者限定の EQ-5D-5L 指数値・EQ VAS・Mini MoCA も解析した（Table 2 の脚注cにより post hoc と明記）。
  • 全患者にデンマークの value set を当てた EQ-5D-5L 指数値の副次解析も、全例および生存者限定の双方で実施。
  • ソフトウェア：R バージョン 4.2.0 および 4.2.1。
  • 多重検定のため、P値は0.01未満を統計学的に有意とした（したがって信頼区間はすべて99%CI）。
補足

事前解析計画からの4つの逸脱（本文に明記されている） 著者らは以下の逸脱を自ら列挙している（詳細と理由は ESM1）。JCで必ず取り上げるべき点。

  1. HRQoL と Mini MoCA が非正規分布だったため、Kryger Jensen and Lange 検定のみを使用した。
  2. 死亡の統計的取り扱いが計画に明確に規定されていなかった。主として G-computation とノンパラメトリック・ブートストラップを併用した調整ロジスティック回帰を用いた。
  3. 生存者限定の副次解析を追加した（＝事前計画に無かった post hoc 解析）。
  4. Little's test が「完全ランダム欠測」を棄却したにもかかわらず、best–worst／worst–best case の感度分析を追加した。

逸脱の2番目（死亡の解析手法が事前に決まっていなかった）は、主要な数値の出し方が結果を見た後に決まった可能性を残す。方向性を変えるほどの逸脱ではないが、「完全に事前規定された解析」と紹介するのは正確でない。

9. 感度分析 🔬

  • complete case 解析と未調整解析の結果は、主要結果と同様だった。
  • best–worst／worst–best case シナリオは例外で、欠測が中等度あるため結果が両方向に振れうることが示された（詳細は ESM1 の Table S1）。
  • 全患者にデンマークの value set を当てた EQ-5D-5L 指数値の副次解析も実施されたが、本文の Results に個別の数値は記載されていない（Table S1 に収載）。

この感度分析の意味：主要結果は「頑健」と単純には言えない。多重代入という前提の下では安定しているが、欠測が最悪の方向に偏っていた場合には結論が変わりうる、と著者らは正直に書いている。

10. 考察 — 先行研究との比較 📚

  • メタ解析との整合：敗血症または敗血症性ショック患者を対象とした系統的レビュー・メタ解析では、バイアスリスクの低い8試験において、ランダム化後90日に最も近い時点での全死因死亡の相対リスクは 0.99（97%CI 0.89–1.10）だった。本研究の1年結果はこれと整合する。
  • Sepsis-3 定義でのHRQoL研究は他に無い：著者らは、Sepsis-3 基準で定義された敗血症性ショック患者のHRQoLを評価した研究を1本も把握していないと述べている。
  • ARISE との比較：早期目標指向療法（EGDT）の ARISE 試験は、救急外来の早期敗血症性ショックを対象とし、1992年の敗血症基準を用いていた。90日死亡は EGDT群 18.6%、通常ケア群 18.8% と本研究よりはるかに低い。著者らはこれを「より若年の集団で、昇圧薬や人工呼吸を受けた患者が少なかったこと」で説明できるとしている。ARISE の1年HRQoL（生存者限定・EQ-5D-3L）は本研究より低かったが、著者らはこれを①3段階版の天井効果、または②本研究では低スコアが非生存者に集中していること、で説明しうるとした。一方 EQ VAS の結果は本研究と同様だった。
  • 進行中の試験：ARISE FLUIDS（NCT04569942）は、救急外来の敗血症・低血圧・乳酸上昇例で「輸液制限＋早期昇圧薬」対「初期の多めの輸液＋遅めの昇圧薬」を比較しており、EQ-5D-5L による1年HRQoLデータを追加で提供する予定である。
  • FACTT との比較：著者らが把握する唯一の認知機能を評価した輸液試験は FACTT で、急性肺傷害患者において保存的 vs リベラルな輸液管理は2か月時点および1年時点でより強い認知障害と関連していた。本研究は同様の結果を得なかった。著者らはその理由を「FACTT の集団が小規模で、はるかに若く、敗血症は20〜25%しか含まれていなかったこと」で説明できる可能性がある、としている。
  • 認知機能の重要性：敗血症は認知パフォーマンスの低下と関連することが知られている。本研究の患者は Mini MoCA で中央値22/30（30点満点）であり、著者らは「敗血症性ショック生存者の認知機能低下という観察研究の知見を裏づけるように見える」と述べている。
補足

旧版のこのノートは FACTT との関係を「否定した」と書いていた（訂正済み） 旧版は「CLASSIC はこれをはるかに高い追跡率（認知機能 86.3%）で否定した形になる」と記述していた。 原文はそう述べていない。 著者らは "We did not find similar results which can possibly be explained by the small population that was much younger and only 20–25% had sepsis" ＝「同様の結果は得られなかった。これは集団が小規模で若く、敗血症が20〜25%しかいなかったことで説明できる可能性がある」と書いている。 つまり著者らの立場は「FACTTの所見を反証した」ではなく「対象集団が違うので直接比較できない」である。原文の慎重さを保つべき箇所なので訂正した。

11. 強みと限界（著者らの記述）⚖️

強み（著者らが挙げた4つ）

  1. 死亡についてはほぼ完全なデータが得られ、HRQoL の欠測も中等度にとどまった。
  2. 認知機能は認定スタッフが統一SOPに従って評価しており、評価者間信頼性が高い。
  3. 患者を面接したアウトカム評価者は割付に盲検化されていた。
  4. CLASSIC は8か国31 ICU を巻き込んだ大規模なヨーロッパ試験であり、外的妥当性が高い。

🧪 批判的吟味（JCでの論点）

① 「差がない」を「同等」と読み替えていないか（最重要）

本試験は非劣性試験でも同等性試験でもない。優越性の枠組みで差を検出できなかっただけである。1年死亡の99%CIは −4.8 〜 +7.8%ポイント。上限の7.8%ポイントは、死亡率50%の集団では約13人に1人を余分に死なせる大きさに相当する。この幅を「同等」と呼ぶことはできない。著者ら自身が Conclusions で "clinically important differences could not be excluded" と明記していることを、JCでは必ず読み上げる。

② 検出力は事前に設計されていない

本論文には1年アウトカムに対するサンプルサイズ設計・検出力計算の記載が無い。CLASSIC のサンプルサイズは主論文の90日死亡（主要アウトカム）に合わせて決められており、1年アウトカムはその余りで測っている。さらに多重検定への対処としてP<0.01・99%CIを採ったため、同じデータでも95%CIより幅が広くなり、差を検出しにくくなっている。「有意差なし」の解釈にはこの二重の制約がかかる。

③ 分母が本文中で3通りに書かれている

第4節の警告コールアウトの通り、抄録（746／767）、Results本文（767／782）、Table 2 ヘッダ（767／782）が食い違い、報告された割合（51.3%／49.9%）を再現できるのは 750／767 だけである。査読を通った論文でも一次データの再計算は必要という実例。JCの演習として全員に検算させる価値がある。

④ Mini MoCA の信頼区間も抄録と本文で違う

抄録 −1.59〜1.14、本文と Table 2 は −1.59〜1.31。方向は変わらないが、抄録だけで論文を引用してはいけないことの実例。

⑤ 追跡率の分母も統一されていない

本文は「1554例の97.9%」と書くが、解析集団は1549例であり、報告されている割合（97.9%・91.3%・86.3%）はいずれも1549を分母にしないと再現できない（1414/1549＝91.28%、1337/1549＝86.31%）。また Methods は欠測を8.8%／9.2%／13.8% と書くのに対し Table 2 は 8.7%／9.0%／13.7% と書いている。いずれも結論を変えない微小な不整合だが、数字の出所を確認する習慣を促す。

⑥ 代諾者の人数が本文と図で合わない

Results 本文では家族による代理回答が制限群24例＋標準群21例＝45例。しかし Figure 3 の注記は「生存患者749例のうち 55例（7.3%）が家族による代理回答」としている。45 ≠ 55。分母749は本文の365＋384と一致するので、分子だけが食い違っている。ESM を見ないと解消できない。

⑦ 生存者限定解析は post hoc である

Table 2 の脚注cに "Post hoc analyses" と明記されている。統計解析計画からの逸脱の3番目としても本文に列挙されている。旧版の本ノートは「生存者のみの解析でも両群同様」とだけ書いており、事前計画ではないことを示していなかった。生存者限定の数値は探索的な位置づけとして扱うべきである。

⑧ 死亡へのゼロ割り当ての功罪

この設計には正当性がある（生存者バイアスの回避、EuroQol の推奨、検出力の維持）。一方で副作用として、死亡率が約50%の集団では複合スコアが実質的に死亡の再検定に近づく。Figure 2B のヒートマップで左半分が真っ赤なのはそのためで、EQ-5D-5L 指数値・EQ VAS・Mini MoCA の「差がない」は、大部分が「死亡に差がない」の言い換えである。生存者限定解析（post hoc）が併記されているのはこの弱点の補償だが、そちらは事前計画外という別の弱点を持つ。QOLと死亡を1つの指標に畳み込むと、どちらの解釈も難しくなるというトレードオフを議論する価値がある。

⑨ 解析集団は ITT か

解析は「全ランダム化例から同意撤回5例を除く1549例」で、ITTに近い（modified ITT）。ただし本論文には per-protocol 解析の記載が無い。プロトコル遵守度（実際にどれだけ輸液量に差がついたか）も本論文には記載が無く、主論文に委ねられている。「割付どおりの介入が1年間続いたわけではない」点は自明だが、ICU退室後は両群とも同じ通常診療に戻るため、1年アウトカムに対する介入のシグナルは希釈されているはずである。この希釈を織り込むと、そもそも1年時点で差を検出できる仮説だったのかという問いが立つ。

⑩ 感度分析が「両方向に振れうる」

best–worst／worst–best シナリオでは結果が変わりうると著者ら自身が書いている。欠測は Little's test で完全ランダム欠測が棄却されており、しかも非回答者は回答者より軽症に見えた（Table 1）。軽症で連絡がつかなかった人が良好なQOLを持っていた可能性が高く、多重代入がそれをどこまで再現できたかは検証しようがない。

⑪ 外的妥当性 — 日本の診療に当てはまるか

31 ICU すべてがヨーロッパで、大半がデンマーク。感染巣は消化管が最多（35〜42%）で、日本の敗血症性ショックの分布（肺炎が最多になることが多い）とは異なる。ランダム化前24時間の輸液量が中央値3000 mL前後という前提も、施設によっては当てはまらない。著者らも「標準治療としてより多量の輸液が投与される設定では異なる結果が得られる可能性がある」と明記している。

  • 1年アウトカムに対するサブグループ解析の記載は本文に無い。
  • per-protocol 解析の記載は本文に無い。
  • 両群のICU内・入院中の実際の輸液量は本論文には再掲されていない（主論文にある）。
  • 死因の内訳、90日以降の死亡の原因、再入院・在宅復帰率などは本論文には無い。

⚠ 注意

⚠️ この論文をJCで「制限輸液は安全」と紹介してはいけない 本試験が示したのは「1年時点で差を検出しなかった」ことであって、「安全性が確認された」ことではない。 死亡の99%CI上限は+7.8%ポイント（NNH 約13）で、臨床的に許容し難い害がまだ区間内にある。 一方で「制限は危険だ」という主張の根拠にもならない（下限は −4.8%ポイントで利益側にも同じだけ開いている）。 正しい紹介の仕方は「輸液戦略の選択を長期転帰で正当化することは、現時点ではどちらの方向にもできない」である。

結論 敗血症性ショック1554例のCLASSIC試験を1年追跡しても、輸液制限は生存・QOL・認知機能のいずれも変えなかった（1年死亡 51.3% vs 49.9%、絶対差 1.5%ポイント、99%CI −4.8 〜 7.8）。 ただし「差がない」は「同等」ではない。99%CI上限の7.8%ポイントはNNH 約13に相当し、臨床的に重要な害も利益もまだ区間内にある。

  • 輸液戦略の議論を長期転帰で決着させることはできない。 90日で差が無かったものは、1年でも差が無かった。
  • 敗血症性ショックの1年死亡は約50%（90日約42%）。90日以降も死亡が積み上がり続けることを、家族への説明とICU退室後フォローの設計に織り込む。
  • 生存しても元通りではない。 1年生存者の EQ-5D-5L 指数中央値 0.83／0.81、EQ VAS 70、Mini MoCA 22/30（軽度認知障害のカットオフは26未満）。移動・ふだんの活動・痛みの3領域に問題が残る。
  • 長期アウトカムは電話で測れる。 認定スタッフによる母語での面接で86〜98%の追跡率。ただし認知機能検査は代諾不可という設計上の制約を最初から見込むこと。
