🏥 聖路加ICUでの実践への示唆

聖路加ICUでの実践

病棟プロトコルへの落とし込み

  • この論文で当院の診療を変えるところは無い。単施設228例の proof-of-concept で、著者自身も実装を提案していない。「顔で重症度を判定する」運用は導入しない
  • 教育での使い道はある。「なんとなく悪そう（gut feeling）」を言語化する枠組みとして、研修医・看護師の申し送り教育に紹介できる。ただし後述のとおり この論文の効果量は、顔ではなく「人工呼吸をされているかどうか」でほぼ説明できる ので、そのまま「顔で分かる」と教えない
  • 顔色は使えないと知っておく。蒼白・正常・紅潮の3分類は、経時的なSOFA悪化とまったく関連しなかった（下記の数値）。「顔色が悪い」を重症度の根拠として申し送らない
  • むしろ紅潮のほうが院内死亡が低かった（紅潮 3/43 = 7% 対 蒼白 14/80 = 18%）。「赤ら顔＝敗血症で悪い」と単純に読むと方向を間違える
  • AI・カメラモニタリングの文脈で位置づけを持っておく。当院でバイタル自動収集や画像モニタリングを検討する際、「顔」というモダリティに研究の潮流があること自体は知っておく価値がある。ただし本研究はその実現可能性を示したものではない

🧭 この論文の位置づけ（Known / Unknown / What's new）

補足

リサーチ・イン・コンテキスト

  • Known（既に分かっていたこと）：医療者は患者の顔と全身の見た目を、意識するかしないかに関わらずベッドサイド評価に統合している。写真判定の研究では「病気そうに見える」人は蒼白な皮膚・蒼白な口唇・半分閉じた目を持つことが多い（Axelsson 2018）。一般病棟でも、閉眼・口角下垂・開口・頭部の向きが変わった患者は悪化しやすい（Madrigal-Garcia 2018, CCM）。救急外来では言語・ボディランゲージ・顔貌が重症度の情報を持つ（Shiber 2023）
  • Unknown（分かっていなかったこと）：顔貌を客観的に計測した指標と、ICU入室中の多臓器不全との関連は不明だった。とくに「入室時の顔貌が、その後の経過（縦断的なSOFA）と関係するか」は検討されていなかった
  • What's new（本研究の新規性）：入室3時間以内に標準化ピクトグラムで顔貌（目の開き具合・顔色）を採点し、7日間の連続SOFAとの関連をGEEで解析した。目の開き具合は縦断SOFAと関連し、顔色は単独では関連しないが目の開き具合との交互作用を示した。顔貌を組み込んだモニタリング技術の概念実証（proof of concept） という位置づけ

📌 全体要約

要旨

ひとことで ICU入室3時間以内に医学生・看護学生がピクトグラムで採点した「目の開き具合」は、その後7日間のSOFAスコアと関連した（未調整 1段階あたり 0.7点、95%CI 0.5〜0.9／調整後 0.6点、95%CI 0.4〜0.8）。ただしカテゴリ別に見ると、有意だったのは「細目」と「人工呼吸中」だけで、この関連の大半は「人工呼吸をされているか」（β 2.8点）が担っている。

  • デザイン：SICS-II（単施設・前向き観察コホート）の副次研究。2019年3月26日〜7月10日に急性入室した18歳超・ICU滞在24時間以上見込みの成人 228例
  • 曝露：入室3時間以内、学生がベッドサイドであらかじめ定義された標準化ピクトグラムを用いて顔貌を採点。目の開き具合（開・半開・細目・閉）と顔の皮膚色（蒼白・正常・紅潮）。閉眼の場合は人工呼吸中かどうかも記録
  • アウトカム：ICU入室後7日間の毎日のSOFAスコア（毎朝10時のモーニングレポート値、または最も近い値）。連続SOFAは計 852件
  • 主結果（目の開き具合）：開眼→半開→細目→閉→人工呼吸中と1段階進むごとに、7日間平均でSOFAが 0.7点（95%CI 0.5〜0.9）高い。年齢・性別・BMI・APACHE IVで調整すると 0.6点（95%CI 0.4〜0.8）
  • カテゴリ別（開眼を参照）：半開 +0.8（95%CI −0.3〜1.8）／細目 +1.3（95%CI 0.4〜2.3）／閉 +0.9（95%CI −0.02〜1.8）／人工呼吸中 +2.8（95%CI 2.0〜3.6、p<0.001）。単調増加していない
  • 主結果（顔色）：正常色を比較対象として、蒼白 +0.1（95%CI −0.6〜0.7）、紅潮 −0.1（95%CI −0.9〜0.7）。経時的なSOFA悪化との関連なし
  • 交互作用：顔色は目の開き具合とSOFAの関連を修飾した（P-interaction < 0.1）。紅潮の影響が現れたのは「半開」または「閉」の患者のみで、他の目のカテゴリでは修飾は見られなかった
  • 時間経過：SOFAは全群で低下したが、「半開」群だけは低下しなかった
  • 死亡：Table 1 の90日死亡は 61例（27%）。Fig 1A に示された院内死亡は 29例（13%）。紅潮の患者は生存しやすかった
  • 著者の結論：顔のキュー、主として目の開き具合と顔色の採点は、重症患者の病態と進行について有用な洞察を与えた。「完全な顔は個々の特徴の総和より多くの情報を与える」。顔貌を組み込んだ高度なモニタリング技術は、将来の集中治療支援を高める可能性を秘めている

📖 詳細

1. まず前提 — この病態・評価の基礎（初めての人にも）🧩

要旨

5分で背景を掴む SOFA（Sequential Organ Failure Assessment）スコア：呼吸・凝固・肝・循環・中枢神経・腎の6臓器をそれぞれ0〜4点で採点し、合計0〜24点で臓器不全の程度を表す。ICUで最も広く使われる臓器障害の指標。中枢神経の項目は Glasgow Coma Scale（GCS）から導かれる——この点が本研究では効いてくる（後述）。

GEE（一般化推定方程式）：同じ患者から7日分のSOFAを繰り返し測ると、データ同士が独立でなくなる（同じ人のSOFAは日をまたいで似る）。GEEはこの相関を「作業相関構造」として明示的に扱い、集団平均としての関連（population-averaged effect）を推定する手法。本研究は exchangeable（交換可能） 構造を用いている＝「同一患者内のどの2日の相関も等しい」と仮定するもっとも単純な形。

gut feeling（臨床的直感・ゲシュタルト）：「なんとなく悪そう」という、明示的な数値に還元されないベッドサイドの印象。数値化されていないので教育しにくく、検証もしにくい。本研究のキーワードにも Gut feeling が入っており、著者らはこの直感の一部を顔貌という測れる要素に分解することを狙っている。

APACHE IV：入室後24時間の生理学的異常と慢性疾患・入室理由から死亡確率を予測する重症度スコア。本研究では交絡因子として調整に使われている。

（これは論文本文ではなく一般的な背景知識） ICUでは鎮静薬（プロポフォール・デクスメデトミジン等）を使うと患者は目を閉じる。したがってICU患者の「目が閉じている」は、病気の重さと鎮静の深さの両方を反映する。本論文は鎮静について一言も触れていない（本文全文を検索したが sedation / RASS / Richmond の語は一度も現れない）。

2. 背景と目的 👁️

医療者は本能的に患者の顔と全体の見た目をベッドサイド評価に統合しており、これらの視覚的キューは患者の状態について有用な情報を与え、治療とケアについてより情報に基づいた判断を可能にする、と著者らは述べる。

先行研究では病気を反映する顔のキューが患者において同定できることが示されてきた。しかし、顔貌とICU入室中の疾患重症度との関連は不明のままである。この関連を理解することは、ICUにおける患者状態に関連した「顔面モニタリング」の可能性について有用な洞察を与えうる。

そこで本 proof-of-concept 研究では、目の開き具合と顔の皮膚色を取り上げ、ICU入室後1週間の最大SOFAスコアで測った経時的な多臓器不全との関連を検討した。

3. 方法（Methods）📐

  • デザイン：SICS-II（Simple Intensive Care Studies II）の副次研究。単施設・前向き観察研究（NCT03577405）
  • 施設・期間：Groningen大学医療センター（UMCG）。2019年3月26日〜2019年7月10日
  • 組み入れ：18歳超で、ICU滞在が少なくとも24時間見込まれる急性入室患者全例
  • 除外：本文に明示的な除外基準の記載は無い（組み入れフローは Additional file 1: Figure S2 に譲られており、本文中に脱落数の記載は無い）
  • 評価者：30名の学部の医学生・看護学生がシフト制でボランティア参加。急性入室があると学生に電話が入り、ベッドサイドに来てデータを収集する体制
  • 曝露の測定（顔貌）：
  • ICU入室後3時間以内に、あらかじめ定義された標準化ピクトグラム（Additional file 1: Figure S1A）を用いて患者の顔を採点
  • 目の開き具合：開（open）／半開（half-open）／細目（slit）／閉（closed）の4段階
  • 完全閉眼のときは、人工呼吸中かどうかを追加で判定した。これにより解析上のカテゴリは5つになる
  • 顔の皮膚色：蒼白（pale）／正常（normal）／紅潮（flushed）の3段階
  • ピクトグラムは「蒼白な顔と部分的に閉じた目が病気を示す」とした先行研究（Axelsson 2018）に基づいて作成された。顔はあらゆる肌のタイプに対応し普遍的に適用できるよう中立的にデザインされ、肌色別のシミュレーションが Figure S1B に示されている
  • 盲検化：観察者は電子カルテ（EHR）にアクセスできず、臨床データに盲検化されていた
  • 観察者間一致（inter-observer agreement, κ）は記録されていない。著者らが Limitations で明記している（"we did not record inter-observer agreement"）
  • アウトカムの測定（SOFA）：
  • ICU入室後7日間、毎日のSOFAスコア
  • 採点したのは顔貌評価に盲検化された別の学生で、この学生は臨床業務を行わず、EHRのデータのみに基づいて採点した
  • 毎日の値は朝10時のモーニングレポート、または可能な限り10時に近い時刻の値を選んだ（SOFAの定義は Additional file 1: Table S1）
  • ICU在室日にSOFAの構成項目や変数が欠測していた場合は、利用可能な臨床情報に基づいて補完した。補完の具体的手順は本文に記載が無い
  • 補完の結果、全患者がICU在室の各日についてSOFAスコアを持ち、連続SOFAは合計852件となった
  • 解析：
  • 連続変数は分布に応じて平均（SD）または中央値（IQR）、カテゴリ変数は割合で表示
  • GEE、交換可能（exchangeable）相関構造。アウトカム変数は連続SOFAスコア
  • 調整変数：年齢・性別・BMI・APACHE IV スコア
  • モデルに投入した決定因子：目の開き具合（半開・細目・閉・人工呼吸中の4項目）、顔の皮膚色（正常・紅潮の2項目）、およびその交互作用項 4×2
  • 参照カテゴリ：目は「開眼」、顔色は「蒼白」（Methods の記載）
  • ソフトウェア：Stata version 17
  • 有意水準：p < 0.05、P-interaction < 0.1
  • サンプルサイズ設計・多重比較の補正・感度解析についての記載は本文に無い
  • 欠測・脱落（Additional file 1: Table S1 の注記より）：

有意差記号が付いているのは、人工呼吸中の群が全6時点（1〜4日目が p<0.001、5日目が p<0.05、6&7日目が p<0.01）と、細目の群の1〜3日目（いずれも p<0.05）だけである。半開・閉には1点も付いていない。

本文の記述と一致するのは次の点：SOFAは全群で経時的に低下したが、「半開」群だけは低下しなかった（灰色の線が3日目以降むしろ上向く）。ただし半開はn=25の小群で、6&7日目まで残る例数は原文に示されていない。

6. 結果 — 顔色と交互作用 🎨

  • 紅潮の患者は生存しやすかった（Fig 1A：紅潮43例中の院内死亡3例＝7%、対して蒼白80例中14例＝18%）
  • カテゴリ化すると、蒼白も紅潮も、正常色と比べて縦断SOFAはほぼ同じだった（蒼白 +0.1、95%CI −0.6〜0.7／紅潮 −0.1、95%CI −0.9〜0.7）
  • 目の開き具合と縦断SOFAの関連は、顔の皮膚色によって修飾された（P-interaction < 0.1）。詳細は Additional file 1: Figure S3 に置かれており、本文には具体的な数値が示されていない
  • 紅潮がSOFAに与える影響は「半開」または「閉」の患者で認められ、他の目のカテゴリでは肌色による修飾は見られなかった
⚠ 注意

参照カテゴリの記述が Methods と Results で食い違う Methods は「蒼白を顔色の参照カテゴリとした」と書いているのに、Results は「蒼白または紅潮の患者は、正常な肌色の患者と比べて縦断SOFAが同程度だった」と、正常色を比較対象にして報告している。モデル記述（投入した決定因子は「正常」と「紅潮」の2つ）は Methods の「蒼白＝参照」と整合するので、Results の文章のほうが誤りである可能性が高い。数値を引用するときはこの矛盾を注記する必要がある。

なお抄録では「半開または閉眼＋紅潮の患者は、蒼白または正常な顔色の患者よりSOFAが低かった」と、方向まで明示している。この方向を示す数値は本文には無く、Figure S3 に依拠している。ノート内で方向を語るときは「抄録の記述による」と断るべき箇所である。

7. 考察 — 著者の3つの結論と含意 💭

著者らは結果が次の3点を支持するとまとめている。

  1. ICU入室時の目の開き具合は、より悪い縦断的SOFAスコアと関連した
  2. 顔の皮膚色という特性それ自体は、経時的により悪いSOFAとは関連しなかった
  3. 顔面モニタリング技術の概念にとって重要なことに、顔の皮膚色は目の開き具合と交互作用し、縦断SOFAとの関連を修飾した

3点目は紅潮の患者で死亡率が低かった観察と整合し、例えば感染症に対する適切な反応を示唆するのかもしれない、と著者らは述べる（あくまで示唆であり、検証はしていない）。

先行研究の位置づけとしては、写真で「病気そう」と評価された人は蒼白な皮膚・蒼白な口唇・部分的に閉じた目を持つことが多かった研究、閉眼・口角下垂・開口・頭部の向きが変わった一般病棟患者は悪化しやすかった研究、救急外来入室時の言語コミュニケーション・ボディランゲージ・顔貌が重症度の情報を与える研究が挙げられ、「臨床的ゲシュタルトは個々の特性の総和より複雑である」という概念を全体として支持すると結論している。

含意と一般化可能性として、この10年で希少疾患の表現型意思決定支援が GestaltMatcher のような顔認識ツールで進歩したことに触れ、知的モニタリングセンサーによる顔貌・全身の見た目の把握が、疾患進行の予測にリアルタイム情報を与えて入院患者のケアを助けるかは興味深いとする。スマートカメラや知的システムは看護師のモニタリング負担を減らし、労働力効率を最適化してケアに集中できるようにする可能性がある——ただしこの可能性の探索にはさらなる研究が必要である、と締めくくっている。

🧐 批判的吟味（JCでの論点）

  1. アウトカムに曝露が組み込まれている（incorporation bias）。SOFAの中枢神経項目はGCSから導かれ、GCSの3要素の1つが開眼（eye opening）である。すなわち「目の開き具合」でSOFAを予測する構図は、部分的に同じものを両辺に置いている。著者はこれを限界として挙げつつ「刺激して開眼させるGCSと、観察のみの本研究は異なるので、影響は人工呼吸中の患者に限られ、結果はむしろ過小評価だろう」と主張する。しかしこの主張は検証されておらず、GCS-Eが低い（開眼しない）患者は当然SOFAのCNS項目が高くなる方向の循環は残る。「過小評価」と断じる根拠は本文に示されていない。
  1. 「1段階あたり0.7点」は、5段階目に治療（人工呼吸）を置いた尺度の傾きである。開・半開・細目・閉は顔の所見だが、5段階目の「人工呼吸中」は治療の有無であって顔の所見ではない。しかもこの群がn=107（46.9%）で効果量2.8点と突出している。「顔貌が0.7点」という要約は、実質的に「挿管されている患者は重症だ」という自明な事実を言い換えたものになっている可能性が高い。カテゴリ別の推定値（細目1.3 > 閉0.9、CIが0をまたぐものが2つ）が単調でないことも、線形の段階仮定を支持しない。
  1. 鎮静が一切扱われていない。ICUで目が閉じている最大の理由は鎮静である。本文全文を検索しても sedation・RASS・sedative の語は一度も現れず、鎮静深度も鎮静薬使用も交絡因子として調整されていない。この研究の最大の交絡が、変数として存在すらしていない。「顔貌が臓器不全を反映する」ではなく「鎮静された患者は重症で臓器不全が多い」という説明が、データと完全に整合する。
  1. これは予測研究ではない。曝露（入室3時間以内の顔貌）とアウトカム（入室日を含む7日間のSOFA）は時間的に重なっており、1日目のSOFAとの断面的な差が推定値に含まれる。判別能（AUROC）・較正・再分類のような予測性能は一切評価されていない。「顔で先が読める」という読み方は本研究の設計を超えている。
  1. 交互作用の基盤が薄い。P-interaction < 0.1 という緩い基準を用い、交互作用項は 4×2 = 8個。多重比較の補正は行われていない。加えて Fig 1A の通り、紅潮×半開は4例、紅潮×細目は4例、紅潮×人工呼吸中は15例と極小セルである。「紅潮＋半開／閉でSOFAが低い」は探索的な所見にとどまる。
  1. 観察者間一致（κ）が測られていない。ピクトグラム採点という主観的評価を、訓練された研究者ではなく30名の学部学生が交代で行っている。ある学生の「細目」と別の学生の「閉」が同じ患者を指すかどうかは検証されていない。しかもカテゴリ別推定値は細目と閉で順序が逆転している——測定の信頼性が低ければ、隣接カテゴリの入れ替わりはこの通りの形で現れる。
  1. 顔色の測定妥当性。中立的にデザインされたピクトグラムでも、実際の患者の肌の色調・ICUの照明・皮膚温で見え方は変わる。著者も濃い肌色での推定困難を認めている。さらにオランダでは民族が登録されないため、この誤分類の程度すら評価できない。
  1. 脱落の情報量が大きい。7日目まで残るのは45例（20%）で、脱落は「回復して退室」と「死亡」の両方から生じる。exchangeable GEE は欠測完全ランダム（MCAR）に近い仮定に依存するが、ここでの脱落は明らかに予後と関連する（informative dropout）。図1Bの後半は生存かつ在室の患者だけを描いており、線が下がることを「改善」と読むと生存者バイアスに引っかかる。
  1. Table 1 の内的不整合（緊急手術74例が29%と印字、内科と足して227例）と、Methods と Results で顔色の参照カテゴリが食い違う点。査読で拾われるべき記述の粗さがある。
  1. 報告の不備：カテゴリ別推定値が調整後なのか未調整なのか、本文の書き方では判別できない（「調整しても同様だった」の直後に「カテゴリ化すると」と続く）。また p 値は人工呼吸中の1つしか記載されていない。
  1. Brief Report としての限界。5ページの短報で、主要な図（交互作用 Figure S3、組み入れフロー Figure S2、ピクトグラム原図 Figure S1）はすべて Additional file に置かれている。本文だけでは交互作用の方向と大きさを確認できない。

✅ Take home message

TAKE HOME

結論 入室時の「目の開き具合」は7日間のSOFAと確かに関連したが（1段階あたり0.7点、調整後0.6点）、その関連はほぼ「人工呼吸中かどうか」（+2.8点）が担っており、顔の所見そのものの寄与は小さい。しかもアウトカムのSOFAには曝露と同じ「開眼」がGCS経由で含まれ、最大の交絡である鎮静はこの論文で一度も言及されていない。

「顔で重症度がわかる」と読まない。単施設228例の proof-of-concept であり、臨床実装できる知見ではない。顔色（蒼白・正常・紅潮）は縦断SOFAとまったく関連せず、むしろ紅潮のほうが院内死亡は低かった（7% 対 蒼白18%）。
