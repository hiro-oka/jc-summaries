原題
Extracorporeal Membrane Oxygenation for Respiratory Failure: A Narrative Review

🏥 聖路加ICUでの実践への示唆

  • 人工肺の結露は「sigh」で飛ばせる — sweep gas を 9〜10 L/min に約30秒上げる手技が明記されている。当院の日勤帯ラウンドに組み込める具体的手技。22 循環｜VV-ECMO 実戦管理ガイド に追記した
  • 再循環を数字で判定できる — 脱血側 SO₂ > 75%、または SaO₂ − 脱血側SO₂ < 10% なら再循環を疑う。当院は肺前圧を測っていないぶん、送脱血の飽和度で判断する余地が大きい
  • PaCO₂ の下げ幅に定量的な上限 — 導入前後の相対低下 >50% で神経学的合併症が増える。「急に下げない」を数字で言えるようになる
  • DO₂:VO₂ は 2 ではなく 3 を目標に — 嫌気性代謝は <2:1 で始まるが、余裕をもたせて ≥3:1 を目標とする、という書き方。当院ガイドの「≥2」より安全側
  • モルヒネは回路吸着が少ない — フェンタニル・ミダゾラム・デクスメデトミジン・プロポフォールは吸着が多く、ケタミン・ヒドロモルフォン・モルヒネ・オキシコドン・クエチアピンは少ない。ECMO中の鎮痛にモルヒネを使う薬理学的な裏づけになる
  • 腹臥位はルーチンにしない — 観察研究では有益に見えたが、170例のRCTで死亡・離脱時間ともに差がなかった
  • 肥満はもはや相対禁忌ではない — むしろ死亡リスクは低くICU在室も短い（デバイス関連合併症は多い）
  • 離脱はプロトコル化する価値がある — 非医師主導の離脱プロトコルがECMO日数を短縮し、抜去を早めた

🧭 この論文の位置づけ（Known / Unknown / What's new）

  • Known：VV-ECMO が重症ARDSの標準的救済手段であること、EOLIA基準、lung rest、抗凝固の考え方
  • Unknown：V-P ECMO を「最適な配置」として選ぶべき患者像（著者らも further research が必要と明言）。ECMO中の補助療法（NO・筋弛緩）のルーチン使用の是非
  • What's new：①ELSO の新命名法（V-V / V-P / V-VA、ハイフン＝人工肺）を実践レビューに落とし込んだ ②急性肺性心（ARDSの約22%）を起点に V-P ECMO を位置づけた ③低酸素の鑑別と離脱を、それぞれ1枚のアルゴリズム図にまとめた

📌 全体要約

呼吸不全に対するECMOを、生理 → 患者選択 → 人工呼吸器 → 回路管理 → 低酸素のトラブルシュート → 合併症 → 離脱の順に通しで解説した実践レビュー。ワシントン大学の呼吸器・集中治療チームによる。

強みは2つ。ひとつは数字が具体的なこと（DO₂:VO₂ ≥3、Q<sub>ECMO</sub>/Q<sub>CO</sub> 0.6、ΔP 正常 ~25 mmHg、LDH >2000・遊離Hb >50、PaCO₂ 相対低下 >50%、カニュラ間隔 10–15 cm、再循環の 75%/10% 基準）。もうひとつは、右心を軸に配置変更（V-P / V-VA）を語っていること。ARDSの約22%に急性肺性心が合併し、重症例では死亡リスクが上がるという事実から出発して、「RVが悪ければ V-P、循環も要るなら V-VA」という判断を明示している。

一方で系統的レビューではないため、推奨の強さは示されない。エビデンスの重みづけは読者側の仕事である点は留意する。

📖 詳細

1. 命名法（ELSO 2023 の統一表記）

  • ハイフンが人工肺を表し、左が脱血・右が送血
  • V-V＝静脈脱血 → 人工肺 → 静脈送血／V-P＝静脈脱血 → 人工肺 → 肺動脈送血／V-A＝静脈脱血 → 人工肺 → 動脈送血
  • 追加カニュラは大文字を足す：VV-V（脱血をもう1本）、V-AV（送血をもう1本）
  • モード名（VV ECMO / VA ECMO）はハイフンなし、配置（V-V / V-A）はハイフンあり、と使い分ける

2. 配置の選び方

配置脱血送血使いどころ
V-V肝内下大静脈上大静脈（右内頸静脈経由）呼吸不全の標準。先端は 10–15 cm 離す（再循環対策）
V-V（二腔カニュラ1本）右内頸静脈右房（三尖弁方向へ）1本で済む。再循環が原理的に少ない
V-P肝内下大静脈主肺動脈急性肺性心・右心不全。2本法か二腔カニュラ（ProtekDuo®）
V-VA静脈静脈＋大腿動脈に分流循環補助も要るとき

V-P の根拠：急性肺性心はARDSの約22%に合併し、重症例は死亡リスクが高い。V-P は RV機能を改善し、血管作動薬スコアを下げ、酸素化を改善したと報告されている。機序は再循環の消失と、DO₂ が RV機能に依存しなくなること。ただし配置戦略としての優劣は今後の研究課題。

3. 生理

  • 脱血は肝内下大静脈から、カニュラは通常 25〜29 Fr
  • 人工肺出口は通常 SaO₂ 100%・PO₂ >500 mmHg になるため、溶存酸素が酸素含量の最大10%を占めうる
  • 混合の式：C3 =（C1×自己肺血流 + C2×ECMO血流）/ 総血流。VV では右房で混ざる
  • DO₂ は Hb・SaO₂・心拍出量・Q<sub>ECMO</sub>/Q<sub>CO</sub> 比で決まる。敗血症などの高心拍出状態ではこの比が下がって DO₂ が落ちる
  • Q<sub>ECMO</sub>/Q<sub>CO</sub> ＝ 0.6 でおおむね SaO₂ >90% を保てる
  • DO₂:VO₂ — 健常は約5:1、<2:1 で嫌気性代謝。ECMO中は余裕をみて ≥3:1 を目標とする
  • VO₂ は発熱・疼痛・呼吸努力・炎症・カテコラミンで増え、敗血症・多臓器不全・ミトコンドリア障害で減る。正確には実測でしかわからないので、乳酸を代用指標にする
  • SaO₂ 80〜85% で足りることが多い。DO₂:VO₂ が保たれ組織低酸素の徴候がなければ、もっと低くても許容されうる

4. 患者選択

EOLIA 基準（多くのセンターが採用）：

  • P/F <50 が3時間超、または P/F <80 が6時間超（いずれも FiO₂ >80%）— 最適な人工呼吸設定と補助療法（筋弛緩・腹臥位・吸入肺血管拡張薬）を行ったうえで
  • または pH <7.25 かつ PaCO₂ >60 mmHg（最適設定下で）

CESAR：Murray score ≥3 または pH <7.2。ECMOセンター搬送群で生存 63% vs 47%。ただし搬送群の20%は人工呼吸最適化だけでECMOに至らず、その82%が生存した。

EOLIA の解釈：ITT解析で有意差なし。ただし対照群の28%が救済ECMOにクロスオーバーし、その43%が生存。ベイズ流post hocとメタ解析は約10%の死亡減少を示唆。

絶対禁忌：抜去の見通しが立たない非回復（肺移植ブリッジの計画がない場合）／確立した多臓器不全の瀕死状態／短期予後不良（転移性悪性腫瘍など）／破局的神経損傷

相対禁忌：重症の中枢神経損傷・出血／不可逆で高度の中枢神経病変／全身性出血／抗凝固の禁忌／免疫抑制／高齢（閾値は確立していない）／人工呼吸 7日超

注意すべき最近の知見：

  • HFNO・NIV の長期使用も、その後ECMOに至った患者の死亡と独立に関連（COVID-19）。「挿管前の期間」も勘定に入れる
  • 肥満は相対禁忌ではない — 死亡リスクはむしろ低く、ICU在室も短い。デバイス関連合併症は多い
  • 重症喘息は離脱成功 86.7%・生存退院 83.5%（ELSOレジストリ2017）と成績が良い。ただしカニュレーション基準の合意はない

予測スコア：PRESERVE / PRESET / RESP（−22〜15点）。RESPはCOVID-19では成績がまちまちで、NIV・HFNO日数を加味すると改善しうる。

5. 人工呼吸器

  • lung rest が基本。一回換気量・駆動圧・プラトー圧・mechanical power を大きく下げる
  • 高めのPEEP・低い駆動圧が生存と関連。EIT（電気インピーダンス・トモグラフィ）で最適PEEPを設定した検討では、多くの患者で PEEP 10〜15 cmH₂O が過膨張と無気肺を最小化した
  • 例外：気管損傷・気管支胸膜瘻の重症エアリークは、低いPEEPと超低換気（VT ≤4 mL/kg IBW）で創傷治癒を優先する
  • 重症喘息：Pplat <30 を保てるならむしろVTは大きめにし、超低呼吸回数にして呼出時間を稼ぎ auto-PEEP を防ぐ

補助療法：ECMO導入後のルーチン使用は支持されない。腹臥位は観察研究では有益に見えたが、170例のRCTで死亡・離脱時間ともに有意差なし。吸入肺血管拡張薬・筋弛緩薬もECMO中の検討が不十分（持続筋弛緩は転帰改善と関連しなかった）。ただし自己肺血流が多く難治性低酸素になる患者では、換気血流比の改善を狙って個別に検討する余地がある。

6. 毎日の回路チェック

脱血カニュラ：固定・空気・亀裂・出血・フィブリン/血栓・チャタリング・色（暗赤） 人工肺：空気・血栓/フィブリン・結露 送血カニュラ：固定・空気・亀裂・出血・フィブリン/血栓・チャタリング・色（鮮紅） コンソール：回転数・ECMO血流量・回路内圧・人工肺の圧較差 ΔP（正常 ~25 mmHg）・脱血/送血カニュラの圧・FdO₂・sweep gas 流量 患者：バイタル・volume status・尿の色（溶血の指標）

POINT

結露は「sigh」で飛ばす 人工肺の結露は、sweep gas を 9〜10 L/min に約30秒上げることで除去できる。これが sweep を日常的に 0 にしない理由のひとつ（気相が洗われないと結露がたまる）でもある。

採血：Hb/Hct・血小板・フィブリノゲン・aPTT・PT/INR・LDH・遊離ヘモグロビン（pfHb） 溶血の検査所見：LDH >2000 U/L または pfHb >50 mg/dL。カルボキシHb上昇も溶血の指標で、死亡率上昇と関連する。

目標値：

  • SaO₂ 80〜85% で許容。人工呼吸中の SaO₂ 80% と違い、ECMO中はヘモグロビンが人工肺で直接飽和され、溶存酸素の緩衝も大きいので、急速に落ち込むリスクが小さい
  • pH ≥7.3 になるよう sweep gas で PaCO₂ を調整。症例により permissive hypercapnia も可
  • 導入前に高CO₂血症がある場合は、24時間かけて sweep を段階的に上げる。相対低下 >50%（(導入前PaCO₂ − 導入後PaCO₂)/導入前PaCO₂）で神経学的合併症のリスクが上がる
  • Hb は歴史的に 10 g/dL 目標だったが、7 g/dL で多くの患者に十分というエビデンスがある

画像・呼吸器：胸部X線（原疾患・気管チューブ位置・カニュラ位置・気胸/胸水）。呼吸器は RR・VT・Pplat・PEEP・駆動圧・静的コンプライアンス Cstat。Cstat 悪化は原疾患進行・院内感染・気胸・気道クリアランス不良を示唆し、ECMO中の気管支鏡は安全。Cstat 改善は離脱の合図。

心エコー：急性肺性心が多いので、週1回程度のPOCUSでRV/LVを見る。RV障害 → 強心薬・吸入肺血管拡張薬・V-VA/V-P への変更、LV障害 → 強心薬・V-A/V-VA への変更。

7. 薬剤の回路吸着

回路（チューブ＋人工肺）は表面積が大きく、脂溶性・高蛋白結合の薬剤が吸着される → 分布容積が増え血中濃度が下がる。ただし時間が経つと結合部位が飽和して濃度が上がり、中毒になりうる。中止後も回路がリザーバーとなって再分布することもある。

吸着が多い吸着が少ない
フェンタニル、ミダゾラム、デクスメデトミジン、プロポフォールケタミン、ヒドロモルフォン、モルヒネ、オキシコドン、クエチアピン
  • ヒドロモルフォン主体の鎮静は、フェンタニル主体と比べせん妄・昏睡のない生存日数が多く、麻薬必要量が少なかった
  • 抗菌薬は多くが通常の重症患者用量（体重・腎機能ベース）でよい。ボリコナゾールなど吸着の大きい薬は負荷量・維持量の増量が要る

8. 低酸素・組織低酸素の鑑別

定義的な現れ方：FdO₂ 1.0 でも SaO₂ <80〜85% かつ乳酸上昇。

主な原因：①再循環 ②人工肺の不全 ③ECMO流量不足／Q<sub>ECMO</sub>/Q<sub>CO</sub> 低下 ④心拍出量低下による DO₂ 低下 ⑤高代謝による VO₂ 増加

見に行くもの：患者（チアノーゼ・末梢循環不良・シバリング・けいれん）／回路（脱血と送血の色の差、チャタリング・suck down）／人工肺（フィブリン沈着・血栓）／胸部X線／人工肺前後の血ガス／心エコー

個別の対応：

  • 人工肺不全：ΔP 上昇 ＋ 人工肺後 PO₂ 低下 ＋ 人工肺後 PCO₂ 上昇 → 交換
  • Q<sub>ECMO</sub>/Q<sub>CO</sub> 低下（高心拍出のとき）：人工肺の定格流量を超えない範囲で ECMO流量を上げる。β遮断薬は避ける — SaO₂ は上がるが DO₂ が下がり、かえって組織低酸素を悪化させうる
  • 流量低下・suck down：血管内容量減少・腹腔内圧上昇・胸腔内圧上昇（気胸）を探す。容量負荷で改善する。酸素化に余裕があれば逆に流量を下げるのも手。難治なら脱血カニュラ追加か V-P へ
  • 低心拍出：POCUSでLV/RVを評価 → 強心薬。難治なら V-VA、RV不全なら V-P
  • 高代謝：鎮静強化、重症例では筋弛緩

再循環（原理と診断）：

  • 送血された酸素化血が右房に入らずそのまま脱血カニュラへ吸い込まれる現象。人工肺前の飽和度が上がる一方、右房へ行く血の脱酸素化割合が増えて SaO₂ が下がる
  • 流量を上げるほど悪化する（脱血側の陰圧が強まり、送血血をより多く引き込む）
  • 診断：カニュラ間隔 <8〜10 cm で送脱血の色に差がない／脱血側 SO₂ >75%／SaO₂ − 脱血側SO₂ <10%
  • 対処：カニュラを離す／二腔カニュラ1本に変更／V-P へ

9. 合併症の頻度

  • カニュレーション合併症 約6%（血管損傷・後腹膜/心損傷・空気塞栓・感染・静脈血栓）。経験ある術者が、エコーまたは透視下で、輸血製剤を準備して行う
  • 1000 ECMO時間あたり：カニュラトラブル 0.155／空気塞栓 0.025／血栓 0.103／刺入部出血 0.123／回路交換 0.258
  • 約30%の患者で回路・人工肺の交換が必要になる
  • そのほか：カニュラ以外からの出血（消化管）、中枢神経出血・虚血、溶血、下肢虚血、腎代替療法

10. 離脱

第一歩は原疾患の改善。回復のサイン＝肺コンプライアンス改善・X線の陰影改善・PaO₂/SaO₂上昇・PaCO₂低下かつ etCO₂ 上昇。

前提：できるだけ euvolemic にしておく（利尿薬・透析による除水）。

手順：

  1. ECMO流量は保ったまま、人工肺側の酸素と sweep を落としていく
  2. FdO₂ を 20% ずつ 1.0 → 0.21
  3. sweep gas を 0.5〜1.0 L/min ずつ、1 L/min まで
  4. 同時に人工呼吸器の設定を上げていく。ただし VT 6〜8 mL/kg IBW・Pplat <28〜30 cmH₂O・FiO₂ ≤60% は守る
  5. 血ガスが許容範囲（pH ≥7.3）なら sweep off トライアル（sweep を 0 に）。2〜24時間
  6. 判定：呼吸窮迫・血行動態不安定がないこと、PaO₂ ≥70、pH ≥7.3
図の解説

FdO₂ を落とさない施設もある FdO₂ は weaning せず sweep gas だけを落とす施設もあり、著者らはどちらでも同じ目標に到達すると明記している。

プロトコル化の効果：非医師主導のECMO離脱・sweep off トライアルのプロトコルは、ECMO日数を減らし、離脱と抜去を早めた。

11. 結論（著者ら）

ARDS には lung rest と個別化したPEEPを。他の病態はより個別の呼吸器設定が要る。右心不全の徴候を定期的に監視し、必要なら V-P / V-VA へ配置を変える。生理・画像・ガス交換の改善が見えたら離脱を検討する。

12. 批判的吟味（JCでの論点）

  • ナラティブレビューであり、推奨の強さや根拠のレベルが示されない。数字は具体的だが、その多くは単一の観察研究や専門家意見に由来する
  • DO₂:VO₂ ≥3:1 は「余裕をもたせて」という書き方で、この閾値を検証した臨床研究の引用はない。ELSO の ≥2 とどちらを採るかは施設判断
  • V-P ECMO の推しは強いが、著者ら自身が「配置戦略としての優劣は further research が必要」と留保している。ProtekDuo® のような特定デバイスの入手性も国内では別問題
  • Hb 7 g/dL で十分は2件の引用に基づく。SaO₂ 80%台を許容する管理と両立するかは本文で検討されていない（→ 22 循環｜VV-ECMO 実戦管理ガイド §5-6 で実際に計算して検討した）
  • 米国単施設（ワシントン大学）の視点。カニュラサイズ 25–29 Fr など、体格の前提が日本と異なる可能性がある

✅ Take home message

  • 数字が具体的なのが最大の価値 — DO₂:VO₂ ≥3、Q<sub>ECMO</sub>/Q<sub>CO</sub> 0.6、ΔP ~25 mmHg、LDH >2000・pfHb >50、PaCO₂ 相対低下 >50%、再循環の 75%/10% 基準
  • 人工肺の結露は sweep 9〜10 L/min × 30秒の「sigh」で飛ばす
  • 再循環は脱血側SO₂で判定できる（>75%、または SaO₂ との差 <10%）
  • モルヒネ・ケタミン・ヒドロモルフォンは回路吸着が少ない。フェンタニル・ミダゾラム・プロポフォール・デクスメデトミジンは多い
  • 腹臥位はECMO中のルーチンにしない（RCTで差なし）。肥満は相対禁忌ではない
  • 右心を定期的に見て、悪ければ V-P / V-VA へという配置変更の発想
