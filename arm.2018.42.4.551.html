🏥 聖路加ICUでの実践への示唆

聖路加ICUでの実践

病棟プロトコルへの落とし込み

  • NGT そのものが嚥下を悪くしている可能性を前提に置く。脳卒中患者20例で、NGT 留置中の舌骨移動距離は 0.81±0.36 cm、抜去30分後は 1.14±0.36 cm（p=0.009） と、抜くだけで有意に改善し、NGT なしの脳卒中患者（1.2±0.32 cm）と統計学的に区別できないレベル（p=0.909）まで戻った。「嚥下が悪いから NGT」だけでなく「NGT だから嚥下が悪い」という逆方向の因果を疑う。
  • 1 mL の唾液量ですら誤嚥している。本研究の NGT 群は VFSS（NGT 抜去後）で 平均 PAS 6.97±1.03＝誤嚥群（PAS 6–8）に相当した。経管栄養をしていても唾液誤嚥は起こる。当院で NGT 留置患者の口腔ケア・体位・吸引の頻度を「食べていないから安全」と緩めない。
  • 長期見込みなら早期に PEG を検討する。著者らは、NGT 群は罹病期間が長く（1.90±1.80年 vs 対照 0.78±0.64年、p=0.014）「本来なら PEG にすべき集団だった」と明言している。ICU から一般床・転院へ移る患者で、経口摂取再開の見込みが立たない場合、NGT を漫然と継続せず PEG 移行の判断を前倒しする。
  • ベッドサイド超音波で嚥下を追える。VFSS と違って被曝がなく、臥床患者でも施行でき、NGT 留置中でも測定できる（VFSS は NGT があると実施困難）。当院で嚥下評価待ちが発生する ICU 患者に、舌骨−下顎距離（R−S、(R−S)/R）の測定を試験導入する価値がある。プローブは 3–6 MHz コンベックス、正中矢状断でオトガイ下から、ゼリーを多めにして圧をかけないのがコツ（圧迫すると嚥下運動そのものを妨げる）。
  • ただしこれは20例・単施設・1 mL 水のみの小規模研究であり、「NGT を抜けば誤嚥が減る」ことも「臨床転帰（肺炎）が改善する」ことも証明していない。当院の実践を変える根拠としては、あくまで「疑いを持つ理由」レベルにとどめる。

🧭 この論文の位置づけ（Known / Unknown / What's new）

補足

リサーチ・イン・コンテキスト

  • Known（既に分かっていたこと）：脳卒中後の嚥下障害は 25〜32% に生じ、遷延すると栄養・水分摂取障害、在院日数延長、感染リスク上昇を招く。NGT は PEG より低侵襲で患者にも好まれるが、鼻咽頭を持続的に刺激して分泌を増やし、胃食道逆流による食道炎と誤嚥性肺炎のリスクを高める。長期栄養管理では PEG が NGT より安全・確実とされる。嚥下時の舌骨運動は食道括約筋を開くうえで重要で、その低下・遅延は誤嚥の主要な危険因子である。健常若年成人10例を対象とした VFSS 研究（Huggins ら）では、NGT が舌骨運動を妨げ嚥下速度を低下させることが報告されていた。
  • Unknown（分かっていなかったこと）：NGT 留置下の舌骨運動を超音波で定量した研究はなかった。とくに脳卒中患者において、NGT の有無で嚥下動態がどう変わるか、抜去で戻るのかは示されていなかった。
  • What's new（本研究の新規性・意義）：超音波＋動画解析ソフト（Kinovea／ImageJ）を用い、NGT 留置中と抜去30分後を同一患者内で比較した初めての研究。NGT は舌骨移動距離・移動度・軌跡面積を有意に低下させ、抜去により NGT なしの脳卒中患者と同等まで回復することを示した。長期経管栄養が必要な脳卒中患者では PEG を早期に検討すべきという既存の推奨に、生理学的根拠を追加した。

📌 全体要約

要旨

ひとことで 脳卒中患者20例で、NGT 留置中は嚥下時の舌骨移動が有意に小さく（0.81±0.36 cm）、抜去30分後には 1.14±0.36 cm へ有意に改善（p=0.009）し、NGT なしの脳卒中患者と区別できないレベルに戻った。NGT は嚥下運動そのものを機械的に妨げており、長期経管栄養が必要な患者では早期の PEG 移行を考慮すべき。

  • デザイン：単施設・前向きの3群比較（韓国 Sahmyook Medical Center、2017年5月〜7月、IRB No. SYMC-1706-03）。
  • 対象：A群＝NGT 留置中の脳卒中患者20例（A1＝NGT あり、A2＝抜去30分後の同一患者）、B群＝NGT なしの脳卒中患者25例、C群＝脳病変も嚥下障害もない健常成人25例。
  • 課題：唾液を模した 1 mL の水の嚥下。各被験者3回、1分間隔。
  • 測定：超音波（3–6 MHz コンベックス、正中矢状断）で安静時の下顎−舌骨間距離（R）と最短距離（S）を計測し、R−S（舌骨移動距離）、(R−S)/R（移動度）を算出。動画解析ソフト Kinovea と ImageJ で軌跡面積（Area、ピクセル） と Interval（舌骨運動開始から最短接近までの時間、秒） を自動計測。
  • 主要結果（Table 2）：R−S は A1 0.81±0.36 → A2 1.14±0.36 cm（p=0.009）、(R−S)/R は 0.22±0.08 → 0.3±0.08（p=0.005）。A2 は B群（1.2±0.32 cm、0.3±0.08）と有意差なし（p=0.909、p=0.997）。
  • Area は A1 441.43±198.46 → A2 553.43±193.59 ピクセル（p=0.118、非有意）、Interval は A1 1.51±0.37 → A2 1.35±0.31 秒（p=0.383、非有意）。ただし A1 は B群・C群と比較して有意に悪かった。
  • 誤嚥の実態：A群の VFSS（NGT 抜去後）による PAS は平均 6.97±1.03＝誤嚥群に相当。
  • 結論：NGT は脳卒中患者の 1 mL 水嚥下時の舌骨運動を妨げるが、抜去により回復する。長期の経管栄養を要する脳卒中患者では、NGT が嚥下機能に及ぼす悪影響を考慮すべきである。

📖 詳細

1. まず前提 — この病態・評価法の基礎（初めての人にも）🧩

要旨

5分で背景を掴む

  • 舌骨運動が嚥下の要：嚥下時、舌骨と喉頭が前上方に挙上することで喉頭蓋が傾き、輪状軟骨板が咽頭後壁から離れて上部食道括約筋（UES）が食塊到達前に開く。舌骨の移動が小さい・遅いと、UES が開かず、喉頭閉鎖も不十分になり、誤嚥のリスクが上がる。
  • NGT が邪魔をする機序（先行研究 Huggins ら）：NGT は UES を部分的に閉塞して食塊の通過を遅くし、その結果 UES の開大時間が延び、舌骨挙上を長く維持する必要が生じる。つまり 舌骨挙上が早く始まり、長く続く＝咽頭期が延長する。さらに NGT は上下食道括約筋の閉鎖能を弱め、下部食道括約筋の弛緩を増やし、咽頭−声門内転反射を鈍麻させるため、誤嚥性肺炎のリスクを高める。
  • VFSS（嚥下造影）：嚥下評価の標準法だが、被曝があり、透視室への移動が必要で、NGT 留置中は実施が難しい。
  • 超音波による嚥下評価：低コスト・無被曝・ベッドサイド可。下顎骨と舌骨は音響陰影として描出され、その距離の変化から舌骨運動を定量できる。脳卒中患者で VFSS との高い相関、良好な検者内・検者間信頼性が報告されている。
  • 本研究の4つの指標
  • R：安静時の下顎−舌骨間距離
  • S：嚥下時の最短距離
  • R−S：舌骨の移動距離（cm）
  • (R−S)/R：移動度（安静時距離で正規化した比。無次元）
  • Area：舌骨軌跡が描く面積（ピクセル）。正常の舌骨は前上方 → 最大変位で一時停止 → 後下方という二次元の紡錘形運動を描くが、脳卒中患者では二次元性が失われ直線的になる。
  • Interval：舌骨運動開始から最短接近までの時間（秒）
  • PAS（Penetration-Aspiration Scale）：本研究では PAS 1＝非誤嚥、2–5＝喉頭侵入（penetration）、6–8＝誤嚥（aspiration） と定義。声帯より下に入れば誤嚥、声帯を越えなければ侵入。

2. 背景と目的 🧠

脳卒中後の嚥下障害は 25〜32% に生じ、遷延すれば栄養・水分の欠乏を招く。口腔・咽頭・食道に未消化物が残れば在院期間の延長や敗血症リスクの上昇にもつながる。誤嚥性肺炎のリスクが高い場合は NGT や PEG の適応を検討することになるが、NGT は鼻咽頭を持続的に刺激して過剰な粘液分泌を起こし、胃食道逆流による食道炎と誤嚥性肺炎のリスクを高める。嚥下機能の回復が遅れると、NGT 留置期間はしばしば長期化する。

本研究の目的は、超音波を用いて NGT 留置の有無で脳卒中患者の嚥下機能を比較すること、および少量の唾液による誤嚥性肺炎リスクを検討し、長期 NGT 栄養患者を PEG に切り替える客観的基準づくりの基礎データを得ることである。

3. 方法（Methods）📐

  • デザイン：単施設・前向きの群間比較（および A群内の前後比較）。2017年5月〜7月。Sahmyook Medical Center 倫理委員会承認（IRB No. SYMC-1706-03）、全被験者から同意取得。
  • 対象（組み入れ）：①画像で確定した脳卒中、②2か月以上同一薬剤で病状が安定した "on state"。
  • 除外：①認知機能低下で同意困難、1段階命令に従えない、座位保持不能、②口腔咽頭に関わる手術・疾患の既往（甲状腺摘出、声帯麻痺など）、③頭頸部癌の既往、④肺炎治療中、⑤胃潰瘍。
  • 群構成：A群 20例（NGT あり）、B群 25例（脳卒中・NGT なし）、C群 25例（健常成人）。A群は同一患者を2回測定：A1＝NGT 留置中、A2＝NGT 抜去後（嚥下と抜去の間に30分の間隔）。
  • 超音波：Accuvix V10（Medison、ソウル）、3–6 MHz コンベックスプローブ。座位・頭部中間位。オトガイ下から正中矢状断で舌根の縦断像を描出。カップリング剤を多めに使い、プローブ圧を最小限にして嚥下運動への圧迫の影響を抑えた。1 mL の水を嚥下させ全過程を動画記録、各被験者3回・1分間隔。動画は 640×480 ピクセル、30 fps。単一検者（Kwak HJ）が全測定を実施。
  • コンピュータ解析：Kinovea v.0.8.15 でトレーサマーカーを舌骨に置き、時間をミリ秒単位で自動計測。軌跡が描く面積は ImageJ 1.51p でピクセル単位に計測。
  • VFSS：A群のみ、NGT 抜去後に座位で施行（Brivo OEC 850 C-arm、GE Healthcare）。1 mL の水嚥下について側面像で侵入・誤嚥を評価。
  • 統計：連続変数（年齢・罹病期間・BMI・身長・体重・MMSE・MBI・MASA・舌厚・安静時距離）は ANOVA ＋ Tukey HSD。カテゴリ変数（性別・病変部位）はカイ二乗検定。A1 と A2 の R−S、(R−S)/R、Area、Interval は対応のある t 検定。3群比較（A1/B/C および A2/B/C）は ANOVA。群間の相関は Spearman 順位相関。SPSS 17.0、P<0.05 を有意。

⚠ 注意

臨床上の要注意ポイント 「NGT を抜けば嚥下が正常に戻る」ではない。 抜去で回復するのは「NGT がなければ本来到達していた脳卒中患者の水準（B群）」までであって、健常者水準ではない。NGT 抜去は嚥下訓練や誤嚥予防の代替にならない。

⚠ 注意

原著内の記載の食い違い（本ノートで採用した値） 抄録は A2 の (R−S)/R を 「0.30±0.09 cm」、B群を 「0.30±0.09 cm」 と記載しているが、本文 Table 2 ではいずれも 0.3±0.08 である。また (R−S)/R は比（安静時距離で正規化した無次元量）であり、cm という単位表記は抄録側の誤り。本ノートでは本文 Table 2 の値と単位（無次元）を採用した。旧ノートは抄録側の「0.30±0.09 cm」を引用していたため訂正した。

6. 考察 🩺

  • 著者らは、A群は本来 PEG にすべき集団だったと明言している。罹病期間が長く（B群より有意に長い）、長期の経管栄養を要する患者が NGT のまま留置されていたのは、介護者側の選好によることが多いとし、唾液誤嚥を防ぐためにも PEG に移行すべきだったと述べる。舌骨運動が抜去で回復するという本研究の所見は、長期使用では NGT より PEG を早期に検討すべきとする先行研究を支持する。
  • 軌跡面積（Area）の意味：正常な舌骨は前上方 → 最大変位で一時停止 → 後下方という二次元の紡錘形運動を描く。脳卒中患者ではこの二次元性が失われ直線的になり、舌骨運動と喉頭蓋の回転が協調しないパターンを示す。したがって軌跡面積は、喉頭蓋の回転角度と関連して嚥下に影響すると推測される。
  • コンピュータ解析の利点：R−S/R をノギスで手計測する方法より、二次元画像として 0.01 ミリ秒単位で計測できるコンピュータ解析の方が容易で、実際の舌骨運動範囲より小さく測ってしまう誤差を避けられる。VFSS より時間・空間の制約が少ないため、NGT 栄養患者の嚥下機能を継続的にフォローするのに向いている。

限界（著者らの記載）

  1. NGT 群のサンプルサイズが小さい（20例）。
  2. NGT 留置中は VFSS が実施できないため、超音波との対比ができなかった。
  3. 症例数の制約から、嚥下障害の原因疾患や脳卒中の病変部位で層別せず一括して解析した。
  4. 1 mL の食塊量（唾液の模擬）のみのデータであり、10〜20 mL といった通常の食塊量での検討が今後必要。

本ノートとして追記する注意点

  • 交絡：A群は B群より罹病期間が長く、MBI・MMSE・MASA も有意に低い。A1 と B の比較には強い交絡がある。ただし本研究の中核である A1 vs A2 は同一患者内の前後比較であるため、この交絡の影響を受けにくい。
  • 一方 A1 vs A2 は盲検化されておらず、順序も固定（必ず A1 → A2）である。30分の間隔と練習効果・鎮静の変化などの時間依存の要因は排除できない。
  • 臨床転帰（肺炎発症、経口摂取再開率）は評価されていない。これは代用指標の研究である。
