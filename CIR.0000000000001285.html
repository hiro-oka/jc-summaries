🏥 聖路加ICUでの実践への示唆

聖路加ICUでの実践

病棟プロトコルへの落とし込み

  • 術後トロポニン監視の対象を決める：本ガイドラインは「既知の心血管疾患／心血管症状／65歳以上＋リスク因子」で中等度以上リスクの非心臓手術を受けた患者に、術後24時間と48時間のトロポニン測定を 2b（弱い推奨）で提示した。当院で予定外ICU入室・SDU入室になる術後患者はここに合致する層が多く、「測る／測らない」を主治科任せにせず入室時オーダーセットで定義する価値がある。同時に、低リスク手術での無症状スクリーニングは 3: No benefit なので足切り基準も同じセットに書く。
  • MINSを「拾って終わり」にしない：トロポニン陽性後の流れ（Figure 6）を院内フローに落とす。ST上昇の有無 → 心筋梗塞普遍的定義の充足 → 虚血性か非虚血性か、の3段で分類し、MINSと判定したら外来フォローへ確実に渡す（2a）。当院はICU退室後の追跡が途切れやすいので、Hotel ICU の「退室後訪問」の枠組みに MINS フォローを乗せるのが現実的。
  • SGLT2阻害薬の術前中止をチェックリスト化：ガイドラインは Class 1 で手術3〜4日前中止（エルツグリフロジンは4日以上）を求めている。正常血糖ケトアシドーシスは ICU で「原因不明のアニオンギャップ開大性アシドーシス」として現れ、血糖が正常なため見逃されやすい。ICU入室時の内服歴確認項目に SGLT2i を明示的に入れる。
  • 周術期の抗凝固ブリッジをやめる方向で統一：本ガイドラインはブリッジングを 3: Harm（ほとんどの症例で有害）とし、機械弁僧帽弁などごく限られた超高リスクにのみ 2a とした。DOACは「時間で切る（time reversal）」が原則で、ヘパリンブリッジは不要。当院で術後ICU管理する心房細動患者の抗凝固再開は「止血が得られたら」（2a）を基準にし、DOACは高出血リスク手技後 48〜72時間で再開する PAUSE のやり方を標準にできる。
  • 術中・術後の低血圧を「治療対象」として明文化：MAP 60〜65 mmHg 以上／SBP 90 mmHg 以上の維持が Class 1（術中）、術後低血圧の治療も Class 1。ICUでの術後管理でも同じ閾値を引き継ぐ。ただしそれより高い目標（MAP 80など）を狙う根拠はない（POISE-3・単施設RCTがいずれも陰性）ので、昇圧薬を盛る方向に倒さない。
  • 新規発症の術後心房細動（POAF）を「一過性だから様子見」にしない：非心臓手術後のPOAFは脳卒中HR 2.00（心臓外科後の1.20より高い）。ICUで見つけた新規AFは、誘因治療（敗血症・貧血・疼痛）に加えて退院後3〜6か月以内の外来フォローを紹介状に明記する（Class 1）。当院のRRS・ICU退室サマリーのテンプレートに1行追加すれば運用できる。
  • CIED患者の術前計画を麻酔科・循環器と共有：臍より上の電気メス使用が見込まれるなら、ペースメーカ依存かどうかで対応が分かれる（磁石か再プログラムか）。術後、退院前に必ず設定を戻す（Class 1）— 戻し忘れによる突然死が登録研究で報告されている。ICUは「デバイスを止めたまま病棟に返さない」最後の砦になる。
  • 重症肺高血圧の待機手術は院内で完結させない：専門センターへの相談（2a）、観血的血行動態モニタリング（2a）、術後ICU管理の事前確保が推奨されている。当院で受けるなら術前からICU枠を押さえる前提で調整する。

補足

リサーチ・イン・コンテキスト

  • Known（既に分かっていたこと）：米国では年間 1440万件の入院手術と1920万件の外来手術（世界で約3億1300万件）が行われ、45歳以上の手術入院患者の45%が複数の心血管危険因子を持ち、約25%に動脈硬化性心血管疾患がある。45歳以上の入院手術では33件に1件で周術期死亡・心筋梗塞・虚血性脳卒中が起き、米国だけで年間15万件を超える。RCRI（1999）を代表とするリスク指標、機能的能力（METs）、術前ECG・心エコー・負荷試験といった評価手段は2014年版で既に整理されていた。予防的冠動脈血行再建が無益であること（CARP試験）、手術当日のβ遮断薬開始が有害であること（POISE）も既知だった。
  • Unknown（分かっていなかったこと）：①どのリスクスコアが最良か（いまだに決着していない）。②術前バイオマーカー（BNP・トロポニン）が高値だったときに何をすれば予後が良くなるか。③MINS（非心臓手術後心筋障害）を見つけた後の最適治療。④術後新規心房細動に抗凝固を始めるべきか。⑤SGLT2阻害薬・GLP-1受容体作動薬という新しい薬剤クラスの周術期の扱い。⑥術中血圧の最適目標値。
  • What's new（本ガイドラインの新規性・意義）：2014年版を全面的に置き換える10年ぶりの改訂。(1) 全体を貫くステップワイズ・アルゴリズム（Figure 1）を新設し、「どこで立ち止まるか」を1枚にした。(2) MINS を独立した章（Section 9）として立て、定義・監視・対応を初めてガイドライン化。(3) SGLT2阻害薬は術前3〜4日中止を Class 1 で明記（周術期正常血糖ケトアシドーシス対策）、GLP-1受容体作動薬にも言及。(4) 抗凝固のブリッジングを 3: Harm に格下げし、PAUSE 由来の時間ベース中断表（Table 13）を採用。(5) 術中 MAP ≥60〜65 mmHg／SBP ≥90 mmHg 維持を Class 1 に格上げ。(6) 術後新規心房細動に対する退院後フォローを Class 1 に。(7) 「やらない」推奨（3: No benefit）を各所に置き、過剰スクリーニング・過剰治療の抑制を明示的な目標にした。

📌 全体要約

要旨

ひとことで 非心臓手術の周術期心血管管理は、リスク層別 → 機能的能力 → 「その検査が方針を変えるか」 の順に絞り込み、変わらないなら検査しない。新しい焦点は MINS の監視と対応、SGLT2阻害薬の術前中止、抗凝固ブリッジングの原則廃止の3点である。

  • 9学会合同・92ページ・約70の推奨からなる大型ガイドライン。2014年版 ACC/AHA 周術期ガイドラインをsupersede（置き換え）する。
  • 対象は 18歳以上の成人が非心臓手術（NCS）を受ける場合の、術前評価から術後管理まで。心臓手術は対象外。
  • 全体の思想は「非手術患者と同じ適応で心血管スクリーニング・治療を行う」。手術という事実そのものを検査の理由にしない。
  • リスク定義：MACE（主要心血管イベント）リスク <1% を低リスク、≥1% を elevated risk（中等度＋高度） とする。閾値は伝統的に RCRI >1 または任意の計算ツールで >1%。
  • タイミング定義：Emergency（通常2時間未満）／Urgent（2〜24時間）／Time-sensitive（最大3か月遅らせられる）／Elective（完全な評価が可能）の4分類。
  • リスク計算ツールは既知の心血管疾患がある患者に COR 2a / LOE B-NR。RCRI・NSQIP MICA・NSQIP汎用計算機・AUB-HAS2 など複数あるが、どれが優れるかのデータはない。
  • 機能的能力は DASI（12項目・0〜58.2点）による構造化評価が 2a。閾値は DASI ≤34 または <4 METs。麻酔科医の主観評価はアウトカムと関連しなかった（METS study）。
  • フレイルは65歳以上全例（および64歳以下でフレイルが疑われる例）で中等度以上リスク手術の前に評価が 2a。フレイルは30日死亡の相対危険 3.71（95%CI 2.89–4.77）と関連。
  • 術前バイオマーカー：BNP/NT-proBNP は 2a、トロポニンは 2b。ただし高値だったときに何をすれば予後が改善するかを示した研究はない。
  • 術前検査の「やらない」推奨：無症状・低リスク手術の ECG（3: No benefit）、安定患者のルーチン左室機能評価（3: No benefit）、機能的能力良好・低リスクでのルーチン負荷試験（3: No benefit, B-R）、同条件での CCTA（3: No benefit）、ルーチンの侵襲的冠動脈造影（3: No benefit）。
  • 冠動脈血行再建：ACS なら血行再建＋手術延期が Class 1。慢性冠動脈疾患で左主幹部 ≥50% 狭窄なら 2a。それ以外の非左主幹部病変へのルーチン術前血行再建は 3: No benefit（B-R）。
  • PCI後の待機期間（Figure 5）：バルーン単独 >14日（1）、BMS >30日（1）、ACSに対するDES-PCI は ≥12か月（1）、慢性冠動脈疾患に対するDES-PCI は ≥6か月（2a）、時間制約があれば ≥3か月（2b）、DES/BMS後 ≤30日で抗血小板薬を中断する待機手術は 3: Harm。
  • 薬剤の周術期継続・中止：スタチンは継続（1）・適応があれば開始（1）。β遮断薬は継続（1）・当日開始は 3: Harm（B-R）・開始するなら7日以上前（2b）。RAASi は高血圧目的なら中等度以上リスク手術の24時間前中止が 2b、HFrEF目的なら継続が 2a。クロニジン新規開始は 3: No benefit（B-R）。SGLT2阻害薬は3〜4日前中止が Class 1。メトホルミンは継続（2a）。
  • 抗凝固：多職種チームによる時間ベース中断が Class 1。ルーチンのブリッジングは 3: Harm（C-LD）。ワルファリン内服の超高リスク血栓症例に限りヘパリンブリッジが 2a。止血後の再開が 2a。
  • 術中・術後血圧：術中 MAP ≥60〜65 mmHg または SBP ≥90 mmHg 維持が Class 1（B-NR）。術後低血圧の治療も Class 1。降圧薬の再開は臨床的に可能になり次第（1, C-EO）。
  • MINS：非心臓手術後の心筋障害は約 20% に発生。30日死亡は約 10%、トロポニン最高値の四分位で 1%（最低）→ 17%（最高）。80〜90%が無症状。監視は 2b、外来フォローは 2a、抗血栓療法は 2b。
  • 術後新規心房細動（POAF）：非心臓手術後のPOAFは30日以内の脳卒中を 62%、死亡を 44% 増やす。長期でも脳卒中・死亡がそれぞれ 37% 増。非心臓手術後（HR 2.00）は心臓手術後（HR 1.20）より脳卒中との関連が強い。5年でのAF再発は 39%。
  • 9つの Top Take-Home Messages が冒頭に置かれ、ステップワイズ評価・過剰検査回避・チーム医療・新規糖尿病薬/心不全薬/肥満薬の周術期影響・MINS・POAF・ブリッジング限定・FoCUS の使いどころ、を要約している。

1. まず前提 — 非心臓手術の周術期心血管リスクの基礎（初めての人にも）🧩

要旨

5分で背景を掴む 非心臓手術（NCS: noncardiac surgery） とは、心臓そのものを操作しない手術すべて（腹部・整形・血管・脳神経・泌尿器など）を指す。心臓手術は本ガイドラインの対象外である。

なぜ心臓が問題になるのか。手術侵襲はカテコラミンサージ、炎症性サイトカイン、凝固カスケードの活性化、血小板活性化亢進、線溶低下を起こし、血栓が形成されやすい状態（thrombotic milieu） を作る。同時に、麻酔・出血・疼痛・貧血は心筋の酸素需給バランスを崩す。この2つが、周術期の心筋梗塞（type 1＝プラーク破綻／type 2＝需給ミスマッチ）と心筋障害を生む。

MACE / MACCE：MACE は major adverse cardiovascular event（主要心血管イベント）。MACCE は cerebral（脳血管）を含めた major adverse cardiac and cerebral event。本ガイドラインは MACE リスク 1% を低リスクと中等度以上リスクの境界にしている。

RCRI（Revised Cardiac Risk Index, 1999）：虚血性心疾患・脳血管疾患・心不全既往・インスリン使用糖尿病・血清クレアチニン ≥2.0 mg/dL・高リスク手術（腹腔内／胸腔内／血管）の6項目に各1点。0点＝Class I、1点＝II、2点＝III、3点以上＝IV。導出コホートROC 0.76、検証0.81。「RCRI >1」が中等度以上リスクの伝統的閾値。

METs（metabolic equivalents, 代謝当量）：安静時酸素消費量（約3.5 mL/kg/min）を1 MET とする運動耐容能の単位。4 METs が「機能的能力が悪い」の閾値で、「階段2階分を上れる」がおおよそ 4 METs を超える活動にあたる。

DASI（Duke Activity Status Index）：12個の日常活動をできるかどうかで点数化する自己記入式指標。合計 0〜58.2点。本ガイドラインは DASI ≤34 を「機能的能力が悪い」 とする。

MINS（myocardial injury after noncardiac surgery, 非心臓手術後心筋障害）：虚血性と考えられる原因でトロポニンが基準上限99パーセンタイルを超えること。心筋梗塞の普遍的定義を満たすか否かは問わず、無症状の心筋障害も含む。肺塞栓・脳卒中・敗血症など非虚血性の原因は除外する。手術患者は麻酔・鎮痛・創部痛のせいで症状を訴えられないため、この概念が必要になった。

CIED（cardiovascular implantable electronic device）：ペースメーカ・植込み型除細動器（ICD）・植込み型モニタの総称。手術中の電気メス（ESU: electrosurgery unit）が発する電磁干渉（EMI） がペーシング抑制や不適切ショックを起こしうる。

FoCUS（focused cardiac ultrasound）：限定された標準断面だけを見る簡易心エコー。原因不明の血行動態不安定の場面で「ざっくり病態を掴む」ために使う。包括的経胸壁心エコー（TTE）の代わりにはならない、というのが Top Take-Home Message の9番目である。

SGLT2阻害薬（sodium-glucose cotransporter-2 inhibitor）：尿糖排泄を促す糖尿病薬で、いまや心不全・慢性腎臓病の標準治療でもある。周術期絶食と組み合わさると飢餓性ケトーシス様の機序で正常血糖ケトアシドーシス（euglycemic ketoacidosis） を起こす。血糖が正常〜軽度上昇にとどまるため見逃されやすい。

GLP-1受容体作動薬（glucagon-like polypeptide-1 receptor agonist）：糖尿病・肥満に広く使われる。胃排出遅延・胃不全麻痺を起こし、麻酔導入時の誤嚥リスクを高めうる。

COR（推奨クラス）と LOE（エビデンスレベル）の読み方

本ガイドラインの全推奨には COR（Class of Recommendation） と LOE（Level of Evidence） が付く。COR は「効果の大きさと確実性がリスクに対してどれだけ勝るか＝推奨の強さ」、LOE は「その判断を支えるデータの型・量・一貫性＝エビデンスの質」を表す。この2つは独立している（強い推奨だが専門家意見に基づく、ということが起こりうる）。

2. ガイドラインの目的・範囲・方法 📐

  • 対象（PICOのP）：18歳以上の成人で、非心臓手術を受けることが検討されている患者。術前評価から術後管理までの全期間。
  • 目的：周術期リスクの評価と低減。ただし「即時の手術リスクの評価と低減」が第一目的であっても、修正可能な心血管リスクが見つかったら術後・退院後も追跡することを求めている。

多職種ケアモデル（"pathway"）は周術期の標準化と回復の加速（早期離床・早期経口摂取・オピオイド節減鎮痛・DVT予防）に用いられる。ただし著者らは慎重で、多職種モデルが周術期の心臓ケアの質やアウトカムを改善したことを示すデータはほとんどないと明記している。ERAS（enhanced recovery after surgery）が心血管合併症・GDMT・術前心臓検査の使用量を減らすというメタ解析所見も乏しい。COVID-19 期に加速した電話・ビデオでの術前評価は、手術キャンセル率低下と患者満足度改善の根拠は十分あるが、心血管アウトカムへの影響は報告されていない。

■ QOL（Section 2.2）

WHO は QOL を「その人が生きる文化・価値体系の文脈における、自らの人生の位置づけについての個人の認識」と定義する。患者報告アウトカム尺度（PROM）が使えるが、質問票よりも患者の優先事項を聴くことが重要とされる。手術の長期的QOL便益が短期的心臓リスクを上回る患者もいるが、この比は文献上一定していない。共同意思決定を含む周術期評価は患者満足度の高さと関連していた。「QOL改善を目指した実行可能な推奨を作れるだけの確固たるエビデンスはまだない」と率直に述べている。

2aB-NR既知の心血管疾患がある、または65歳以上、または45歳以上で心血管疾患を示唆する症状がある患者が中等度以上リスクの非心臓手術を受ける場合、周術期リスク評価を補強するため術前に BNP または NT-proBNP を測定することは妥当である。
2bB-NR同じ対象で、周術期リスク評価を補強するため術前に 心筋トロポニン（cTn） を測定することを考慮してもよい。

位置づけ：cTn と BNP は安価で広く利用でき、それぞれ心筋障害と心筋壁ストレスを検出・定量する。複数の大規模前向き研究で、両者とも周術期心合併症に対して高い予後予測能と優れた陰性的中率を示している。

⚠ 注意

臨床上の要注意ポイント 術前バイオマーカーが高値だった患者に対して、周術期心血管アウトカムを改善する管理法を示した研究は、現時点で1つもない（原文："there have been no studies in patients with elevated preoperative biomarkers to recommend management that improves perioperative cardiovascular outcomes"）。低リスク患者での有用性も未評価。さらに バイオマーカー測定は、その値をきっかけに行われる下流の検査（cascade of testing）を通じてリスクを増やす可能性がある と明記されている。コスト・バリューの章では、術前 BNP/NT-proBNP も術前 cTn も "uncertain value"（費用と健康便益の関係が判定できない） と評価されている。「測れる」と「測るべき」は別である。

エビデンス（BNP/NT-proBNP）：

  • 術前・術後いずれの ナトリウム利尿ペプチド値も、30日および180日の死亡または非致死性MI の複合の独立した予測因子。
  • VISION の入れ子サブスタディでは、術前 NT-proBNP >100 pg/mL が全死因死亡と独立に関連。
  • BNP/NT-proBNP の最適閾値は明確に確立されていない。
  • 3597例のコホート研究では、NT-proBNP を従来のリスクスコアに加えても、リスクスコア＋自己申告の機能状態を超える予測改善は得られなかった。

エビデンス（トロポニン）：

  • 虚血の症状・徴候がない患者の術前高感度 cTn は、慢性心筋障害を持つ患者と、周術期・術後にリスクの高い患者を同定できる。
  • しかしこの情報単独に基づいて起こすべき行動はない（原文："There is no action predicated on this knowledge alone"）。
  • ただし術前ベースライン値は術後トロポニンの解釈に役立ち、術後の急性心筋障害の診断確定に寄与する。
  • 術前 cTn を加えると、RCRI の周術期MACE 予測能は改善する。
  • 異質な集団からの限定的エビデンスにとどまる。

POINT

推奨（Stress Testing）

CORLOE推奨
2bB-NR中等度以上リスクの非心臓手術を受ける患者で、機能的能力が不良または不明、かつ検証済みリスクツールで周術期心血管イベントリスクが高い場合、誘発性心筋虚血の評価のため負荷試験を考慮してもよい。

※機能的能力不良＝<4 METs または DASI ≤34。

論理の核心（原文の慎重さのまま）：

  • 術前負荷試験で可逆性虚血があると周術期心イベントリスクは上がる。しかし陽性的中率は modest で、RCRI やナトリウム利尿ペプチドを超える予後情報を加えるかは明確でない。
  • 検査は高価で、不要な下流検査や手術の遅延を招きうる。
  • 術前血行再建が周術期MACEや心臓死を減らすことは示されていない。過剰検査・過剰治療の可能性が高い。
  • したがって術前虚血検査の目的は「未診断の冠動脈疾患を見つけること」ではなく、「血行再建によって臨床アウトカムが改善すると考えられる患者（＝左主幹部病変、または左室駆出率低下を伴う重症多枝病変）を同定すること」である。
  • ただしそれらの患者は術前血行再建の研究から除外されており、この文脈での血行再建の有用性は不明、と著者自ら留保している。
  • 異常な負荷試験結果は、高リスク所見がない限り冠動脈造影や血行再建の引き金にしてはならない。

エビデンス：

  • 機能的能力 <4 METs（階段1〜2階を上れない、平地を時速3マイル以上で歩けない）は、原因が心臓であれ非心臓（関節炎・慢性肺疾患・肥満）であれ周術期心イベントリスクを高める。
  • 運動可能なら薬物負荷より運動負荷が望ましい。
  • CARP試験：≥70%狭窄病変を1つ以上持つ冠動脈疾患 510例を、大血管手術前の冠動脈血行再建 vs 内科治療にランダム化。血行再建群は血管手術までに36日遅延。30日の周術期MI にも、中央値2.7年の全死因死亡にも差はなかった。
  • 安定した運動能力 ≥4 METs の患者は周術期心イベントリスクが相対的に低い。

9-6. 心肺運動負荷試験（CPET, Section 4.4）

推奨なし（シノプシスのみ）。要点：

  • CPET は運動に対する生理学的応答評価の gold standard。運動不耐の原因（心臓 vs 肺）の鑑別、術前最適化の指針、プレハビリテーションの情報提供ができる。
  • 心血管合併症のみより頻度の高い「全原因の合併症」を予測する。腹部・血管・減量・胸部の大手術でリスク予測を支持する研究がある。
  • 限界：周術期CPETの研究の大半は後ろ向き・単施設で予測精度がばらつく。高リスクの閾値もコホート・術式で異なり、時代とともに閾値が下がってきた（嫌気性代謝閾値が 11 → 9〜10 mL/min/kg へ）。これは外科・周術期診療の進歩を反映している。
  • 代替として 6分間歩行試験があり、特別な機器が不要で実施しやすい。CPET との相関は一定しないが、これは両検査とも訓練された人員が標準化された方法で行う必要があることを示唆する。

POINT

  • しかし CCTA は臨床リスクスコアと比べ、MACE を起こさない患者のリスクを不適切に過大評価する確率が5倍以上高い。これが手術の遅延・中止、不要な医療資源使用、ひいては患者の合併症・死亡と医療費増につながる。

  • したがって ICA は最高リスク患者に限定すべき。慢性冠症候群患者に対する「待機的非心臓手術前のルーチンICA＋血行再建」戦略は推奨できない。
  • 術前冠動脈造影の適応は非手術時と同じであるべき：急性冠症候群、最大限の抗狭心症療法にもかかわらず増悪する狭心症、負荷試験で新規に診断された中等度〜重度虚血、非侵襲的検査での閉塞性左主幹部病変の指標。

11. 心血管併存症と周術期管理（Section 6）❤️

11-1. 冠動脈疾患（Section 6.1）

  • 大手術を受ける患者の約 18% に冠動脈疾患があり、周術期MACE リスク増加と関連する。
  • 病変の部位・範囲・重症度が周術期リスクを規定する。急性冠症候群の既往は慢性冠動脈疾患より周術期リスクが高い。
  • RCRI の導出・検証コホート（>3500例）では、心筋梗塞の既往は周術期MACEを 3.5倍に増やした。
  • 冠動脈ステント留置例もリスクが高い：約28,000例の後ろ向きコホートで、2年以内にステントを留置された患者は非ステント対照より周術期MACE のオッズが2倍。
  • MACE リスクは血行再建から手術までの期間に反比例する。

根拠の要点：

  • STEMI では一次PCI＋ステント留置による即時再灌流でアウトカムが改善。不安定狭心症/NSTEMI では、①心原性ショック、②難治性狭心症・難治性不整脈・血行動態不安定を伴う ACS、③GRACE スコア >140、のいずれかで血行再建が適応となる。
  • 左主幹部病変：ISCHEMIA・COURAGE・BARI-2D はいずれも慢性冠動脈疾患におけるルーチン血行再建の便益を否定したが、これらの試験は左主幹部病変を除外している。古いRCTでは CABG が左主幹部病変の死亡を減らした。血管手術予定の多枝病変（左主幹部含む）の非ランダム化患者では、保護されていない左主幹部病変だけが術前血行再建で生存利益を示した唯一の血管造影サブセットだった。ベイズ法でも PCI は CABG と同様に、保護されていない左主幹部病変で内科治療より生存を改善する。
  • CARP試験：待機的大血管手術前のルーチン予防的血行再建（PCI または CABG）は 30日・1年の死亡/MI に差をもたらさなかった。左主幹部病変・LVEF <20%・重症AS の患者は除外されている。
  • CARP を含む7研究・3949例のメタ解析でもルーチン血行再建の便益なし。
  • 血管手術患者で冠動脈血行再建は死亡の原因を心血管から非心血管へ移すだけで、絶対死亡は減らないと報告されている。
  • 出血合併症は PCI で高く、とくに薬剤溶出ステント留置後6か月間で高い。
  • 一般論として、2021年血行再建ガイドラインは「DAPT の推奨を守れるだけ手術を安全に延期できる限り」非心臓手術患者にも適用できる。臓器移植手術・血管手術・多枝病変では多職種チームの関与が推奨される。

機序と疫学：

  • 周術期高血圧は大手術患者の推定 25% に影響し、待機手術延期の主因の1つ。
  • コントロール不良の高血圧は左室拡張末期圧上昇 → 心筋需要増加 → 心内膜下虚血を生む。周術期には心血管疾患・脳血管イベント・出血のリスクを高める。
  • 大規模コホートでは術中・術後の低血圧が心血管・腎アウトカム悪化と死亡のリスクを高める。術中高血圧や血圧変動の寄与を示すデータは比較的少ない。
  • 周術期の急性血圧低下が心血管イベントや死亡を減らすことを示した質の高いRCTはなく、むしろ有害でありうる。
  • 血圧の評価法（収縮期／拡張期／平均／脈圧）、閾値（絶対値／相対値）、測定頻度のいずれについても最適解は確立していない。

具体的データ：

  • 英国 CPRD の待機的非心臓手術 251,000例：術前 DBP >90 mmHg は30日術後死亡の増加と関連。
  • 30の観察研究のメタ解析：術前高血圧の診断は心血管合併症を 35% 増加。
  • 単施設 58,276例：導入前 SBP >160 mmHg と複合アウトカム（心・神経・腎合併症または院内死亡）の関連は、RCRI 構成要素を1つ以上もつ患者（n=10,512）でのみ有意だった。
  • 手術当日の血圧上昇は白衣高血圧の可能性があるため、外来のベースライン血圧を参照して管理する。RCRI 構成要素がなければ、術前血圧 <180/110 mmHg でも、また導入前のいかなる血圧でも、周術期合併症増加のエビデンスは乏しい。
  • 観察研究における害の閾値は概ね MAP <65 mmHg または SBP <90 mmHg が約15分間持続したところ。
  • 3つの主要試験の解釈は難しい：
  • INPRESS（高リスク298例）：SBP をベースラインの ±10% 以内に維持する戦略が、SBP >80 mmHg 維持に比べ約 25% の相対リスク低下。ただし低血圧の程度、とくに有害な可能性がある MAP 55〜70 mmHg 域の詳細が報告されておらず解釈が難しい。
  • 単施設試験（高リスク458例）：MAP ≥60 vs ≥75 mmHg。高い目標の便益なし。
  • POISE-3（7490例）：低血圧回避戦略（目標 MAP ≥80）vs 高血圧回避戦略（目標 MAP ≥60）。高い目標の便益なし。
  • 結論：「専門家意見としては術中 MAP ≥60〜65 または SBP >90 mmHg を維持するが、より高い血圧目標を支持する試験エビデンスは現時点で不十分」。
  • POISE-2 サブスタディ：術後4日目までの SBP <90 mmHg の持続時間が長いほど MI・死亡の複合が増加（10分増加あたりOR 2.83）。ただし低血圧の管理（輸液・血管作動薬・機械的補助）は臨床チームの裁量で、統制も報告もされていない。ICU など集中的モニタリング環境では低血圧の早期認識が可能になりうる。
  • 血管作動薬による低血圧治療の系統的レビュー・メタ解析：大腹部手術では術後合併症と在院日数を減らしうる。
  • 術後高血圧の原因：疼痛、炎症、不安、低酸素、体液過剰、尿閉、慢性降圧薬の中断。心筋虚血/梗塞、急性非代償性心不全、脳虚血、不整脈のリスクを高める。

GDMT の中断は有害：HFrEF の GDMT は4クラス（①レニン・アンジオテンシン系阻害＝ARNI・ACEi・ARB、②β遮断薬、③ミネラルコルチコイド受容体拮抗薬、④SGLT2阻害薬）。HFrEF 入院患者で、明確な禁忌なしに GDMT を中止すると死亡と再入院が増加する。HFmrEF・HFpEF・HFimpEF、および無症候性収縮/拡張機能障害を含む stage B pre-HF にもガイドラインどおりの管理を行う。

進行心不全：NYHA III〜IV で臨床的に非代償性または血行動態不安定な患者では、待機手術の延期と循環器コンサルトを考慮すべきである。

図の解説

Figure 2 の実務上の含意 この図の分岐点は「症候性か」「LVEF ≥50% か」「手術は低リスクか」「延期できるか」の4つに集約される。無症候性・LVEF ≥50%・低リスク手術なら、弁介入を挟まずそのまま手術へ進む（2a） のが本ガイドラインの立場である。逆に症候性、または LVEF <50%、または「中等度以上リスク手術で延期可能」なら、すべて「AVRの適応か」の判断に合流する。BAV は「AVR の適応でない」場合の選択肢の1つとして、緩和ケアや共同意思決定と同じ枠内に置かれており、独立した推奨としては格上げされていない点に注意する。

病態生理：頻脈は拡張期時間を短縮し僧帽弁通過圧較差を増大させ、左房圧上昇 → 肺動脈圧上昇 → 肺水腫 → 全身性低血圧を招く。 周術期の目標：低〜正常の心拍数、高〜正常の全身血管抵抗、十分な前負荷の確保、可能なら洞調律を維持するリズムコントロール。 僧帽弁介入の基準（弁膜症ガイドライン準拠）：症候性（NYHA ≥II）のリウマチ性重症MS、または無症候性でも肺動脈収縮期圧 >50 mmHg。 データの限界：MS 患者の非心臓手術管理を導くデータは乏しく、多くが妊娠時の文献から外挿されている。周術期の心拍数コントロールの便益を検討したRCTは存在しない（既存RCTは安定した症候性外来患者での症状・運動時間の改善を示したのみ）。 モニタリング：Swan-Ganz カテーテル、動脈ライン、TEE。ただしモニタリングの強度は手術と麻酔手技のリスクに見合わせる。ICU での回復、または PACU での長時間観察が適切なことがある。

11-12. 慢性の大動脈弁逆流・僧帽弁逆流（Section 6.4.3）

POINT

推奨（Chronic Aortic and Mitral Regurgitation）

CORLOE推奨
1C-EO中等度または重症の弁逆流が疑われる患者では、周術期管理の指針として待機的非心臓手術の前に心エコーを行うことが推奨される。
1C-EO臨床像と逆流の重症度から弁介入の適応を満たす弁膜症患者では、周術期リスク低減のため、待機的な中等度以上リスク非心臓手術の前に弁介入の必要性を検討すべきである。
2aC-LD無症状で中等度または重症の僧帽弁逆流（MR）があり、左室収縮機能が正常、推定肺動脈収縮期圧 <50 mmHg の患者では、待機的非心臓手術を行うことは妥当である。
2aC-LD無症状で中等度または重症の大動脈弁逆流（AR）があり、左室収縮機能が正常（LVEF >55%）の患者では、待機的非心臓手術を行うことは妥当である。

いずれも 2020年 ACC/AHA 弁膜症ガイドラインから Modified。

要点：

  • 逆流性弁膜症は狭窄性弁膜症より一般に忍容性が高いが、心血管リスクは増加する。
  • 1年以内の心エコーは、機能状態と症状が前回から変わっていなければ術前評価に使ってよい。
  • 弁介入の適応を満たすなら、可能な限り待機的な中等度以上リスク手術の前に弁形成/置換を行う。外科手術の適応がない MR では 経カテーテル僧帽弁 edge-to-edge repair（TEER） も選択肢。
  • MR の周術期管理：後負荷増加と徐脈を避ける。全身麻酔、あるいは神経軸性局所麻酔＋オピオイドの併用は血管拡張を起こし全身血管抵抗を下げるため MR には概ね有利。ただし前負荷は維持する。観血的血行動態モニタリングや術中TEE で左室充満圧を持続的に最適化できる。術後 24〜72時間の集中的モニタリングを考慮。
  • AR の周術期管理：重症AR は心室容積と壁ストレスの増大により、低血圧・不整脈・心不全・死亡のリスクがある。中等症以上のAR 患者は対照と比べ周術期の血行動態不安定、肺水腫と挿管遷延による罹病、院内死亡が多かった。左室収縮機能障害、血清クレアチニン >2 mg/dL、中等度以上リスク手術が過剰死亡と関連。AR では徐脈を避ける（拡張期充満時間を短くして逆流量を減らすため）。体液量への細心の注意が必要。
  • MR の危険因子：EF 低値と既存の心房細動。

11-13. TAVI 後・僧帽弁 TEER 後（Section 6.4.4）

  • TAVI 後の非心臓手術の安全性に関するエビデンスは小規模症例集積と、スイス・ベルン大学病院の前向き TAVI レジストリ1件に限られる。

いずれも 2023年 ACC/AHA/ACCP/HRS 心房細動ガイドラインから Adapted。

疫学：

  • 心房細動は最も頻度の高い不整脈で、2009年時点の米国での未診断心房細動の推定有病率は人口の約 13%。
  • 既存の心房細動をもつ患者は、非心臓手術後30日以内の全死因死亡・心不全・虚血性脳卒中のリスクが高い。
  • 血行動態が安定していれば、心房細動患者の非心臓手術で必要な変更は経口抗凝固薬の中断だけであることが多い。術前に心房細動があってレートコントロールが不良なら、手術前に内科的管理を最適化する。

術後新規発症心房細動（POAF）の重大性：

  • 250万人弱（2,458,010例）のメタ解析：POAF は術後30日以内の早期脳卒中を 62%、早期死亡を 44% 増加させる。長期脳卒中も 37%、長期死亡も 37% 増加。
  • サブグループ解析：POAF と脳卒中の関連は非心臓手術（HR 2.00、95%CI 1.70–2.35）のほうが心臓手術（HR 1.20、95%CI 1.07–1.34）より強い。
  • POAF 患者の脳卒中機序が非手術時の心房細動と同じかは不明。
  • デンマークのレジストリ：退院後30日以内に経口抗凝固を開始すると、無投与に比べ血栓塞栓イベントが 48% 減少。
  • ASPIRE-AF 試験（非心臓手術後の新規心房細動に対する DOAC vs 無抗凝固）が進行中。
  • 新規診断心房細動 10,723例（平均68±10歳、女性41%）の縦断データベース：15% が非心臓手術後に POAF を発症。POAF は 5年での心房細動再発リスク 39% と関連し、心不全と死亡のリスクも高かった。
  • フォローアップ：非心臓手術後 3〜6か月以内の外来フォローが推奨される。より集中的なモニタリング（1〜2週間の携帯型心電図、30日イベントモニタ、選択例では植込み型心臓モニタ）が正当化されることもある。

レート/リズムコントロールの実際：

  • 血行動態が安定した POAF では 心拍数 <110 bpm を目標とする。房室結節伝導を抑えるβ遮断薬またはカルシウム拮抗薬を用い、ジゴキシンは補助または他剤禁忌時に考慮。
  • 房室結節ブロック薬に抵抗性なら、同期電気的除細動または抗不整脈薬による薬理学的除細動を考慮。
  • リズムコントロールを行う前に、48時間を超える持続の心房細動や血栓塞栓高リスク患者では左心耳血栓の除外が必要になりうる。
  • 低血圧を伴う血行動態不安定な頻脈性心房細動には同期電気的除細動が推奨される。
  • 非心臓手術における新規発症心房細動に対するレート vs リズムコントロール戦略を比較したRCTは存在しない（Section 12 のエビデンスギャップに明記）。

11-15. 植込み型心臓電気デバイス（CIED, Section 6.6）

POINT

推奨（Preoperative Management of Patients With CIED）

CORLOE推奨
1B-NRCIED 装着患者が待機的非心臓手術を受け電磁干渉（EMI）が予測される場合、手術前に管理計画を立てるべきである。計画には CIED の種類（ペースメーカ、ICD、植込み型モニタ）・製造業者・機種の同定を含む。
1B-NRペースメーカ依存の患者が臍より上の手術を受け EMI が予測される場合、ペーシング抑制を避けるため、ペースメーカを再プログラムするか、ジェネレータ上に磁石を置いて非同期モードにすべきである。
1B-NR経静脈 ICD をもつペースメーカ依存の患者が臍より上の手術を受け EMI が予測される場合、デバイスを再プログラムすべきである※。ペースメーカ依存でなければ、再プログラムまたは磁石のいずれでも頻拍治療や不適切ショックを抑制できる。
1B-NR術前に非同期ペーシングへ再プログラムした、または頻拍治療をオフにした患者では、退院前の術後にデバイス機能を復旧すべきである。
1C-LDリードレスペースメーカを装着したペースメーカ依存患者が、臍より上で EMI が予測される手術を受ける場合、非同期モードへの再プログラムを行うべきである。
2aC-LD皮下植込み型 ICD（S-ICD） をもつ患者が、鼠径部より上で EMI が予測される非心臓・非胸部手術を受ける場合、デバイスの再プログラムまたは磁石により一時的に頻拍治療を無効化することは妥当である。

※ペースメーカ依存の ICD 患者では、頻拍治療を無効化し、かつペーシング抑制を避けるため非同期モードに再プログラムする。

EMI の物理：

  • 電気メス（ESU）がパルスジェネレータやリードに近いほど EMI が起きやすく、距離が離れれば減衰する。Figure 3 の脚注では、EMI 源が CIED ジェネレータから 15 cm 未満のとき有意なリスクとみなす。
  • 臍より下の ESU は経静脈デバイスに EMI を起こしにくい。ただしアンダーボディ型の対極板を使う場合は臍より下でも EMI のリスクがあり、磁石か再プログラムが必要。
  • 単極 ESU は双極 ESU より EMI が多く、凝固モードは切開モードより多い。双極 ESU と超音波メスは EMI を起こしにくい。
  • 単極 ESU では対極板（dispersive electrode）でジェネレータと心臓から電流を逸らす。対極板はジェネレータからできる限り遠くに置き、電流経路がジェネレータやリードを横切らないようにする。
  • EMI はペーシングスパイクと QRS 波形を心電図上で覆い隠すことがある。
  • EMI が予測されなくても、頭蓋内・脊髄内・眼内手術など、CIED のショックによる患者の体動が望ましくない状況がある。

磁石の限界：

  • 磁石は術前にその CIED での効果を確認せずに頼ってはならない。一部のデバイスはプログラム可能な磁石応答をもち、非同期ペーシング強制以外の作用をする。
  • 十分な電池残量があれば磁石で 85〜100 bpm のペーシングになる。電池消耗とともに磁石レートは低下する。非同期（VOO または DOO）ペーシングが予想レートで生じていることを確認することが重要。
  • 一部のペースメーカでは磁石は10拍だけ非同期ペーシングを強制した後、プログラム設定に戻る。これらのデバイスは EMI 回避のため再プログラムが必須。
  • 肥満患者や腹臥位患者、ジェネレータへの持続的な接触が確保できない場合、磁石は無効になりうる。
  • 磁石は ICD で非同期ペーシングを強制しない（頻拍治療の抑制のみ）。
  • リードレスペースメーカは磁石応答が製造業者依存で、完全に心内にあるため磁石の正しい位置決めが難しい。
  • S-ICD に磁石を当てると R波同期のビープ音が鳴り、位置が正しいことを示す。音が聞こえなければ再プログラムが必要。磁石を使うなら粘着テープで固定する。

電池確認とその他：

  • ペースメーカは12か月ごと、ICD は6か月ごとの interrogation で電池状態を確認する。
  • ESU・モニタ・骨鋸・体動による EMI がレート応答機能を誤作動させ、望ましくない頻脈を招くことがある。砕石術や電気けいれん療法の際はレート適応機能を無効化する。
  • 外部除細動・カルディオバージョンができない手技では、CIED 機能を無効化する間、経皮ペーシング/除細動パッドを患者に貼付しておく。
  • 頻拍治療を再作動させ忘れたことによる突然死がレジストリに報告されている。
  • 患者自身が退院時にリモート伝送を行うことで安全性に寄与できる。
  • 緊急手術で EMI が予測される場合は磁石を使用し、CIED の種類・製造業者・プログラム設定をできる限り早く同定する。
  • 施設として CIED プロトコルを整備すべき（Figures 3 and 4）。管理計画には手技の詳細、患者体位（腹臥位など）、予測される EMI の種類を織り込み、具体的なプログラム変更、磁石への応答、ペースメーカ依存性、電池寿命、重篤な不整脈の既往を記載して診療記録に残し、周術期の全臨床医がアクセスできるようにする。
  • S-ICD は表面積が大きく左胸壁に沿って位置するため、鼠径部より上の ESU の影響を受けやすい。

POINT

  • STOP-Bang 質問票でスクリーニングした 245例のうち 182例が術前レベルIII 睡眠ポリグラフを受け、70例（38%）で OSA、11例（6%）で中等症〜重症 OSA。

図の解説

Figure 5 の実務上の含意 図の骨格は「何を入れたか（バルーンのみ／BMS／DES）」と「なぜ入れたか（ACS か CCD か）」の2軸で待機期間が決まる、というもの。同じ DES でも適応が ACS なら12か月、CCD なら6か月と倍違う。この差は「PCI が MI に対して行われた患者は術後MACE が約3倍」というデータに由来する。時間制約がある場合の3か月と1か月以内は Harm という下限は、ACS/CCD で共通である。当院で消化器癌の手術予定患者にステント既往がある場合、「いつ・何を・なぜ入れたか」の3点をカテ記録から確認するだけで、この図から待機期間が一意に決まる。

個別の根拠（抜粋）：

  • 大規模後ろ向き（>20,000例）：PCI 既往は1年時点まで周術期MACE と出血の危険因子であり続ける。
  • VA のマッチドコホート：周術期MACE は PCI 後6か月間が最高で、その後 1% で安定。
  • 221,379 の非心臓手術入院の後ろ向き解析：PCI 後6か月以内では周術期MI 4.7%、出血 32%、死亡 4.4%。
  • ステント種別（BMS vs DES）は6か月時点の周術期MACE と関連しなかった（大規模コホート）。ただし約40,000例の多施設前向きレジストリでは、旧世代 DES はどの時点でも BMS より高リスクだった。
  • カナダの約8000例：DES-PCI 後6か月超に行われた大待機手術の MACE 発生率は 1.2% で、PCI 歴のない中等度リスク手術患者に近づく。
  • PCI 後30日以内の手術は破滅的：BMS-PCI 後 <30日 vs >3か月で MACE 10.5% vs 2.8%。デンマークの全国レジストリ（2005〜2012年）では、DES-PCI 後1か月以内の非心臓手術は心臓死のリスク13倍、全死因死亡4倍。別の研究では PCI 後1か月未満の非心臓手術で MI 7.2%（vs 0.5%）、心臓死 5.0%（vs 0.4%）、全死因死亡 9%（vs 2.1%）。前向き研究では PCI から35日未満での手術は90日超と比べ合併症リスクが2倍。
  • アスピリン継続：ステント留置後の非心臓手術で、アスピリン使用は死亡と非致死性MI の低下（絶対リスク減少 5.5%）と関連し、大出血・生命を脅かす出血は同等だった。46研究・>30,000例のメタ解析では、単剤・二剤いずれの抗血小板療法も出血リスクをわずかに増やすが血栓リスクは増やさない。
  • POISE-2 のアスピリン部分（n=10,010）：術前および術後30日のアスピリン投与は死亡または非致死性MI の複合を減らさず（7.0% vs 7.1%、HR 0.99、95%CI 0.86–1.15、P=0.92）、大出血のハザードを23%増加させた。試験登録前のアスピリン使用の有無で結果は一貫していた。事前規定の PCI 既往層（n=4382）では、アスピリン継続 vs 中断で死亡/非致死性MI に差がなかった（7.7% vs 7.8%、HR 1.00、95%CI 0.81–1.23）。血管手術サブグループでも、慢性アスピリンの周術期中止は心血管イベント増加と関連しなかった。
  • 小規模RCT 220例では周術期アスピリンが術後MACE を絶対 7.2% 減らした、という相反する報告もある。アスピリン継続は非重篤な出血イベントを 1.5倍にし、周術期急性心血管症候群の最大10%にアスピリン中止が先行していた。
  • 静注抗血小板薬によるブリッジング：BRIDGE 試験（CABG 患者でのカングレロル vs プラセボ）は、大出血を過剰に増やさずより強い血小板抑制を示した。非心臓手術での MONET BRIDGE 試験（PCI 後12か月以内）が進行中。糖蛋白 IIb/IIIa 阻害薬をブリッジング戦略として用いる確立したデータはない。
  • トラネキサム酸（POISE-3）：非心臓手術で複合出血アウトカムはトラネキサム酸群で有意に低かった。ただし正味の臨床的便益は患者依存的で、出血リスクの高い患者には有益だが、心血管イベントリスクの高い患者には有害である。

再開のタイミング：

  • VKA は再開しても完全な抗凝固効果まで数日かかる。したがって、低〜中等度出血リスク手技で止血が得られたら、術後12〜24時間という早期にVKAを再開してよい。以前の治療量で再開するのが基本だが、併用薬（抗菌薬、NSAIDs、アセトアミノフェン）、栄養、薬物クリアランスが周術期に変化しうるため追加のモニタリングが必要になりうる。
  • DOAC は開始後およそ2〜3時間でピーク濃度と治療域の抗凝固効果に達する。したがって完全な抗凝固が臨床的に妥当になった時点で再開する。止血が得られていれば術後6時間という早期でもよい。PAUSE 試験では高出血リスク手技後 48〜72時間で DOAC を再開し、出血・血栓イベントとも全体に低かった。

3: HarmB-R非心臓手術を受ける患者でβ遮断薬の即時の必要性がない場合、術後死亡リスク増加のため、手術当日にβ遮断薬を開始すべきではない。

歴史的経緯（原文の記述）：

  • 周術期β遮断薬が虚血と主要心イベントを減らすという当初の楽観は、大規模RCTによって大きく後退した。虚血性心イベントと心房性不整脈を減らす中等度の便益は、害（脳卒中）によって相殺され、全死因死亡の増加と関連した。
  • 早期の研究で便益が示されたのは、長期にβ遮断薬を内服していた患者から薬を取り上げたことによる可能性がある。長期適応のβ遮断薬を急に中止することは有害であり、避けるべきである。
  • POISE（POISE-1）：β遮断薬未使用患者に手術直前から高用量β遮断薬を投与し周術期を通じて維持した大規模多施設試験。MACE の中等度の減少という便益と、低血圧・脳卒中という害が拮抗し、全死因死亡は正味で増加した。とくに高用量で開始した場合に有害。
  • 本ガイドラインは、2014年版の系統的レビューと同様に、データの信頼性への懸念から一群の周術期β遮断薬試験を検討対象から除外している（偽の結果を導くおそれがあるため）。
  • 3つのメタ解析はいずれも周術期β遮断薬投与の潜在的害について一致していたが、結果はいずれも POISE-1 の大きなサンプルサイズに強く影響されている。
  • RCRI で規定される高リスク患者ではβ遮断の便益が高い可能性を示唆する大規模観察研究があるが、臨床試験では再現されていない。
  • 開始時期：大規模観察研究では、手術の7日未満前にβ遮断薬を開始すると、31日以上前に開始した患者より死亡リスクが高かった。8〜30日前に開始した患者では過剰死亡もなく、周術期の便益も示されなかった。したがって開始が必要なら手術の7日以上前とする。
  • 周術期β遮断薬の開始時期、用量調整法、便益を得る患者サブグループ（RCRI 別など）、手術そのものがβ遮断の適応になりうるかを判定するに足る規模・検出力のRCTは存在しない。
  • 最適戦略は：明確な長期または急性の適応をもつ患者に限定して使用し、手術の1週間以上前に開始し、周術期の血行動態に応じて慢性β遮断薬を調整し、退院時に確実に継続すること。

疫学：

  • 米国成人の 3410万人（人口の13%） が糖尿病、さらに 730万人（2.8%） が未診断糖尿病。
  • 一般外科患者の最大 20% が糖尿病、23〜60% が前糖尿病または未診断糖尿病。
  • 糖尿病は ASCVD（冠動脈疾患・慢性腎臓病・心不全）の有病率を高め、周術期心血管イベントと手術部位感染のリスクを増やす。
  • 麻酔と手術のストレスが肝糖新生と末梢組織の糖利用の均衡を崩し、調節ホルモンと炎症性サイトカインに影響する。術中血糖コントロールの最適目標値は明確に定義されていない。

HbA1c：

  • HbA1c 高値が術後アウトカム不良と因果的に結びつくのか、単に周術期血糖管理不良のマーカーにすぎないのかは依然として論争がある。
  • より良い血糖コントロールを達成するために手術を延期することが心血管アウトカムを改善するというエビデンスは存在しない。
  • 検証された HbA1c のリスク閾値はないが、HbA1c が 8% を超えるなら待機手術の延期が妥当でありうる。緊急または時間制約のある手技は目標 HbA1c 達成のために遅らせてはならず、周術期血糖コントロールの最適化に注力する。
  • 非心臓・非血管手術の術前血糖の後ろ向き研究：血糖 ≥200 mg/dL は正常血糖の患者と比べ全死因死亡が2倍超、心血管死亡が4倍超。術前に糖尿病治療を受けていた患者は全死因死亡・心血管死亡がより低かった。

SGLT2阻害薬：

  • 腎での糖再吸収を阻害して尿糖排泄を促す非インスリン系血糖降下薬。
  • 稀な合併症として正常血糖糖尿病性ケトアシドーシスがあり、血糖 <250 mg/dL の正常血糖でありながら、代謝性アシドーシス（pH <7.3）、血清重炭酸低下（<18 mEq/L）、血中・尿中ケトン上昇を呈する重篤な術後合併症として定義される。
  • 術後にいつ SGLT2阻害薬を再開すべきかについての明確なガイドラインは存在しない。理想的には患者が臨床的に安定し通常の食事を再開するまで推奨しない。

メトホルミン：

  • 従来の中止推奨は「身体的ストレス下で乳酸アシドーシスが誘発される」という懸念に由来したが、新しいデータはメトホルミンが乳酸アシドーシスと関連しないことを示唆する。2型糖尿病 >10,600例の集団ベースコホートで乳酸アシドーシスで入院した 163例を性・年齢マッチ対照と比較したところ、メトホルミンの現在使用は乳酸アシドーシスのリスクと関連しなかった。
  • UKPDS：肥満を伴う2型糖尿病でメトホルミンは血糖低下に加え心血管死亡を減らした。事前規定サブグループ解析で糖尿病関連エンドポイント 32%、糖尿病関連死 42%、全死因死亡 36% のリスク低下。10年追跡でも糖尿病関連エンドポイント 21%、MI 33%、全死因死亡 27% の有意な減少が持続した。

GLP-1受容体作動薬（推奨は作られていないが本文に記載）：

  • 新しいデータは、糖尿病管理で使用が増えている GLP-1受容体作動薬が臨床的に有意な胃不全麻痺と胃排出遅延を起こしうることを示唆している。
  • 米国麻酔科学会（ASA）のコンセンサス声明は、手術時の胃内容物の肺誤嚥リスクを減らすため、週1回製剤は待機的非心臓手術の1週間超前、1日1回製剤は前日に中止することを推奨している。
  • Section 12（エビデンスギャップ）では「さらなる研究が必要だが、アドバイザリーは GLP-1受容体作動薬を待機的非心臓手術の前に1回分中止することを示唆している」と、より控えめな表現になっている。

13-3. 術中モニタリング — 心エコー（Section 8.3.1）

POINT

推奨（Echocardiography）

CORLOE推奨
2aC-LD非心臓手術中に原因不明の血行動態不安定を呈する患者では、専門技術が直ちに利用可能であれば、原因究明のための周術期 TEE または FoCUS の緊急使用は妥当である。
3: No benefitC-LD有意な血行動態破綻のリスク因子も手技リスクもない非心臓手術患者では、心疾患のスクリーニングや心筋虚血のモニタリングのためのルーチンの術中 TEE は推奨されない。

要点：

  • 心エコーは両心室機能、弁機能、心内構造、心膜腔、胸部大動脈を評価できる。
  • 非心臓手術では主に「持続する原因不明の血行動態不安定」の診断ツールとして使われる。ただし TEE は高リスク因子をもつ患者や高リスク非心臓手技での術中モニタリングツールとしても使用が増えている。心臓手術と肺移植では広く使われる。
  • TEE は全体として低リスクの手技だが、合併症は起こりうるため利益とリスクを勘案する。
  • FoCUS は限られた標準断面からなり、血行動態不安定時の病態を粗く同定するために使う。追加の心エコー情報が心臓由来の原因の除外に必要なら、包括的検査を行うべきである。
  • モダリティの選択は状況・機器と専門技術の可用性・適応による（左心耳と胸部大動脈は TEE のほうがよく評価できる）。
  • 系統的レビュー：術中 FoCUS（TTE）は原因不明の低血圧の原因診断と治療指針に有用な非侵襲的ツールとなりうる。ただしエビデンスの質は低い。これは血行動態不安定という予測不能な状況で高品質研究（RCT）を設計する困難さを反映している。
  • 非心臓手技でのルーチン術中 TEE の有効性データは限られており、予測精度・費用対効果・安全性のいずれの点でもルーチンの TEE モニタリングを推奨するデータは不十分。
  • Top Take-Home Message 9：原因不明の血行動態不安定があり臨床的専門技術が利用可能な場合、緊急 FoCUS を周術期評価に使用できる。ただし FoCUS は包括的な経胸壁心エコーの代替にはならない。

13-5. 術中モニタリング — 一時的機械的循環補助（Section 8.3.3）

POINT

  • 予防的使用は症例報告レベル。後ろ向き研究では心移植前に一時的 MCS を要した患者で死亡の増加はなかった。
  • 救済使用（IABP、ECMO、経皮的心室補助装置）は、薬物治療が奏功しない予期せぬ心原性ショックに対して報告されている。
  • 抗凝固戦略、MCS 管理、血行動態モニタリング、感染予防に関する専門的助言を含む多職種アプローチが不可欠。具体的な推奨は AATS/ISHLT の MCS 臨床実践ガイドラインを参照。

POINT

推奨（Pulmonary Artery Catheters）

CORLOE推奨
2bC-LD心血管疾患をもつ患者が非心臓手術を受ける場合、血行動態に大きく影響する基礎疾患（非代償性心不全、重症弁膜症、複合ショック状態、肺高血圧）が術前に是正できないときには、肺動脈カテーテル留置を考慮してもよい。

要点：

  • ルーチン使用でアウトカムが良くなるという理論的根拠は「臨床医の周術期血行動態理解が深まる」というもの。しかし使用がアウトカムを改善することを証明した大規模RCTはなく、肺動脈カテーテル留置は侵襲的で高コストである。
  • 「肺動脈カテーテルはモニタリング機器であり、患者アウトカムは提供されたデータの適切な解釈と実装された治療プロトコルに基づいて評価されるべきだ」という反論もある。
  • 使用は減少しているが、血行動態不安定患者のモニタリングでは依然として好まれる方法。ICU 入室 53,312例の後ろ向き解析では、重症外傷でショック、高齢、または急性心不全の患者は肺動脈カテーテル誘導管理から利益を得た。前向き観察多施設コホートでも、急性心不全患者、とくに低血圧または強心薬使用中の患者では肺動脈カテーテルの適切な使用が死亡を減らした。
  • ASA III〜IV の高リスク手術患者を肺動脈カテーテル使用の有無にランダム化した試験：死亡・罹病率に差なし。ただし肺動脈カテーテル群で肺塞栓症が増加した。
  • 2013年の5研究（n=2395）の系統的レビュー・メタ解析：肺動脈カテーテルによる術前最適化と血行動態管理は、中心静脈圧カテーテルと比べて周術期アウトカムを変えなかった（血管・腹部・胸部・整形外科・腹部再建術・高リスク手術）。大動脈再建術でも同様。

13-7. 周術期の貧血管理（Section 8.4）

POINT

推奨（Perioperative Anemia Management）

CORLOE推奨
2aA出血が予想される非心臓手術を受ける患者では、術中出血量の減少、輸血の減少、貧血の回避のためトラネキサム酸は妥当である。
2aB-R鉄欠乏性貧血のある患者が待機的非心臓手術を受ける場合、輸血の減少とヘモグロビン上昇のため術前の鉄剤投与（経口または静注）は妥当である。

疫学と定義：

  • 軽度の術前貧血でさえ、術後の罹病・死亡（呼吸器・尿路・創部・敗血症・血栓塞栓合併症を含む）の独立した危険因子である。
  • 慢性腎臓病・糖尿病・心血管疾患・心不全の患者では貧血の有病率が高い。
  • WHO の貧血定義：男性 Hb <13 g/dL、女性 <12 g/dL。
  • 手術患者の最大 64% が貧血で、その半数超が中等症〜重症。鉄欠乏が 40〜50% の原因。
  • 鉄欠乏の指標：フェリチン <100 ng/mL、トランスフェリン飽和度 <20%、および/または小球性低色素性赤血球（MCV <80 fL、MCHC <27 g/dL）。
  • 貧血が自動的に鉄欠乏の評価を起動するスクリーニング体制は、通常手順で臨床医が行うより鉄欠乏性貧血をはるかによく同定する。
  • 大半の貧血は2〜4週間で是正できる。貧血管理プログラムは輸血率・合併症・死亡を減らす。

輸血閾値：

  • AABB（Association for the Advancement of Blood & Biotherapies）は、整形外科手術患者と心血管疾患患者に対して 8 g/dL の制限的輸血閾値を推奨している。7 g/dL は 8 g/dL とおそらく同等だがエビデンスが不足している。
  • 急性冠症候群患者のメタ解析：輸血閾値 Hb ≤8 g/dL vs ≤10 g/dL で、死亡・MACE・ACS 再発・30日心不全のいずれにも差はなく、輸血量・コストの削減もなかった。
  • 輸血を受けた患者は受けなかった患者と比べ、肺・敗血症・創部・血栓塞栓合併症、急性腎障害、在院日数延長、感染が多い。術中輸血は死亡リスク増加と関連する。

トラネキサム酸：経口・静注・局所投与できる合成リジン系抗線溶薬で、プラスミノゲンのフィブリンへの結合を阻害し術中出血を安全に減らす。静脈血栓塞栓症・MI・けいれん・虚血性脳卒中・TIA・腎疾患・心房細動の既往をもつ高リスクの下肢人工関節置換術患者でも、トラネキサム酸は輸血を減らし、静脈血栓塞栓症・MI・けいれん・脳卒中・TIA と関連しなかった。

鉄剤：

  • 術前の鉄補充は活用されていない（underused）。静注鉄は鉄欠乏患者で安全かつ有効に貧血を是正する。
  • 経口鉄は術前1〜2週間だけの投与ではほとんど効果がなく、バイオアベイラビリティの低さ・忍容性の欠如・長い治療期間のため、鉄欠乏性貧血の迅速な術前治療には不十分。
  • 静注鉄は単回投与でも経口鉄よりヘモグロビン濃度と貯蔵鉄の上昇に有効で、輸血率と再入院率を減らす。
  • 非心臓手術患者への貧血管理アプローチにより、1件の合併症を防ぐ治療必要数（NNT）は 6、1件の合併症関連死を防ぐ NNT は 25。
  • 術後の静注鉄も鉄欠乏性貧血の治療でヘモグロビンを改善し、術後輸血・感染・在院日数を減らす。
  • フェリックカルボキシマルトース、フェリックデリソマルトース、フェルモキシトールは鉄が炭水化物シェルに包まれており鉄の緩徐な放出を可能にするため、単回輸注で高用量を投与できる。鉄スクロースは安定性が低く低用量投与（1回最大 200〜300 mg） となる。

POINT

推奨（MINS Surveillance and Management）

区分CORLOE推奨
サーベイランス2bB-NR既知の心血管疾患、心血管疾患の症状、または65歳以上で心血管危険因子をもつ患者が中等度以上リスクの非心臓手術を受ける場合、心筋障害の同定のため術後24時間および48時間に心筋トロポニンを測定することが妥当でありうる。

MINS の定義と疫学：

  • 周術期心筋障害は非心臓手術患者の約20% に発生し、無症候性の心筋障害から明らかな術後MI（虚血症状または心電図変化、病的Q波、あるいは画像上の生存心筋喪失の所見で定義）までの幅をもつ。
  • MINS は type 1・type 2 の両方の MI を包含し、無症候性心筋障害も含む。理由は「手術患者は麻酔・鎮痛・手術部位の疼痛のため症状を報告できないことがある」から。
  • 診断要件：虚血性と推定される原因で 心筋トロポニンが1回以上、基準上限99パーセンタイル超であること。肺塞栓症・脳卒中・敗血症などの非虚血性病因は除外する。
  • 30日死亡は約 10%。トロポニン最高値に比例し、最高四分位で 17%、最低四分位で 1%。30日術後死亡の人口寄与危険度は 34%。
  • MINS 患者の 80〜90% は虚血の徴候・症状を欠くが、それらの患者でも30日死亡は相当に高い。
  • MINS の予測因子：心血管危険因子と心血管疾患、腎疾患、緊急/準緊急手術。
  • 機序は異質でありうるが、大半の症例で動脈硬化性冠動脈疾患が推定される病因。

サーベイランスのエビデンス：

  • 45歳以上 21,842例の前向きコホート（高感度トロポニンT による術後サーベイランス）：虚血所見を伴わない術後トロポニン上昇は30日死亡のハザードを3倍、虚血所見を伴う術後トロポニン上昇は5倍にした（MINS なしの患者との比較）。
  • 中等度以上リスク患者の MINS 評価は、第4版心筋梗塞普遍的定義でも AHA の科学的声明でも支持されている。
  • 術後トロポニン値を正しく解釈するには、術前ベースライン値または連続測定が有用（心筋障害が急性か慢性かを判別するため）。
  • 従来の第4世代アッセイでも高感度アッセイでも周術期サーベイランスに使用できる（利用可能性に基づく）。
  • トロポニンのサーベイランスは「心イベントリスク >20% の患者」を同定するには有効だが、MINS 患者の最適な管理は依然として不確実であり、さらなる研究を要する。既に冠動脈疾患に対する最大限の GDMT を受けている中等度以上リスクの ASCVD 患者では、MINS の診断が臨床管理を変えるかどうかも不明である。「明確な管理戦略が緊急に必要」と原文は述べている。

管理のエビデンス：

  • 約5000例の単施設研究：MINS 患者のうち循環器コンサルトを受けた、または循環器科へ転科した患者は30日死亡が低かった。別の研究でも MINS 診断後の早期の循環器紹介が早期死亡の有意な減少と関連。
  • 患者には手術の場で MINS の診断を伝えるべきである。
  • 小規模観察研究：MINS 患者で心血管薬物療法を強化すると1年の MACE が低下。ただしMINS における抗血小板薬とスタチンの使用を支持するデータは観察コホートのみに基づく。
  • POISE の事後解析：周術期MI 患者ではアスピリンとスタチンの使用が30日死亡の減少と関連。別の観察研究（n=5109）では術後のスタチン使用が1年死亡の低下と関連。
  • 前向き研究では、MINS 患者のうち心血管疾患に対する GDMT が強化されたのは3分の1未満だった。
  • MANAGE 試験（MINS に対する薬物療法を評価した唯一のRCT）：1754例の術後患者を MINS 発症から35日以内にダビガトラン 110 mg 1日2回 vs プラセボにランダム化。ダビガトランは主要血管イベントの複合を有意に減らし、大出血は増やさなかったが、軽微な出血と消化管出血が過剰だった。ただし両群とも約半数が試験終了前に試験薬を中止しており、登録の遅れとサンプルサイズ縮小のために主要アウトカムが事後的に変更されている。
  • 傾向スコアマッチの後ろ向き解析では、MINS 患者の退院時抗血小板療法が1年死亡リスク低下と関連。術前の血小板関連遺伝子・凝固関連遺伝子の発現亢進が MINS の危険因子と同定されており、抗血栓薬の役割には機序的な仮説がある。

14-2. 術後 STEMI / NSTEMI の管理（Section 9.2）

POINT

推奨（Management of Postoperative STEMI/NSTEMI）

CORLOE推奨
1B-NR非心臓手術後に STEMI を発症した患者は、出血リスクと血栓リスクを臨床像の重症度と比較考量したうえで、侵襲的冠動脈造影（ICA）の考慮を含む GDMT の対象とすべきである。
1C-EO非心臓手術後に NSTEMI を発症した患者は、術後の出血リスクと血行動態状態を考慮したうえで、自然発症MI の患者に推奨されるのと同じ薬物療法を受けるべきである。
2aC-LD非心臓手術後に NSTEMI を発症した患者は、出血リスクと血栓リスクを臨床像の重症度と比較考量したうえで、ICA の対象として考慮できる。

疫学と実際：

  • 周術期MI の発生率は定義・患者リスク因子・術式により 0.9〜15% と幅広い。
  • 非心臓手術後の周術期MI は、type 1 MI（急性プラーク破綻）よりも需給不均衡による type 2 MI として現れることが多い。
  • 鎮静と鎮痛が患者の症状そのものと症状報告能力を制限するため、周術期のMI 認識は難しい。
  • 周術期 STEMI・NSTEMI の患者は死亡リスクが高く、約3分の1が30日以内に死亡または再入院する。死亡の危険因子はトロポニン最高値、出血イベント、末梢動脈疾患の存在。
  • 周術期 type 1 MI は自然発症 ASCVD による MI と同じ薬物療法が理想。type 2 MI が疑われる場合は需給不均衡の基礎原因（高血圧、低血圧、頻脈、貧血）に対処する。
  • トロポニン上昇は心不全・敗血症・肺塞栓症など非虚血性原因でも起こりうる。
  • 急性冠動脈閉塞が疑われる場合に ICA が適応となりうるが、残存出血リスク・術式・術後経過時間を含む個別リスク層別の後に行う。
  • 周術期 STEMI は周術期MI 患者の少数だが、院内死亡は 30〜35%。GDMT を速やかに開始し、出血と低血圧という術後リスクとの均衡を取る。緊急 ICA を強く考慮すべきである。意思決定は外科医・麻酔科医・循環器医のチームで行う。
  • NSTEMI：薬物療法には少なくとも1剤の抗血小板薬（便益が出血リスクを上回る限り）と高強度スタチンの開始を含める。血行動態が許せば、β遮断薬・ACEi・硝酸薬を狭心症の症状緩和と長期心血管リスク低減の両面から考慮してもよい。
  • 後ろ向き観察解析ではMI の侵襲的管理は保存的管理より院内死亡が低かった。ただし PCI 後の全身抗凝固と長期抗血小板療法の必要性を考えると、残存する術後出血リスク・術式・手術からの経過時間と天秤にかけるべきである。
  • 緊急 ICA から最大の利益を得うるのは：GDMT に反応しない持続症状、血行動態不安定の所見、バイオマーカーの持続的上昇、新規の局所壁運動異常または心室機能低下の画像所見をもつ患者。

15. 特殊集団（Section 10）🧬

15-1. 肝移植・腎移植前の術前評価（Section 10.1）

推奨なし（シノプシスのみ）。

  • 末期腎疾患・末期肝疾患の患者は、一般人口より心血管危険因子と冠動脈疾患の有病率が高く、心不全や肺高血圧など他の心血管病態のリスクもある。
  • 新しい研究は、腎移植前の冠動脈疾患スクリーニングは、ルーチンの術前検査と比べて標的を絞ったアプローチでも術後アウトカムが同等であることを示唆する。
  • US Renal Data System と Medicare 請求データ：腎移植前1年間により頻回の侵襲的/非侵襲的冠動脈疾患検査を行っても、移植後30日の死亡や急性MI の低下と関連しなかった。
  • ISCHEMIA-CKD 試験（進行慢性腎臓病・慢性冠動脈疾患・負荷試験で中等度〜重症虚血をもつ非手術成人）：冠動脈造影＋血行再建＋薬物療法の初期侵襲的アプローチは、初期薬物療法単独に比べ、中央値2.2年の追跡で死亡またはMI のリスクを減らさなかった。
  • 2022年 AHA 科学的声明「腎・肝移植候補者における冠動脈疾患スクリーニングの新しいエビデンス」が、現代のデータとスクリーニング・管理のアプローチをまとめている。

15-2. 肥満と減量手術（Section 10.2）

推奨なし（シノプシスのみ）。

  • 肥満は世界的に増加し、米国成人の3分の1超に影響する。
  • 減量手術は BMI ≥35 kg/m² の患者に対する最も有効で持続的な減量介入で、2型糖尿病・高血圧・脂質異常症を含む肥満関連疾患を改善または寛解させる。
  • 集団ベースの後ろ向きコホート（n=2638）：心血管疾患と肥満を併存する患者では、減量手術が中央値4.6年の追跡で MACE 発生率の低下と関連。
  • 減量手術患者は若く低リスクの特徴で選択されがちだが、リスクがないわけではない。大規模メタ解析では周術期MI 0.37%、全死因死亡 0.08%。
  • 494,611例の後ろ向き多施設研究（Roux-en-Y 胃バイパスまたはスリーブ状胃切除）：心疾患既往は周術期心停止と30日死亡のリスク増加と関連。同研究ではスリーブ状胃切除は Roux-en-Y より有害事象が少なかった。
  • 別の観察研究：減量手術を受ける肥満患者で ACS または心不全の既往は周術期心血管合併症のリスク増加と関連。
  • したがって術前評価での病歴と危険因子への細心の注意が不可欠。
  • 肥満患者には減量目的で GLP-1受容体作動薬が処方されることが増えており、非心臓手術前の中止に関する考慮事項は Section 7.8（周術期血糖管理）で扱われている。

16. コスト・バリューの考慮（Section 11）💰

基本的な枠組み（原文の論理）：

  • 治療薬では「技術の使用」と「価値」の関係は直接的だが、診断検査では間接的かつ条件依存的である。理由は、診断検査はデータを生むだけで、価値を作るのは臨床医がそのデータをどう使うかだから。
  • 検査の価値は、患者リスクと手術リスクという臨床文脈によって大きく変わる。
  • 結果を使って健康を改善できる文脈 → 価値は検査費用と健康改善のトレードオフ（費用対効果）で決まる。
  • 結果を知っても健康が改善しない文脈 → 検査を行わないことによって価値が生まれる。
  • 検査が害を招きうる文脈（偶発所見 → 追加検査 → 追加リスクや治療の遅れ） → ここでも検査を行わないことによって価値が生まれる。
検査価値の評価
術前 BNP / NT-proBNP中等度以上リスクの非心臓手術で既知の心血管疾患・症状・65歳以上＋リスク因子の患者のリスク評価に使えるが、この情報が臨床医のアウトカム改善や医療費への影響に使えるかを評価した研究はない。よって "uncertain value"（不確実な価値）。心血管疾患もリスク因子もない低リスク手術の患者では改善を示すエビデンスもない。低価値の BNP 検査をなくせば、即時の費用節減に加えて後続の診断検査のカスケードも消える。
術前 心筋トロポニン同様に "uncertain value"。
術前 12誘導心電図1件 14.57ドル（2022年 Medicare 償還） と安価で、健康がわずかでも改善するなら費用対効果があるとみなせる。中等度以上リスク手術で活動性の心血管症状または MACE リスク増加がある患者では、術前心電図は短期死亡と MACE を予測する。しかし、心電図結果を知ることが臨床医の意思決定を改善したか、長期の臨床的・経済的アウトカムを改善したかを報告した研究はない。2967例の研究では、心電図は病歴のリスク因子情報を超えて術後死亡・MI の予測を改善しなかった。よって中等度以上リスク手術での術前心電図は "uncertain value"。対照的に、低リスク患者の低リスク手術でのルーチン術前心電図はアウトカムにほとんど影響せず、廃止すれば費用節減になるという点では多くの研究が一致している。
CCTA解剖学的情報を与えるが、機能的負荷試験と比べて侵襲的冠動脈造影の増加と医療費増加と関連してきた。PROMISE 試験（症候性の冠動脈疾患疑い患者で CCTA vs 機能的検査）では、中央値2年の追跡で CCTA は臨床アウトカムを改善しなかった。90日の平均費用は同等（CCTA 2494ドル vs 機能的検査 2240ドル、差 254ドル、95%CI −634〜906）だが、CCTA でより多くのインターベンション心臓手技が行われた。3年累積費用も同等（7213ドル vs 6586ドル、差 627ドル、95%CI −463〜1609）。PROMISE データを用いた Markov マイクロシミュレーションでは、CCTA＋非侵襲的FFR は機能的検査より侵襲的冠動脈造影の選択が効率的で、生涯での質調整生存年が高く（25.15 vs 24.68、差 0.46、95%CI 0.44–0.49）費用が低かった（7222ドル vs 7989ドル、差 −767ドル、95%CI −805〜−729）。ただし PROMISE は非心臓手術前の評価患者を組み入れておらず、外挿には注意を要する。
負荷試験負荷心エコーは運動心電図より正確だが1回あたりの費用が高い。安定した狭心症疑い患者のRCTでは検査結果に大差：運動心電図は陰性 55.7%・陽性 7.2%・判定不能 37.1%、負荷心エコーは陰性 94.8%・陽性 4.7%・判定不能 0.5%。負荷心エコーは外来・救急受診が少なく、冠動脈造影が少なく（6.3% vs 13.4%、P=0.02）、平均費用が低く（P=0.04）、3年時点の複合（死亡・MI・予定外血行再建・胸痛入院）に差なし（3.7% vs 3.2%、P=0.38）。機能的能力が良好で症状が安定した患者、および低リスク手術の低リスク患者は術前負荷試験から利益を得ない。PROMISE Minimal Risk Tool は検査を先送りしてよい低リスク患者の同定に用いられており、シミュレーションでは低リスク患者での検査先送りは患者の健康便益をより大きくし費用を下げうる（最低リスク10%で −749ドル、95%CI −1647〜−158／最低リスク20%で −677ドル、95%CI −1333〜−71）。

17. エビデンスギャップと今後の研究方向（Section 12）🔭

原文が挙げるギャップを領域別に転記する。

周術期ケア提供とリスク評価

  • 多職種ケア提供モデルが周術期検査（適切な非侵襲的負荷試験の使用など）や心血管アウトカムに与える影響を厳密に検証した研究はほとんどない。とくに術前評価での遠隔診療の使用と、高リスク患者の専門診療の調整については追加の検討が必要。
  • どの周術期リスク指標が他より優れるかを支持するエビデンスがない。リスクスコアを周術期管理の指針として最もよく使い、術後MACE を減らす方法についての追加データが必要。

周術期管理

  • 周術期ケアを導くのに最も適した血圧の評価法・閾値・測定頻度は確立していない。有害心血管アウトカムの減少と関連する具体的な周術期血圧閾値を同定する質の高いRCTが必要。
  • 非心臓手術を受ける新規発症心房細動患者で、周術期のレートコントロール vs リズムコントロール戦略を評価したRCTは存在しない。術後心房細動の最適サーベイランスと管理についての追加研究が必要。
  • 安定患者の非心臓手術前の冠動脈血行再建を支持するエビデンスは限定的であり、大手術前に血行再建を受ける高リスク患者でアウトカム改善を記録したRCTもない。
  • LVAD 植込み後の非心臓手術の最適タイミングを導くデータが限られている。
  • 最近の脳卒中患者における待機的非心臓手術までの最適な遅延期間は不確実。最近の脳卒中患者で非心臓手術が課す過剰な心血管・脳血管リスクも十分に定義されていない。

術前評価

  • 術前トロポニンの孤立性上昇以外に適応がない場合、それ以上の検査（負荷試験や冠動脈カテーテル検査）が有益だというエビデンスはない。
  • 心電図結果を知ることが臨床医の意思決定を改善するか、長期の臨床的・経済的アウトカムを改善するかを報告した研究はない。
  • 非心臓手術を受ける安定患者でのルーチンの術前左室機能評価（FoCUS・心エコーのルーチン使用）を支持するデータが不足している。

周術期薬物療法

  • ステント非留置のバルーン形成術後、TAVI 後、TEER 後に待機的非心臓手術を受ける患者の DAPT 管理に関する質の高いデータが限られている。
  • 非心臓手術を受ける患者における PCI 後の短縮DAPT の有効性と安全性にはさらなる検討が必要。
  • 周術期のスタチン開始が長期アウトカムに与える役割、低リスク患者・低リスク手技での役割、理想的なタイミング・薬剤・用量レジメン（再負荷など）を明らかにする大規模RCTが必要。
  • サクビトリル/バルサルタン（ARNI）の周術期の役割（害も益も）に関するデータは現時点で存在しない。
  • 周術期患者におけるカルシウム拮抗薬の休薬・継続・開始のリスクと便益を評価する大規模RCTが必要。
  • 慢性α2受容体作動薬療法の周術期継続はRCTで検討されていない。
  • 非心臓手術患者における糖蛋白IIb/IIIa阻害薬のブリッジング戦略としての確立したデータがない。
  • β遮断薬開始の最適アプローチは依然として不明：最大の便益を得る患者サブグループの同定、薬剤選択、手術に対する開始タイミング、術前用量調整の安全性。
  • 糖尿病患者の周術期ケアの課題：術後アウトカムを予測する血糖コントロール指標の評価、周術期血糖コントロール法の選択、旧来および新規の糖尿病薬の周術期管理。最適な周術期血糖値や術後の SGLT2阻害薬再開のタイミングを扱った研究はほとんどない。
  • GLP-1受容体作動薬：さらなる研究が必要だが、アドバイザリーは胃内容物の肺誤嚥リスク低減のため、待機的非心臓手術前に1回分の中止を示唆している。

術中管理

  • 非心臓手技における術中 TEE のルーチン使用の有効性を支持するデータは限られている。
  • 非心臓手術で心原性ショックのリスクがある患者に MCS をルーチン使用することを支持する質の高いエビデンスは現時点でない。
  • 肺動脈カテーテルが患者アウトカムを改善する、あるいは費用対効果に優れることを示した大規模RCTはない。

周術期サーベイランス

  • MINS は認識が不十分な臨床上のジレンマであり、その基礎にある病態生理学的機序の解明にはさらなる検討が必要。MINS 診断後のリスク軽減のための最適治療（抗血小板薬・スタチンの使用を含む）に関するデータは限られている。

エビデンスと実務インパクトの乖離 GLP-1受容体作動薬について、本ガイドラインは COR/LOE 付きの推奨を1つも作っていない。にもかかわらず、Top Take-Home Message の5番目に「糖尿病・心不全・肥満の新しい治療は重要な周術期の意味をもつ」と掲げられ、本文では ASA コンセンサス声明（週1回製剤は1週間超前、1日1回製剤は前日に中止）が紹介されている。 この「推奨ではないが本文に書かれた1文」が、実務上は最も多くの患者に影響する。GLP-1受容体作動薬は糖尿病だけでなく肥満治療で爆発的に処方が増えており、待機手術患者の相当数が内服している。1週間の休薬指示は、外来での説明・血糖管理・手術日程調整のすべてに波及する。 しかも Section 12（エビデンスギャップ）では表現がさらに後退し、「さらなる研究が必要だが、アドバイザリーは1回分（1 dose） の中止を示唆している」となっている。本文の「週1回製剤は1週間超前」と、ギャップ章の「1回分」は、週1回製剤では同じ意味だが、日次製剤では大きく異なる。ガイドライン内で表現が揺れている。 JCでの論点：エビデンスがまだない領域について、ガイドラインは「推奨を作らずに本文で紹介する」という形を取った。これは科学的には誠実だが、読者は「ガイドラインに書いてある」として推奨と同等に扱う。実装のときは「これは COR 付き推奨ではない」ことを院内文書に明記すべきではないか。

論点3：バイオマーカーの推奨は「測る根拠」と「測った後の根拠」が非対称

  • BNP/NT-proBNP は 2a（測定は妥当）、トロポニンは 2b。しかし本文には、
  • 「術前バイオマーカー高値の患者に、周術期心血管アウトカムを改善する管理を推奨できる研究はない」
  • 「（術前トロポニンについて）この知識単独に基づいて起こすべき行動はない」
  • コスト・バリューの章：BNP も トロポニンも "uncertain value"
  • Section 12：「術前トロポニンの孤立性上昇以外に適応がない場合、それ以上の検査が有益だというエビデンスはない」

という4つの記述がある。

  • つまり本ガイドラインは、「測ることは妥当（2a）だが、測った結果で何をしても良くなる証拠はなく、追加検査は無益」 という構造の推奨を出している。
  • さらに、3597例の研究では NT-proBNP をリスクスコアに加えても、リスクスコア＋自己申告の機能状態を超える改善はなかった。Figure 1 でもバイオマーカー測定は「機能的能力が不良」かつ「追加検査が方針を変える」を通過した後に置かれている。機能的能力を丁寧に取ればバイオマーカーは不要になる可能性がある、と読むこともできる。
  • JCでの論点：この 2a は何を根拠にしているのか。「予後予測能が高い」は「臨床的に有用」と同義ではない。予測ツールの評価には discrimination（識別能）だけでなく clinical utility（decision curve analysis 等） が必要だが、本ガイドラインはその議論をしていない。

論点4：術前検査の「やらない」推奨が守られにくい実装ギャップ

本ガイドラインは 3: No benefit を8か所以上に配置しているが、「やらない」ことは「やる」ことよりはるかに実装が難しい。理由は構造的である。

実装が難しい理由具体的な機序本ガイドラインが提供しているもの／いないもの
①責任の非対称性検査をして異常が出れば「見つけた」評価になるが、検査をしなくてイベントが起きれば「なぜ調べなかったのか」と問われる。やらなかったことの説明責任のほうが重いガイドラインは「推奨されない」と書くが、やらなかった場合の免責的な記述はない
②発注者と評価者の分離術前検査を発注するのは外科医・麻酔科医だが、結果を解釈し追加検査を決めるのは循環器医。発注の段階で「この検査が方針を変えるか」を問う人がいないFigure 1 は「追加検査は意思決定に影響するか？」という分岐を明示的に置いている（この点は優れている）。ただし誰がこの問いに答えるかは書かれていない
③システムの慣性電子カルテの術前オーダーセットに ECG や心エコーが既定でチェックされている施設が多いガイドラインはオーダーセットや DE-implementation（脱実装）の方法論には触れていない
④カスケードの不可視性「余計な検査1件」のコストは 14.57ドル（ECG）に見えるが、実際には偶発所見 → 追加検査 → 手術延期 → 原疾患進行、という連鎖が起きる。この連鎖は個々の臨床医からは見えないコスト・バリューの章が「cascade of care」という言葉で明示的に警告している点は評価できる。ただしカスケードの規模を定量した数字は提示されていない
⑤患者・家族の期待「手術前だから心臓を調べてほしい」という期待は強い共同意思決定を推奨しているが、「検査をしない」ことを説明するための材料（絶対リスク・害の数字）は用意されていない
  • 実際、本ガイドライン自身が引用する数字がこの困難さを示している：砕石術 30,892例で術前 ECG が引き起こしたキャンセルは 13件（0.04%）、そのうち後の精査が異常だったのは 1例のみ。それでも術前 ECG は世界中でルーチンに行われ続けている。
  • JCでの論点：当院で「やらない」推奨を実装するなら、①術前オーダーセットの既定チェックを外す（デフォルトの変更）、②「この検査が方針を変えるか」を問う欄をオーダー画面に置く、③術前検査の実施率をモニタリング指標にする、の3つがガイドライン本文よりも効く可能性が高い。ガイドラインを配るだけでは「やらない」推奨は実装されない。

論点5：LOE の分布が示すエビデンス基盤の脆弱さ

  • 本ガイドラインで LOE A が付いた推奨は極めて少ない：麻酔法（揮発性 vs TIVA、2a/A）、ルーチン肺動脈カテーテルの否定（3: No benefit / A）、トラネキサム酸（2a/A） の3つだけである。
  • 一方、弁膜症（AS・MS・AR/MR）、肺高血圧、LVAD、HCM、成人先天性心疾患、術後NSTEMI はほぼすべて C-LD / C-EO。ICU で最も判断に迷う重症患者ほど、推奨の根拠は専門家意見に近い。
  • とくに注目すべき組み合わせ：
  • AS の「重症AS は AVR の必要性を評価すべき（Class 1）」は LOE C-LD
  • 肺高血圧の「PAH 標的治療を継続する（Class 1）」も LOE C-LD
  • LVAD の「LVAD チームと調整する（Class 1）」は LOE C-EO
  • HCM の「陽性変力薬・頻脈・前負荷減少は有害（3: Harm）」も LOE C-LD — しかも本文は「術中管理を検討した研究は存在しない」と明記
  • JCでの論点：Class 1 / LOE C-EO という推奨は、「専門家が全員そうすべきだと考えているが、それを支持するデータはない」という意味である。これを「エビデンスに基づく診療」として引用するのは正確ではない。COR だけを抜き出した院内サマリーを作ると、この区別が失われる。当院で要約を作るなら、COR と LOE を必ず並記する。

論点6：術中血圧目標の「下限は Class 1、上限は根拠なし」という非対称

  • MAP ≥60〜65 mmHg / SBP ≥90 mmHg の維持は Class 1（B-NR）。根拠は観察研究で「MAP <65 mmHg または SBP <90 mmHg が約15分持続」が害の閾値だったこと。
  • しかしこれより高い目標を検証した3つの試験のうち、2つ（POISE-3・単施設RCT）は陰性、1つ（INPRESS）は陽性だが解釈困難。INPRESS は「低血圧の程度、とくに有害の可能性がある MAP 55〜70 mmHg 域の詳細が報告されていない」と本ガイドラインが直接批判している。
  • 観察研究に基づく閾値を Class 1 にするという判断自体が論点になる。B-NR（非ランダム化）で Class 1 は、本ガイドラインの中では比較的踏み込んだ格付けである。
  • JCでの論点：この Class 1 は「MAP 65 を下回らせるな」であって「MAP 65 を目標にせよ」ではない。臨床現場で「65が目標」と読み替えられると、65 付近をうろうろする管理になり、結果的に閾値を下回る時間が増える。目標は閾値より上に置くべきだが、どこに置くかの根拠はない、というのが正直な現状。

論点7：MINS を「見つけること」と「どうするか」の断絶

  • サーベイランスは 2b（弱い推奨）、外来フォローは 2a、抗血栓療法は 2b。サーベイランスより事後対応のほうが推奨クラスが高いという珍しい構造になっている。
  • MANAGE 試験は MINS に対する唯一のRCT だが、本ガイドライン自身が3つの重大な限界を挙げている：①両群の約半数が試験終了前に試験薬を中止、②登録の遅れとサンプルサイズ縮小のため主要アウトカムを事後変更、③軽微出血と消化管出血が過剰。
  • 前向き研究では MINS 患者の3分の1未満しか GDMT が強化されていなかった。つまり「見つけても何もしていない」のが現状。
  • 「既に最大限の GDMT を受けている ASCVD 患者では、MINS の診断が臨床管理を変えるかどうかも不明」と原文が明記している。
  • JCでの論点：サーベイランスを 2b で推奨しながら、その後の管理が確立していないと自ら認めるガイドラインを、そのまま院内プロトコル化してよいか。当院で導入するなら、少なくとも「トロポニンを測る対象」と「陽性だったときに誰が何をするか」を同時に決めなければ、検査が増えるだけになる。これは論点4の実装ギャップと表裏一体である。

論点9：ガイドラインとして構造的に弱い点

  1. アルゴリズムが未検証：Figure 1 について著者自身が「このアルゴリズムに沿った周術期ケアの臨床アウトカムは前向きに検証されておらず、臨床判断に取って代わるものではない」と明記している。ガイドラインの中核となる図が未検証であることは、読み手に十分伝わっていない可能性が高い。
  2. リスク計算ツールの「使い方」が空白：「検証済みツールを使え（2a）」とは言うが、どのツールを使うか、閾値をいくつにするか、結果に応じて何を変えるかは、いずれも指定されていない。「予測して何をするか」の研究がほとんどないことを自ら認めている。
  3. 費用の記載が米国限定：ECG 14.57ドル、CCTA 404ドルなどはすべて米国 Medicare の値。日本の診療報酬とは構造が異なる。
  4. PICO(TS) 構造の不徹底：「Modified: PICO(TS) 構造化などの書式変更」と説明しているが、推奨表そのものは PICO 形式ではなく従来の文章形式であり、対象集団の定義が推奨ごとに微妙に異なる（「中等度以上リスク手術」「待機的非心臓手術」「非心臓手術」が混在）。
  5. アウトカムの定義が推奨間で不統一：MACE・MACCE・「死亡または非致死性MI」「心停止・MI・全死亡」が混在し、Table 4 でもリスクスコアごとにアウトカム定義が異なることが示されている。異なるアウトカムで作られたスコアを「MACE >1%」という単一閾値で運用するという運用上の矛盾がある。

論点10：それでも本ガイドラインが価値をもつ理由

  • 「やらない」推奨を体系的に配置したこと自体が最大の貢献。過剰検査・過剰治療の抑制を明示的な目標に掲げた周術期ガイドラインは珍しい。
  • Figure 1 の「追加検査は意思決定に影響するか？」という分岐は、リスク層別と検査適応の間に臨床的有用性の関門を置いた点で優れている。ここが本ガイドラインの思想の核心。
  • MINS を独立章にしたことで、これまで「術後にトロポニンが上がったが症状がないので様子見」とされてきた患者群に、名前と管理経路が与えられた。
  • 抗凝固ブリッジングを 3: Harm に落としたことは、実務上のリスク低減効果が最も大きい変更である（BRIDGE・PERIOP-2・PAUSE の一貫した所見に基づく）。
  • エビデンスギャップの章（Section 12）が具体的で、「どのRCTが必要か」がほぼ研究計画のレベルで書かれている。

✅ Take home message

TAKE HOME

結論 周術期の心血管管理は「検査を増やすこと」ではなく「その検査が方針を変えるかを問うこと」で改善する。2024年版が実務を最も変えるのは、SGLT2阻害薬の術前3〜4日中止（Class 1）、抗凝固ブリッジングの原則廃止（3: Harm）、そして術後トロポニン監視によるMINSの検出とその後のフォローである。

  • 手術という事実だけでは検査の理由にならない。非手術患者と同じ適応で心血管スクリーニングと治療を行う（Top Take-Home Message 2）。
  • 負荷試験は「未診断の冠動脈疾患を見つけるため」ではなく、「血行再建で予後が変わる患者（左主幹部病変・EF低下を伴う重症多枝病変）を見つけるため」にだけ行う。それ以外は 3: No benefit。
  • SGLT2阻害薬は手術3〜4日前に必ず止める（Class 1）。止め忘れると術後に正常血糖ケトアシドーシスが起き、血糖が正常なので見逃される。
  • 抗凝固のヘパリンブリッジは、ほとんどの患者で有害（3: Harm）。DOACは「時間で切る」（Table 13）。ブリッジが妥当なのは機械弁僧帽弁などVKA内服の超高リスク例に限られる。
  • 術中は MAP 60〜65 mmHg・SBP 90 mmHg を下回らせない（Class 1）。ただしそれより高い目標を狙う根拠はない（POISE-3 陰性）。
  • MINS は非心臓手術患者の約20%に起こり、その80〜90%は無症状で、30日死亡は約10%。中等度以上リスク手術の高リスク患者では術後24時間・48時間のトロポニンを測る（2b）。
  • MINS を見つけたら外来フォローへ確実に渡す（2a）。見つけて何もしないなら、測る意味がない。
  • 術後に新規発症した心房細動は「一過性」ではない。非心臓手術後のPOAFは脳卒中HR 2.00、5年での再発39%。退院後3〜6か月の外来フォローは Class 1。
  • PCI後の待機期間は「何を入れたか」と「なぜ入れたか」で決まる。DES＋ACSなら12か月、DES＋慢性冠動脈疾患なら6か月、時間制約があれば3か月、1か月以内は有害。
  • β遮断薬は継続はするが、手術当日に始めてはいけない（3: Harm）。始めるなら7日以上前。
  • CIED は「臍より上のEMI」と「ペースメーカ依存か」の2問で対応が決まる。そして術後、退院前に必ず設定を戻す（戻し忘れによる突然死が報告されている）。
  • COR と LOE は必ずセットで読む。弁膜症・肺高血圧・LVAD・HCM の推奨はほぼ C-LD/C-EO、すなわち専門家意見である。
  • GLP-1受容体作動薬は推奨表に入っていない。それでも実務への影響は最大級であるという非対称を意識して院内文書を作る。
