  • ただし「捨てる」のではなく、1点だけ実務に残す。 本稿が正しく突いたのは、PEEPを上げる根拠は「酸素化が悪いこと」ではなく「開く肺があること」である、という原則である。COVIDか否かに関わらず、高PEEPの前提はリクルータビリティであって低酸素の重さではない。
  • 判定に使う指標を決めておく。 本稿が挙げた指標のうち、当院でそのまま使えるのは次の2つ。①シャント分画の計算（本稿は「酸素化を評価する最良の手段」と書く）、②EtCO₂／PaCO₂比（1未満ならシャントと死腔の増大を示唆）。当院の重症呼吸不全の記録票にこの2つを入れる価値はある。
  • PEEP上げの中止基準を血行動態に置く。 本稿はPEEPを上げる過程で SvO₂（混合静脈血酸素飽和度）が低下したら心拍出量が不足しており、それ以上のPEEPは無意味と明記し、心エコーでの右心評価を推奨している。これは分類論と独立に妥当な運用で、当院の高PEEP試行手順に組み込める。
  • 一回換気量 7〜8 mL/kg を「本稿が許した」という理由で採用しない。本稿は type 1 に限り 7〜8 mL/kg・呼吸数20回/分以下を提案するが、アウトカムデータはゼロである。当院は 4〜8 mL/kg PBW・駆動圧15 cmH₂O未満・プラトー圧30 cmH₂O未満の標準を維持する。
  • 腹臥位を「コンプライアンスが良いから」という理由で省略しない。 本稿は type 1 での長時間腹臥位を「利益がごく小さく、スタッフの疲弊を招く」と否定するが、反論側の2本はいずれもこれを退けている。当院は P/F 150 mmHg未満なら禁忌がない限り腹臥位を維持する（→ 🫁 ARDSに対する腹臥位療法 Home）。
  • 本稿から確実に引き継ぐべき唯一の実務は、非挿管患者での吸気努力の評価である。食道内圧スイングが理想、不可能なら呼吸努力の臨床徴候を丁寧に診る。これは分類論の当否と無関係に有用で、当院のHFNC／NPPV運用の判定軸にできる。

🧭 この論文の位置づけ（Known / Unknown / What's new）

補足

リサーチ・イン・コンテキスト

  • Known（既に分かっていたこと）：ARDSは両側性浸潤影と心不全で説明できない低酸素血症を特徴とする症候群で、ベルリン定義（JAMA 2012）で分類される。従来型ARDSでは低酸素血症の主因は無気肺・含気消失に由来する右左シャントであり、肺は小さく硬い（baby lung）。低一回換気量が死亡を減らすこと（ARMA試験）、重症例で腹臥位が死亡を減らすこと（PROSEVA）は確立していた。
  • Unknown（分かっていなかったこと）：2020年3月時点で、COVID-19肺炎がベルリン定義を満たすにもかかわらず「重度の低酸素血症と、ほぼ保たれた呼吸器系コンプライアンスの共存」という奇妙な組み合わせを示すという臨床印象が北イタリアから広がっていた。この印象が本物なのか、本物ならば換気管理を変えるべきなのかは、まったく検証されていなかった。
  • What's new（本稿の新規性・意義）：COVID-19肺炎を単一の病態として扱うのをやめ、2つの型（type 1／type 2）に分けて別々の呼吸管理を当てるという枠組みを提示した。type 1 では高PEEPを避け一回換気量を緩めてよい、type 2 は通常の重症ARDS管理、という具体的な設定値まで踏み込んだ点が、当時の実務に大きな影響を与えた。同時に、type 1 から type 2 への移行を P-SILI が加速しうるという主張を通じて「早期挿管」論の理論的支柱になった。ただし本稿は論説であり、この枠組みを支える患者数も、アウトカムデータも、本稿には示されていない。

📌 全体要約

要旨

ひとことで COVID-19肺炎はベルリン定義を満たしてもなお「特異な疾患」であり、その本質は低酸素血症の重さと、比較的良好に保たれた呼吸力学との乖離である。著者らは患者を type 1（非ARDS的・コンプライアンス50 mL/cmH₂O超）と type 2（ARDS的・40 mL/cmH₂O未満） に分け、type 1 には低いPEEP（8〜10 cmH₂O）と緩い一回換気量（7〜8 mL/kg）を、type 2 には通常の重症ARDS管理を提案した。

  • 出発点：COVID-19肺炎はほとんどの場合ベルリン定義のARDSに当てはまる。それでも「特異な疾患（a specific disease）」であり、独特のフェノタイプを持つ、と著者らは主張する。
  • 主要な特徴：低酸素血症の重症度と、比較的良好な呼吸力学の維持との乖離（dissociation）。呼吸器系コンプライアンスの中央値は通常 約50 mL/cmH₂O。
  • 著者らが強調する観察：コンプライアンスが中央値より低い患者も高い患者も、低酸素血症の重症度は同程度である。
  • 提案する2型：type 1（"non-ARDS"） と type 2（ARDS） で病態生理が異なる。入院時点ではCTで明瞭に区別できる。CTが使えない場合、コンプライアンスと（可能なら）PEEPへの反応が「不完全な代替指標」になる。
  • type 1（コンプライアンス50 mL/cmH₂O超）：肺のガス容積は高く、リクルータビリティは最小。低酸素血症は低酸素性肺血管攣縮（HPV）の消失と肺血流調節の破綻によると考えられ、主因は換気血流不均衡。高PEEPと腹臥位は虚脱肺の再開通ではなく肺血流の再分布によって酸素化を改善する。CTでリクルートできる領域はほとんど無いのに、右左の静脈血混合は典型的に約50%に達する。
  • type 2（コンプライアンス40 mL/cmH₂O未満）：ICUに入室したCOVID-19患者の 20〜30%。重症ARDSに相当する。低コンプライアンスは疾患の自然経過による可能性もあるが、初期の呼吸管理に起因する部分（浮腫の増加）を否定できない。ICU入室前にCPAPやNIVを受け、非常に高い呼吸ドライブ・強い吸気努力・著しく陰性の胸腔内圧を呈していた患者が含まれる。したがってウイルス性肺炎に加えて self-inflicted ventilator-induced lung injury（P-SILI） を持つと考えられる。
  • ICU前の管理：患者が殺到する状況ではCPAPとNIVが第一選択。しかしケアの鍵は呼吸ドライブと吸気努力の評価であり、理想は食道内圧スイングの測定。呼吸窮迫があれば、type 1 から type 2 への移行を避けるために気管挿管を強く考慮すべき。
  • ICU内の管理（type 1）：PEEPは 8〜10 cmH₂O に制限（それ以上はコンプライアンスを下げ右心機能に影響）。一回換気量は 6 mL/kg に縛らず 7〜8 mL/kg でよい。呼吸数は 20回/分を超えない。腹臥位は救済手段としてのみ。患者を「静かに」しておき、何としても介入することよりも、やり過ぎないことの利益が大きい。
  • ICU内の管理（type 2）：重症ARDSの標準治療（低一回換気量・腹臥位・相対的に高いPEEP）。PEEPは 14〜15 cmH₂O まで慎重に段階的に上げてよいが、SvO₂の低下は心拍出量不足を示唆し、それ以上のPEEPは有用でない。心エコーで右心機能を評価する。
  • 共通の管理：シャント分画の計算が酸素化評価の最良の手段。EtCO₂／PaCO₂ 比が1未満ならシャントと死腔の増大を示唆。一酸化窒素（NO）は type 1（血管麻痺）には効かず、肺高血圧のありうる type 2 には効く可能性。両型ともDダイマーを毎日確認し、適応があれば慎重に抗凝固する。
  • 本稿が示していないもの：観察された患者数、追跡アウトカム、統計解析、前向き検証は一つも示されていない。著者貢献欄には「本稿の着想は、ICU内外で治療した多数のCOVID-19患者の直接観察から導かれた」とのみ記されている。

📖 詳細

1. まず前提 — なぜ「コンプライアンスが良いのに低酸素」が問題なのか（初めての人にも）🧩

要旨

5分で背景を掴む ARDS（acute respiratory distress syndrome、急性呼吸窮迫症候群）：両側性の肺浸潤影と、心原性肺水腫では説明できない低酸素血症を特徴とする症候群。単一の疾患ではなく、肺炎・敗血症・外傷など多様な原因の共通の終着点である。重症度は P/F比（PaO₂/FiO₂） で層別する。

呼吸器系コンプライアンス（Crs）：肺と胸郭の「膨らみやすさ」。Crs＝一回換気量÷（プラトー圧−PEEP）、単位は mL/cmH₂O。健常成人ではおよそ 80〜100。従来型ARDSでは使える肺（baby lung）が小さくなるため 30前後まで落ちる。コンプライアンスは実質的に「換気に参加している肺の量」を測っている。

シャントと静脈血混合：肺胞ガスと接触せずに肺を通過してしまう血流の割合が シャント（shunt）。真のシャントと換気血流不均衡を合わせた見かけの値を 静脈血混合（venous admixture） と呼ぶ。従来型ARDSでは「潰れた肺胞にも血流が流れる」ことが低酸素の主因なので、非含気肺の割合が多いほど低酸素が重いという相関が成り立つ。

低酸素性肺血管攣縮（HPV, hypoxic pulmonary vasoconstriction）：肺の一部が低酸素になると、その領域の血管が収縮して血流を減らし、酸素のある領域へ血流を振り向ける生体の自動調節。これが働かなければ、潰れていない肺でも「換気されない場所に血が流れる」状態が生じ、低酸素になる。

リクルータビリティ（recruitability）：PEEPを上げたときに再開通する肺胞の量。PEEPが効くには「開くべき潰れた肺」が必要であり、それが無ければPEEPは過膨張と血行動態悪化を招くだけになる。

P-SILI（patient self-inflicted lung injury、患者自己誘発性肺傷害）：非挿管の患者が強い吸気努力を続けると、胸腔内圧が大きく陰性になり経肺圧が過大になって、人工呼吸器がなくても肺を傷害しうるという概念。「だから早く挿管すべきだ」という主張の理論的根拠になった。

本稿の論争的な位置：もし「肺が潰れていないのに低酸素」なのだとしたら、原因はシャントではなく血流分布の異常ということになり、PEEPを上げても開く肺がないので高PEEPは無駄で有害という結論が導かれる。従来型ARDSの標準（低一回換気量・高めのPEEP・腹臥位）を一部で逆転させる提案なので、当時から激しい論争になった。

本稿の体裁：エディトリアル（論説）。原著データ・統計解析・アウトカムは含まれない。

2. 背景と目的 🫁

本稿は一文の宣言から始まる。COVID-19肺炎はベルリン定義のARDSを満たしうるにもかかわらず、独特のフェノタイプを持つ特異な疾患である。

その「主要な特徴（main characteristic）」として著者らが挙げるのは、次の一点に尽きる。

  • 低酸素血症の重症度と、比較的良好な呼吸力学の維持との乖離（dissociation）

具体的には、呼吸器系コンプライアンスの中央値が 通常およそ 50 mL/cmH₂O である、と述べる。従来型ARDSの典型値（30前後）と比べれば明らかに高い。

そして著者らは、この主張の裏付けとして一つの観察を添える。

  • コンプライアンスが中央値より低い患者も、高い患者も、同程度の重症度の低酸素血症を経験する

この一文は本稿の論理の要でもあり、同時に最大の弱点でもある（→ §15 論点3）。「コンプライアンスの高低が低酸素の重さを説明しない」からこそ「コンプライアンス以外の機序（血流分布）が主役だ」という推論が成り立つ一方で、その同じ事実は「コンプライアンスで患者を2つに割る意味が薄い」ことも同時に意味している。

そこから著者らは、病態生理の異なる2型の患者が存在するという仮説を提案する。区別の手段は次のとおり。

手段本稿の評価
胸部CT入院時点で type 1 と type 2 を明瞭に区別できる（Fig. 1）
呼吸器系コンプライアンスCTが無い場合の代替。原文は "imperfect surrogates"（不完全な代替指標） と明記

4. Type 1 — 「ほぼ正常なコンプライアンスを伴う孤立性ウイルス性肺炎」🫧

原文の見出しは "Type 1: Near normal pulmonary compliance with isolated viral pneumonia"。著者らはこの型を "non-ARDS" と括弧書きしている。

■ 定義

  • 重度の低酸素血症が、呼吸器系コンプライアンス 50 mL/cmH₂O 超と併存する

■ 肺の状態

  • 肺のガス容積は高い
  • リクルータビリティは最小（minimal）

■ 低酸素血症の機序

低酸素血症は「おそらく（likely）」次の2つによる、と著者らは述べる。

  1. 低酸素性肺血管攣縮（HPV）の消失
  2. 肺血流調節の障害

したがって、重度の低酸素血症は主として換気血流（VA/Q）不均衡による。

■ 高PEEPと腹臥位はなぜ効くのか（著者らの説明）

  • 高PEEPと腹臥位は、虚脱領域のリクルートメントによって酸素化を改善するのではない
  • 肺血流を再分布させ、換気血流の関係を改善することによって酸素化を改善する

■ 一見矛盾する所見

  • これらの患者の胸部CTは「リクルートできる有意な領域が存在しない」ことを裏付ける
  • にもかかわらず、右左の静脈血混合は典型的に約50%に達する

この「開く肺が無いのに血液の半分がシャントしている」という組み合わせが、type 1 を従来型ARDSと決定的に分ける、というのが本稿の主張の核である。

5. Type 2 — 「低下したコンプライアンス」🧱

原文の見出しは "Type 2: Decreased pulmonary compliance"。著者らはこの型を ARDS と括弧書きしている。

■ 定義と頻度

  • ICUに入室したCOVID-19患者の 20〜30%
  • 重度の低酸素血症が コンプライアンス 40 mL/cmH₂O 未満と併存し、重症ARDSを示す
  • この記述には文献[3]（Maiolo ら、AJRCCM 2018『Reclassifying acute respiratory distress syndrome』）が付されている

■ 低コンプライアンスの由来（著者らの両論併記）

原文は明確に両方の可能性を並べている。

可能性原文の書き方
疾患の自然経過「低いコンプライアンス（すなわち低いガス容積と増加したリクルータビリティ）が疾患の自然な進展によることは確かにありうる」
初期呼吸管理による医原性「しかし、この程度の傷害（浮腫の増加）が初期の呼吸管理に部分的に起因する可能性を、我々は排除できない」

■ 医原性を疑う根拠

著者らが挙げるのは、ICU入室前の観察である。これらの低酸素患者の一部は、

  • ICU入室前に CPAP または非侵襲的換気（NIV） を受けている
  • 非常に高い呼吸ドライブを呈する
  • 力強い吸気努力（vigorous inspiratory efforts） を示す
  • 著しく陰性の胸腔内圧を生じている

したがって、ウイルス性肺炎に加えて self-inflicted ventilator-induced lung injury を持っている可能性が高い、と結論する（文献[4] Brochard・Slutsky・Pesenti、AJRCCM 2017）。

なお原文のこの語は "self-inflicted ventilator-induced lung injury" というP-SILIとVILIを合成した独特の表現であり、一般に流通している "patient self-inflicted lung injury (P-SILI)" とは字面が異なる。意味するところは同じである。

7. 「L型／H型」の4軸定義 — 姉妹論文（ICM 2020）からの補足 🔤

補足

このセクションの出典は本稿ではない 本稿（Crit Care 2020;24:154）は type 1／type 2 という語しか使わない。日本の集中治療で流通した L型（Type L）／H型（Type H） という名称と、4つの軸による定義は、同じ著者グループが同月に *Intensive Care Medicine* に発表した姉妹エディトリアル Gattinoni L, Chiumello D, Caironi P, Busana M, Romitti F, Brazzi L, Camporota L. COVID-19 pneumonia: different respiratory treatments for different phenotypes? *Intensive Care Med*. 2020;46:1099–1102. doi:10.1007/s00134-020-06033-2（PMID 32291463／PMC7154064）に由来する。以下はそのICM論文の本文に基づく。本稿の主張と混ぜないため、セクションを分けて示す。

■ ICM論文が挙げる「型を決める3因子」

同一の病原体（SARS-CoV-2）でありながら患者像が大きく異なる理由として、ICM論文は3つの因子の相互作用を挙げる。

  1. 感染の重症度・宿主反応・生理学的予備能・併存疾患
  2. 低酸素血症に対する患者の換気応答性
  3. 発症から病院で観察されるまでの経過時間

この3因子の相互作用が「時間に関連した疾患スペクトラム」を生み、その両端に2つの一次フェノタイプが立つ、という構成である。

8. 「type 1 から type 2 へ移行する」という主張とその根拠 ⏳

本稿における移行の主張は、次の2箇所に現れる。

■ 移行を示唆する記述①（type 2 の成り立ち）

type 2 の低コンプライアンスについて、著者らは「この程度の傷害（浮腫の増加）が、初期の呼吸管理に部分的に起因する可能性を排除できない」と書く。ICU入室前にCPAP／NIVを受け、高い呼吸ドライブと強い吸気努力、著しく陰性の胸腔内圧を呈していた患者が含まれるからである。

■ 移行を示唆する記述②（挿管の適応）

ICU前の管理を論じる箇所で、著者らは端的にこう書く。「呼吸窮迫が存在するならば、自己誘発性肺傷害による type 1 から type 2 への移行を避ける／制限するために、気管挿管を強く考慮すべきである」。

■ 根拠の中身

本稿がこの移行仮説のために提示している根拠は、次の3つに尽きる。

  1. ICU入室前の患者に、高い呼吸ドライブと強い吸気努力が観察されたという臨床印象
  2. P-SILIの概念論文（Brochard L, Slutsky A, Pesenti A. AJRCCM 2017;195:438–442）の引用1件
  3. 姉妹論文（ICM 2020）における 同一患者2時点のCT（Fig. 1a→1b、7日間の変化）1例

つまり、移行の存在を示す縦断データは症例1例分であり、移行を防げることを示すデータは存在しない。姉妹論文はさらに踏み込み、食道内圧スイングが5〜10 cmH₂O なら一般に忍容されるが、15 cmH₂O を超えると肺傷害のリスクが増すのでできるだけ早く挿管すべき、という数値基準まで示す。この閾値も検証されたものではない。

この移行仮説が「早期挿管」論の理論的支柱になり、パンデミック初期の世界的な挿管方針に影響した。その方針が正しかったかどうかは、本Vaultの COVID-19急性呼吸不全でHFNOは早期挿管より人工呼吸器フリー日を8日増やす（36施設・PSマッチ122例・CritCare2021） や COVID-19の挿管タイミングもHFNC使用も死亡と関連しない（アトランタ4病院175例・CCM2020） などで別途扱っている。

9. 提案された管理（ICU入室前・非挿管患者）🚑

■ 第一選択

患者が病院に殺到する状況では、CPAPとNIVが第一選択である。これらはしばしばICU外（救急外来や一般病棟）で適用され、通常は血液酸素化を改善する。

■ しかしケアの鍵は別にある

  • ケアの重要な側面は、呼吸ドライブと吸気努力の評価であるべき
  • 理想的な指標は食道内圧スイングの測定
  • 不可能であれば、吸気努力の臨床徴候を注意深く精査すべき

■ 挿管の適応

  • 呼吸窮迫が存在すれば、気管挿管を強く考慮すべき
  • 目的は、自己誘発性肺傷害による type 1 → type 2 の移行を避ける／制限すること

酸素化ではなく吸気努力を挿管判断の軸に置くという発想は、この論説の中で最も後世に残った部分である。

■ なぜ「三すくみ」なのか（どれが何に勝ち、何に負けるか）

  • ① は ② に対して個別症例で強い。コンプライアンス80 mL/cmH₂O の患者が実在する以上、その患者に高PEEPをかけることの害は② の枠組みでは記述しにくい。
  • ② は ① に対して集団データで圧倒的に強い。1654例 対 約150例（うち公表された定量記述は32例）という差は、統計的にも社会的にも決着に近い。
  • ③ は ② の批判を吸収できる。「あなたの1654例は進行後を、我々の症例は発症直後を見ている」と言えば、中央値の食い違いは矛盾でなくなる。実際 ② の論説は「いずれもベースライン測定だからタイミングでは説明できない」と書くが、「ベースライン」の定義は研究ごとに異なり、発症からの日数は揃っていない。ここは ② の論証の最も弱い部分である。
  • しかし ③ は ② の要求そのものには答えられない。② が突きつけたのは「亜型を主張するなら、それが管理を変えることを前向きに示せ」である。病期で切る枠組みも、病期を前向きに判定して治療を割り付けたRCTを一つも持たない。
  • そして ③ は ① を実質的に取り下げてもいる。「2つの型」ではなく「1つの疾患の連続的な時間経過」だと言い直した時点で、本稿の「type 1／type 2 という並存する2型」という主張は著者自身によって置き換えられた。

つまり三者はそれぞれ他をひとつずつ崩せるが、誰も「前向き検証」という同じ壁を越えていない。決着がついていない理由はここにある。

13. その後どうなったか — 2021〜2026年からの振り返り 🕰️

Vault内の完全版ノートに基づいて、この論争の帰趨を整理する。

■ ① 換気管理：COVID専用のアルゴリズムは残らなかった

COVID-19の集中治療 — この4年の到達点と積み残し（RECENT ADVANCES・ICM2023） に至るまでに、COVID-19専用の換気戦略は標準として残らなかった。低一回換気量・低駆動圧・P/F 150未満での腹臥位・個別化PEEPという枠組みがそのまま適用されている。本稿の type 1 に対する提案（PEEP 8〜10、VT 7〜8 mL/kg、腹臥位は救済のみ）を採用したガイドラインは存在しない。

■ ② フェノタイプ別治療は、ARDS全体で今も前向き検証がゼロ

ARDSの内科的マネジメント — 定義・フェノタイプ・換気設定と非換気治療の到達点（ナラティブレビュー・ICM2026） は、ARDS領域の主要研究者らによる2026年時点の到達点として次のように整理する。

  • 生物学的フェノタイプ（低炎症型／高炎症型）は、臨床試験の外では利用可能でも推奨もされていない
  • フェノタイプ別に治療効果が違うという所見は、すべて陰性・不確定に終わった試験の事後解析（post hoc）由来であり、前向きに検証した試験は一つもない
  • LIVE試験の教訓：CTで直接見える「肺形態」という比較的単純なフェノタイプですら、前向きの分類には誤りが生じ、その誤分類は害と関連した

最後の点は本稿にとって深刻である。本稿は CTによる分類を推奨し、CTが無ければコンプライアンスで代用せよと述べる。LIVE試験は、まさにその「CTで肺形態を分類して換気を変える」戦略を前向きに検証し、全体で利益なし・誤分類は害と関連という結果を出した。

■ ③ COVID-19に固有のサブフェノタイプも仮説の段階にとどまった

COVID-19の3つのサブフェノタイプと回復期血漿の治療効果の差（REMAP-CAP二次解析・ICM2022） は、1239例のバイオマーカーから3群を同定し、回復期血漿の治療効果が層で異なる可能性を示した（不均一性の検定 p = 0.008）。しかし、

  • サブフェノタイプ1：OR 1.05（0.81–1.36）
  • サブフェノタイプ2：OR 0.66（0.37–1.19）
  • サブフェノタイプ3：OR 0.71（0.45–1.12）

と、3群すべてで信頼区間が1を跨いでいる。言えるのは「交互作用があるかもしれない」までである。

■ ④ 「変えるべきだ」を前向きに証明できたのはステロイドだった

一方で、COVID-19が実際にARDS管理を変えた領域はある。デキサメタゾンは大規模RCTで検証されて標準治療になった（COVID-19に対するデキサメタゾン（RECOVERY試験・NEJM2020） ／ 重症COVID-19へのステロイド投与と死亡率（WHO REACTメタ解析））。反論側の論説が「提案された管理変更を検証した優れた例」と名指ししたのはこれである。要求水準を満たしたのは薬剤であって、フェノタイプ別換気ではなかった。

15. 批判的吟味（JCでの論点）🔍

■ 論点1：2020年前半のCOVID文献という文脈

本稿は 2020年3月24日受理・4月7日受理決定・4月16日公開。北イタリアの第1波の最中に、受理まで14日で世に出た。この時期のCOVID文献は、症例数が少なく、査読が異例に速く、後に覆ったものが多い。本稿はその典型例であり、論説（peer-reviewed だが原著ではない）という形式が、データの薄さを制度的に許容している。JCではまず「これは仮説の提示であって、知見の報告ではない」という位置づけを固定したい。

■ 論点2：一般論を立てた n が本稿には存在しない

これが最大の論点である。本稿には患者数が一行も書かれていない。定量値が付いているのは Figure 1 の2症例だけ。「ICU入室患者の20〜30%が type 2」という頻度の記述にも、本稿内に分母がない。分母は姉妹論文の "our series" と「著者らが測定した150例」という表現にしか現れず、その150例は一次データとして公表されていない。世界の換気設定に影響した枠組みが、この規模の未公表観察に立脚していた事実は、それ自体がJCの主題になる。

■ 論点3：本稿は自らの分類の根拠を、自ら否定する一文を含んでいる

本稿の冒頭には、著者らが強調のために置いた一文がある。「注目すべきは、コンプライアンスが中央値より低い患者も高い患者も、同程度の重症度の低酸素血症を経験することである」。

この一文は「低酸素の機序はコンプライアンスでは説明できない」という主張のために置かれている。ところが同じ一文は、コンプライアンスで患者を2つに割っても、説明したい当の現象（低酸素の重さ）は分かれないことも意味している。分類変数が、その分類で説明しようとしている結果と関連しないのなら、その分類は何を予測しているのかが問われる。JCではこの内的緊張を最初に指摘したい。

■ 論点4：連続量の両端に名前を付けただけではないか

本稿の閾値は type 1 が「50超」、type 2 が「40未満」 である。そして本文は中央値が約50だと述べている。すなわち、

  • 分布の中央値のすぐ上を「type 1」と呼んでいるため、定義上おおよそ半数が type 1 に入る
  • 40〜50 の帯には名前がない。ここに入る患者をどう扱うかは本稿に書かれていない
  • 2つの型を分ける「谷」の存在（双峰性）は、本稿でも姉妹論文でも一度も示されていない

分布が単峰性の連続量であるなら、これは両端に名前を付けた記述であって、生物学的に異なる2つの実体の同定ではない。ARDSのフェノタイプ研究が潜在クラス分析などでデータ駆動的にクラスの数を決める手続きを取るのに対し、本稿の分類は閾値を先に置いている。この方法論上の違いは、後の議論のすれ違いの一因になった。

■ 論点5：この分類に基づいて管理を変えたRCTは存在するか

存在しない。 2026年時点で、type 1／type 2（あるいは Type L／Type H）に前向きに割り付けて換気戦略を変え、アウトカムを比較したRCTは報告されていない。最も近い前向き検証は LIVE試験（CTによる肺形態フェノタイプに基づく個別化換気、Lancet Respir Med 2019）だが、結果は全体で利益なし、かつ誤分類が害の増加と関連であった（→ ARDSの内科的マネジメント — 定義・フェノタイプ・換気設定と非換気治療の到達点（ナラティブレビュー・ICM2026））。本稿はCTでの分類を推奨しているのだから、LIVE試験の結果は本稿の戦略に最も直接的に不利な前向きデータである。

■ 論点6：Figure 1 の2症例は主張を証明していない

Figure 1 は本稿の唯一の実証的支柱だが、次の限界がある。

  • n=2。しかも type 1 症例のコンプライアンスは 80 と、本稿が示す中央値50から大きく外れた極端例
  • 静脈血混合が type 1 で56%、type 2 で49% と逆転しているが、本稿はこの逆転に一言も触れていない。もし type 2 の低酸素が「非含気肺による右左シャント」で説明されるなら、非含気39%の type 2 のほうが静脈血混合が高くなるはずである
  • 2例は別々の患者であり、経時変化ではない。「type 1 が type 2 に移行する」という主張の証拠にはならない

■ 論点7：姉妹論文との数値の不整合

姉妹論文（ICM 2020）は Type H の肺重量を 「1.5 kg超、重症ARDSと同じ桁」と定義する。しかし本稿 Figure 1 の type 2 症例の肺重量は 1441 g であり、この基準を満たさない。同じ著者グループが同月に出した2本の間で、代表症例が自らの定義を満たしていない。細部ではあるが、定義が事後的に整えられた痕跡と読める。

■ 論点8：P-SILI 因果の循環

本稿は「type 2 の患者はICU前にCPAP／NIVを受け、高い吸気努力を示していた。ゆえに P-SILI が浮腫を増やした可能性がある」と論じる。しかし同じ観察は「重症だからCPAP／NIVが必要になり、重症だから吸気努力が強かった」という逆向きの説明とも完全に両立する。本稿はこの交絡を検討していない。にもかかわらず結論は「移行を防ぐために早期挿管」という介入の推奨にまで進んでいる。観察の方向性が不明なまま、介入を推奨したという点が、この論説の論証上の最大の飛躍である。

■ 論点9：引用の当て方

  • type 2 の「20〜30%・コンプライアンス40未満は重症ARDS」に付された文献[3]は Maiolo ら AJRCCM 2018、すなわちパンデミック前のARDS再分類研究である。COVID-19における頻度を支持する文献ではない
  • type 1 で 6 mL/kg 超でも安全とする根拠に付された文献[5]は ARMA試験（NEJM 2000） である。ARMA は低一回換気量が死亡を減らすことを示した試験であり、「高い換気量でも安全」を支持する方向には使えない
  • 全7文献のうちCOVID-19に関する原著は1件も含まれていない

■ 論点10：利益相反の記載

原文の記載は "Competing interests: Not applicable." である。通常は "None declared"（申告なし）と書く欄に「該当なし」と書かれている。実質的な問題ではないかもしれないが、この時期の投稿の慌ただしさを示す痕跡として読める。

■ 論点11：それでも本稿を読む価値はどこにあるか

批判を並べたうえで、公平に評価しておきたい点が2つある。①「PEEPが効くには開く肺が要る」という原則を、パンデミックのただ中で臨床医に強く意識させた功績は大きい。反論側もこの原則自体は共有している。②挿管の判断軸を酸素化から吸気努力へ移すという発想は、その後のP-SILI研究と呼吸ドライブ研究の出発点になった。間違っていたのは「2つの型に割る」という操作化であって、その背後の生理学的着眼ではない、という整理がJCとしては最も生産的だと考える。
