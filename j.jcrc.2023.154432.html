🏥 聖路加ICUでの実践への示唆

聖路加ICUでの実践

明日からどうするか ① 当院のJIPAD入力で「血液ガス」と「アルブミン」の欠測率を今すぐ確認する。 欠測が多い施設ほど予測死亡が低く出て、SMRが高く（＝成績が悪く）見える。 本研究では血ガス欠測 10.3%、アルブミン欠測 10.1% が全体平均で、施設間のばらつきが大きいのはこの2項目。当院の欠測率が全国平均より高ければ、当院のSMRは実力より悪く表示されている可能性がある。

② なぜそうなるのか（機序）を理解しておく。 死亡予測モデルは欠測変数を「正常」とみなす。 たとえばアルブミンが欠測なら急性生理学スコア（APS）は0点になり、APACHE III ではアルブミンが 2.5–4.4 g/dL の正常範囲だったことにされる。 したがって急性生理学変数が欠測すると予測死亡率は下がり、SMR（＝観察死亡÷予測死亡）は上がる。

③ 「その検査を測らない」という診療方針が、そのまま質指標のペナルティになる。 著者の指摘：ICUによっては血ガスやアルブミンを意図的に測定しないことがある。APACHE III の APS に含まれるこれらの検査を測らないICUは、成績が悪いとみなされうる。 当院で「不要な採血を減らす」方針を進めるなら、JIPAD入力への影響を同時に評価する必要がある。

④ JRODはアルブミン欠測に対しては頑健だった。 アルブミン欠測が多い施設でSMRが上がらなかったのは JROD モデルだけ（APACHE III では上がった）。 当院のSMRを報告するとき、JROD 側の数値の方が欠測の影響を受けにくいことを知っておく。

⑤ 24時間尿量の欠測が最も強い死亡関連因子だった。 APACHE III で OR 1.90（95%CI 1.17–2.97）、JROD で OR 1.88（1.18–2.87）。 頻度は低いが、欠測していること自体が「重症・混乱した症例」のマーカーになっている可能性がある。入力漏れとして見過ごさない。

⑥ 著者の結論は運用への直接の指示になっている。 > 臨床医とICU管理者は、患者の死亡リスクとICUパフォーマンスを正確に評価するために、血液ガスとアルブミンのデータを利用可能にすべきである。そうでなければ、APS に血ガスやアルブミンを含まないモデルを検討すべきである。

3点で掴む Known（既に分かっていたこと）

  • APACHE や SAPS といった一般的重症度スコアリングシステムはICUで広く使われ、パフォーマンスと効率の評価のベンチマークを提供する。

📖 詳細

1. まず前提 — なぜ「測らない」ことがSMRを悪化させるのか

要旨

初学者向けの基礎 重症度スコアの「欠測＝正常」ルール 死亡予測モデルは一般に、欠測変数を正常とみなす。 具体例（本論文の記述そのまま）：アルブミンが欠測なら急性生理学スコア（APS）は0点になり、APACHE III ではアルブミン値が正常（2.5–4.4 g/dL＝25–44 g/L）だったものとして扱われる。

その帰結

  1. 急性生理学変数が欠測する → APS が実際より低くなる
  2. → 予測死亡率が低くなる
  3. → SMR（＝観察死亡数 ÷ 予測死亡数）の分母が小さくなる
  4. → SMR が高くなる＝「予測より多く死んでいる＝成績が悪い」ように見える

つまり「検査を測らない」という診療方針が、そのまま質指標のペナルティに転化する。 これが本論文の問題意識。

APS（acute physiology score／急性生理学スコア）に含まれる変数（本研究が扱ったもの） 脈拍、平均血圧、体温、呼吸数、動脈血液ガス（PaO₂・FiO₂・pH・PaCO₂）、白血球数、GCS、24時間尿量、ヘマトクリット、クレアチニン、BUN、ナトリウム、アルブミン、ビリルビン、血糖

Brier score：予測死亡率と観察転帰の差の二乗の平均。0〜1で小さいほど較正が良い。 注意：本研究では「欠測があると Brier score が下がる」という一見よさそうな現象が起きている。これは較正が良くなったのではなく、予測が全体に低い方へ寄って「めったに死なない」という予測が当たりやすくなっただけと読むべき（死亡率が低い集団では、全員に低い確率を割り当てると Brier score は下がる）。

較正ベルト（calibration belt）：較正曲線に信頼区間を付けて帯状に表示したもの。モデルがどの予測確率の範囲で誤較正しているかを判別できる。

2. 背景

  • APACHE や SAPS といった重症度スコアリングシステムはICUで広く使われ、患者転帰の予測とICUのパフォーマンス・効率評価のベンチマークを提供する
  • しかしこれらのモデルの性能は時間とともに劣化し、ケースミックスも変わるため、性能改善の調整がしばしば必要
  • APACHE III-j（1998年に更新された APACHE III の版）は日本のICUで広く使われるが、死亡リスクを観察死亡率の2倍以上に過大評価する
  • そこで2021年に APACHE III-j から JROD が作られ、良好なモデル性能を示した
  • モデル性能の経時的劣化に加えて、重症度スコアにおける急性生理学変数の欠測もモデル性能に影響する
  • しかし、どの欠測変数が従来の APACHE III と較正済みの JROD に影響するのかは不明のままだった。
⚠ 注意

著者の問題提起 血液ガスやアルブミンといった検査データは、一部のICUでは意図的に測定されないことがある。APACHE III の APS に含まれるこれらの検査を測定しないICUは、パフォーマンスが悪いとみなされうる。

3. 方法（Methods）

3-1. データ

JIPAD（日本集中治療医学会が設立した日本最大のICU患者臨床レジストリ）。

  • 2022年7月時点で 99 ICU が参加、28万人超の患者情報
  • APACHE II の死亡リスク算出に必要な臨床重症度情報を含む。成人には APACHE III・SAPS II・JROD、小児には PIM 2・PIM 3 を使用
  • データは医師・看護師・医療補助者が手入力するか、電子カルテから自動取得される。いずれの方法でも、データはローカルソフトウェアで検証されマスターデータベースにアップロードされ、その後 JIPADワーキンググループが定期的に確認する

3-2. 対象

組み入れ：2015年4月〜2019年3月にICU入室した16歳以上で、ICU在室が24時間以上 除外：退院時転帰または予測死亡データの欠測

3-3. 変数

APS変数：脈拍、平均血圧、体温、呼吸数、動脈血液ガス（PaO₂・FiO₂・pH・PaCO₂）、白血球数、GCS、24時間尿量、ヘマトクリット、クレアチニン、BUN、ナトリウム、アルブミン、ビリルビン、血糖

その他：入室区分、入室元（手術室・救急外来・同一病院の病棟や他ケアユニット・他院からの転送）、慢性疾患、疾患カテゴリ

各患者の APACHE III-j スコアと JROD スコアを抽出し、院内死亡の予測と、ICU退室時・退院時の生存状況を得た。 施設別の欠測割合を検討するため、各患者データを匿名化された施設番号に紐づけた。

3-4. 統計解析

  1. 欠測の数とカテゴリ別に、APACHE III と JROD の観察・予測死亡率と SMR を算出
  2. ABG・アルブミン・血糖・ビリルビンの欠測割合を施設ごとに算出してプロット
  3. 各カテゴリについて、予測死亡数と、施設の欠測割合に対するSMRの平滑化スプライン曲線を算出
  4. 較正プロットと Brier score を、ABG・アルブミン・血糖・ビリルビンの欠測あり/なしで算出。信頼区間を較正ベルトとしてプロットし、モデルが誤較正している範囲を判別
  5. 多重ロジスティック回帰で、欠測変数と死亡の関連を検討（APACHE III・JROD 両モデルの予測死亡率で調整）

R 4.2.0。P<0.05 を有意。

5. 考察

5-1. 主要な発見

  • APACHE III・JROD の SMR は、欠測値の数が増えるにつれて上昇する傾向があった。
  • ABG とアルブミンの欠測率は約10%で、他のカテゴリより高かった。
  • これらの欠測は予測死亡率を偽性に低下させ、両モデルでSMRを上昇させた。
  • APACHE III の SMR は、ABG とアルブミンの欠測が多い施設で高かった。

5-2. なぜ正確な予測モデルが必要か

> 患者の死亡リスクを評価しICUのパフォーマンスを評価するには、正確な予測モデルを使うことが不可欠である。APACHE III や SAPS 3 のような重症度スコアリングシステムはICUで広く使われている。しかしこれらのモデルの性能は時間とともに劣化する。

6. 限界（著者の記載を原文の慎重さのまま）

  1. 本研究は日本の選ばれたICUで実施されたため、結果は他国に一般化できないかもしれない。
  2. 日本最大のICUレジストリのデータを用いたが、レジストリへの参加は義務ではない。したがって、患者の予後評価とICUパフォーマンスに関心のある活動的なICUだけがこのレジストリに参加している。こうした評価に消極的なICUは、ABG やアルブミンの欠測について異なるパターンを持つ可能性があり、欠測データの評価結果に影響しうる。より広いスペクトラムのICUで、モデルが同様に APS 変数の欠測の影響を受けるかを判定するには、さらなる研究が必要である。

7. 結論（著者の言葉に沿って）

> APACHE III および較正済み JROD モデルにおける生理学的変数の欠測は、偽性に低い予測死亡率と高いSMRをもたらした。 血液ガスとアルブミンの欠測割合が高い施設は、APACHE III における予測死亡率とSMRの評価にも影響を与えた。 > > 臨床医とICU管理者は、患者の死亡リスクとICUパフォーマンスを正確に評価するために、血液ガスとアルブミンのデータを利用可能にすべきである。そうでなければ、APS に ABG やアルブミンのデータを含まないモデルを検討すべきである。

🔍 批判的吟味（JCでの論点）

⚠ 注意

① 「欠測がSMRを上げる」ことと「欠測の多い施設の質が実際に低い」ことを分離できていない 施設レベルで「欠測割合が高い → SMRが高い」という関連が示されたが、「測らない施設は他の面でも診療が粗い」という交絡を否定できない。 本研究は施設の他の特性（規模・専従医数・看護配置）で調整していない。「欠測がSMRを歪めている」のか「欠測の多い施設は本当に成績が悪い」のかは、この解析では決着しない。

⚠ 注意

② Brier score の「低下」を良い方に読んではいけない 欠測があると Brier score が下がる（＝一見よくなる）が、これは較正が改善したのではなく、予測が全体に低い方へ寄って「めったに死なない」という予測が当たりやすくなっただけ。 死亡率が低い集団では、全員に低い確率を割り当てるだけで Brier score は下がる。著者はこの点を明示的に注意喚起していない。

  • ③ JROD がアルブミン欠測に頑健だった理由が説明されていない。 「アルブミン欠測が多い施設でSMRが上がらなかったのは JROD のみ」「Brier score もアルブミン欠測では低下しなかった」という2つの所見は一貫しているが、なぜそうなるのかの機序は論じられていない。 JROD が階層GAMで施設ランダム切片を持つことと関係する可能性があるが、本論文では検討されていない。
  • ④ 24時間尿量の欠測が最強（OR約1.9）なのに、施設レベルの解析対象に入っていない。 Figure 2・3 で扱われたのは ABG・アルブミン・血糖・ビリルビンの4つのみ。 尿量は頻度が低い（<1%）ためと思われるが、最も強い関連を示した変数が施設分析から外れているのは一貫性を欠く。
  • ⑤ 「レジストリに参加するのは熱心なICUだけ」という限界②は重い。 つまり本研究が観察した欠測率（ABG 10.3%・アルブミン 10.1%）は、日本のICU全体では過小評価である可能性が高い。 実際の全国のSMRの歪みは、本研究が示すより大きいかもしれない。
  • ⑥ 手入力と自動取得が混在している。 方法に「医師・看護師・医療補助者が手入力するか、電子カルテから自動取得される」と明記されている。 入力方式そのものが欠測パターンを規定しているはずだが、方式別の解析はない。→ DPC×JIPAD検証が示した「JIPADも手入力の限界を抱える」という論点と直結する。
  • ⑦ 対象期間が2015–2019年。 ==JRODの開発コホート（2018年度）と重なる。== 開発に使ったデータで欠測の影響を評価している部分があり、独立性は完全ではない。
  • ⑧ 実務的な帰結の重さ。 著者の結論「そうでなければ、APS に ABG やアルブミンを含まないモデルを検討すべき」は、「測らない施設のために、測る施設の情報を捨てたモデルを作れ」という提案でもある。 質評価の公平性と予測精度のトレードオフを、どこで取るかという問題を提起している。

✅ Take home message

TAKE HOME

まとめ

  1. 死亡予測モデルは欠測変数を「正常」とみなす。 だから測らないほど予測死亡が下がり、SMRが上がる（＝成績が悪く見える）。
  2. JIPAD の 61,357例で、約5人に1人が1つ以上の欠測を持つ。 最も多いのは ABG 10.3%・アルブミン 10.1%で、施設間のばらつきもこの2項目が突出している。
  3. 欠測が多い施設ほどSMRが高い（APACHE III・JROD とも）。ただしアルブミン欠測に対しては JROD だけが頑健だった。
  4. 予測死亡率で調整しても、欠測自体が死亡と関連する：24時間尿量 OR 約1.9、アルブミン OR 1.30（APACHE III）／1.16（JROD）、ABG OR 1.17（APACHE III のみ）。
  5. 「不要な採血を減らす」という診療方針が、そのまま質指標のペナルティになる。 当院でJIPADの欠測率を点検し、SMRの解釈に反映すべき。
  6. 著者の運用への指示：血ガスとアルブミンのデータを利用可能にせよ。できないなら、それらを含まないモデルを検討せよ。
  7. APACHE III-j 予測 22.8% 対 実測 11.3%、JROD 予測 11.3% 対 実測 11.3% ＝ JROD の較正の良さが独立コホートで再現された。
