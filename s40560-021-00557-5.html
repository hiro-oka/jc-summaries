🏥 聖路加ICUでの実践への示唆

聖路加ICUでの実践

明日からどうするか ① パンデミック期のICU成績を SMR で語ってはいけない。 COVID-19患者では APACHE II・SAPS II・APACHE III-j がいずれも死亡を過大評価し（SMR 0.52・0.56・0.55）、JROD は逆に過小評価する（SMR 1.15）。 感染症の流行期に病床の多くを特定疾患が占めると、SMRが施設の質ではなく患者構成を反映してしまう。

② 識別能そのものが落ちる（AUROC 0.70前後）ことの意味。 通常のICU集団では APACHE III-j の AUROC は 0.915 だった。COVID-19では 0.70–0.72 に落ちる。「誰が危ないか」を並べる能力自体が失われている。 較正のずれ（過大/過小評価）は再較正で直せるが、識別能は各予測因子の係数を更新するか新しい予測因子を加えないと改善しない。

③ 当院の年次QIレポートで2020–2021年度のSMRを扱うときの注記。 当院の JIPAD レポートでも該当年度は COVID-19 症例を含む。その年度のSMRを他年度と単純に比較しない。 本論文が「その年に何が起きていたか」の公式な説明になる。

④ 新興感染症のたびに同じ問題が起きる。 著者の指摘：逼迫したICUには新しいリスクスコアを導出・検証する時間がない。 だから既存のスコアを使わざるを得ない。次のパンデミックに備えるなら、「モデルが壊れることを前提に、質評価をいったん凍結する運用ルール」を先に決めておくべき。

⑤ 重症度スコアの限界を研修医教育で教える題材になる。 「APACHE II が16点だから死亡率30%」と言えない状況が現実に起きた、という具体例。スコアは開発集団の写像でしかない。

補足

3点で掴む Known（既に分かっていたこと）

  • COVID-19パンデミックの開始以降、世界中のICUが、他の患者とはまったく異なる治療アプローチを要する患者の治療に苦闘してきた。
  • COVID-19患者向けの新しいリスク予測モデルは開発されていたが、その多くはICU患者に特化して開発されたものではなく、モデル開発研究と同じ性能を実臨床で発揮するかも不明だった。
  • 英国からの1本のレター（Stephens ら）が、APACHE II が死亡リスクを過小評価したと報告し、パンデミック前に広く使われていたリスクスコアは COVID-19 の臨床重症度評価に不適切と結論していた。

Unknown（分かっていなかったこと）

  • ICU患者向けに開発された従来のリスクスコアが COVID-19 患者に適用できるかは不明だった。 予測性能が分からないため、医療者は臨床重症度の評価とICUの医療の質のモニタリングに困難を抱えていた。
  • 日本で開発されたばかりの JROD も、パンデミック前のデータで開発され、ICUの一般的用途を想定していたため、COVID-19患者での妥当性は限定的かもしれなかった。

What's new（本研究の新規性）

  • APACHE II・SAPS II・APACHE III-j・JROD の4つを、同一のCOVID-19 ICUコホートで横並び比較した。
  • 識別能も較正も、いずれのモデルでも不良であることを示した。
  • 英国の報告とは推定リスクの方向が逆（英国＝過小評価、日本＝過大評価）でありながら、同じ結論（パンデミック前のモデルは不適切）に至った。

📖 詳細

1. まず前提 — なぜパンデミックでリスクスコアが壊れるのか

要旨

初学者向けの基礎 リスク予測モデルは「開発集団の写像」である。 開発時の患者構成（ケースミックス）、疾患の生物学、治療の内容が変われば、予測は当たらなくなる。COVID-19 は3つすべてを同時に変えた。

本研究に登場する4つのモデル

モデル特徴
APACHE II1985年開発。急性生理学スコア＋年齢＋慢性疾患。世界で最も広く使われる
SAPS II（Simplified Acute Physiology Score II）1993年開発。欧州発の簡易版
APACHE III-jAPACHE III の日本版。日本のICUで広く使われるが、日本人集団で死亡を2倍以上に過大評価する
JROD（Japan Risk of Death）APACHE III-j を JIPAD データで再較正した日本版モデル。→ JROD 日本版死亡リスク予測モデル — APACHE III-jの過大評価を階層GAMで補正（JIPAD 33557例・JIntensiveCare2021）

識別能と較正（再掲）

  • 識別能（AUROC）＝死ぬ人と死なない人を順位づけできるか。壊れると「誰が危ないか」が分からなくなる
  • 較正＝予測確率の絶対値が実際と合っているか。壊れると「何%死ぬか」がずれる

この違いが本論文の核心。 較正のずれは JROD 論文で使われたような簡単な更新法（切片・傾きの再較正）で直せる。しかし識別能は、各予測因子の係数を更新するか、他の関連予測因子を加えないと改善しない。

較正プロットの読み方

  • 傾き1・切片0が完全較正
  • 傾きが1より小さい＝モデルがリスクを「広げすぎ」ている（高リスク者を高く言いすぎ、低リスク者を低く言いすぎ）
  • 切片が負＝全体として過大評価

SMR＝観察死亡数 ÷ 予測死亡数。1.0 が「予測どおり」。1未満は予測より良い（＝モデルが過大評価している可能性も含む）。

2. 背景 — パンデミック下でICUが直面した「測れない」問題

COVID-19患者は他の患者とまったく異なる治療アプローチを要する。 多くの重症例がICUに入室したが、ICU患者向けに開発された従来のリスクスコアリングシステムが COVID-19 患者に適用できるかは不明だった。

その結果として何が起きたか

  • 予測性能が不明なまま、医療者は ①患者の臨床重症度の評価と ②ICUの医療の質のモニタリングの両方で困難に直面した

新しいモデルは作られたが

  • COVID-19患者向けの新しいリスク予測モデルは開発された
  • しかしその多くはICU患者に特化して開発されたものではない
  • モデル開発研究と同じ性能を実臨床で発揮するかも不明
⚠ 注意

著者の重要な現実認識 逼迫したICUには、新規のリスクスコアを導出し検証する時間がない可能性が高い。そうした状況では、ICUは APACHE や SAPS といった従来のスコアリングシステムを使わざるを得ない。 実際、いくつかの最近の研究が COVID-19 の臨床重症度の情報を提供するために APACHE と SAPS を用いている。しかし、それらを COVID-19 患者に適用する妥当性を検討した報告はごくわずかしかない。

英国からの先行報告（Stephens ら）

  • APACHE II が死亡リスクを過小評価した
  • 結論：パンデミック前に広く使われていたリスクスコアリングシステムは、COVID-19 の臨床重症度の評価には不適切

日本の状況

  • 研究グループが最近 JROD（APACHE III-j を再較正した予測モデル）を開発したところだった
  • しかし JROD はパンデミック前に収集されたデータで開発され、ICUでの一般的用途を想定して設計されたため、COVID-19患者では妥当性が限定的かもしれない

そこで本研究は、APACHE II・SAPS II・APACHE III-j・JROD が COVID-19 患者に適用できるかを調べ、その予測性能を判定した。

3. 方法（Methods）

  • データ：JIPAD から、2020年1月〜2021年2月に入室した COVID-19 確定例を抽出
  • JROD の適用方法：先行研究（JROD論文）と同じ方法で死亡を予測。ただし開発期間を2019年1月〜12月に設定。これを研究コホートに適用したものを JROD2019 予測死亡率と定義
  • 評価指標：
  • AUROC（識別能）
  • Brier score（識別能＋較正）
  • Hosmer–Lemeshow 検定（較正）
  • 較正プロット（較正の視覚化）
  • 標準化死亡比 SMR（質評価への適用可能性）
図の解説

JROD2019 という工夫 元の JROD は2018年度データで較正されていた。本研究では「パンデミック直前の2019年で較正したモデル」を作り直して当てている。 つまり「時期のずれ」という交絡をできるだけ排除したうえで、それでも COVID-19 では機能しないことを示した。モデルが古いから当たらないのではなく、疾患が違うから当たらないという論証になっている。

4-2. モデル性能（Table 2・Figure 1）

識別能（AUROC）：4モデルとも 0.70前後。JROD2019 が最も良いが 0.718 で、95%CI の下限は 0.654。 通常のICU集団で APACHE III-j が示す 0.915 とは比べものにならない。

⚠ 注意

SMR の解釈が完全に反転する 同じ444例について、APACHE II で評価すると SMR 0.52（＝予測の半分しか死んでいない＝優秀）、JROD2019 で評価すると SMR 1.15（＝予測より多く死んでいる）。 どちらも間違っている。 モデルの較正が壊れているから、SMR はもはや医療の質を測っていない。質評価のために SMR を出すこと自体が無意味になる、というのが本論文の実務的な帰結。

5. 考察

5-1. 英国の報告と方向は逆、結論は同じ

  • 英国（Stephens ら）：APACHE II が過小評価
  • 本研究（日本）：APACHE II・SAPS II・APACHE III-j が過大評価、JROD2019 が過小評価

推定リスクの方向（過大評価/過小評価）は先行報告と異なるが、パンデミック前に使われていたリスクモデルは COVID-19 患者に適していないという同じ結論に至る。

図の解説

方向が逆になる理由（本文には明示されていないが重要） 日本の COVID-19 ICU 患者の実死亡率が英国よりはるかに低かった（15.5% 対 その2倍超）ことが、同じモデルを当てても「過大評価」と「過小評価」に分かれた直接の理由。 医療提供体制・入室基準・患者背景の国際差が、そのままモデルの当たり外れの方向を決めている。

5-2. JROD すら救えなかった

> 特筆すべきは、APACHE III-j の予測能力を改善するために開発された JROD2019 でさえ、最適とはいえない予測性能を示したことである。

5-3. 質評価ツールが使えなくなる

予測性能が悪いため、これらのリスクモデルで算出した予測死亡率を、ファネルプロットや指数加重移動平均（EWMA）チャートといった質評価ツールに、高い信頼性をもって組み込むことは難しい。

その結果： > とくに COVID-19 患者がICU病床の高い割合を占めるICUでは、医療の質の評価と改善を実施することが困難になる。

5-4. 較正は直せるが、識別能は直せない

著者の最も技術的に重要な指摘：

> 較正は、JROD研究で行われたような簡単な更新法で改善できる。しかし識別能は、各予測因子の係数を更新するか、他の関連する予測因子を追加することによってしか改善できない。

したがって： > COVID-19患者向けに特別に設計された改訂リスク予測モデルと、それをICUに実装するためのロジスティックな支援が、緊急に必要である。

6. 限界

図の解説

レターゆえの制約 本論文は Letter to the Editor であり、限界を独立したセクションとして記述していない。読み手が自分で補う必要がある。以下は本文の記述から導かれる制約である。

  • 444例・40ICUは、リスクモデルの検証としては小さい。とくに死亡69例では、較正プロットの各分位に含まれるイベント数が少ない
  • 2020年1月〜2021年2月という初期のパンデミック期のデータ。変異株・ワクチン・デキサメタゾンやトシリズマブといった治療の標準化以前であり、その後の COVID-19 患者には当てはまらない可能性がある
  • COVID-19 特化型モデルの開発は行っていない（問題提起にとどまる）
  • JIPAD 参加40ICU が日本の COVID-19 診療を代表するかは不明

7. 結論（著者の言葉に沿って）

モデルの識別能と較正はいずれも不良であった。COVID-19患者の臨床重症度を評価し、COVID-19患者で圧迫されたICUにおける医療の質をモニタリングするためには、改訂されたリスク予測モデルが必要である。

🔍 批判的吟味（JCでの論点）

⚠ 注意

① 「モデルが悪い」のか「集団が違う」のか 本論文が示したのは「COVID-19患者にこれらのモデルを当てると当たらない」という事実であって、「なぜ当たらないか」の機序は検討されていない。 考えられる原因は複数ある：①COVID-19の生理学的異常が APACHE の変数（酸素化・循環・意識）に十分反映されない、②治療（ECMO・長期人工呼吸）が予後を大きく変える、③入室基準が施設・時期で大きく違う。どれが主因かで、必要な「改訂」の中身がまったく変わる。

⚠ 注意

② 識別能 AUROC 0.70 を「不良」と呼ぶかは文脈次第 通常のICU集団の 0.915 と比べれば大幅な低下だが、COVID-19という単一疾患に絞った集団では、集団の均質性が上がるぶん AUROC が下がるのは統計的に当然（spectrum effect）。 「疾患を絞れば AUROC は下がる」ことと「モデルが壊れた」ことは区別すべきで、本論文はここを論じていない。JCの最大の論点になりうる。

  • ③ SMR 0.52 と 1.15 のどちらが真実に近いのか。 本論文は「どちらも信用するな」と言うだけで、では何を使えばよいかを示していない。 実務者が明日から使える代替がない。著者も「改訂モデルが緊急に必要」と述べるにとどまる。
  • ④ 死亡率15.5%という日本の成績をどう読むか。 英国の半分未満。APACHE II スコアは同等。 これは①日本のICU入室基準が緩かった（軽症も入室）、②医療の質が高かった、③人口構成・肥満率の差、のいずれとも解釈できる。本論文はこの差を説明していないが、実はこれ自体が最も興味深い所見である。
  • ⑤ JROD2019 という再較正でも救えなかったことの含意。 較正だけを直す「軽い更新法」は、JROD論文で「大半の定期更新にはこれで十分」と主張されていた。本論文はその主張の限界を、同じ著者グループが自ら示したことになる。 論文どうしの関係として読むと面白い。
  • ⑥ 較正プロットの傾きが 0.47–0.78 と一様に小さい。 単なる過大/過小評価ではなく、「リスクの広がりを大きく見積もりすぎている」形の崩れ。 切片だけを直しても解決しない種類の問題で、著者の「識別能は係数更新でしか直らない」という指摘と整合する。
  • ⑦ 444例で4モデル×5指標を評価している。 多重比較の調整はないが、本研究はモデル選択ではなく「どれもダメ」を示すのが目的なので、この点は致命的ではない。 ただし「JROD2019 が最も良い」という順位づけは、95%CIが大きく重なるので主張できない。

✅ Take home message

TAKE HOME

まとめ

  1. COVID-19患者では、APACHE II・SAPS II・APACHE III-j・JROD のいずれも識別能（AUROC 0.70前後）と較正（H-L 検定 すべて p<0.001）が不良。
  2. SMR は 0.52（APACHE II）から 1.15（JROD2019）まで、使うモデルで完全に反転する。 パンデミック期の SMR で施設の質は語れない。
  3. 日本の COVID-19 ICU 患者の院内死亡は 15.5% で、APACHE II スコアが同等の英国コホートの半分未満だった。
  4. 較正は簡単な更新法で直せるが、識別能は各予測因子の係数更新か新規予測因子の追加でしか直せない。 ここが本論文の技術的な核心。
  5. 逼迫したICUに新しいスコアを導出・検証する時間はない。 だから既存スコアを使わざるを得ず、その結果として質評価が成立しなくなる。この構造的問題を先に想定しておく必要がある。
  6. 自分たちが作った JROD が機能しないと自ら報告した点で、JIPADワーキンググループの科学的誠実さを示す論文でもある。
