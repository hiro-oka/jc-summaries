🏥 聖路加ICUでの実践への示唆

聖路加ICUでの実践

病棟プロトコルへの落とし込み

  • 抑制率そのものを目標値にしない。まず「誰が決めたか・記録があるか」を測る。 本研究で最も衝撃的なのは抑制率8%ではなく、抑制の決定者の63%が看護師単独で、35%は署名済みの医師指示すら存在しなかったという運用実態である。当院でも「抑制の有無」ではなく 決定プロセスの可視化（指示の有無・指示者・理由・再評価時刻）を監査項目にする。
  • 抑制の85%は「他者への危険」ではなく「患者自身の危険」を理由としている。 さらにその内訳は、実際に危険行動があった例はごく一部（41例中5例）で、大半は「危険がありうる」という予防的（pre-emptive）抑制だった。当院でも「自己抜管を予防するため」という理由づけが自動的に抑制を正当化していないか、指示の文言レベルで点検する価値がある。
  • 家族への通知を標準手順に組み込む。 本研究で近親者に通知されていたのは38%のみ、40%は通知の有無すら不明だった。当院では抑制開始時に家族へ説明し、その記録を残す運用を明文化する（説明できない抑制は続けない）。
  • 1日の抑制時間が長い。 抑制患者の46%は研究日のうち12時間以上抑制されており、中央値13時間だった。「一時的な処置」のつもりが実質終日になる。シフトごとの再評価と自動解除（デフォルトで解除・継続には理由を要する）をルール化する。
  • 抑制を減らす最大の構造要因は人員配置である可能性が高い。 著者らは豪NZの低い抑制率の一因を、人工呼吸患者に対して通常1:1という看護配置に帰している。当院で抑制削減を議論する際は、教育やプロトコルだけでなく 夜勤帯の看護配置・観察体制とセットで論じる。
  • 抑制の代替として、せん妄の予防・早期発見、鎮痛優先の鎮静、早期離床、家族の面会時間拡大を先に置く。抑制はこれらが尽きたあとの最終手段として位置づける。

🧭 この論文の位置づけ（Known / Unknown / What's new）

補足

リサーチ・イン・コンテキスト

  • Known（既に分かっていたこと）：ICUでの身体抑制の実施率は国によって大きく異なり、「ほとんどの患者に抑制を行う国」から「まったく使わない国」まで幅がある。豪州・ニュージーランドでは10年前のポイントプリバレンス研究でICU患者の7%が抑制されていたと報告されていた。
  • Unknown（分かっていなかったこと）：その7%という数字以外に、誰がどのような理由で・どれくらいの時間・どのような指示のもとに抑制しているのかという運用の詳細はほとんど記述されていなかった。また10年間で実施率が変化したのかも不明だった。
  • What's new（本研究の新規性・意義）：44施設627例のポイントプリバレンス研究により、抑制率は8%と10年前からほぼ不変であること、抑制患者の大半は人工呼吸中で「自分自身への危険」を理由とし、決定は主に看護師が行い、医師指示の署名は半数程度にとどまることを示した。抑制を「する／しない」ではなく、多職種による共同意思決定と記録という運用課題として提示した点が新しい。

📌 全体要約

要旨

ひとことで 豪州・ニュージーランドのICUでは 13人に1人（8%）が身体抑制を受けており、その割合は10年前から変わっていない。抑制患者の88%が人工呼吸中、85%は「患者自身への危険」が理由で、決定は63%が看護師、35%は署名済みの医師指示がなく、家族に通知されていたのは38%にとどまった。

  • デザイン：ANZICS CTG Point Prevalence Program の一環として2019年の指定3日間（6月4日・19日・26日）に実施されたポイントプリバレンス研究。
  • 規模：44 ICU（豪州36・ニュージーランド8）、16歳以上の入室患者627例。
  • 主要アウトカム：24時間の研究期間中に一度でも身体抑制を受けた患者数。
  • 結果：48例（8%）が抑制。うち42例（88%）が人工呼吸中、24例（50%）が神経系の入室診断。精神保健法（Mental Health Act）下で扱われた患者は皆無。
  • 抑制の様態：35例（73%）で2か所以上の身体部位が抑制され、研究日の抑制時間の中央値は 13時間（IQR 7〜24）。
  • 運用：抑制の決定者は 看護師30例（63%）、ICUレジストラ11例（23%）、ICUコンサルタント4例（8%）。医師の指示があったのは25例（52%）のみ、署名済み指示なしが17例（35%）。
  • 施設体制：不穏・不隠状態への対応スタッフ教育がある施設は 31施設（70%）、抑制に関するガイドラインがある施設は 36施設（82%）（最終改訂からの中央値15か月）。
  • 著者の結論：抑制の是非を個人が単独で判断するのではなく、多職種による共同意思決定と、さらなる研究が必要である。

📖 詳細

1. まず前提 — 身体抑制とは何が問題なのか（初めての人にも）🧩

要旨

5分で背景を掴む 身体抑制（physical restraint） とは、患者の身体の動きを器具や拘束具によって制限する行為を指す。ICUでは典型的に、気管チューブ・中心静脈カテーテル・ドレーンといった生命維持デバイスの自己抜去を防ぐ目的で、手首（ミトン・抑制帯）や体幹に用いられる。 問題は3つある。第一に、抑制は患者の自律（autonomy）を制限する行為であり、法的・倫理的な正当化を必要とする。第二に、抑制自体が害を生む（皮膚損傷・神経障害、不動による筋力低下、そしてせん妄の増悪や心的外傷）。第三に、抑制は「本当に必要か」を客観的に判定しにくい——実際に危険な行動が起きたから抑制するのか、起きるかもしれないから抑制するのかで意味がまったく異なる。 ここで出てくる用語をひとつ定義しておく。ポイントプリバレンス研究（point prevalence study） とは、ある特定の日に「その瞬間に入院しているすべての患者」を横断的に調べる方法で、施設をまたいだ実際の診療実態（practice pattern）を捉えるのに向いている。因果関係は分からないが、「現場で実際に何が行われているか」を測るには最も直接的な手法である。ANZICS CTG はこの手法を定期的に回すプログラムを持っており、本研究もその一環である。 なお、抑制の頻度は医療文化に強く依存する。ICUの看護配置（豪NZでは人工呼吸患者に1:1が標準）、鎮静の深さの文化、法制度（精神保健法の適用範囲）が異なれば、同じ「抑制率」でも意味が変わる。

2. 背景と目的 🫁

ICUにおける身体抑制の実施率は国によって極端に異なる。ほとんどのICU患者に抑制を行う国がある一方で、まったく使用しないと報告する国もある。豪州・ニュージーランドでは10年前のポイントプリバレンス研究でICU患者の7%が身体抑制を受けていたと報告されたが、その研究は抑制の使われ方についてほとんど詳細を提供していなかった。

そこで著者らは、(1) この10年で抑制の実施率が変化したか、(2) 抑制が実際にどのように使われているかを明らかにする目的で本研究を行った。

3. 方法（Methods）📐

  • デザイン：ANZICS Clinical Trials Group の Point Prevalence Program の枠組みで行われた前向きポイントプリバレンス研究。
  • 対象（組み入れ・除外）：2019年の指定3日間（6月4日・19日・26日）のいずれかに、参加ICUに在室していた16歳以上のすべての患者。参加各施設で人を対象とする研究の倫理委員会承認を得て、患者同意は免除された。
  • データ収集：各施設のICU研究スタッフがデータを収集し、研究センターへ提出した。
  • 主要アウトカム：24時間の研究期間中のいずれかの時点で身体抑制が適用された患者数。
  • 副次的に収集した項目：抑制を適用する決定を誰が行ったか、理由、抑制の持続時間、指示（オーダー）の有無と署名者、近親者への通知の有無、およびそのICUが抑制適用に関するプロトコルを持っているか。
  • 解析：記述統計（中央値[四分位範囲]、n（%））。
⚠ 注意

臨床上の要注意ポイント 本研究では抑制による有害事象は収集されていない。したがって「抑制は8%で行われており大きな害はなかった」とは読めない。 著者自身が「身体抑制はリスクがないわけではなく、患者の自律を侵害しうる」と明記しているが、その害の大きさは本研究のデザインでは評価できない。抑制の是非を論じる際にこの論文を「安全性の根拠」として引用してはならない。

4. 結果 💧

臨床疑問：豪州・ニュージーランドのICUでは、どれくらいの患者が、誰の判断で、どのような理由と手続きのもとに身体抑制を受けているのか。

参加規模と抑制率

  • 44 ICU（豪州36・ニュージーランド8） が 627例 のデータを提供した。
  • そのうち 48例（8%） が身体抑制を受けていた（およそ 13人に1人）。

抑制された患者の特徴（n = 48）

  • 男性38例（79%）、年齢中央値 53歳（IQR 35〜64、範囲19〜86）、体重中央値 82 kg（IQR 68〜97、範囲55〜140）。
  • APACHE-II 平均17（SD 7）、慢性併存疾患ありは10例（21%）。
  • 研究日に人工呼吸を受けていたのは42例（88%）。
  • ICU入室診断が神経系だったのは24例（50%）（APACHE-IIIj コード 401–410、1501–1506、601、1601）。
  • 精神保健法（Mental Health Act）のもとで治療されていた患者はゼロ。

抑制の理由・様態・持続時間

  • 抑制の主たる理由は 「患者自身への危険」41例（85%）。この内訳は、予防的に抑制した「自分自身に危険を及ぼす可能性がある」29例、実際に危険な行動を示した5例、その他／医療デバイスの抜去防止 7例。
  • 「他者への危険」はわずか 2例（4%）、「医療処置の実施」3例（6%）、不明2例（4%）。
  • 2か所以上の身体部位に抑制が適用されたのは35例（73%）（抑制点数2か所が33例〈69%〉、4か所が2例〈4%〉、1か所が10例〈21%〉）。
  • 抑制のエピソード回数は 1回38例（79%）、2回5例（10%）、3回1例（2%）。
  • 研究日における総抑制時間の中央値は13時間（IQR 7〜24）。区分別では 0〜6時間 8例（17%）、6〜12時間 9例（19%）、12〜18時間 10例（21%）、18〜24時間 12例（25%）。

誰が決め、どう記録されていたか

  • 抑制を適用する決定を主に行ったのは ICU看護師30例（63%）、ICUレジストラ11例（23%）、ICUコンサルタント4例（8%）。精神科医・精神科看護師による決定はゼロ。
  • 抑制の医師指示（オーダー）が存在したのは25例（52%）にとどまる。署名者はICUレジストラ18例（38%）、ICUコンサルタント7例（15%）、看護師2例（4%）で、署名済み指示なしが17例（35%）。
  • 近親者に抑制を通知していたのは18例（38%）、通知していない11例（23%）、不明19例（40%）。

施設側の体制

  • 不穏・不隠（restlessness/agitation）への対応に関するスタッフ教育を提供している施設は 31施設（70%）。
  • 抑制適用のガイドラインを持つ施設は 36施設（82%）（最終改訂からの経過期間の中央値 15か月、IQR 6〜35）。

28日時点の転帰（抑制された48例）

  • 生存退院 29例（60%）、一般病棟に在院中13例（27%）、ICU在室中4例（8%）、死亡2例（4%）。

5. 著者の考察と限界 🧠

著者らは、豪NZのICU患者のおよそ13人に1人が身体抑制を受けており、これは10年前とほぼ同じ割合であると述べている。この値は世界の他地域からの報告よりは低いものの、抑制された患者の大半が人工呼吸中で、他者ではなく自分自身への危険を理由とし、医師指示の記録率が低いという点は他地域の報告と共通していた。

豪NZで抑制率が低い理由として著者らが挙げるのは、人工呼吸患者に対して通常1:1という看護配置である。他地域よりも手厚い配置が、物理的な拘束の代わりに人による見守りを可能にしている可能性がある。

限界としては、抑制による有害事象が収集されていないこと、ポイントプリバレンス研究であるため因果関係や経時変化を追えないこと、そして近親者への通知の有無が40%で不明であるようにデータの欠測が一定量あることが挙げられる。

著者らの結論は、これらのデータが 「ICU患者の身体抑制に関する多職種間の共同意思決定（inter-professional shared decision-making）」と、この診療実態に関するさらなる研究の必要性を後押しする というものである。

✅ Take home message

TAKE HOME

結論 豪NZのICUでは13人に1人（8%）が身体抑制を受け、その割合は10年間変わっていない。 重要なのは頻度ではなく運用である——決定の63%は看護師単独、35%は署名済み医師指示なし、家族への通知は38%のみ、抑制時間の中央値は13時間。抑制を減らす前に、まず「誰が決め、なぜ続け、いつ解除するか」を記録・共有する多職種プロセスを作ることが先である。
