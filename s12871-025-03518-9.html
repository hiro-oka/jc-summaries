  • Known（既に分かっていたこと）：敗血症・敗血症性ショックでは輸液が治療の柱である一方、体液貯留（fluid overload）が有害でありうることは繰り返し示されてきた。累積の正の水分バランスが高い患者ほど死亡・臓器不全が多いという観察研究は多数ある。一方、輸液戦略の RCT（CLASSIC・CLOVERS）は、制限的アプローチの一貫した死亡改善を示していない。
  • Unknown（分かっていなかったこと）：観察研究群を横断的に統合したとき、「達成された水分バランス（achieved fluid balance）」と死亡の関連はどの程度の大きさか。水分バランスの指標（絶対値・体重補正値・累積・日次）や評価する時間窓の違いが、効果推定値と研究間異質性をどれだけ説明するのか。腎代替療法の必要性との関連はあるのか。
  • What's new（本研究の新規性・意義）：26研究・64,755例を統合し、①高い水分バランスは死亡のオッズを約2倍にする関連がある（OR 2.11、95%CI 1.65–2.69、I²=85%）、②その関連は時間窓や定義を変えてもおおむね一貫する、③一方で RRT/CRRT との関連は有意でない（OR 1.34、95%CI 0.76–2.36）、④用量反応はメタ回帰上は線形（スプラインでは非線形性は検出されず）、⑤研究レベルの因子では異質性を説明できない、⑥GRADE の確実性は両アウトカムとも very low、を示した。加えて Table 2 で「水分収支の計算に何を含めたか」を研究ごとに一覧化し、標準化の欠如を可視化したことが、効果量以上の貢献。

要旨

📖 詳細

1. まず前提 — 水分バランスという「曝露変数」の正体 🧩

要旨

5分で背景を掴む 水分バランス（fluid balance, FB） は「総入力 − 総出力」で定義される、ICU で最も日常的な体液量の指標。ただし本論文を読むうえでは、これが4つの異なる顔を持つことを先に押さえる必要がある。

  • 絶対値 FB（absolute FB）：指定した時間窓の正味の量（mL）。いちばん素朴な形
  • 体重補正 FB（indexed FB）：絶対値を体重で割った値（mL/kg）。体格差を吸収するが、体重の測定精度に依存する
  • 累積 FB（cumulative FB）：日々の正味バランスを窓の期間ぶん足し上げた値。何日目まで足すかで値は大きく変わる
  • 日次 FB（daily FB）：24時間単位の正味バランス

これに加えて、曝露を カテゴリ（categorical、閾値や四分位で「高／低」に切る） で扱うか 連続量（continuous） で扱うかの軸がある。本レビューはさらに、複数方式を併用した研究を mixed と分類している。

なぜ水分の貯め込みが悪いと考えられているか。生理学的には、①肺・脳・腸管をはじめとする臓器の浮腫による酸素拡散距離の延長と機能障害、②腹腔内圧上昇と静脈うっ血による腎灌流圧（＝平均動脈圧 − 中心静脈圧）の低下、③グリコカリックス障害と毛細血管漏出（capillary leak）による血管内から間質へのシフト、が挙げられる。ここから、蘇生（Resuscitation）→ 至適化（Optimization）→ 安定化（Stabilization）→ 除水（Evacuation）という ROSE モデル、および脱蘇生（de-resuscitation）の概念が生まれた（蘇生とde-resuscitationの進歩 — ROSE・GDFT・fluid stewardship・輸液蓄積症候群（CurrOpinCritCare2025））。

一方で本レビューが扱うのは、治療方針としての輸液戦略ではなく、結果として達成された水分バランスである。この区別が本論文の設計の核心にあたる。RCT（CLASSIC・CLOVERS）は「制限か通常か」という割り付けを比較しているのであって、達成された水分バランスという共通の曝露を標準化しているわけではない。だから著者は RCT をプールしなかった。

もうひとつ、本論文を読む前提として重要なのが 記録の精度である。水分バランスは検査値ではなく、人の手で足し引きされた帳簿である。動脈ライン洗浄、不感蒸泄、便中水分、発熱、開放腹部、数日かけて溜まって排液日にだけ引かれる胸水・腹水 — これらは容易に抜け落ちる。この点は 体液量評価_水分バランスと体重測定の精度（システマティックレビュー）（Davies 2019）が正面から扱っており、本論文も Discussion で「FB 記録の不正確さは報告されているが、本統合では定量できない」と述べている。

2. 背景と目的

敗血症・敗血症性ショックは ICU 入室の主要因であり、依然として高い罹患率・死亡率を伴う。修正可能かもしれない因子のひとつとして、重症病態の経過中に蓄積する水分バランスがリスクマーカーとして繰り返し検討されてきた。しかしその算出方法と報告様式は研究間で大きく異なる。

観察研究では、累積 FB が高い患者ほど死亡と臓器不全が多いと報告されてきたが、これらの関連は異質性が大きく、FB を「いつ」「どう」評価したか（固定時点の絶対値か、数日にわたる累積和か、体重で標準化した指標か）に敏感である。この違いを整理することが、既存文献の解釈と今後の研究設計の両方に必要である。

本レビューの目的は、①高い FB と死亡の関連を定量すること、②代替的な FB 指標や評価時間窓によって効果推定値と研究間異質性が変わるかを検討すること、③副次的に RRT の必要性との関連を探ること。著者は冒頭から「非ランダム化デザインに内在する限界を承知のうえで」と断りを入れている。

RCT については「輸液戦略という治療方針を対象にしており、達成された FB そのものを扱う本レビューとは関連はするが別の問い」と位置づけ、Discussion で文脈づけのために言及するにとどめ、因果推論には用いないと明言している。

3. 方法（Methods）

  • デザイン：システマティックレビュー＋メタ解析。PRISMA 2020 準拠（チェックリストは Table S1）。PROSPERO に前向き登録（CRD42024538393）
  • プロトコルの補足（著者による2点の釈明）
  • 研究タイプ：登録時には「介入研究」も適格候補として挙げていたが、プロトコル完成段階で「達成された FB を曝露とする定量統合」に絞ることを事前規定した。RCT は割り付けられた介入を評価しており、研究レベルで調和された達成 FB を通常報告しないため、ナラティブ要約にとどめプールから除外した
  • 統計解析：実施した解析（ランダム効果プール、影響診断、線形連続モデルと探索的スプラインモデルを含むメタ回帰、ファンネルプロットと Egger 検定による出版バイアス評価）は登録計画と整合。スプラインモデルは非線形性への対応として明示的に「探索的」とラベル
  • 情報源・検索：PubMed・Scopus・CINAHL を開始から 2024年5月28日まで。手作業での参考文献確認と関連メタ解析のスクリーニングを追加。投稿直前に更新検索を実施し、追加分は PRISMA フロー図に反映
  • 組み入れ基準：一次観察研究（前向き・後ろ向き、傾向スコア法の有無を問わない）で、達成された FB（FB = 総入力 − 総出力）と全死因死亡の関連を、ICU に入室した成人（18歳以上）の敗血症・敗血症性ショック患者で評価したもの。FB を曝露として定量（絶対・体重補正・累積・日次のいずれか）し、死亡（ICU・院内・28日・90日）を報告していること
  • 除外基準：質的研究、エディトリアル、コメンタリー、レター、学会抄録、症例報告、ガイドライン、レビュー（メタ解析の有無を問わない）、非英語論文、部分的な輸液指標のみを報告するもの（「輸液療法」「投与レジメン」「静注輸液」「輸液戦略」など出力を伴わないもの）、および定量的 FB を伴わず臨床的・画像的基準のみで定義された fluid overload
  • 選択・データ抽出：Covidence 上で実施。重複は自動除去。①タイトル／抄録スクリーニング、②全文スクリーニングの2段階で、3名（FF・IC・DO）が独立・盲検で実施。不一致は経験ある第4の研究者（TB）を交えて協議。抽出項目は著者名、年、国、デザイン、サンプルサイズ、集団特性（年齢・性別・併存症など）、FB の値、FB の算出方法、死亡アウトカム
  • バイアスリスク：2名（DO・FF）が独立に ROBINS-E（曝露に関する非ランダム化研究のバイアスリスク）を適用。「どの領域にも検出されず、第1領域のみ some concerns」なら低リスク。いずれかの領域で懸念が3つを超えれば高リスク、3領域を超えて高リスクなら very high risk。不一致は協議、必要に応じて第3者（IC）が裁定
  • 統計解析
  • 二値アウトカムに固定効果モデルとランダム効果モデルの両方を当てはめ、研究間異質性が大きいことからランダム効果推定値を主とした
  • オッズ比は逆分散法でプール。固定効果（Peto を含む）は感度分析扱い
  • 異質性は I²（および該当時は τ²）で定量
  • 影響診断とメタ回帰で異質性の源を探索
  • 小研究効果はファンネルプロットと Egger 検定で評価
  • GOSH（Graphical Display of Study Heterogeneity） にクラスタリングを組み合わせ、プール推定値に不釣り合いな影響を与える研究のサブグループを同定
  • 探索的用量反応：(i) 研究レベルの「高 FB 群に割り当てられた患者割合」を予測変数とする連続メタ回帰、(ii) その割合の三分位（Low / Medium / High）で層別するカテゴリカルメタ回帰。ランキングプロットはモデルベースの確率から導出し記述的に提示
  • ソフトウェア：R 4.3.2（meta、dmetar、metafor、splines ほか）
  • エビデンスの確実性：GRADE。観察研究のみのため初期確実性は low。方法論的限界・異質性でさらに格下げ、大きな効果・用量反応・残差交絡が関連を弱める方向であることを理由に格上げしうる

この最後の指摘は地味だが重い。生存者と死亡者で FB を比較する解析は、曝露から転帰への向きではなく転帰から曝露への向きで記述しており、オッズ比の解釈が変わる。

13. 考察 — 著者はどこまで言い、どこで留保したか

要旨：高 FB の患者は低 FB の患者に比べて死亡のオッズが約2倍だったが、RRT/CRRT との関連は有意でなかった。両アウトカムとも研究間異質性が大きく、メタ回帰では研究レベルの特性が異質性の意味ある部分を説明しなかった。

輸液実践そのもののばらつき：ESICM の FENICE 国際コホートは、輸液チャレンジの適応・量・速度・モニタリングが施設間で大きく異なり、動的指標や安全上限の使用がまれであることを示している。曝露そのものが標準化されていない領域である。

交絡が本丸：著者は「高い FB は治療効果というより、背景にある重症度のマーカーを反映している可能性がある」と述べ、観察デザインと重症度領域の調整が不完全なコホートが複数含まれることから、重症度による残差交絡はありうるとする。したがって高 FB と死亡の関連は因果ではなく仮説生成として扱うべき、というのが著者自身の位置づけ。

RCT との関係：CLASSIC と CLOVERS は、より制限的なアプローチの一貫した死亡改善を示していない（敗血症性ショックの輸液制限は90日死亡を減らさない（CLASSIC・NEJM2022）、敗血症性ショックの輸液制限は1年後の生存・QOL・認知機能も変えない（CLASSIC 1年追跡・ICM2023））。ただしこれらは「割り付けた戦略」を評価しており、達成された FB を共通の曝露として標準化していない。進行中の試験として ARISE FLUIDS（NCT04569942）と EVIS（NCT05179499）が挙げられている。

FB を計算する臨床的動機：組織灌流と酸素供給の維持という文脈で、体液過剰による有害事象（肺・脳その他の臓器浮腫）と、体液不足による酸素供給・細胞機能の障害の両方を避けることにある。ある後ろ向き研究は負の FB と生存改善の関連を報告した。敗血症・敗血症性ショックの発症直後により頻回に FB を計算すれば、悪化の早期同定と支持療法の前倒しにつながるかもしれない — ただしこれは仮説であり、本データからは確立されないと明記されている。

毛細血管漏出とサードスペース：重症病態では毛細血管漏出やサードスペースへのシフトが併存しうるが、直接定量が難しい。エコー所見や腹腔内圧モニタリングなどの間接的徴候から推測しうる。こうしたシフトは「見かけの低容量血症」を作り、さらなる輸液投与を促し、腎機能障害と相まって悪循環を生みうる（低容量血症と末梢浮腫が同居する理由 — 間質圧の低下とリンパポンプ不全という第2の機序（総説・CritCare2023））。

時間軸の重要性：時間窓別の層別で、最初の1〜2日では関連が有意でなく、2日を超える窓では一貫して有意だった。著者はこれを「FB 評価におけるタイミングの重要性」と読んでいる。

FB 測定の不正確さ（本ノートの核心のひとつ）：著者は「現時点で FB 決定の標準化・検証された方法は存在しない」「FB チャートの不正確さは報告されているが、本統合では定量できない」と明言し、精確な計上を妨げる要因を具体的に列挙している。

14. 限界（著者自身の記載）

  • 正の FB と死亡を扱う既発表論文の数が限られ、組み入れの大半が観察研究（後ろ向きまたは前向き）で比較的小規模だった
  • 輸液蘇生 対 制限の RCT（CLASSIC、CLOVERS）は存在するが、治療戦略を扱うもので達成 FB を直接評価していないため、プール解析に含めていない。この区別は解釈上明示されるべきである
  • 重症度による交絡が主要な限界。血行動態が不安定な患者、臓器障害の強い患者ほど多くの輸液を受けるため、高い FB はベースライン重症度の代理変数になりうる。重症度調整は研究間で不均一かつしばしば不完全で、残差交絡は排除できない
  • FB の算出・報告方法の異質性（入力・出力項目、敗血症発症からの評価タイミング、絶対値／体重補正／累積／日次の別）。サブグループ解析とメタ回帰で対処を試みたが、残差異質性は高いままだった
  • 時間軸に沿った標準化データの欠如。多くの研究は数日分または ICU 滞在全体の累積 FB のみを報告しており、本レビューの所見は主に「入院中の全体的な体液蓄積」を反映する。敗血症の早期蘇生期における輸液投与戦略の直接的な根拠にはならない
  • 病院前・救急搬送中に投与された輸液が一貫して捕捉されていたか確認できず、早期時点における達成 FB の曝露誤分類を招いた可能性がある
  • 多くの研究がショックのない敗血症と敗血症性ショックを区別せず、あるいはショック状態で層別せずに統合していた。ショック状態と血行動態のフェーズは輸液必要量と耐容性を修飾する可能性が高く、層別の欠如が異なる関連を覆い隠しているかもしれない
  • 適格研究数が比較的少ないため、非線形の用量反応や細かいサブグループ層別（評価タイミング、敗血症フェノタイプ）を検討する力が限られた。FB を連続予測変数とする探索的メタ回帰は生態学的バイアスと検出力不足を踏まえて慎重に解釈すべき
  • 初回のデータベース検索が PROSPERO 登録前に行われた点は方法論上の限界。投稿前に更新検索を実施した

15. 批判的吟味（JCでの論点）

⚠ 注意

この論文の最大の弱点 — 曝露変数そのものが測れていない 本レビューの曝露は「水分バランス」だが、その水分バランスの記録精度が疑わしいことは、既に別のシステマティックレビューが示している（体液量評価_水分バランスと体重測定の精度（システマティックレビュー）、Davies 2019）。Davies は13のコホート研究を統合し、①FB 記録の精度は疑わしい、②体重測定は精度が高いが連日実施が難しい、③両者の一致は乏しく不感蒸泄を補正しても改善しない、と結論している。本論文の著者も Discussion でこの問題に触れているが、「定量できない」として先に進んでしまう。 測定誤差のある曝露を二値化（高／低）してオッズ比を出すと、通常はヌル方向へのバイアス（regression dilution）が生じる。それでも OR 2.11 が出たのだから真の関連はもっと強い、という読み方が一見成り立つ。しかし誤差が非微分的（non-differential）である保証はない。重症な患者ほど、記録が漏れやすい出力（下痢・不感蒸泄・発熱・開放腹部・胸腹水）を多く持つ。すなわち重症例ほど出力が過小に、結果として FB が過大に記録されやすい。これは死亡と相関する方向の系統誤差であり、関連を人工的に強める向きに働く。「記録の精度」の層と「記録と死亡の関連」の層は独立ではなく、前者の誤差構造が後者の効果量を直接汚染している。

論点2：ランダム効果と固定効果の乖離が示唆するもの

固定効果 OR 1.76（1.65–1.87）に対しランダム効果 OR 2.11（1.65–2.69）。ランダム効果のほうが大きいということは、重みの小さい（＝小規模な）研究ほど効果が大きいことを意味する。これは典型的な小研究効果のシグナルである。ところが著者は Egger 検定 p=0.06 をもって「非対称性は示されなかった」と結論している。p=0.06 は慣例的な閾値のすぐ外側であり、Egger 検定の検出力は研究数14では低い。にもかかわらず GRADE 評価では「潜在的な出版バイアス」を格下げ理由に挙げており、本文と GRADE 表の間で判断が揺れている。JC ではここを突きたい。

論点3：時間窓サブグループの数値の不自然さ

1〜2日以内 OR 2.03（0.80–5.15、I²=0%）と、2日超 OR 2.03（1.24–3.34、I²=83.2%）。点推定値が小数第2位まで完全一致しているにもかかわらず、信頼区間も I² もまったく異なる。偶然の一致はありえるが、全体推定値 2.11 とも一致しないまま2つの層が同じ 2.03 になるのは不自然で、転記ミスの可能性を疑う余地がある。加えて、この結果からは「早期の FB は予後と関連せず、後期の FB のみ関連する」という結論と、「単に早期の研究数が少なく検出力がないだけ」という説明の区別がつかない。層ごとの研究数が本文に記載されていないため読者は検証できない。

論点4：サンプルサイズの内訳が合わない

Table 1 に記載された26研究の n を合計すると 65,691 となり、本文・抄録の 64,755 と 936 の差が生じる。差はちょうど Zhang 2022 の n=936 と一致する。同様に、主要アウトカムのプール（14研究、32,004例）についても、フォレストプロット A に数値が載る14研究の Table 1 上の n を合計すると 36,300 で一致しない。副次アウトカム（8研究、12,204例）も、対応8研究の合計 15,741 と食い違う。比較群に入らなかった患者が除外された結果である可能性はあるが、その説明は論文中にない。数字の出所が追えないメタ解析は、再現性の観点で減点対象になる。

論点5：自らの除外基準に反する研究が入っている

除外基準には「出力を伴わない部分的な輸液指標のみを報告する研究」が明記されている。ところが Table 2 によれば Shen 2018（n=8,584）は入力1項目・出力0項目で FB を算出している。この研究は主要アウトカムのプールに OR 2.09（1.79–2.44）という強い重みで寄与している。出力を数えない「水分バランス」は定義上バランスではなく投与量であり、事前規定した除外基準との整合が取れていない。

論点6：Table 2 の記述と本文の記述が食い違う

本文は「不感蒸泄や複雑な出力（消化管排液・ドレーン排液など）を報告する研究はまれだった」と述べるが、Table 2 の集計ではドレーンは 17/19 研究で採用されている（まれなのは胸腹腔穿刺 2/19、出血 2/19、不感蒸泄 2/19、嘔吐 3/19、消化管喪失 5/19）。ドレーンを「まれ」に含めた本文の記述は表と矛盾する。

論点7：研究の年号が表・図・本文で一致しない

Table 1 の Acheampong 2015 は Table 2 では Acheampong 2020、Table 1 の Sakr 2017 はフォレストプロットと ROBINS-E 図では Sakr Y 2016、Table 1 の Neyra 2015 は図では Neyra JA 2016、Table 1 の de Oliveira 2015 は Table 2 と図では de Oliveira 2014 と表記されている。同一文献に複数の年号が併存している状態で、読者が原典を追う障害になる。また Kharadi 2022 と Koonrangsesomboon 2015 がともに n=1,048 である点も、確認したくなる一致である。

論点8：探索的解析どうしが整合しない

連続メタ回帰は線形の右上がり（傾き 0.787、p<0.0001）を示し、著者はこれを「線形の用量反応を支持する」と要約した。一方、三分位解析では 中間の三分位でリスクがピークとなり最高三分位ではやや低いという非単調のパターンが出ている。スプラインは非線形性を検出しなかった（p=0.51）が、これは非線形がないことの証明ではなく検出力不足でも同じ結果になる。3つの探索的解析が異なる形を示している以上、「用量反応があるので GRADE を格上げできる」という論法には進めない（実際、著者は格上げしていない）。

論点9：生態学的誤謬

用量反応の予測変数は「研究レベルで高 FB 群に割り当てられた患者の割合」であり、個々の患者の FB の量ではない。研究レベルの割合と研究レベルの死亡の関連から、個人レベルの用量反応を推論することは 生態学的誤謬（ecological fallacy） そのもの。しかも「高 FB 群の割合」は、その研究が用いた閾値の高さによって決まる — 閾値を低く設定した研究ほど高 FB 群の割合が大きくなる。したがってこの予測変数は「曝露の強さ」ではなく「研究デザインの選択」を測っている可能性がある。著者自身も生態学的バイアスに言及しているが、Fig 5 が本文中で最も目を引く図であることを踏まえると、扱いは軽い。

論点10：閾値がどこにも示されていない

臨床医が最も知りたい「何 mL、何 mL/kg、何%を超えると危ないのか」という問いに、本レビューは答えていない。組み入れ研究では +5%・+10% といった体重比の閾値や四分位が用いられているはずだが、研究ごとの閾値の一覧は本文にも Table 1・Table 2 にも掲載されていない。曝露の二値化に用いた切り分け点を提示せずに「高 対 低」のオッズ比だけを統合したことは、本レビューの実務的価値を大きく損なっている。逆に言えば、JC でこの論文を扱うときの最大のテイクアウェイは「閾値を語る段階に文献がまだ到達していない」という現状認識である。

論点11：検索から出版までの時間差

検索の締め切りは 2024年5月28日、Crossref 上の公開は 2025年11月26日、誌面の巻号は2026年。投稿直前に更新検索を実施したと記載されているが、その更新検索の日付と追加件数は本文に明記されていない（PRISMA 図にも独立した記載はない）。1年半の空白がある領域で、更新の実施日が確認できないのは弱点。

論点12：バイアスリスクの分布

ROBINS-E で低リスクと判定された研究は26件中0件。高リスク17件、some concerns 9件。低リスク研究が1件も存在しないメタ解析のプール推定値は、何を推定しているのかという原理的な問いが立つ。著者が GRADE を very low としたのは正しい判断だが、それならば要約の一行目に「OR 2.11」を置くことの妥当性も議論の余地がある。
