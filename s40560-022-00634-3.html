🏥 聖路加ICUでの実践への示唆

聖路加ICUでの実践

明日からどうするか ① 時間外入室の方が、院内死亡が低い。

入室時間帯n院内死亡
時間外（off-hours）20,4033,399（16.7%）
時間内（office-hours）7,7971,604（20.6%）

調整オッズ比 0.91（95% CI 0.84–0.99）。多重代入による感度分析でも 0.89（0.82–0.97）と一致。 ＝時間外に入室した患者の方が、院内死亡が約9%低い。

② 「時間外」の定義を確認しておく。 時間内＝平日（月〜金）9:00〜17:00。それ以外（夜間・週末・祝日）はすべて時間外。 この定義では、患者の 72.4%（20,403/28,200）が「時間外」入室になる。 時間外の方が多数派である点に注意。

③ APACHE II に差がないのに死亡率が違う。 APACHE II 中央値 18（IQR 13–24）で、時間外群と時間内群に有意差なし。 ＝重症度では説明できない。 ただし、侵襲的介入（人工呼吸・CRRT・IABP・ECMO）は時間内入室の患者に多く行われていた。 → 「時間内に入る患者の方が、実は重い／複雑」という交絡の可能性が強く示唆される（後述）。

④ 平日だけに死亡率の日内変動がある。週末にはない。 平日の予測院内死亡率は3つのピークを持つ：08:00→09:00の急上昇、14:00のピーク、01:00のピーク。 週末は比較的一定で、平日のようなピークを形成しない。 → 著者の含意：平日の特定の時間帯に「需要と供給の不均衡」が生じている。 8時→9時の急上昇は申し送り・回診の時間帯、14時は日中業務のピークと重なる。 当院で確認すべき：入室が集中する時間帯とスタッフ配置が合っているか。特に朝の申し送り時間帯に入室が重なっていないか。

⑤ サブグループでは異質性がない。 疾患カテゴリ（循環器・神経・外傷・その他）でも、施設要因（認定集中治療医数・専従ICU看護師数・ICU病床数）でも、臨床的に重要な異質性は認めなかった。 → 「集中治療医が多い施設だけは時間外でも大丈夫」ということではない。 結果は施設の体制によらず一貫している。

⑥ この結果をどう使うか。 「時間外だから危ない」を根拠に夜間の受け入れを制限する議論は、日本のデータでは支持されない。 むしろ著者が提起しているのは逆方向の懸念："raised some concerns for a possible imbalance between ICU staffing and workload during office-hours"（時間内のスタッフ配置と業務量の不均衡への懸念）。 → 当院の議論も「夜間の人を増やす」ではなく「日中の業務が過密になっていないか」に向けるべき、という含意になる。

🧭 この論文の位置づけ（Known / Unknown / What's new）

補足

3点で掴む Known

  • ICU入室時間が患者転帰に与える影響は、複数の国からの研究で結論が一貫していない。
  • 平日夜勤帯や休日のICU入室が転帰不良と関連するとする研究がある一方、時間外と時間内で死亡率が同等とする研究も多数ある。
  • この不一致の理由は多因子的：時間内（office-hours）の定義の違い、研究集団の違い、研究規模、case-mix と重症度の補正が不十分であること。
  • さらに各国の診療実践と組織構造の違いにも注意が必要。
  • 時間外は資源が不足しがちで、診断・治療手技が時間内まで延期される可能性がある。

Unknown

  • 日本では国内の臨床試験も多施設観察研究も存在せず、現行の医療制度下でICU入室時間が転帰に影響するかは不明であった。

What's new

  • 日本の全国レジストリ（JIPAD）で初めて、時間外ICU入室と院内死亡の関連を検討した。
  • 時間外入室はむしろ院内死亡が低かった（調整OR 0.91）。著者の予想に反する結果。
  • 予測院内死亡率の日内変動が「平日のみ」に存在し、週末にはないことを示した。

📖 詳細

1. まず前提 — 「weekend effect」と時間外診療の問題

要旨

初学者向けの基礎 ① weekend effect（週末効果）とは 「週末や夜間に入院した患者の方が転帰が悪い」という現象。 英国のNHSで大きな政策論争を引き起こし、多くの国で検証されてきた。 想定される機序：

  • 時間外はスタッフ（特に上級医）が少ない
  • 診断・治療手技（CT・内視鏡・血管内治療・手術）が時間内まで延期される
  • 検査室・薬剤部などの支援体制が薄い

② なぜ結果が一貫しないのか（著者の整理）

理由内容
定義の違い「時間内」を何時から何時とするか、週末をどう扱うかが研究ごとに違う
研究集団の違いICU全体か特定疾患か
研究規模検出力不足
case-mix と重症度の補正が不十分時間外に来る患者と時間内に来る患者は、そもそも違う
国ごとの診療実践・組織構造の違い夜間の医師配置・救急搬送体制が国で全く違う

③ 多水準（マルチレベル）ロジスティック回帰とランダム切片 患者は病院に入れ子（nested）になっている。 同じ病院の患者は互いに似ている。 ランダム切片モデルは「病院ごとのベースラインリスクの差」をランダム効果として明示的に扱う。 これをしないと信頼区間が不当に狭くなる。

④ 「予測院内死亡率の日内変動」という解析の意味 0:00〜23:00の各時刻ごとに、共変量を調整したうえでの予測死亡率を算出する。 ＝「同じような患者がこの時刻に入室したら、死亡率はどうなるか」を時刻の関数として描く。 平日にピークがあり週末にないなら、それは「患者の性質」ではなく「その時刻に病院で起きていること（業務の集中・引き継ぎ）」を反映している可能性が高い。

2. 方法（Methods）

  • データ：JIPAD（JSICMが2014年に立ち上げた全国ICUレジストリ。2017年時点で21 ICU・217床が参加）
  • JIPADに登録されている患者情報：年齢、性別、身長、体重、入室日時、入室元（救急外来・手術室・病棟・他のケアユニット・他院転院）、入室区分（予定・緊急・ICU内手技）、入室時診断（循環器・呼吸器・消化器・代謝・神経・血液・筋骨格・産婦人科・泌尿生殖器・外傷など）、心肺蘇生後、APACHE IIスコア、慢性臓器不全（AIDS・心不全・呼吸不全・肝硬変・急性白血病または多発性骨髄腫・リンパ腫・転移性癌・免疫抑制・維持透析）
  • 施設レベル情報：ICU専従集中治療医数、ICU専従常勤看護師数、ICU病床数、病院病床数、病院種別（大学・公的・民間）

3. 結果

3-1. 患者背景

  • 28,200例。年齢中央値 71歳（IQR 59–80）。
  • APACHE II 中央値 18（IQR 13–24）。時間外群と時間内群に有意差なし。
  • 慢性臓器不全の分布にも臨床的に重要な差はなかった。
  • 人工呼吸・CRRT・IABP・ECMO などの侵襲的介入は、時間内入室の患者により多く行われていた。

3-2. 主要アウトカム

群n院内死亡
時間外20,4033,399（16.7%）
時間内7,7971,604（20.6%）
  • 調整オッズ比 0.91（95% CI 0.84–0.99）
  • 感度分析（多重代入）：粗OR 0.78（0.73–0.83）、調整OR 0.89（0.82–0.97）

3-3. 予測院内死亡率の日内変動

TAKE HOME

平日にだけ3つのピークがある 平日：予測院内死亡率が日内変動を示す。

  • 08:00 から 09:00 にかけての急上昇
  • 14:00 のピーク
  • 01:00 のピーク

週末（祝日含む）：比較的一定で、平日のようなピークを形成しない。

解釈の手がかり：08:00→09:00 は「時間外から時間内への切り替わり」そのもの。申し送り・朝の回診・当直帯からの引き継ぎが集中する。 14:00 は日中業務（手術・検査・処置）のピークと重なる。

3-4. サブグループ解析

  • 疾患カテゴリ（循環器・神経・外傷・その他）でも、施設要因（認定集中治療医数・専従ICU看護師数・ICU病床数）でも、臨床的に重要な異質性は認めなかった。

4. 考察（著者の解釈）

  • 「時間外入室の方が院内死亡が低い」という結果は予想に反するものであった。
  • この結果は、時間内におけるICUのスタッフ配置と業務量の不均衡の可能性について懸念を提起する。
  • 他国と比較するのに十分なデータセットを用いた今後の研究が求められる。

🔍 批判的吟味（JCでの論点）

⚠ 注意

① 「時間内に入る患者の方が実は重い」という交絡が疑わしい APACHE II に差はないが、侵襲的介入（人工呼吸・CRRT・IABP・ECMO）は時間内入室の患者に多く行われていた。 APACHE II は入室後24時間の生理学的データに基づくスコアで、「治療の複雑さ」や「臓器補助の必要性」を十分に捉えない。 考えられるシナリオ：

  • 病棟で悪化した患者は、日中の回診で発見されて日中に入室する（＝「じわじわ悪くなった患者」）
  • 時間外の入室は、救急外来からの外傷・心筋梗塞など「急性で単純な」病態が多い

＝「時間外の方が良い」ではなく「時間外に来る患者の方が予後が良い病態」である可能性が高い。 JCで最初に指摘すべき点。

⚠ 注意

② 「時間外」が患者の72.4%を占める 平日9:00–17:00 は1週間168時間のうち40時間（23.8%）。当然、患者の大半が「時間外」になる。 「時間外」という括りが粗すぎる：平日の18時と日曜の午前3時が同じ群に入っている。 日内変動の解析（Fig.3）が示すとおり、時刻によって死亡率は大きく違う。 2値の曝露に潰した主解析は、その情報を捨てている。

  • ③ 21 ICU・217床という規模。 2017年時点でJIPAD参加はまだ21施設。日本のICU（800施設超）の2.6%。かつ自発的参加のため質の高い施設に偏る。「日本のICU」を代表するとは言い難い。
  • ④ 除外基準に「ICU内手技のための入室で24時間以内に生存退室」が含まれる。 予定手術後の入室も除外。＝軽症の予定入室を除いた「緊急入室中心」の集団。この設計自体は妥当だが、結果を一般化する範囲は限定される。
  • ⑤ 効果量が小さく、CIの上限が 0.99。 調整OR 0.91（0.84–0.99）は、有意性ぎりぎり。 感度分析でも 0.89（0.82–0.97）。「時間外の方が良い」という主張は統計的には弱い。 むしろ「時間外が悪いという証拠はない」と読むのが誠実。
  • ⑥ 「日中の業務過密」という解釈は本研究から直接は導けない。 著者の "concerns for a possible imbalance ... during office-hours" は仮説の提示であって、業務量のデータは一切測定されていない。
  • ⑦ 予測死亡率の日内ピークの解釈が本文で深められていない。 08:00→09:00 の急上昇は、時間内/時間外の境界そのもの。「9時に入室と記録された患者」に何かが起きている可能性（記録の丸め・当直帯からの持ち越し）も考えられる。
  • ⑧ 施設のシフト体制が測定されていない。 「ICU専従集中治療医数」は測っているが、夜間に何人いるかは測っていない。時間外の実質的な人員配置が不明==。→ 平日10時の集中治療医対病床比の論文は、まさにこの点を「平日10時」という特定時点で測定している。両論文を並べて読む価値がある。==
  • ⑨ 院内死亡というアウトカムの限界。 在院日数に依存する。時間外入室の患者が早く転院・退院していれば、院内死亡は低く出る。
