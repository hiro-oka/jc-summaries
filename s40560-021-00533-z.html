🏥 聖路加ICUでの実践への示唆

聖路加ICUでの実践

明日からどうするか ① 当院の SMR を「どのモデルで出したか」を必ず併記する。 同じ患者集団でも、APACHE III-j で出すと SMR 0.48、JROD で出すと SMR 1.00 になる。 当院の JIPAD レポートでは APACHE III での SMR が 0.57〜0.62、JROD では約1.03 と報告されている。「SMRが1を大きく下回る＝優秀」ではなく、「APACHE III-j がもともと死亡を2倍以上に過大評価している」だけかもしれない。 経営会議や院内報告で SMR を出すときは、モデル名を必ず添える。

② JROD で SMR≈1.0 なら「全国並み」。それが正しい読み方。 JROD は全国平均で SMR＝1.00 になるように較正されているので、JROD-SMR は「全国の中での相対位置」を示す指標。当院の JROD-SMR が約1.03 であることは「全国平均並み」を意味し、APACHE III-j の 0.6 という数字が示唆するような突出ではない。→ 🗂 聖路加ICU 一次資料インデックス（Dropbox）

③ ファネルプロットで「外れ値」と出ても、即座に質の問題とは限らない。 著者自身が、44ICU中8ICUが3SD管理限界の外に出たこと（統計的期待値は0.2%）について、「モデルに組み込まれていないケースミックスの調整不足」または「提出データのエラー」が原因の可能性があると明記している。当院が外れ値になった場合も、まずデータ入力の検証から入る。

④ EWMA チャートは経時トレンドの監視に使える。 ファネルプロットが「ある期間の質を1点で要約する」のに対し、EWMA は逐次的な動的トレンドを捉える。異常なトレンドや逸脱をより早く拾える。 当院の月次QIレビューに導入する価値がある。

⑤ モデルは古くなる。JROD は「JROD2018」と呼ぶべきだと著者自身が書いている。 ICNARC が ICNARCH-2015 と年号を付けているのと同じ発想。当院の年次レポートで JROD-SMR を経年比較するときは、モデルの再較正年が変わっていないかを確認する。

🧭 この論文の位置づけ（Known / Unknown / What's new）

補足

3点で掴む Known（既に分かっていたこと）

  • ICU患者の死亡リスク予測モデル（APACHE、MPM、SAPS）は、①個々の患者の死亡リスク予測と、②予測死亡と観察死亡を比較した質のモニタリングの2つの目的で使われる。
  • APACHE III-j は日本のICU患者の死亡リスクを、実測死亡の2倍以上に過大評価する（Irie ら、JIPAD紹介論文）。 識別能（discrimination）は優秀だが較正（calibration）が悪い。
  • ANZICS は ANZROD、ICNARC は ICNARCH という自国版モデルを開発して、ベンチマーク性能を改善してきた。

Unknown（分かっていなかったこと）

  • 日本には、日本のICU集団と臨床環境に合わせて較正されたリスク予測モデルが存在しなかった。
  • 較正し直したモデルが、実際に質指標（SMRファネルプロット、EWMAチャート）として使えるかは検証されていなかった。

What's new（本研究の新規性）

  • JROD（Japan Risk of Death）モデルの開発。 APACHE III-j を捨てて作り直すのではなく、その線形予測子（linear predictor）を入力として再較正するという省力的な手法を採った。
  • 3つの再較正モデルを比較し、階層一般化加法モデル（hierarchical GAM）＝Model 3 が最良であることを示した。ICU単位のランダム切片を入れることでファネルプロットの過分散（overdispersion）を解消した点が鍵。
  • 「モデル性能が良いこと」と「質指標として使えること」は別問題であると実証した。 Model 1・2 は性能指標では Model 3 とほぼ同等なのに、ファネルプロットでは過分散を起こして使い物にならなかった。

📖 詳細

1. まず前提 — 「識別能」と「較正」は別物

要旨

初学者向けの基礎 リスク予測モデルの性能は、まったく異なる2つの軸で評価される。ここを混同するとSMRの解釈を誤る。

軸意味指標直感的な言い方
識別能（discrimination）死ぬ人と死なない人を順位づけできるかAUROC「誰が危ないかを当てられるか」
較正（calibration）予測した確率の絶対値が実際と合っているかHosmer–Lemeshow検定、較正プロット、Brier score「10%と言ったら本当に10%死ぬか」

APACHE III-j は識別能が優秀（AUROC 0.915）なのに較正が壊滅的（較正プロットの切片 −1.32、SMR 0.48）。 つまり「危ない人を見分ける力はあるが、死亡確率を2倍以上に言いすぎる」。

なぜそれが問題なのか。 医療の質指標である SMR（standardized mortality ratio）＝観察死亡数 ÷ 予測死亡数 は、分母に予測死亡を使う。予測死亡が2倍に膨らんでいれば、SMRは自動的に半分になる。 日本のICUの SMR が軒並み 0.5 前後になるのは「日本のICUが世界一優秀だから」ではなく、「使っているモデルが日本人集団に合っていないから」である。

なぜ較正が崩れるのか。 集団のケースミックス、観察死亡率、データの質が変われば較正は悪化する。本研究集団は予定手術が約60%を占めるが、APACHE III の開発集団では予定手術は3分の1しかなかった。 この差が較正不良に寄与した可能性がある。

用語

  • 線形予測子（linear predictor, lp）：ロジスティックモデルの「ロジット」部分。本研究では APACHE III-j の予測死亡率から逆算した log(p/(1−p))
  • オフセット変数：係数を1に固定して回帰式に入れる変数。切片だけを更新したいときに使う
  • 一般化加法モデル（GAM）：一般化線形モデルの拡張で、アウトカムと説明変数の関係を滑らかな非線形関数でモデル化できる
  • 階層モデル（hierarchical model）：クラスタ（ここではICU）レベルの分散を組み込む。これが過分散を減らす鍵
  • 過分散（overdispersion, Φ）：データのばらつきがランダム変動の範囲を超えている状態。Φ>1 で過分散。モデルの誤特定を示唆する
  • ファネルプロット：施設ごとの質指標を精度パラメータ（ここでは予測死亡数）に対してプロットした図。管理限界が漏斗（funnel）状になる
  • EWMA（指数加重移動平均）チャート：最新データに重みλを与えて移動平均をとる管理図。本研究では λ=0.005

2. 背景 — なぜ日本版が必要だったのか

リスクモデルは、それが使われる集団と臨床環境に合わせて調整されるべきである。

  • ANZICS は ANZROD（Australian and New Zealand Risk of Death）を開発・検証し、ベンチマーク性能を改善した
  • ICNARC（英国）も自前のモデルを更新し続けている（ICNARCH-2015）
  • 日本には、それに相当するものがなかった。

APACHE III-j の問題は具体的に測定されていた：日本のICU患者について、実測死亡の2倍を超える予測を出していた（Irie ら、JIPAD紹介論文）。→ JIPAD 日本ICU患者データベースの紹介

本研究の目的：APACHE III-j を更新し、日本のICU環境用に最適化する。新たに開発・検証されるモデル＝JRODは、ベンチマークと質指標の追跡に使われることを想定して設計された。SMRファネルプロットと死亡のEWMAチャートで適用可能性を検証する。この2つの図示ツールは、ANZICS と ICNARC が配布する質レポートでも使われている。

3. 方法（Methods）

3-1. データソース

JIPAD（Japanese Intensive care PAtient Database）＝日本最大のICU患者臨床レジストリ（成人・小児とも）。日本集中治療医学会の ICU機能評価委員会が統括。

  • 2020年10月時点で77 ICUが参加、17万人超の患者情報
  • ANZICS データベースと提携し、同様のデータを収集している。APACHE II、APACHE III、SAPS II、PIM 2、PIM 3 の死亡リスク算出に必要な臨床重症度情報を含む
  • データ入力の精度を高めるため、ICUがJIPADに参加する時点で入力品質をチェックし、その後も JIPADワーキンググループが定期的に確認する
  • 参加ICUは各年度の全入室患者のデータを提出する

3-2. 対象

組み入れ：2018年4月1日〜2019年3月31日にICU入室した患者

除外：

  • 小児ICU入室、または 16歳未満（APACHE III-j は成人用モデルであるため）
  • 同一入院中のICU再入室
  • 単一の医療手技のみのための入室（中心静脈カテーテル挿入、心房細動の電気的除細動など）＝「集中的な」ケアを受けたとみなされないため
  • 退院時転帰が欠測

3-3. 再較正の方法（Steyerberg の枠組みに基づく）

APACHE III-j の識別能は日本のICU集団で優秀であることが既に示されていたので、開発の焦点は較正の改善に置かれた。予測死亡を下げる必要があった。

Model 1（切片のみ更新）

$$\text{Logit} = \beta_0 + \text{offset}(lp)$$

  • lp（線形予測子）をオフセット（係数を1に固定）として唯一の説明変数にする
  • 元モデルの切片だけを更新する。集団のケースミックスの変化を反映し、平均予測死亡＝平均観察死亡となるようにモデルを改善する
  • lp は手元の APACHE III-j 予測死亡率から逆算：lp = log( APACHE III-j予測死亡率 / (1 − APACHE III-j予測死亡率) )

Model 2（切片＋傾きを更新）

$$\text{Logit} = \beta_0 + \beta_1 \cdot lp$$

  • Model 1 の説明変数を通常の変数（オフセットなし）として扱う
  • 切片に加えて線形予測子の全体的な係数を更新し、較正プロットの傾き1・切片0を目指す

Model 3（階層一般化加法モデル）

$$\text{Logit} = \beta_0 + f(lp) + u_i, \quad u_i \sim N(0, \sigma^2)$$

  • f は非線形関係をモデル化する平滑化関数
  • u_i は ICU i のランダム切片（平均0・分散σ²の正規分布に従う）
  • 目的は2つ：①較正プロットを対角線にさらに近づける、②ファネルプロットの過分散を緩和する
  • 階層モデルはクラスタレベルの分散を組み込むので過分散が減る。ICUレベルの特性を説明するためにランダム切片を追加した
図の解説

なぜ Model 3 が必要になったか（開発の経緯） 著者は Model 1・2 を作った後で、「較正プロットはまだ対角線から離れている」「修正Hosmer–Lemeshow検定も較正がなお不良であることを示した」「ファネルプロットの過分散も緩和できるはずだ」と考えて Model 3 に進んだ。論文としては段階的な改良の過程がそのまま報告されている。 過分散があると、管理限界の外に多くの点が出てしまい、モデルが「本当の外れ値」を検出する役に立たなくなる。

3-4. 性能評価の指標

指標何を測るか
AUROC識別能
Brier score識別能と較正の両方。予測確率と観察結果の差の二乗の平均。0〜1で小さいほど良い
scaled Brier scoreBrier score を、アウトカム発生割合の影響を緩和するよう調整したもの。Pearson の R² と同様に解釈できる
修正 Hosmer–Lemeshow 検定較正。通常の H-L 検定は標本サイズが大きいと過剰検出になり、帰無仮説を棄却しやすくなるため、大規模データ用に修正した版を使った
較正プロット較正の視覚的評価。観察死亡を予測死亡に対してプロット。傾き1・切片0が完全較正
AICモデル適合度の相対指標。過剰適合にペナルティ。低いほど良い

修正H-L検定と較正プロットでは、この分野の慣行に従い予測死亡率で10分位（deciles）に分割した。

3-5. 質指標への適用可能性の検証

SMRファネルプロット

  • 質指標＝SMR、精度パラメータ＝各モデルで求めた予測死亡数
  • 過分散係数 Φ を確認。Φ＝各プロットの標準化Pearson残差の二乗和 ÷ 標本単位数（＝ICU数）。Φ>1 で過分散

EWMAチャート

  • λ（最新データへの重み）＝0.005、開始点＝平均死亡率
  • 予測死亡から算出した管理限界を描き、「in-control」の動きを評価
  • ファネルプロットは一定期間の質を1点で要約するのに対し、EWMAチャートは質指標の動的トレンドを逐次的に捉える。異常なトレンドや逸脱を拾える分、EWMAの方が情報量が多い。

3-6. モデル検証

optimism補正 AUROC を算出して妥当性を評価。

  • 開発集団に過剰適合して性能が「過度に楽観的」になっていないかを見る
  • 計算式：元集団のAUROC − 平均optimism。optimism ＝「ブートストラップ標本でのAUROC − 元集団でテストしたAUROC」
  • Model 1・2 は 5,000回のブートストラップ、Model 3 は 10,000回のシミュレーション標本の事後分布から算出

3-7. 統計解析

  • 修正H-L検定と較正プロットでは p≦.05 を有意
  • ファネルプロットとEWMAチャートの極端例判定には、質管理で慣例の3標準偏差の閾値
  • R 3.6.3、階層GAMには mgcv パッケージ 1.8–33
  • モデル1〜3のRコードは Additional file 1 で提供

5. 考察

5-1. なぜ Model 3 が JROD になったのか

  • 全モデルで AUROC >0.9＝識別能は優秀
  • 較正は再較正で改善し、最大の改善は Model 3（Brier score、scaled Brier score、較正プロットで確認）
  • AIC 最低＝最良適合
  • 過度の楽観性は最小（元のAUROCとoptimism補正AUROCの差から判断）
  • ファネルプロットで過分散を示さなかった唯一のモデル
  • これらを総合して Model 3 が JROD モデルとして採用された。

5-2. 国際比較 — ANZROD・ICNARC との関係

ANZROD および ICNARC モデルと比較して、JROD は同様のモデル性能を示した。 識別能は優秀、較正は modest。ANZICS と ICNARC が自前のモデルでリスク予測を行い、定期的に質レポートを配布しているように、JROD も日本におけるベンチマークと質改善の目的に使える。

5-3. なぜ「軽い」更新手法を選んだのか

> リスク予測モデルの性能は時間とともに劣化するので、リスク予測の信頼性を担保するために性能を定期的に評価すべきである。

本研究集団では識別能は優秀だが較正が不良だった。較正が崩れるのは、集団のケースミックス・観察死亡率・データの質が変わったとき。本研究集団のケースミックスは APACHE III の開発集団と異なっていた（予定手術がほぼ60% 対 3分の1）ことが較正不良に寄与した可能性がある。

識別能が良くて較正だけが崩れる、というのはリスク予測モデルでよくあるパターン。その場合：

  • Model 3 の更新手法は簡単に適用できる
  • 他のモデル更新手法は、全共変量の係数更新や新変数の追加といった大掛かりな改訂を要する
  • 大掛かりな更新は、識別能を改善する必要があるときには必要だが、膨大な計算と再評価を要する。しかも、標本サイズが小さい場合、重要な変数が更新のたびに劣化したり脱落したりする可能性がある
  • 「本手法は使いやすく妥当で、大半の定期更新にはこれで十分だと我々は考える。資源に限りのある他の医療システムにも役立ちうる」

推奨：モデルの性能を定期的に（例：年次質レポート作成時に）評価し、必要なら更新する。

5-4. JROD は「JROD2018」と呼ぶべきかもしれない

> 本研究で示した更新版JRODモデルは、まもなく古くなるかもしれない。とくに較正は数年以内に劣化しうる。再較正の年をモデル名に付ける（すなわち JROD2018）必要があるかもしれない。 ICNARC は再較正モデルを ICNARCH-2015 と命名している。

6. 限界（著者の記載を原文の慎重さのまま）

  1. 2018年4月〜2019年3月の日本のICU集団への局所的調整である。外的妥当性の検証は行っていない。ただし、モデルの一般化可能性を高めることは本研究の目的ではなかったのでこのステップは必要ない。 モデルは標本集団に含まれる患者の医療の質を評価するために用いられることを意図している。内的妥当性は検証し、過剰適合は明らかでなかった。各国・各医療システムは、自らのローカルな環境にモデルを調整すべきである。
  2. ファネルプロットとEWMAチャートの適用可能性を統計的・図示的にしか検証していない。管理限界の外に位置したICUをまだ調査していない。JRODモデルのファネルプロットでは44参加ICU中8ICUが管理限界の外にプロットされた。特別な原因がなければ、統計的には3SDの管理限界を超えるのは0.2%にすぎないはずである。 この8ICUが真の外れ値かどうかを探索する必要がある。「out-of-control」のシグナルは、モデルに組み込まれなかったケースミックスの調整不足や提出データの誤りによって生じた可能性もある。

> [!warning] 著者の踏み込んだ記述 > 下側管理限界を下回るICUは自らの良好な成績に安心・満足しうるが、上側管理限界を超える外れ値（予測より有意に悪いアウトカム）を調査することは繊細な問題である。 これらのICUの質は外部の基準で評価される必要があり、診療パターンの再考を迫られる施設もあるだろう。それはしばしば重い負担となる。誰しも「out of control」だと指摘されたくはない。すべての医療者が患者のために懸命に戦っているのだから。 質指標を質改善活動に用いるためには、モデルの臨床的信頼性が検証されなければならない。

  1. 機械学習のような現代的技術は予測精度を改善しうる。ただし、どれだけの性能改善が必要かという議論が続く（本文はここで終わる）。

7. 結論（著者の言葉に沿って）

Model 3 は良好な性能を示し、ICUにおける医療の質をモニタリングするための JROD モデルとして採用できる。ただし、外れ値検出の臨床的妥当性についてはさらなる検討が必要である。本研究で用いた更新手法は、他のセッティングでも有用でありうる。

🔍 批判的吟味（JCでの論点）

⚠ 注意

① 「較正し直した」＝「SMRの平均を1.0にした」ということ JROD の SMR は定義上 1.00 になる（全国平均で較正しているから）。つまり JROD-SMR は絶対的な「良い/悪い」ではなく、あくまで「全国の中での相対位置」を示す。 全国の医療水準そのものが低ければ、SMR 1.0 は「平均的に悪い」ことを意味しうる。国際比較には使えない指標である。

⚠ 注意

② 44ICU中8ICUが外れ値＝統計的期待値の40倍 3SD管理限界を超えるのは期待値0.2%（44施設なら0.09施設）なのに、実際は8施設（18%）。著者は「Model 3 は過分散を示さなかった」と書いているが、この数字を見る限り残余の施設間異質性はまだ大きい。 単一のランダム切片では吸収しきれない構造（大学病院か否か、症例構成、終末期医療の方針）が残っている可能性が高い。

  • ③ 予定手術が58.9%という集団。 日本のICUの実態を反映しているとはいえ、術後患者中心の集団で較正したモデルを、内科系・救急系中心のICUに当てはめてよいかは別問題。 施設ごとのケースミックスが極端に違う場合、SMRの比較可能性は落ちる。
  • ④ 外的妥当性を検証していないことを著者が「必要ない」と言い切っている。 論理としては筋が通る（ベンチマーク専用モデルだから）が、実際には JROD は今後、開発年度以外のデータにも適用されていく。 「その年のデータで毎年較正し直す」運用が守られなければ、この主張は崩れる。
  • ⑤ 階層モデルでICUランダム切片を入れることの副作用。 ICUレベルの変動をモデルに吸収させるということは、「そのICU固有の悪さ」も予測死亡に織り込んでしまうということ。 質評価の目的からすると、これは測りたい信号の一部をノイズとして消している可能性がある。統計的にはファネルが綺麗になるが、質指標としての感度は下がりうる。この論点は本文で議論されていない。
  • ⑥ 修正Hosmer–Lemeshow検定への依存。 Model 3 だけ p=.84 で非有意だったことが採用の決め手のひとつだが、検定の非有意は「較正が良い証拠」ではなく「較正が悪いと言えない」だけ。 較正プロットでの視覚判断と併せて読むべきで、著者もそうしている。
  • ⑦ APACHE III-j の線形予測子を入力にする＝元モデルの変数選択をそのまま継承する。 APACHE III-j に含まれない重要な予後因子（フレイル、治療制限の方針、入室前の機能状態）は、いくら再較正しても入らない。 「軽い更新で十分」という著者の主張は較正の話であって、モデルの本質的な情報量は増えていない。
  • ⑧ 「誰しも out of control と指摘されたくない」という記述の重み。 質指標を運用する側の実務的困難を、論文中で正面から言語化している珍しい例。 JIPADの事務局作業・施設フィードバックを担う立場からは、この一文が最も実践的に重要かもしれない。

まとめ

  1. APACHE III-j は日本のICU患者の死亡を約2倍に過大評価する（平均予測17.0% 対 実測8.1%）。 その結果、SMR は 0.48 という「見かけの優秀さ」を生む。
  2. JROD は APACHE III-j の線形予測子を階層一般化加法モデルで再較正したモデル（Model 3）。ICUごとのランダム切片が鍵。
  3. 識別能はもともと問題なかった（AUROC 0.915→0.917）。改善したのは較正（修正H-L p<.001→.84、Brier 0.062→0.047、SMR 0.48→1.00）。
  4. モデル性能が良いことと、質指標として使えることは別問題。 Model 1・2 は性能指標では遜色ないのに、ファネルプロットで過分散を起こして使えなかった。
  5. JROD-SMR は「全国の中での相対位置」を示す指標。 1.0 が全国平均。国際比較には使えない。
  6. 44ICU中8ICUがファネルの外に出た（期待値0.2%）。 外れ値＝質が悪い、と即断してはいけない。ケースミックス調整不足やデータ入力エラーの可能性を先に潰す。
  7. モデルは劣化する。年次質レポート作成時に性能を評価し、必要なら再較正する。名前に年号を付ける（JROD2018）ことも検討されている。
