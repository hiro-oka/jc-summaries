🏥 聖路加ICUでの実践への示唆

聖路加ICUでの実践

病棟プロトコルへの落とし込み ■ 今日から変えること

  • IVCの使い方を虚脱率（呼吸性変動）に一本化する。「呼気終末IVC径（絶対値）へ乗り換える」という潮流には、まだ乗らない。乗り換えを支える根拠が薄いことが本レターの主張。
  • ただしIVC虚脱率は動的指標の中では精度が低い部類であることを、使う側の共通認識にしておく。単独で輸液を止める／続けるの判断はしない。
  • IVCで白黒がつかないときは、PLR・EEO・ミニ輸液負荷といった実際に前負荷を動かす検査に進む。腹部が張っている症例ではPLRが当てにならない点も併せて運用する（→ 腹腔内圧上昇下ではPLRが当てにならない（EEO・ミニ輸液負荷は有効・CritCare2026））。

■ 概念として持ち帰る一点

  • 「輸液反応性がある」と「静脈うっ血がある」は同時に成立しうる。うっ血所見（E/e′・VExUS など）があるから輸液反応性がない、とは言えない。逆も同様。当院のエコー教育で、この2つを対立概念として教えないよう表現を直す。

■ 研修医への伝え方

  • 「popular な指標が正確とは限らない。ただし、代わりに提案された指標がそれより正確とも限らない」— 本レターは、置き換え提案を鵜呑みにしないための良い教材。元論文の根拠を1本ずつ読み直すと、代替案の足元が見えるという読み方の実例として使える。

🧭 この論文の位置づけ（Known / Unknown / What's new）

補足

リサーチ・イン・コンテキスト

  • Known（既に分かっていたこと）：IVC（下大静脈）の呼吸性変動＝虚脱率は、ベッドサイドで最も普及した輸液反応性（FR）指標である一方、診断精度は動的指標のなかで高くないことが繰り返し報告されてきた。Orso らのシステマティックレビュー／メタ解析（2020）は、当初の報告より曲線下面積（AUC）が低いことを示している。
  • Unknown（分かっていなかったこと）：では虚脱率をやめて何を使うのか。元論文（Vieillard-Baron ら 2024）は「呼吸性変動は正確に予測できない」として呼気終末IVC径（IVC_EE、絶対値）を代替として紹介した。しかし絶対値が虚脱率より優れるという直接の証拠は示されていなかった。
  • What's new（本レターが示したこと）：代替案の根拠として引かれた Vieillard-Baron ら（2018）の研究を読み直すと、IVC_EE で妥当な評価ができたのは29%にとどまり、71%は評価困難で、感度・特異度が算出できていない。しかも IVC_EE は鎮静＋人工呼吸完全同調下で測られており、虚脱率と同じ制約を受ける。したがって「絶対値 > 虚脱率」とは結論できず、現時点でIVCの用途を虚脱率に限定するのが現実的かつ科学的に妥当、というのが本レターの結論。

📌 全体要約

要旨

ひとことで IVCの呼吸性変動を捨てて呼気終末IVC径に乗り換えよ、という提案に対する反論。代替案の根拠となった研究では71%の患者が評価困難で感度・特異度すら出せておらず、しかも同じ測定条件の制約を受ける。IVCの使用は虚脱率に限定するのが妥当。

  • 元論文の主張は「IVC respiratory variations は popular だが FR を正確に予測できない」→ 代わりに IVC_EE（呼気終末径） を提示、というもの。
  • その根拠とされた Vieillard-Baron ら 2018 は、IVC_EE で輸液反応性を妥当に評価できたのが29%、残る71%は評価困難という内容であり、この結果から感度・特異度は導出できない。
  • 元論文自身が「IVC_EE は FR と独立に関連するが、FR予測の診断的価値は全体として低いままである」と書いている。
  • 元論文が提示した指標はすべて静的指標で、多くは FR に対する予測精度すら示されていない。
  • 静脈うっ血の静的パラメータは、輸液反応性の対概念（＝反応性がないことの代理）としては使えない。輸液反応性のある状態とうっ血サインは併存しうる（Muñoz ら 2024）。
  • IVC虚脱率は他の動的指標よりAUCは低いが、静的指標として報告されている値よりは正確。
  • 内頸静脈の虚脱率には期待が持てるが、さらなる研究が必要。

📖 詳細

1. まず前提 — この論争の基礎（初めての人にも）🧩

要旨

5分で背景を掴む 重症患者に輸液を入れる前に知りたいのは「入れれば心拍出量が増えるのか（＝輸液反応性 fluid responsiveness, FR がある）」である。エコーでこれを見る方法は大きく2種類に分かれる。 動的指標は、前負荷を実際に（可逆的に）動かして反応を見る。PLR（受動的下肢挙上＝自己輸血）、EEO（呼気終末閉塞＝15秒換気を止める）、ミニ輸液負荷（100 mL を1分で）などがこれにあたる。 静的指標は、ある瞬間の形や圧を測って推定する。IVC径、CVP、E/e′（左室充満圧の推定指標）などが代表。静的指標は一般に予測精度が低いことが知られている。 IVC（下大静脈）は両者の境界にある。IVC虚脱率（呼吸に伴う径の変動率）は「呼吸という周期的負荷に対する反応」を見るので半ば動的だが、精度は動的指標に劣る。一方IVC_EE（呼気終末の絶対径）は完全に静的な量である。 本レターは「精度が低いから虚脱率をやめて絶対径に移ろう」という提案に対し、移った先の根拠はもっと薄いと指摘したものである。

2. 背景 — 何に対する応答か 🎯

Vieillard-Baron ら（*Intensive Care Med* 2024, doi:10.1007/s00134-024-07407-6）は、エコーで輸液反応性を予測し輸液の必要性を管理する方法を簡潔にまとめた論説を発表した。著者（小野）はその要約努力を評価しつつ、IVCの位置づけの記載に懸念があるとして本レターを書いている。

争点は1つ。元論文が「IVCの呼吸性変動は普及しているが FR を正確に予測できない」と述べ、その代替として呼気終末IVC径（IVC_EE）を紹介した点である。

3. 論点① 代替案（IVC_EE）の根拠は薄い 💧

元論文が IVC_EE の根拠として引いたのは Vieillard-Baron ら（*Intensive Care Med* 2018;44:197–203, doi:10.1007/s00134-018-5067-2）である。本レターはこの研究の中身を次のように読み直す。

  • この研究は、IVC_EE の潜在的交絡因子を参照しながら「将来の可能性」を評価した性格のものであった。
  • 結果として、IVC_EE で輸液反応性を妥当に評価できたのは29%の患者にとどまり、71%の患者は評価困難だった。
  • したがってこの結果から感度・特異度を導出することはできない。
  • さらに IVC_EE は鎮静され人工呼吸に完全に同調した患者で測定されており、IVC虚脱率とまったく同じ制約を受ける。
  • 元論文自身が「IVC_EE は FR と独立に関連するが、FR予測の診断的価値は全体として低いままである」と記載している。

結論：これらの研究から「IVCの絶対値の使用が虚脱率より好ましい」とは結論できない。

⚠ 注意

臨床上の要注意ポイント 「呼吸性変動は不正確だから絶対径に乗り換える」という置き換えは、置き換え先の診断精度が確立していないまま行われている。 精度の低い指標を、精度の分からない指標に取り替えても前進しない。しかも両者は「鎮静＋完全同調」という同じ前提条件を共有しており、その前提が崩れる自発呼吸患者では、どちらも同じように使えない。

4. 論点② 静的指標をFRの対概念に使えない 🩸

  • 元論文が提示した指標はすべて静的指標であり、その多くは FR に対する予測精度すら示されていない。
  • E/e′ は陰性水分バランスへの耐容性を予測すると報告された（Allyn ら, *J Crit Care* 2013;28:1006–1010）。
  • しかし最近の観察研究（Muñoz ら, *Crit Care* 2024;28:52 — 多施設 proof-of-concept 研究）は、重症患者において「輸液反応性のある状態」と「静脈うっ血のサイン」が併存することを報告した。
  • したがって、静脈うっ血の静的パラメータの多くは、輸液反応性の対概念としては使えない。

この一点は、レター本文のなかで最も実務に効く指摘である。「うっ血しているから輸液反応性はないはずだ」という推論が、そもそも成り立たない。

5. 論点③ ではIVC虚脱率はどう位置づくのか 📉

  • IVC虚脱率は、他の動的パラメータよりAUCが低い。
  • しかし、静的パラメータについて報告されている値よりは正確である。
  • AUCが当初の報告より低いことは示されている（Orso ら, *J Intensive Care Med* 2020;35:354–363 のシステマティックレビュー／メタ解析）が、著者はこれを次のように相対化する — 文献が蓄積し分散が増えれば、あらゆるパラメータの精度はより不均一になる。IVCだけが特別に劣化したわけではない。
  • 内頸静脈の虚脱率には期待が持てるが、さらなる研究が必要。

以上より、著者の結論は「現時点では IVC の使用を虚脱率に限定することが、現実的かつ科学的に妥当な判断である」。

6. 限界 ⚠️

  • Correspondence（レター）であり、新規データは一切提示されていない。単著による論評である。
  • 提示される数値は引用文献由来のもの（29% / 71%）のみで、AUCなどの具体値は本文に記載がないため本ノートにも転記していない。
  • 元論文著者側の反論（Author's reply）は別文献であり、本ノートの対象外。両論を読むまでは、この論争は片側しか見ていないことに注意。

✅ Take home message

TAKE HOME

結論 IVCは「虚脱率」に限って使う。呼気終末径（絶対値）への乗り換えは、まだ根拠が足りない。

  • 代替案の根拠となった研究は、71%が評価困難で感度・特異度が出せていない。
  • IVC_EE も虚脱率と同じく鎮静＋人工呼吸完全同調が前提で、制約は共有されている。
  • 「輸液反応性あり」と「静脈うっ血あり」は同時に成立する。うっ血所見を「反応性なし」の代わりに使ってはいけない。
  • IVCで決めきれないときは、PLR・EEO・ミニ輸液負荷という実際に前負荷を動かす検査へ進む。
