🏥 聖路加ICUでの実践への示唆

聖路加ICUでの実践

病棟プロトコルへの落とし込み

  • 「ICUで亡くなった患者の約5人に1人は、死ぬまで気づかれない重大な診断がある」を前提に振る舞う。 本研究の主要な乖離率は 18.5%、うち治療を変えていたはずの class I エラーが 7.5%。診断精度は「経験を積めば上がる」ものではなく、25年間ほぼ横ばいだった（p=0.2997）。
  • 見落としトップ6を、原因不明の増悪時のチェックリストにする。 肺塞栓（24例）、肺炎（23例）、二次性腹膜炎（12例）、侵襲性アスペルギルス症（8例）、感染性心内膜炎（8例）、心筋梗塞（8例）。当院でも「敗血症性ショックだが感染源不明」「原因不明の呼吸不全」の際にこの6つを声に出して除外する運用が有効。
  • 肺塞栓は「螺旋CTがあるのに」見逃される。 本研究でも24例が剖検で初めて判明した。著者は末梢の塞栓が主体だった可能性を指摘するが、臨床的に説明のつかない低酸素・頻脈・ショックでは造影CTの閾値を下げる。
  • 人工呼吸中の肺炎診断は当てにならない。 同グループの別研究（253剖検）で、「胸部X線浸潤影＋3臨床基準（白血球増多・発熱・膿性痰）のうち2つ」という基準の感度は 64.8%・特異度 36%、3基準すべてを要求すると感度 15.5%・特異度 91%。VAP を「否定した」つもりにならないこと。ARDS の臨床基準も感度75%・特異度84%にとどまる（382剖検との比較）。
  • 腹部が読めない患者ほど危ない。 見逃された二次性腹膜炎の主因は消化管穿孔。意識障害、麻薬使用、免疫抑制、人工呼吸は腹部所見をマスクする。病歴が取れない・急速に進行する患者では、腹部CTの閾値を下げる。
  • 心疾患への疑いの目が低すぎる。 心内膜炎と心筋梗塞は繰り返し見逃される。ある研究では剖検を受けた患者の55%しか ICU 滞在中に一度も心電図を取られていなかった。本研究の施設ではほぼ毎日心電図を取っていてなお心筋梗塞が主要な乖離として残った。経食道心エコーでも心内膜炎は見落としうる。
  • 剖検を「質保証プログラム」として位置づけ直す。 本研究の剖検率は 30.3%（適切とされる最低25%を上回り、最適とされる35%に近い）。著者は「ICUで死亡した全患者に剖検を検討すべき」「ICUスタッフへの説得、病理部門の協力、そして病院管理部門が剖検費用を教育・質保証予算に計上することが不可欠」と結論している。当院で剖検率を上げる交渉の際、そのまま使える論拠。
  • 死亡直後のケースカンファを制度化する。 本施設では全医療スタッフが参加して各症例を死亡後すぐに個別検討する会議を日常的に行い、質保証プログラムの一部としていた。当院の M&M カンファの設計に取り込む。

🧭 この論文の位置づけ（Known / Unknown / What's new）

補足

リサーチ・イン・コンテキスト

  • Known（既に分かっていたこと）：剖検は医学教育・患者ケア・医療の質評価に有用で、臨床診断を検証する最も信頼できる方法の一つ。しかし世界的に剖検率は低下しており、その要因として費用、訴訟への懸念、病院認定基準から最低剖検率が外されたことが挙げられる。成人 ICU の既報では死亡前後の診断乖離率は対象集団により 7〜32%（入院患者全体では 5〜40%）。
  • Unknown（分かっていなかったこと）：既報の多くは後ろ向きで症例数が少ない。また、診断技術（螺旋CT、経食道心エコーなど）の進歩によって乖離率が下がっているのか、それとも治療の進歩で患者像が変わり乖離率は変わらないのかについて、報告が割れていた。
  • What's new（本研究の新規性・意義）：25年間（1982-2007）・連続 834 剖検例の前向き研究という規模と設計で、(1) 主要乖離率 18.5%（class I 7.5%／class II 11.4%）、(2) 乖離率は25年間ほぼ一定（p=0.2997、Goodman-Kruskal の τ=0.0025）、(3) しかし乖離をもたらす疾患の内訳は変化しており、とくに肺炎の診断精度は直近で低下、を示した。さらに 2.6% では剖検でも死因が確定できないという、これまであまり記述されなかったカテゴリを提示した。

📌 全体要約

要旨

ひとことで ICU で死亡し剖検された 834 例のうち 18.5% に主要な診断乖離があり、7.5% は治療と転帰を変えていたはずの class I エラーだった。乖離率は 25年間ほぼ横ばいで、診断技術の進歩は「見逃しの割合」を減らしていない。

  • デザイン：スペイン・マドリード Hospital Universitario de Getafe の ICU で 1982年1月〜2007年12月に死亡し剖検された連続全例を対象とした前向き研究。
  • フロー：25年間の ICU 入室 15,815例中、死亡 2,857例（18.1%）。臓器提供 151例と司法解剖 176例を除外。残る死亡例のうち 866例（30.3%） で家族の同意を得て臨床剖検を実施。臨床情報が失われた 32例を除き、834例を解析。剖検を行わなかった最大の理由は家族の拒否。
  • 患者背景：男性 553例（66.3%）／女性 281例（33.7%）、平均年齢 66歳（SD 14）、死亡前の ICU 滞在期間中央値 4日（範囲 2–11日）。入室元は救急外来 40%、内科入院 37%、外科 23%（緊急手術16%、待機手術7%）。
  • 主要結果：主要な見逃し診断は 154例（18.5%）。class I（治療に直接影響する重大な誤診）63例（7.5%）、class II（治療は変わらなかったであろう重大な予期せぬ所見）95例（11.4%）。
  • 最も多い見逃し：肺塞栓、肺炎、二次性腹膜炎、侵襲性アスペルギルス症、感染性心内膜炎、心筋梗塞。
  • 剖検でも死因不明：22例（2.6%）。この群の臨床死因は心停止（心室細動）、呼吸不全、気胸が多かった。
  • 経時変化：class I エラーの中央値 8.5%（IQR 4.6–9.1%）、class II の中央値 13%（IQR 7.2–14.5%）。全体でも期間別でも有意差なし（Pearson χ² で p=0.2997、Goodman-Kruskal の τ=0.0025）。

📖 詳細

1. まず前提 — 「診断乖離」と Goldman 分類（初めての人にも）🧩

要旨

5分で背景を掴む 剖検（autopsy） は、臨床で下した診断が正しかったかを検証する最も信頼性の高い方法の一つ。生前診断と剖検所見が食い違うことを 診断乖離（diagnostic discrepancy） と呼ぶ。 乖離の重み付けには Goldman 分類（Goldman L, et al. N Engl J Med 1983）が世界標準として使われる。

  • class I エラー：治療に直接影響したはずの重大な誤診。「知っていれば治療が変わり、転帰も変わったかもしれない」もの。
  • class II エラー：重大だが治療は変わらなかったであろう予期せぬ所見。理由は「診断は不明でも結果的に適切な治療がすでに行われていた」「有効な治療が存在しなかった」「患者がそれ以上の検査・治療を拒否した」のいずれか。

診断は WHO 分類に従って主要診断（原疾患＝死に至る一連の病的事象を開始した疾患／損傷、および死因＝終末期の最終事象を除いた直接の死因となった病変・機能障害）と副次診断（死亡への寄与因子、その他の非関連疾患）に分けられる。 剖検率の目安：25% が「適切」の最低ライン、35% が「最適」とされる（本研究は 30.3%）。

2. 背景と目的 🫁

剖検は医学教育、患者ケア、医療の質の評価と管理に貢献する価値ある信頼できるツールである。しかし過去数十年、剖検率は世界的に低下しており、費用、訴訟への懸念、病院の認定基準から最低剖検率が除外されたことなどが要因とされる。

成人 ICU の既報では、死亡前後の診断乖離率は対象集団により 7〜32% と報告されているが、多くは後ろ向きで症例数が少ない。

  • 主目的：臨床診断と病理診断を比較して臨床エラーの割合を明らかにする。
  • 副次目的：エラーの経時的推移を評価する。

3. 方法（Methods）📐

  • デザイン：前向き記述研究（連続例、25年間）。
  • 対象：Hospital Universitario de Getafe の ICU で 1982年1月〜2007年12月に死亡し剖検された連続全例。全死亡例について家族に剖検を依頼したが、臓器提供者（提供臓器が剖検に供せない）と司法解剖対象（院外施設で実施され結果にアクセスできない）は除外。施設倫理委員会の承認取得。
  • 臨床診断：ICU 入室時と滞在中の臨床状態を problem-oriented record に登録。最終臨床診断は死亡時点で確定。カルテは剖検所見を知らされていない研究者がレビュー。収集項目は人口統計、入室元（救急／内科／外科）、人工呼吸の有無と日数、ICU 滞在期間、既往、主要臨床疾患、推定死因。
  • 病理診断：既報の事前規定プロトコル（Fernández-Segoviano P, et al. Crit Care Med 1988）に従い、死後12時間以内に実施。剖検前に病理医へ原疾患と臨床死因を含む臨床情報を提供。主要診断に関連する副次診断や予後・管理に影響しえた先行病態も対象とした。臨床診断と病理診断は独立に作成され、両者の突き合わせは研究終了時に初めて行われた。
  • 分類：WHO 分類（主要／副次）に基づき整理し、Goldman 分類で class I／class II に分類。判定者間で意見が割れた場合は、経験ある集中治療医2名が独立にレビュー。
  • 統計：平均（SD）、中央値（IQR）、割合（95%CI）。カテゴリ変数は χ² 検定または Fisher 正確検定、平均値は Student t 検定。両側検定、有意水準 0.05。経時的なエラーの全体差は Pearson χ²、期間間の差は Goodman と Kruskal の τ で推定。SPSS 15.0 を使用。

6. 考察 — なぜ見逃されるのか 💧

肺塞栓：螺旋CTの登場で診断は容易になったはずだが、24例が剖検で初めて判明した。著者は、右室機能障害を伴う臨床的に有意な大きな塞栓ではなく、末梢の塞栓が主体だったためと推測している。

感染症全般：各種剖検研究で見逃された死因の大半を占めるのが感染症で、とくに ICU 症例で顕著。感染源（source of infection）の同定が未解決の重要課題であり続けている。

二次性腹膜炎：本研究で見逃しが多く、主因は腸管穿孔。他研究でも急性腹症は主要な乖離原因（Torgersen らの研究では剖検で 180例（76.6%）に持続する敗血症巣が見つかり、腹膜炎が 23.4% と最多クラス。Battle らの報告では腹膜炎 45%、肺膿瘍 34%、心内膜炎 26%、気管支肺炎 21% が見逃されていた。周術期死亡の外科患者では腹部合併症の見逃しが最大 11%）。遅れ・失敗の理由として、意識障害、麻薬使用、免疫抑制、人工呼吸により適切な病歴聴取が困難であること、および病態の進行が速いことが挙げられる。

肺炎：人工呼吸中の診断の難しさを示す。同グループの別研究（253死亡例）では 142例（56%）が組織学的に肺炎と診断された。剖検所見と比較した生前の臨床診断の精度は以下の通り。

診断基準感度特異度
胸部X線浸潤影＋3臨床基準（白血球増多・発熱・膿性気道分泌物）のうち2つ64.8%36%
胸部X線浸潤影＋3臨床基準すべて15.5%91%

ARDS も同様で、382例の剖検研究では 127例（33%）が臨床基準を満たし、112例（29%）にびまん性肺胞傷害が認められた。臨床定義の感度 75%・特異度 84% で、精度は「中程度」にとどまった。

心内膜炎・心筋梗塞：重症患者では心疾患への疑いの目が不適切に低いと複数の著者が指摘。Perkins らは剖検を受けた患者のうち ICU 滞在中に一度でも心電図を取られていたのは 55% のみと報告した。本施設ではほぼ毎日心電図を取っていたにもかかわらず、心筋梗塞は主要な乖離として残った。心内膜炎は経食道心エコーでも見落としうる。

剖検でも死因不明の 2.6%：専門的な組織学的検索を尽くしても死因が確定できない成人死亡が一定割合存在する。理由として、(1) 一見健康で突然死した成人では形態学的異常が見つからないことがある、(2) 複数の病態が併存し、そのいずれもが死因たりうる、が考えられる。このような症例でも、剖検は疑われた病態を除外するのに役立つ。Pastores らは腫瘍 ICU で 17% がこのカテゴリに該当し、ICU・入院期間が長く、剖検では各臓器の非特異的な慢性炎症・線維化のみを認めたと報告している。

先行研究との比較：本研究の乖離率 18.5% は他の ICU シリーズと比べて良好。文献上、主要な診断乖離は入院患者全体で 5〜40%、ICU 患者で 7〜32%。研究間の差は ICU 患者層の違いと剖検適応の違いで説明されうる。技術進歩にもかかわらず乖離率は経時的に安定という報告（Goldman ら、Kirch ら）がある一方、近年有意に低下したとする報告（Veress ら、Sondereger-Iselli ら、Shojania ら）もある。安定して見える理由として、20世紀を通じて治療対象となる患者像そのものが変化した（医療の進歩で寿命は延びたが、新しい疾患と合併症が現れた）ことが挙げられ、現在 ICU で最も見逃されやすいのは院内感染と日和見感染である。

強みと限界

  • 強み：症例数の大きさと前向きデザイン。剖検を行わなかった理由はほぼ家族の拒否のみ。他研究では「難しい症例ほど剖検が依頼されやすい」という選択バイアスが生じうるが、本研究は ICU で死亡した全患者に剖検を依頼したためこのバイアスは考えにくい。
  • 限界：単一 ICU での研究であり、他施設への一般化には注意が必要。1988年以降は剖検対象選定と剖検手技に標準手順を用いた。また、死亡の予防可能性、治療行為による医原性病変、人的・システム的エラーの帰責分析は本研究の範囲外。

7. 結論（原著） 💧

本研究は生前の臨床診断と剖検所見の間に有意な乖離があることを示した。これは予期せぬ診断を検出するうえでの剖検の重要性を再確認するものであり、診断技術の進歩にもかかわらず剖検は臨床実践において依然として重要な役割を果たしている。剖検は診断精度と治療をモニターすることで医療の質を向上させる有用な教育ツールとみなされるべきであり、ICU で死亡するすべての患者で剖検を検討すべきである。

高い剖検率を維持するには、ICU スタッフが剖検の重要性（教育・質保証プログラムの一部として）を納得していること、病理部門の協力、そして 病院管理部門が剖検費用を教育・質保証の予算に計上することが不可欠である。

結論

  • ICU で死亡し剖検された患者の 18.5% に主要な診断乖離があり、7.5%（class I）は知っていれば治療が変わっていたはずの誤診だった。
  • 乖離率は25年間ほぼ横ばい。診断技術の進歩は「見逃しの割合」を減らしていない。
  • 見逃しトップ6は 肺塞栓・肺炎・二次性腹膜炎・侵襲性アスペルギルス症・感染性心内膜炎・心筋梗塞。原因不明の増悪時にこの6つを声に出して除外する。
  • 剖検は「終わった話」ではなく、ICU の質保証プログラムそのもの。ICU で死亡した全患者で検討する。
