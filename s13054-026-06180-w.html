🏥 聖路加ICUでの実践への示唆

聖路加ICUでの実践

病棟プロトコルへの落とし込み

  • 変えないもの：輸液反応性の一次判断は動的テスト（PLR・EEO・ミニ輸液負荷）＋LVOT VTI 再評価という当院の順序を変える材料はない。本研究の IVCVI ですら AUROC 0.788、カットオフでの感度68.6%／特異度58.6%と、単独で輸液の可否を決められる精度ではない
  • 使えるもの：ショック覚知直後、まだラインもモニターも整っていない3分間で撮る「サブコスタのIVC＋心尖部四腔像」というワークフローは当院でも現実的。IVCVI が明らかに大きい（>18%）かつ E/e’ が低い（<10）なら「入れてよさそう」、逆に IVCVI が小さく E/e’ が高いなら「入れる前に立ち止まる」という事前確率の調整に留める
  • 注意：本研究の輸液反応性の定義には「MAP >5 mmHg 上昇」が含まれ、レスポンダー51例のうち27例（全体の34%）は MAP 基準のみで拾われている。当院で心係数・VTI ベースの判定をしている限り、ここで示された数値をそのまま持ち込むと反応性を過大評価する
  • 測り方の統一：IVCVI は分母が最小径（＝distensibility index 型）。当院で虚脱率（分母＝最大径）を使っているなら別物であり、18%という閾値は流用できない

🧭 この論文の位置づけ（Known / Unknown / What's new）

補足

リサーチ・イン・コンテキスト

  • Known：人工呼吸中のショックでは IVC 径の呼吸性変動が輸液反応性の予測に使えることがメタ解析で示されている（Huang 2018）。僧帽弁 E/e’ は重症患者の左室拡張機能・左室充満圧の指標として確立している
  • Unknown：E/e’ を輸液反応性の予測に転用できるかは結論が出ていない。既存の3研究はいずれも心臓外科術後・経食道心エコーでの検討で、内科系ICU・経胸壁心エコーでのデータがない。E/e’ と IVCVI を同一集団で直接比較した報告もない
  • What's new：内科系ICUの人工呼吸中ショック80例で、経胸壁心エコーによる E/e’ と IVCVI を同一患者で同時に測り、CVP・脈圧変動（PPV）も並べて ROC 比較した。IVCVI（AUROC 0.788）が E/e’（0.682）を上回り、E/e’ は「中等度の識別能にとどまるが特異度は高い（<10 で 75.9%）」という位置づけになった

📌 全体要約

要旨

ひとことで 人工呼吸中のショック80例で4つの指標を同時に比べたところ、IVCVI（AUROC 0.788）が僧帽弁E/e’（0.682）より輸液反応性をよく当て、E/e’ は単独の判断材料ではなく事前確率を調整する補助として使うべき、という結論。

  • 対象は Siriraj 病院（バンコク）内科系ICUの人工呼吸中ショック成人80例（うち75例が敗血症性ショック）、2021年10月〜2024年9月
  • 300 mL の酢酸リンゲル液を15分で投与し、その前後で心エコー指標・CVP・PPV を再評価
  • 輸液反応性の定義は「心係数 >15% 増加 または MAP >5 mmHg 上昇」。51例がレスポンダー、29例がノンレスポンダー
  • 診断能は IVCVI 0.788 ＞ CVP 0.724 ＞ E/e’ 0.682 ＞ PPV 0.652 の順
  • Youden 指数による最適カットオフは IVCVI >18%（感度68.6%／特異度58.6%）、E/e’ <10（58.7%／75.9%）
  • 著者の提案は「IVCVI を優先し、動的テストが行えないときに E/e’ で事前確率を補正し、300 mL 負荷後の LVOT VTI または心係数で答え合わせをする」

📖 詳細

1. まず前提 — この病態・指標の基礎（初めての人にも）🧩

要旨

5分で背景を掴む ショックの初期対応で最初に迷うのは「輸液を入れるか、入れないか」である。入れなさすぎれば臓器灌流が保てず、入れすぎれば肺水腫・腸管浮腫・静脈うっ血で予後が悪化する。この二択に答えを出すための概念が輸液反応性（fluid responsiveness）で、定義は「輸液を入れたら一回拍出量／心拍出量が有意に増える状態」。裏側にあるのは Frank–Starling 曲線で、心室が曲線の上行脚（急峻な部分）にいれば前負荷を足すほど拍出が増え、平坦部にいれば足しても増えない。つまり「輸液反応性がある＝Frank–Starling 曲線の上行脚にいる」ということ。

下大静脈（IVC）の呼吸性変動：陽圧換気中は吸気で胸腔内圧が上がり、右房圧が上昇して IVC が押し広げられる（自発呼吸とは逆向きの動きになる点に注意）。血管内容量が足りていないほど IVC は虚脱しやすく、呼吸に伴う径の振れ幅が大きくなる。本研究の下大静脈変動指数（IVCVI）は剣状突起下走査の M モードで最大径・最小径を測り、

  • IVCVI（%）＝（IVCmax − IVCmin）÷ IVCmin × 100

で計算する。分母が最小径である点が重要で、これは陽圧換気で用いられる distensibility index（膨張指数）と同じ式である。分母を最大径にする「虚脱率（collapsibility index）」とは値が変わるため、閾値を混同してはいけない。

僧帽弁 E/e’：心尖部四腔像でパルスドプラを僧帽弁尖に置いて拾う E波が拡張早期の左室流入速度（＝左房から左室への受動的な流入）、同じ心尖部四腔像で組織ドプラを中隔側僧帽弁輪に置いて拾う e’波が拡張早期の心筋自体の弛緩速度である。E は左房圧と左室弛緩の両方に引っ張られ、e’ は主に弛緩能を映す。したがって E を e’ で割った E/e’ は「弛緩の悪さで補正した流入圧」＝左室充満圧の代用指標になり、集中治療領域でも拡張機能障害の評価指標として広く検証されてきた。E/e’ が高い＝左室が硬く充満圧が高い状態で、Frank–Starling 曲線でいえば平坦部にいる可能性が高いため、輸液反応性がない側に傾くというのがこの研究の仮説である。

比較対象の2つ：CVP（中心静脈圧）は右房圧の代用で、古典的な静的前負荷指標。低ければ「まだ入る」と考えられてきたが、単独では輸液反応性を予測できないという批判が定着している。PPV（脈圧変動）は陽圧換気による一回拍出量の周期的変動を動脈圧波形から拾う動的指標で、精度は高いが「一回換気量が十分（おおむね8 mL/kg以上）」「自発呼吸がない」「不整脈がない」「胸壁・腹腔内圧が正常」といった心肺相互作用の条件が揃わないと成立しない。本研究の表では PPV という略号が脈圧変動と陽性的中率の両方に使われているので読むときは注意が要る。

2. 背景と目的

  • 輸液蘇生はショック管理の中心だが、不足も過剰も転帰を悪化させるため、輸液反応性を正確に予測することが決定的に重要である
  • 心エコーは今やICUで広く使え、血行動態情報と輸液反応性評価の両方を提供する
  • IVCVI は簡便に得られ、自発呼吸下・陽圧換気下の双方で検証があり、人工呼吸中のショック患者を対象としたメタ解析でも有望な結果が示されている
  • 一方 E/e’ を輸液反応性予測に用いた最近の研究は結果が一貫していない。しかもそれらは心臓外科症例を含み、測定は経食道心エコーで行われていた
  • 目的：経胸壁心エコーで測定した僧帽弁 E/e’ の輸液反応性予測能を解析し、IVCVI の予測能と比較する

3. 方法（Methods）

  • デザイン：前向き観察研究（研究プロトコルは Clin Crit Care 2022 に既報）。本稿はその結果を Correspondence 形式で報告
  • 対象：Siriraj 病院（バンコク）内科系ICUに入室した成人・人工呼吸中のショック患者。期間は2021年10月〜2024年9月
  • ショックの定義：収縮期血圧 <90 mmHg または MAP <65 mmHg に、組織灌流不良の所見を伴うもの
  • 測定（ショック診断後ただちに経胸壁心エコー）
  • 左室駆出率：Teichholz 法
  • 心拍出量：LVOT径と LVOT VTI から一回拍出量を算出し、心拍数を乗じる
  • IVCVI：剣状突起下走査の M モードで呼吸周期を通じた最大径・最小径から算出（分母は最小径）
  • 僧帽弁 E/e’：心尖部四腔像で、E波はパルスドプラを僧帽弁開放部に、e’波は組織ドプラを中隔側僧帽弁輪に置いて計測
  • 蘇生を遅らせないため、全エコー指標を3分以内に取得
  • CVP と PPV も輸液負荷の前後で記録
  • 輸液チャレンジ：ベースライン取得後、酢酸リンゲル液 300 mL を15分で投与し、直後に全指標を再測定
  • 輸液反応性の定義：心係数 >15% 増加 または MAP >5 mmHg 上昇
  • 解析：ROC 曲線による AUROC 比較、最適カットオフは Youden 指数で決定。患者背景・治療・転帰は Supplementary Table 1、輸液負荷前後の血行動態変化は Supplementary Table 2 にまとめられている

7. 著者の結論と提案する使い方

  • 人工呼吸中のショックでは僧帽弁 E/e’ は中等度の識別能にとどまり、IVCVI が優れていた
  • 実務上の閾値（IVCVI >18%、E/e’ <10）は反応しそうな患者を拾えるが、感度と特異度のトレードオフが残る
  • 輸液反応性の定義に MAP を組み込んだことで検出が改善した。MAP 基準がなければ27例（34%）が誤分類されていた
  • CVP と PPV は許容できる補助指標だが、PPV の精度は心肺相互作用の条件に依存する

8. 批判的吟味（JCでの論点）

  • 参照基準が緩い：輸液反応性を「心係数 >15% 増加 または MAP >5 mmHg 上昇」と定義した点が最大の論点。MAP は前負荷依存性の指標ではなく、血管トーヌス・昇圧薬の効き方でも動く。レスポンダー51例のうち27例（53%）は MAP 基準のみで拾われており、実質的に「血圧が少し上がった群」を含む集団に対する予測能を測っている。心係数のみを基準にした場合の AUROC が示されていないのは痛い
  • 数値の内的不整合：本文では CVP を「良好な識別能（AUROC 0.724、P = 0.006）」としているが、Table 1 の CVP の P は 0.053 と非有意。逆に PPV は本文の AUROC が P = 0.064 と非有意なのに、表では P = 0.030。表の P が何の検定なのか（AUROC の 0.5 との比較か、カットオフでの分割表の検定か）が本文からは判別できない
  • カットオフでの性能は実用に耐えない：AUROC 0.788 の IVCVI ですら感度68.6%／特異度58.6%。3人に1人のレスポンダーを取り逃がし、ノンレスポンダーの4割を反応ありと誤判定する。AUROC の見た目の良さとカットオフでの成績の乖離は、症例数の少なさと参照基準の緩さの両方を疑わせる
  • 各指標の分母が示されていない：PPV の感度72.7%・特異度54.5%は 8/11・6/11 のような分数に一致しやすく、CVP も含めて全80例で測れていない可能性が高い。指標ごとの解析対象数が書かれていないのは Correspondence の紙幅の制約とはいえ致命的
  • 信頼区間が広い：E/e’ の95%CI 下限は 0.535、PPV は 0.509 と 0.5 のすぐ上。80例（レスポンダー51／ノンレスポンダー29）では、これらの指標が「使える」と言い切れる精度に達していない
  • グレーゾーンの扱いがない：Youden 指数で単一のカットオフを引く方法は、判断不能域（inconclusive zone）を認めるグレーゾーン法に比べて臨床的な有用性を過大評価しやすい
  • PPV の閾値が低すぎる：>8% は一般的な12〜13%より明らかに低い。低一回換気量下で PPV の変動幅が縮む問題は既知だが、本研究では換気設定（一回換気量・PEEP・自発呼吸の有無）が本文に一切記載されておらず、PPV や IVCVI の解釈条件が読めない
  • IVCVI の式に注意：分母が最小径であるため、値は虚脱率より大きく出る。18%という閾値を虚脱率で運用している施設にそのまま持ち込むと過大に反応性ありと判定する
  • 単施設・内科系ICU・敗血症性ショック中心（75/80例）。外科系・心原性ショックへの外挿は困難
  • 測定者の再現性が示されていない：3分以内という時間制約下での e’ 波計測は角度依存性が高く、級内相関係数などの信頼性指標が報告されていない
  • 論文の設計上の位置づけ：CODEFIRE（輸液反応性研究の報告基準）が求める項目（グレーゾーン解析、測定の再現性、換気条件、指標ごとの欠測）の多くが満たされていない。Correspondence という体裁を割り引いても、結論の一般化には慎重であるべき

結論 人工呼吸中のショック80例で、IVCVI（AUROC 0.788、>18%）は僧帽弁E/e’（0.682、<10）より輸液反応性をよく予測した。ただしカットオフでの感度68.6%／特異度58.6%は単独判断に耐えず、E/e’ は「特異度75.9%・陽性的中率81.1%」を活かして事前確率を上げる補助にとどめ、最終判断は300 mL 負荷後の LVOT VTI・心係数の再測定で行う。 なお本研究の輸液反応性の定義には MAP >5 mmHg 上昇が含まれ、レスポンダーの53%（全体の34%）がこの基準だけで拾われている ため、心係数ベースで判定している施設ではここに示された精度をそのまま流用してはいけない。
