🏥 聖路加ICUでの実践への示唆

聖路加ICUでの実践

明日からどうするか ① 日本全体では、high-intensity type ICU は院内死亡の低下と関連しなかった。

③ 感度分析（施設IDをランダム切片とする階層ロジスティック回帰）でも生き残った。 ==術後患者：high-intensity type OR 0.79（0.64–0.98, P=0.03）、closed ICU OR 0.75（0.57–0.97, P=0.03）。== mandatory consultation は 0.81（0.65–1.02, P=0.07）で有意性を失った。 著者の指摘が鋭い：階層モデルは「中間因子（曝露とアウトカムの間にある診療プロセスの違い）まで調整してしまう」ため保守的になりやすい。それでも術後患者で有意だった。

④ 当院（聖路加ICU）にとっての含意。

  • 当院は closed ICU。本研究は「術後患者では closed ICU が有利」という日本のエビデンスを提供している。
  • 当院は心臓外科・消化器外科の術後患者が多いため、本研究の有意なサブグループにまさに該当する。
  • closed ICU で ICUベッド1床あたりの専従集中治療医数の中央値は 0.62（IQR 0.37–0.83）と最も多かった。 当院の配置がこの分布のどこにあるかを確認する価値がある。

⑤ 「なぜ術後患者だけなのか」は分かっていない。ここが次の研究テーマ。 著者の推論：「専従の集中治療医の方が、ICU特有の全身管理やプロトコルに習熟しており、診療プロセスに違いが生じ、アウトカムの違いにつながっている可能性」。 実際、JSICM ICU機能評価委員会の報告では「専任・専従医が人工呼吸器の設定と離脱の方針を決定しているICUの方が死亡率が低い傾向」がある。 ⚠️ ただし JIPAD は診療プロセスのデータを収集していないため、現時点でこの推論は検証できない（著者が明記）。 → JIPAD事業への直接の提言：診療プロセス項目の収集が必要。

🧭 この論文の位置づけ（Known / Unknown / What's new）

補足

3点で掴む Known

  • ICUは、集中治療医の関わり方によって high-intensity type と low-intensity type に分けられる。
  • closed ICU：専従の集中治療医が主治医となり、ICU入室患者の治療方針をすべて決定する
  • mandatory critical care consultation：主治医からの必須の要請を受けて、集中治療医が全ICU入室患者に介入する
  • elective critical care consultation（low-intensity）：主治医から要請があった時のみ集中治療医が介入する
  • Wilcoxらのメタ解析では、high-intensity type ICU の方が院内死亡が低いと報告されている。
  • 日本集中治療医学会が公表した「集中治療部設置のための指針」でも high-intensity type ICU での管理を推奨している。

Unknown

  • しかし、これらに引用されている文献はすべて海外の研究であり、日本でも同じ結果となるかは不明である。
  • 日本のICUは術後患者が多いなど海外と異なる特性があるため、改めて日本のICUで high-intensity type ICU の優位性を明らかにする必要がある。

What's new

  • 日本全国87 ICU・65,395例で、日本初の大規模検証を行った。
  • 全体では high-intensity type ICU の優位性は示されなかった（OR 0.96）。
  • 術後患者に限れば、high-intensity type ICU（OR 0.81）および closed ICU（OR 0.80）が院内死亡の低下と有意に関連した。
  • 施設IDをランダム切片とする階層モデルの感度分析でも、術後患者での関連は保たれた。

📖 詳細

1. まず前提 — ICUの運用体制3類型

要旨

初学者向けの基礎 ① なぜ「運用体制」が問題になるのか ICUは、様々な疾患および病態の重症患者が入室し、集中的な全身管理が行われる場。一般病棟では臓器別の診療科が主治医として診療にあたることが多いが、ICUでは必ずしもそうとは限らない。ICU専従の集中治療医が、疾患および病態にかかわらず全身管理を行う場合がある。

② 3類型の定義（本研究が使っている国際的な定義）

分類型定義
high-intensityclosed ICU専従の集中治療医が主治医となり、ICU入室患者の治療方針をすべて決定する
high-intensitymandatory critical care consultation主治医からの必須の要請を受けて、集中治療医が全ICU入室患者に介入する
low-intensityelective critical care consultation主治医から要請があった時のみ集中治療医が介入する

さらに「集中治療医がまったくいない open ICU」も low-intensity type に含まれるが、JIPAD には参加していない。 ＝本研究の「low-intensity」は日本で最も手薄な体制ではない。 これは結果の解釈に効く（差が出にくい方向のバイアス）。

③ 「専従」の定義 勤務時間の8割以上ICU業務を行っていることとされ、常勤医を想定している。

④ JROD とは APACHE III score が日本のICU患者において予測死亡率を過大に推定してしまうことを是正する目的で作られた死亡予測モデル。 → JROD 日本版死亡リスク予測モデル — APACHE III-jの過大評価を階層GAMで補正（JIPAD 33557例・JIntensiveCare2021）

⑤ 「中間因子（mediator）」を調整するとどうなるか — 本論文の統計的な見どころ 曝露（運用体制）→ 中間因子（診療プロセス）→ アウトカム（死亡）という経路がある場合、 中間因子を調整すると、本来の効果の一部が消えてしまう。 本研究の感度分析（施設IDをランダム切片とする階層モデル）は「未測定の施設因子」を調整する目的だが、施設に紐づく診療プロセスの違いも同時に吸収してしまう。 → 結果は保守的（効果を過小評価する方向）になる。それでも術後患者で有意だった、というのが著者の論法。==

2. 方法（Methods）

  • デザイン：後ろ向きコホート研究。STROBE声明を参照。
  • データ：JIPAD（詳細は https://www.jipad.org ）
  • 対象：2022年4月1日〜2023年3月31日にICUに入室し、2023年8月31日までに退室した患者
  • 除外：PICU施設の患者（6施設）、16歳未満、ICU再入室、中心静脈カテーテル留置などの手技のためだけの入室、施設情報が欠損している施設の患者（2施設）
  • 曝露：ICUの運用体制（JIPADが定義どおりに収集している）
  • 集団特性の変数：年齢、性別、入室経路、術後管理目的の入室の有無、緊急入室の有無、入室時疾患分類、慢性疾患の有無、APACHE III score、APACHE III-j予測死亡率、JROD予測死亡率、ICU退室時死亡、退院時死亡
  • 施設情報：ICU認可病床数、専従の集中治療医数、病院全体の病床数、年間ICU入室患者数、病院の種別。専従集中治療医数・病院全体の病床数・年間ICU入室患者数は「ICUベッド1床あたり」の数値も算出。
  • 主解析：院内死亡をアウトカム、ICUの運用体制を曝露とし、患者レベルのロジスティック回帰。low-intensity type（elective critical care consultation）を基準とし、high-intensity type／mandatory critical care consultation／closed ICU の効果量を推定。
  • 共変量：APACHE III score、術後管理目的の入室の有無、緊急入室の有無、疾患分類（APACHE の予測モデルに似せる形で選択）。加えて「high-intensity type ICU は医師数が多くないと運用が難しい」ため、施設レベルの交絡調整として「ICUベッド1床あたり専従の集中治療医数」を投入。==
  • サブグループ解析：
  • 術後管理目的の入室の有無（海外メタ解析で術後患者での優位性が示されていたため、追証目的）。共変量：APACHE III score、緊急入室の有無、疾患分類、ICUベッド1床あたり専従集中治療医数
  • 探索的解析：緊急入室の有無、疾患分類別（頻度上位4つ）
  • 感度分析：関連が有意となった回帰モデルに、追加で施設IDをランダム切片として組み入れた階層ロジスティック回帰。未測定の施設因子を調整する目的。
  • 統計：R version 4.4.0、P<0.05

4. 考察（著者の解釈）

TAKE HOME

著者の中心的な推論 「high-intensity type ICU（特に closed ICU）では、専従の集中治療医の方が、ICU特有の全身管理やプロトコルに習熟していると考えられ、結果として診療プロセスに違いが生じ、アウトカムの違いにつながっている可能性がある。」 傍証：日本集中治療医学会ICU機能評価委員会の報告では、「専任・専従医が人工呼吸器の設定と離脱の方針を決定しているICUの方が死亡率が低い傾向」を認めている。 統計的な補強：感度分析（階層ロジスティック回帰）は、交絡以外にも中間因子（曝露とアウトカムの中間にある診療プロセスの違い）が調整されてしまう関係で保守的な結果になりやすい。にもかかわらず、術後患者で有意だった。 ⚠️ 「JIPADでは診療プロセスのデータを収集していないため、現時点ではこの推論が正しいか確かめることができない」（著者が明記）。海外の surgical ICU の優位性を示したメタ解析でも、優位性の具体的な理由は分からないとしている。

本研究の強み（著者の主張）

  • 日本全国の多数のICUからのデータから導かれた結果である。
  • JSICM の集中治療専門研修施設報告によると、成人ICUのうち elective critical care consultation は 98施設、mandatory critical care consultation は 187施設、closed ICU は 77施設。運用体制の施設割合から考えると、JIPAD参加施設と日本全国のICUの状況に大きな乖離はないと考えられる。
  • ⚠️ ただしランダムサンプリングではないため、今回の研究結果の一般化可能性は保証されていない（著者が明記）。

5. 限界（著者が挙げているもの）

  • 術後患者において high-intensity type ICU と院内死亡の低下に関連は認めるものの、実際に因果関係があるかは確定的でない。 しかし、因果関係を調べるためのRCTは現実的に困難であり、観察研究からしか知見は得られない。
  • 日本の先行研究では、ICUを closed 化した際の前後比較で、単施設研究などの限界はあるものの、closed ICU になった後の方が死亡率が低下する、あるいはその傾向があると報告されている。
  • closed ICU と mandatory critical care consultation の区別が分かりづらいため、両者の効果に関しては誤分類バイアスが生じている可能性がある。
  • JIPADはデータのvalidation研究を行っていないため、今後の研究で入力情報の正確性を確かめる必要がある。
  • ただし、両者を high-intensity type ICU としてまとめた場合は、誤分類バイアスは生じない。
  • 今後の研究では診療プロセスの情報を収集し、推論が正しいか検証する必要がある。

6. 結語（著者の言葉に沿って）

> 日本の成人ICUにおいて、high-intensity type ICU は院内死亡の低下と有意な関連を認めなかった。しかし、術後患者で high-intensity type ICU は院内死亡の低下と有意な関連を認めた。

🔍 批判的吟味（JCでの論点）

⚠ 注意

① 「low-intensity」の中身が日本と海外で違う 本研究の low-intensity は elective critical care consultation のみ。集中治療医がまったくいない open ICU は JIPAD に参加していない（著者が明記）。 一方、海外メタ解析の「low-intensity」には open ICU が含まれる。 ＝本研究は「集中治療医がいる施設どうし」の比較をしている。差が小さく出るのは当然。 全体で OR 0.96 と有意差がつかなかった主因はここにある可能性が高い。 JCで最初に指摘すべき点。

⚠ 注意

② 術後患者サブグループでの有意性は「多重比較」の産物ではないか サブグループは術後の有無（2）＋緊急入室の有無（2）＋疾患分類上位4つ（4）＝計8つ。そのうち術後患者だけが有意。 多重比較の補正がない。 ただし術後患者サブグループは「海外メタ解析で優位性が示されていたため追証する」という事前の仮説に基づくと著者が明記しており、探索的解析（緊急入室・疾患分類別）とは位置づけが違う。これは擁護材料になる。

  • ③ 交絡調整が「APACHEの予測モデルに似せる形」で行われている。 APACHE III score・術後の有無・緊急入室の有無・疾患分類の4つ。併存疾患・フレイル・治療制限（DNAR）などが入っていない。 closed ICU に重症患者が集まっている（JROD予測死亡率が最も高い）ことを考えると、残差交絡は無視できない。
  • ④ 施設レベルの調整が「ICUベッド1床あたり専従集中治療医数」1つだけ。 病院種別・病床数・年間入室患者数を収集していながら、主モデルには入れていない。 感度分析の階層モデルで施設IDを入れて対処しているが、固定効果として何を入れ何を入れないかの根拠が薄い。
  • ⑤ 「1年間だけ」のデータ。 2022年度のみ。COVID-19の影響が残る時期であり、運用体制が一時的に変更されていた施設があった可能性がある。
  • ⑥ 誤分類バイアス（著者も明記）。 closed ICU と mandatory consultation の区別は現場でも曖昧。JIPADはvalidation研究をしていない（著者の明記） ため、施設の自己申告に依存している。この点はJIPAD事業全体の課題でもある。
  • ⑦ 因果推論の限界。 逆因果の可能性：「成績の良い施設が closed 化する余力を持つ」のか「closed 化したから成績が良い」のか。著者は日本の前後比較研究（単施設）を挙げているが、エコロジカルな比較の域を出ない。
  • ⑧ 「診療プロセスを収集していない」が本質的な限界。 本論文の核心的な推論（プロセスの違いが効いている）が検証不能であることを著者自身が認めている。 → JIPADのデータ辞書に人工呼吸器離脱プロトコル・早期離床・鎮静深度などのプロセス指標を追加する提言につながる。 これは事務局作業の具体的なアジェンダになりうる。
  • ⑨ 「術後患者だけ効く」ことの臨床的解釈。 術後患者は病態が均質で、標準化されたプロトコル（早期抜管・疼痛管理・離床）が効きやすい。一方、内科系の重症患者は病態が多様で、体制よりも個別の判断が効く。この仮説なら「プロセス標準化の効果」という説明と整合する。==
  • ⑩ 効果量の大きさをどう受け止めるか。 術後患者で OR 0.81。院内死亡9.0%を基準にすると、絶対リスク差は約1.5〜2%程度。ICU全体の体制を変えるコストに見合うかは、別途の医療経済評価が要る。

✅ Take home message

TAKE HOME

まとめ

  1. JIPAD 87 ICU・65,395例（2022年度）。退院時死亡 9.0%。
  2. 日本全体では、high-intensity type ICU は院内死亡の低下と有意に関連しなかった（調整OR 0.96、95% CI 0.88–1.05）。
  3. 術後患者に限ると有意：high-intensity type OR 0.81（0.70–0.95）、closed ICU OR 0.80（0.67–0.95）。
  4. 施設IDをランダム切片とする階層モデルの感度分析でも保たれた（術後患者で high-intensity OR 0.79、closed ICU OR 0.75）。
  5. その他のサブグループ（緊急入室の有無・疾患分類上位4つ）では有意差なし。
  6. ⚠️ 本研究の「low-intensity」には open ICU が含まれない（JIPADに参加していない）。海外メタ解析と比較対象が違うため、差が小さく出る構造になっている。
  7. closed ICU には最も重症な患者が集まっている（JROD予測死亡率 中央値 2.3%、院内死亡 10.3%）。粗比較では closed ICU が最も悪く見える。
  8. 著者の推論：専従集中治療医の「診療プロセス」の違いが効いている。傍証としてJSICM ICU機能評価委員会の「人工呼吸器の設定・離脱を専任/専従医が決めるICUの方が死亡率が低い傾向」。
  9. ⚠️ JIPADは診療プロセスのデータを収集していないため、この推論は検証できない（著者が明記）。JIPAD事業への具体的な改善提言になる。
  10. ⚠️ closed ICU と mandatory consultation の誤分類バイアスの可能性。JIPADのvalidation研究が未実施。
