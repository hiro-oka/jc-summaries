🏥 聖路加ICUでの実践への示唆

聖路加ICUでの実践

病棟プロトコルへの落とし込み

  • 「バンドルは項目を配るだけでは動かない。遵守率を測って返すから動く」 — これが本研究の最大の学び。9項目のうち何が効いたかは分離できていないが、全体遵守率が 60% → 83.3% に上がったことと VAP が 24.0 → 3.9/1000人工呼吸日 に減ったことは並行している。当院のVAPバンドル運用でも、遵守率の測定・可視化・フィードバック（グラフ掲示、定例会議）をセットにする設計が要る。
  • 効果は「介入期間中」ではなく「その後」に最大化した。介入期 −56%、介入終了後の追跡期 −85%。文化として定着するまでに時間がかかるという前提で、短期の数字で成否を判定しない。
  • VAPリスクは人工呼吸開始直後が最も高い。前介入期の日次ハザードは5日目で 4.9%。挿管したその日からバンドルを回す設計にする（「数日たってから」では遅い）。
  • SOD（選択的口腔内除菌）の当院での扱い：本研究ではコリスチン＋トブラマイシン＋ナイスタチンを1日3回、48時間以上の人工呼吸が見込まれる患者に投与し、追加のVAP減少が示された。ただし SOD遵守率は 51%〜66% と低く、「48時間以上人工呼吸が続くか」の予測自体が難しいという実務上の壁がある。当院で導入するなら耐性菌サーベイランスの継続が前提であり、日本の疫学（本研究のスイスより多剤耐性の状況が異なる）での検証が必要。まずはSODを除く8項目の徹底が先。
  • 口腔ケアの薬剤選択には国内事情の注意（PDF外の補足）：本研究は 0.2% クロルヘキシジングルコン酸塩水溶液を用いているが、本邦ではクロルヘキシジンの口腔粘膜への適用はアナフィラキシー報告から添付文書上禁忌であり、そのまま移植できない。当院の口腔ケアプロトコルは物理的清掃を主軸に組む。
  • 副次的な利得が大きい：人工呼吸期間中央値 7.14 → 6.35日、ICU死亡率 16.2% → 13.5%、下気道感染症治療に用いる広域抗菌薬の使用量も有意に減少。感染対策の投資対効果を経営会議で説明する際の具体例として使える。

🧭 この論文の位置づけ（Known / Unknown / What's new）

補足

リサーチ・イン・コンテキスト

  • Known（既に分かっていたこと）：VAPは人工呼吸の重大な合併症で、発生率 2〜16件/1000人工呼吸日、寄与死亡率 5〜13%、生存者のICU在室延長は最大9日。予防バンドルによるVAP減少の報告は多数ある。SOD（局所抗菌薬を口腔咽頭に適用し、経腸・経静脈抗菌薬は用いない方法）については、抗菌薬による除菌でVAPが有意に減る（RR 0.27, 95%CI 0.18–0.42）が、全死因死亡・人工呼吸期間・ICU在室期間には影響しないとされていた。一方、RCT 4件を含むメタ解析ではSODの死亡への有益効果も報告されていた。
  • Unknown（分かっていなかったこと）：(1) バンドルの遵守率を報告した研究は少なく、(2) 導入後の持続性を検証した研究はさらに少ない。(3) SODをバンドルに組み込んだ報告はほぼ皆無（既報1件のみ）。(4) SODによる耐性菌誘導の懸念が残っていた（既存のデータの多くは耐性菌の少ないオランダ由来）。
  • What's new（本研究の新規性・意義）：9項目バンドル（SODを含む）を段階的に導入し、遵守率とVAP率を同時に、介入終了後11か月まで追跡。VAPを85%減少させ、SODの追加的価値を統計的に分離して示した。さらに、耐性菌の疫学がオランダより厳しい環境（スイス）で、耐性菌の増加を認めなかったことを報告した。

📌 全体要約

要旨

ひとことで 9項目のVAP予防バンドル（SODを含む）を段階的に導入したところ、VAP発生率は 24.0 → 11.0 → 3.9件/1000人工呼吸日（−85%）へと持続的に低下し、人工呼吸期間とICU死亡率も有意に低下した。SODには追加的価値があり、耐性菌の増加は認めなかった。

  • セッティング：ジュネーブ大学病院（1900床）の混合内科外科ICU（34床、職員250名、年間入室2400例、看護師:患者=1:2）。研究期間中、ICUの構造・人員配置は変更なし。
  • デザイン：quasi-experimental・対照群なしの前後比較。前介入期 8か月（2014年1〜8月）、介入期 12か月（2014年9月〜2015年8月）、後介入期 11か月（2015年9月〜2016年7月）。対象は 48時間超の人工呼吸を受けた患者。
  • 規模：全入室 6287例のうち、ICU在室48時間超 2991例、48時間超の人工呼吸 1262セッション、計 10,825人工呼吸日。
  • 主要アウトカム：初回VAP発生。Cox の cause-specific 比例ハザードモデル（死亡・ICU退室を競合リスクとする競合リスク生存解析）で評価。
  • 結果（初回VAP発生密度／1000人工呼吸日）：前介入 24.0 → 介入 11.0 → 後介入 3.9。介入期 −56%（HR 0.44, 95%CI 0.29–0.65, P<0.001）、後介入期 −85%（HR 0.15, 95%CI 0.08–0.27, P<0.001）。
  • SODの寄与：SODなしの8項目で −42%（HR 0.58, 95%CI 0.38–0.87）、SOD追加でさらに −70%（HR 0.30, 95%CI 0.13–0.72）。
  • 副次アウトカム：人工呼吸期間中央値 7.14 → 6.35日（P<0.003）、ICU死亡率 16.2% → 13.5%（P<0.049）、下気道感染症治療用の広域抗菌薬使用量（DOT/1000患者日）も有意に減少（P<0.028）。耐性菌（コリスチンまたはトブラマイシンに自然耐性）の発生密度は増加せず、コリスチンMICも上昇しなかった。

📖 詳細

1. まず前提 — VAPとSODの基礎（初めての人にも）🧩

要旨

5分で背景を掴む VAP（ventilator-associated pneumonia：人工呼吸器関連肺炎）とは、気管挿管・人工呼吸開始から48時間以降に発症する肺炎。口腔咽頭に定着した細菌がカフ周囲から気道に垂れ込む（microaspiration）ことが主な機序で、「定着 → 誤嚥 → 感染」の連鎖のどこかを切るのが予防の考え方。 バンドル（bundle）とは、単独ではエビデンスが中程度の複数の介入をパッケージにして「全部やる」ことで効果を出す手法。個々の項目の寄与を分離できないのが弱点だが、現場で回しやすいのが強み。 SOD（selective oropharyngeal decontamination：選択的口腔咽頭除菌）とは、口腔咽頭に局所抗菌薬を塗布する方法。経腸・経静脈の抗菌薬は使わない点が SDD（selective digestive decontamination：消化管まで含めて除菌）と異なる。本研究では コリスチン・トブラマイシン・ナイスタチンを1日3回塗布した。狙いは、グラム陰性桿菌と真菌を口腔から減らして「定着」の段階で断つこと。最大の懸念は耐性菌の選択圧である。 用語の一言定義

  • CPIS（Clinical Pulmonary Infection Score）：体温・白血球・喀痰・酸素化・胸部X線・培養から算出する肺炎の臨床スコア。本研究では >6 をVAP診断の要件とした。
  • 発生密度（incidence density）：分母を「人工呼吸日数」にした発生率（件/1000人工呼吸日）。人工呼吸期間が変わっても比較できる。
  • 競合リスク解析：VAP発症前に「死亡」や「ICU退室」が起きるとVAPは観察されなくなる。これらを競合イベントとして扱い、VAP発症のハザードを正しく推定する手法。
  • cause-specific HR：上記モデルにおける、当該原因（VAP）に対するハザード比。
  • DOT（days of therapy）：抗菌薬の使用量指標。1000患者日あたりの投与日数。

2. 背景と目的 🦠

VAPは依然として人工呼吸の重大な合併症であり、発生率 2〜16件/1000人工呼吸日、寄与死亡率 5〜13%、生存者ではICU在室が最大9日延長し、追加コストも大きい。

予防バンドルによるVAP減少の報告は多いが、(1) 遵守率まで報告している研究は少なく、(2) 導入後の持続性を検証した研究はさらに少ない。そして (3) SODを含むバンドルの報告は既報1件のみであった。

SODについては、抗菌薬による除菌でVAPが有意に減る（RR 0.27, 95%CI 0.18–0.42）一方、全死因死亡・人工呼吸期間・ICU在室期間には影響しないとするメタ解析と、RCT 4件を含む解析で死亡への有益効果を示したメタ解析が併存していた。耐性菌の誘導は深刻な懸念として残っていたが、近年のメタ解析では選択的除菌を受けた患者で耐性菌の発生率増加は検出されていなかった。

本研究の主要目的は、多面的VAP予防プログラムの導入がVAP率に与える影響を明らかにすること。副次目的は、SODのVAP率への影響、耐性菌の出現、抗菌薬使用量・人工呼吸期間・在室期間・死亡率への影響の評価である。

3. 方法（Methods）📐

  • デザイン：quasi-experimental・対照群なしの前後比較。質改善プロジェクトとして実施されたため倫理委員会承認は不要とされた。
  • 期間：前介入 8か月（2014年1〜8月）／介入 12か月（2014年9月〜2015年8月）／後介入 11か月（2015年9月〜2016年7月）。
  • VAPサーベイランス：2014年1月から実施。48時間超の人工呼吸（気管チューブまたは気管切開）を受けた全患者について、年齢・性別・SAPS II・入室理由・人工呼吸日・VAPの有無と発症日・CPIS・診断法（BAL または mini-BAL）・分離菌・入退室日・死亡を記録。スクリーニング・データ収集・報告は期間を通じて同じICUスタッフが担当し、VAP診断は2名の研究者が独立に判定し合議で決定した。
  • VAPの定義
  • Probable VAP：(1) 画像変化＋全身炎症（体温 ≥38℃、白血球 >12,000 または <4000/mL）＋臨床的肺所見（膿性気管分泌物）を HELICS 基準で満たし、かつ (2) CPIS >6。
  • Definite VAP：上記に加えて、BAL ≥10⁴ CFU/mL または mini-BAL ≥10³ CFU/mL の定量培養陽性。
  • 早期発症＝人工呼吸開始から4日以内、遅発性＝4日以降。
  • 多面的予防プログラム（9項目、3段階で導入）
導入時期分類具体的な介入
2014年9月基本的な良い実践（7項目）手指衛生の遵守／半坐位（>30°）の維持／0.2%クロルヘキシジングルコン酸水溶液による1日3回の口腔ケア／気管チューブカフ圧 ≥25 cmH₂O の維持／毎日の鎮静中断／毎日のウィーニングトライアル／毎日の積極的な離床

  • 教育とフィードバック：集中治療医・ICU看護師・薬剤師・感染管理／感染症医からなる多職種タスクフォースを2014年5月に設置。医療従事者の知識を2014年8月と2015年12月に質問票で評価。看護師・看護助手・理学療法士向けに1時間の教育プログラムを2014年9月〜2015年3月に実施。日次のeサーベイランスフォームでデータを記録し、5名のICU・感染管理チームが評価を担当。フィードバックは定例会議と、遵守率とVAP率のグラフの掲示によって行った。
  • 遵守率の測定：各指標について1点を与え、評価可能な指標数で割って患者ごとに百分率で表現（手指衛生は集計データ指標のため全体遵守率の計算から除外）。
  • 統計：Mann-Whitney U検定、Kruskal-Wallis検定、独立標本中央値検定、Pearson χ²検定または Fisher正確検定。介入効果はセグメント化回帰（Poissonモデル）で発生率比（IRR）を、また競合リスク生存解析（死亡・ICU退室を競合イベント）を用いた Cox cause-specific 比例ハザードモデルで HR を算出。両側検定、P ≤ 0.05 を有意とした。PASW 23、STATA 13.1。

4. 結果① — 遵守率は測って返せば上がる 📈

前介入／介入／後介入の各期で、手指衛生 73・1224・695件、その他の予防策 223・2042・632件の評価を実施。

  • 手指衛生遵守率：56.2% → 67% → 65.5%（介入期に上昇し、その後も維持）
  • その他8項目の全体遵守率：60% → 80% → 83.3%（介入期・後介入期とも有意に上昇）
  • 各項目の遵守率は各期間の間で有意に上昇した。例外は口腔ケアで、介入期 83.7% から後介入期 79.3% へ有意に低下した。
  • SODの遵守率は低かった：介入期 51%、後介入期 66%。著者らは「48時間超の人工呼吸を正確に予測するのは臨床上困難で、この不確実性がSOD対象患者数を減らした可能性がある」と述べている（ただし集中治療医の予測能力は研究期間を通じて改善した）。

6. 結果③ — SODの追加的価値をどう分離したか 🎯

7. 結果④ — 耐性菌・抗菌薬・その他の転帰 🧪

  • 耐性菌：コリスチンまたはトブラマイシンに自然耐性の菌の発生密度（/1000患者日）は増加せず、コリスチンMICもSOD導入後に上昇しなかった。
  • 抗菌薬使用量：総使用量は3期間で有意な変化なし。ただし下気道感染症治療に用いる広域抗菌薬の使用量は、後介入期に前介入期と比べて有意に減少（P<0.028）。著者らは「臨床的敗血症の治療分と、下気道感染症治療用抗菌薬が総使用量の73%を占める『希釈効果』」で総量が動かなかったことを説明している。
  • 人工呼吸期間：中央値 7.14 → 6.50 → 6.35日（前介入 vs 介入、前介入 vs 後介入で有意）。
  • ICU死亡率：16.2% → 10.4% → 13.5%（前介入 vs 介入、前介入 vs 後介入で有意、P<0.049）。28日死亡率は 23.4% → 17.9% → 20.5%。
  • ICU在室期間：3期間で有意差なし。
⚠ 注意

臨床上の要注意ポイント SODの長期使用には耐性菌の出現・選択に関する継続的なサーベイランスが必須である と著者らは結論に明記している。本研究では耐性菌増加を検出しなかったが、検出法が期間中に変わっており（2015年4月まで全患者の月次point-prevalence、5月以降はSOD対象者の限定スクリーニング）、直腸スワブもSOD終了時の1回のみで反復していないため、選択圧について確定的な結論は出せないと著者自身が述べている。また、後介入期にグラム陽性球菌の相対比率が上昇した点にも留意。

8. 限界（原著の記載）⚠️

  1. ランダム化も同時対照群もないため、予防プログラムの正味の効果を正確に評価するのは困難。
  2. 盲検化されておらず、VAPの定義には主観が入りうる。ただし診断法は期間を通じて変更していない。
  3. 遵守率を患者ごと・日ごとに評価していない。SOD以外の個々の項目の寄与は分離できない。Hawthorne効果（観察されていると行動が変わる）により、非観察期間の遵守率が同等であったとは断定できない。
  4. 単施設研究であり、他のICUへの一般化可能性は不明。
  5. 平均への回帰（初期VAP率が高かったこと）の影響は否定できないが、減少幅の大きさから見て、これだけで全体を説明するのは考えにくい。
  6. SODが気管吸引物の微生物学的検出率を下げ、probable VAP の数を見かけ上減らした可能性は否定できない（実際 probable VAP は 43.8% → 11.6% と大きく減っている）。一方で definite VAP の発生密度も期間を通じて低下しており、著者らは「SODが口腔咽頭液を真に『無菌化』し、気道定着から肺感染への移行を防いだ」という解釈を支持する所見だとしている。

✅ Take home message

TAKE HOME

結論 9項目のVAP予防バンドルを「教育・遵守率測定・フィードバック」とセットで導入すれば、VAPは85%減り、その効果は介入終了後も持続する。効果は介入期（−56%）より後介入期（−85%）で大きい — 定着に時間がかかる前提で設計する。 SODには追加的価値がある（バンドル単独 −42%、SOD追加で計 −70%）が、遵守率は51〜66%と低く、長期使用には耐性菌サーベイランスの継続が必須。 VAPが減っただけでなく、人工呼吸期間（7.14 → 6.35日）とICU死亡率（16.2% → 13.5%）も有意に低下した。
