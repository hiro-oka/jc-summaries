🏥 聖路加ICUでの実践への示唆

聖路加ICUでの実践

病棟プロトコルへの落とし込み ① COVID-19でも腹臥位を「非COVID ARDSと同じ根拠」で実施してよい。 本研究は CT で、腹臥位が非COVID ARDS と同様に虚脱の減少・過膨張の減少・含気分布の均一化をもたらすことを示した。当院で「COVIDのARDSは別物だから腹臥位の効果は不明」という留保を置く必要はない。 ② 腹臥位の目的を「酸素化」ではなく「肺保護」と言語化する。 P/F は 14例全員（100%）で改善したが、==P/Fの改善量は形態学的な改善（虚脱の減少）とまったく相関しなかった（rho −0.415, p=0.134）。酸素化が上がらなくても肺は均一化しているし、酸素化が上がっても虚脱が取れたとは限らない。当院の申し送りでは「P/Fが上がらなかったから腹臥位を中止」という判断を避ける。 ③ 「PEEPを上げる」より「腹臥位にする」方が過膨張を作らない。 同じグループの先行研究では、仰臥位で PEEP を 5→15 cmH2O に上げると虚脱は 168 ml 減るが過膨張が 121 ml 増え、全例（100%）で過膨張が増えた。本研究では腹臥位で虚脱が 82 ml 減り、過膨張も 28 ml 減った（14/15例、93%で減少）。リクルートメントの手段として、まず体位を選ぶ理由になる。 ④ 低容量換気でも過膨張は起きている。 過膨張量が中央値より大きかった7例でも、一回換気量は 6.1 ml/kg PBW、プラトー圧 23 cmH2O だった。「6 ml/kg・Pplat 30以下だから安全」ではない==。CT がなくても、コンプライアンス低下と PaCO2 上昇を過膨張のサインとして読む習慣をつける。 ⑤ 深く鎮静・筋弛緩下の早期（挿管3日以内）の話であることを忘れない。 本研究の対象は全例が深鎮静＋筋弛緩下で、腹臥位開始から60分以内の評価である。当院で行う「数時間〜16時間の腹臥位」や覚醒下腹臥位に、この生理学データをそのまま外挿することはできない。 ⑥ 参考値として持っておくと便利な数字。 ARDS の COVID 肺は仰臥位で総肺容量 3277 ml、うち非含気 13%、低含気 25%、正常含気 50%。肺重量は 1434 g で、推定病前重量より 619 g 重い。CTを撮ったときの「重いかどうか」の目安になる。

🧭 この論文の位置づけ（Known / Unknown / What's new）

補足

リサーチ・イン・コンテキスト

  • Known（既に分かっていたこと）：腹臥位は中等症〜重症ARDS（非COVID）で生存を改善する（PROSEVA ほか）。その機序は、背側の非含気だが灌流されている肺を再開通（リクルート）させ、腹側の過膨張を減らすことにあると考えられてきた。結果として動脈血酸素化はほぼ必ず改善するが、それ以上に重要なのは換気がより均等に分布し、人工呼吸による二次的損傷が減ることである。一方で腹臥位には一過性の低酸素、気管チューブの閉塞・逸脱（事故抜管まで）、静脈還流減少、鎮静増量、嘔吐、静脈路の喪失、褥瘡といったリスクがある。
  • Unknown（分かっていなかったこと）：COVID-19 出現直後から、腹臥位は国際ガイドラインと専門家に推奨され広く行われたが、その前提は「COVID-19 の ARDS も他の ARDS と同じように振る舞う」という仮定だった。COVID-19 の ARDS を他の ARDS と同じに扱ってよいかは論争の的であり（Gattinoni らの表現型論など）、腹臥位が実際に COVID 肺で虚脱と過膨張を減らし含気を均一化するかは、CT による直接の検証を欠いていた。
  • What's new（本研究の新規性・意義）：挿管3日以内の COVID-19 の ARDS 15例で、同一 PEEP 下に仰臥位と腹臥位の胸部CTを撮り、定量解析した。腹臥位により 非含気（虚脱）が 82 ml 減り、過含気（過膨張）が 28 ml 減り、垂直方向の含気の不均一性は全例（100%）で減少した。これは非COVID ARDS の反応と同型である。したがってCOVID-19 でも腹臥位を行う病態生理学的な根拠がある。加えて、①形態学的な改善はガス交換・呼吸メカニクスの変化から予測できない、②多くの症例で「過膨張の減少」が「リクルート」を上回る、という2つの実務的知見を示した。

📌 全体要約

要旨

ひとことで 挿管3日以内の COVID-19 の ARDS 15例で、同一PEEP下の仰臥位・腹臥位CTを比較した予備的生理学研究。腹臥位は虚脱（非含気 −82 ml）と過膨張（過含気 −28 ml）をともに減らし、垂直方向の含気の不均一性を全例で減らした。非COVID ARDS と同じ反応であり、COVID-19 でも腹臥位を支持する病態生理学的根拠となる。

  • デザイン：単施設・前向きの生理学的研究。2020年3月1日〜12月9日に登録。
  • 対象：15例。ARDS（ベルリン定義）、深鎮静＋筋弛緩下の侵襲的人工呼吸中、担当医が挿管3日以内に腹臥位を指示した患者。46例が除外（挿管後にすでにCT撮影済み 16例、搬送に耐えられない 9例、体重100 kg超 6例、当時の異常な臨床負荷で著者が対応不能 15例）。
  • 手順：呼気終末静止CTを、①リクルートメント手技（吸気終末気道内圧 45 cmH2O）後の仰臥位、②腹臥位に変換し再度リクルートメント手技を行った後、の2回、同一PEEPで撮影。
  • 定量解析：非含気（−100 HU超）、低含気（−100〜−500 HU）、正常含気（−500〜−900 HU）、過含気（−900 HU未満）の各コンパートメント容積。さらに CT を胸骨→椎体の垂直10レベル、肺尖→肺底の水平10レベルに分割し、各レベルのガス/組織比を算出。不均一性は10レベルのガス/組織比の標準化中央絶対偏差（SMAD）で表現（値が大きいほど不均一）。
  • 主要アウトカム：腹臥位による非含気（＝肺胞虚脱）と過含気（＝過膨張）の総容積の変化。サンプルサイズは検出力ではなく実施可能性で決定。
  • 主要結果：非含気 −82（26〜147）ml、過含気 −28（11〜186）ml、低含気 +82（53〜174）ml、正常含気は有意な変化なし。垂直方向 SMAD は 0.55（0.50〜0.71）→ 0.20（0.14〜0.27）（p<0.001）。
  • 機能的反応：P/F は 14例全員で改善（平均 +41（21〜97）mmHg）、コンプライアンスと PaCO2 は有意な変化なし。
  • 重要な非相関：形態学的改善はガス交換・メカニクスの変化から予測できない。

📖 詳細

1. まず前提 — この病態・治療の基礎（初めての人にも）🧩

要旨

5分で背景を掴む ARDS（急性呼吸窮迫症候群） では、肺胞に水と炎症細胞が溜まって肺が重くなる。人が仰向けに寝ていると、その重みで背側（下側）の肺がつぶれる。つぶれた肺（非含気領域）には血流はあるのに換気がないので、シャントとなり酸素化が悪化する。一方で腹側（上側）の肺は正常より膨らみすぎ（過含気＝過膨張）になり、人工呼吸のたびに過度に伸展されて損傷する。これが人工呼吸器関連肺傷害（VILI）の主要な機序である。 腹臥位（prone position） にすると、この上下関係が反転する。ただし単純にひっくり返るのではなく、①胸郭と肺の形の関係、②心臓と腹部による圧迫の変化、③背側/腹側の胸郭コンプライアンスの差、④肺重量の垂直分布、といった要因が働いて、結果的に含気の分布が全体として均一に近づく。均一になるということは、「つぶれっぱなしの肺」も「伸ばされすぎの肺」も減るということであり、人工呼吸による害が減る。腹臥位が生存を改善する最も強い理屈はここにある。酸素化の改善はむしろ副次的とされる。 CT による定量解析では、肺を CT値（Hounsfield unit, HU）で4つに分ける。非含気（−100 HU超、ほぼ組織のみ）、低含気（−100〜−500）、正常含気（−500〜−900）、過含気（−900 HU未満、空気がほとんど）。それぞれの容積を測れば、虚脱と過膨張がどれだけあるかが直接分かる。 ガス/組織比（gas-to-tissue ratio） は「その領域の空気の量 ÷ 組織の重さ」で、単位重量あたりどれだけ膨らんでいるかを表す。これを胸骨側から椎体側へ10段階に分けて並べると、仰臥位では上から下へきれいに減っていく（垂直勾配）。この勾配が急なほど不均一である。本研究はそのばらつきを 標準化中央絶対偏差（standardized median absolute deviation, SMAD） という頑健な指標で数値化した。値が小さいほど均一。 重畳圧（superimposed pressure） は、その高さより上にある肺組織の重みが作る圧力。仰臥位で背側ほど大きく、肺をつぶす方向に働く。 本研究が問うたのは一つである。「COVID-19 の肺は、腹臥位に対して他のARDSと同じように反応するのか」。

2. 背景と目的 🫁

腹臥位は COVID-19 出現のはるか前から中等症〜重症ARDSに推奨されてきた。生存を改善する機序は、背側の非含気だが灌流されている肺のリクルートと、腹側の過膨張の軽減だと考えられている。結果として酸素化はほぼ必ず改善するが、より重要なのは換気の分布が均等になり、人工呼吸による害が減ることである。

COVID-19 の出現直後、腹臥位は国際ガイドラインと専門家によって推奨され、中等症〜重症の COVID-19 関連 ARDS に広く用いられた。その根底にあったのは「COVID-19 の ARDS でも腹臥位は有益である」という仮定であった。しかし COVID-19 を他の原因の ARDS と同様に扱うべきかは論争が続いていた。

本研究の目的は、COVID-19 による早期 ARDS 患者で、腹臥位が肺胞虚脱と過膨張を減らし含気を均一化するかを検証することである。著者らは「肯定的な結果が得られれば、この新しい症候群でも腹臥位を支持できる」と考えた。

3. 方法（Methods）📐

  • デザイン：単施設・前向きの生理学的研究。
  • 組み入れ基準：①ARDS の診断（ベルリン定義）、②深鎮静＋神経筋遮断薬下の侵襲的人工呼吸中、③担当医が挿管から3日以内に腹臥位を指示。
  • 除外の内訳（46例）：挿管後にすでに肺CTを撮影済み 16例、放射線部門への搬送に耐えられない 9例、体重 100 kg超 6例、当時の異常な臨床業務量のため著者の誰もデータ収集に当たれなかった 15例。
  • CT撮影プロトコル：肺容量履歴を標準化するため、吸気終末気道内圧 45 cmH2O のリクルートメント手技を実施。その後、造影剤なしの呼気終末静止CTを仰臥位で撮影（PEEP は研究前にICUで担当医が設定していた値と同一）。腹臥位に変換し、同様のリクルートメント手技の後、同一PEEP で2回目の静止CTを撮影。
  • 全体の含気：全肺および各コンパートメントの総容積・組織重量・ガス容積を測定。非含気（密度 −100 HU超）、低含気（−100〜−500 HU）、正常含気（−500〜−900 HU）、過含気（−900 HU未満）。病前肺重量は身長から推定。平均含気は総ガス容積/総組織重量で表現。
  • 局所の含気：各CTスライスを胸骨（腹側）→椎体（背側）の垂直10等分、肺尖（頭側）→肺底（尾側）の水平10等分に分割し、各レベルのガス/組織比を算出。不均一性は各被験者内の10個のガス/組織比の標準化中央絶対偏差（SMAD）で定量。各垂直レベルに重畳する静水圧も算出。
  • 機能的反応：ガス交換と呼吸メカニクスを、リクルートメント手技の20分後に、腹臥位直前と腹臥位60分後に測定。両体位で人工呼吸設定を可能な限り一定に保つよう依頼。腹臥位時の周術期低酸素予防のため FiO2 を上げたい医師には、仰臥位測定の時点で先に上げてもらった。
  • 主要アウトカム：腹臥位による全体的な肺形態反応、すなわち非含気（肺胞虚脱）と過含気（過膨張）の総容積の仰臥位から腹臥位への変化。
  • サンプルサイズ：統計的検出力ではなく実施可能性に基づく。
  • 統計：中央値（Q1〜Q3）または割合。Mann–Whitney 順位和検定、Wilcoxon 符号順位和検定、Fisher 正確検定、Spearman 順位相関。多重比較の補正なし。両側 p<0.05 を有意とした（Sigma Plot 11.0）。

6. 形態学的反応 — 局所の含気と均一性 📐

仰臥位の勾配

  • 過含気は腹側・頭側に多く、非含気は背側・尾側に多い。
  • ガス/組織比は胸骨→椎体、肺尖→肺底のいずれでも減少。
  • 不均一性は水平方向より垂直方向のほうが大きい（SMAD 0.55（0.50〜0.71）対 0.31（0.16〜0.47）、p=0.012）。
  • 重畳圧は胸骨近傍 0.5（0.4〜0.6）cmH2O から椎体近傍 9.1（7.2〜11.3）cmH2O まで増大し、垂直方向の含気勾配を部分的に説明する。

垂直方向の不均一性は 15例全例（100%）で減少した。水平方向で減少したのは 8例（53%）にとどまり、集団としては有意な変化がない。

実測値で見ると、仰臥位では胸骨から椎体へ 3.1（2.5〜4.0）→ 0.1（0.1〜0.2）ml/g と 30倍の落差があるのに対し、腹臥位では椎体から胸骨へ 1.5（0.8〜1.9）→ 0.6（0.2〜1.3）ml/g と落差が大幅に縮む。ピーク値もばらつきも腹臥位のほうが小さい。これが「均一化」の実体である。

7. 機能的反応 — ガス交換とメカニクス 🌡️

ICUに戻った後、14例で仰臥位・腹臥位の生理学的測定を実施（1例は急性かつ重篤な不整脈のため腹臥位が禁忌となり除外）。人工呼吸設定は 10例で同一。4例でわずかに変更（FiO2 増 1例、減 2例、呼吸回数増 1例）。

コンプライアンス（n=14）6例（43%）6例（43%）2例（14%）
PaCO2（n=13、分時換気量不変例）4例（31%、低下）3例（23%）6例（46%、上昇）

集団全体では P/F が 41（21〜97）mmHg 上昇したのに対し、コンプライアンスと PaCO2 は有意な変化がなかった。

読み取るべきことは3つある。

  1. 過膨張の減少量は、仰臥位での過膨張の量からほぼ完全に予測できる（rho −0.961, p<0.001）。もともと腹側が膨らみすぎている患者ほど、腹臥位で大きく解除される。
  2. 過膨張の減少はコンプライアンスの改善と関連する（rho −0.541, p=0.045）。PaCO2 の低下とも関連する傾向がある（p=0.085）。すなわち CT 上の過含気は、実際に肺胞の過伸展を表していると考えられる。
  3. 虚脱の減少（リクルート）は、酸素化・コンプライアンス・PaCO2 のいずれの変化とも相関しない。著者らの説明は明快である。COVID-19 では肺血流分布が極端に不均一なので、同じ量をリクルートしても、その領域の灌流が多いか少ないかで酸素化の反応は大きく変わる。
⚠ 注意

臨床上の要注意ポイント 「腹臥位にしたのに酸素化が上がらないから効果がなかった」という判断は誤りである。本研究では虚脱の減少と P/F の改善が相関しなかった（rho −0.415, p=0.134）。逆に「酸素化が上がったから虚脱が取れた」とも言えない。腹臥位の効果を酸素化だけで評価してはならない。 低容量換気でも過膨張は防げていない。過含気容積が中央値より大きかった7例でも、一回換気量は 6.1（5.7〜6.5）ml/kg PBW、プラトー圧は 23（21〜23）cmH2O だった。「6 ml/kg かつ Pplat 30以下なら安全」という前提は成り立たない。

9. PEEP を上げることとの比較 — 同一グループの先行研究との対照 ⚖️

同じ著者らの先行研究（Protti A, et al. Chest. 2021;161:979-88）では、仰臥位で PEEP を 5→15 cmH2O に上げた場合の変化を測っている。

介入非含気（虚脱）の変化過含気（過膨張）の変化過膨張が増えた患者
PEEP 5→15 cmH2O（仰臥位、先行研究）−168（110〜202）ml+121（63〜270）ml15例中 全例（100%）
腹臥位（本研究、同一PEEP）−82（26〜147）ml−28（11〜186）ml1例のみ（＝14例 93%で減少）

リクルートの量だけを見れば PEEP を上げるほうが大きい（168 ml 対 82 ml）。しかし PEEP 増は代償として全例で過膨張を作るのに対し、腹臥位は過膨張も同時に減らす。著者らの結論は「腹臥位は PEEP 増より少ない過膨張で肺をリクルートしうる」である。

10. 著者らが挙げる限界 ⚠️

  1. 第一波の適格患者を全員は登録できておらず、選択バイアスの可能性がある。
  2. 多重比較の補正を行っていないため、結果は予備的なものとみなすべきである。
  3. CTは呼気終末のみで撮影しており、仰臥位・腹臥位での一回換気量の分布は調べていない。
  4. 研究デザインが実臨床と多くの点で異なる。腹臥位直後に評価しているが、実際には数時間続けるあいだに反応は変化しうる。腹臥位の前後に必ずリクルートメント手技を行っているが、これは通常診療の一部ではない。PEEP は担当医の裁量で、別の設定なら形態・機能とも異なっただろう。以上は一般化可能性を制限する。
  5. 腹臥位の効果は late COVID-19 では同じでない可能性がある。
  6. 生存や人工呼吸期間といった患者中心アウトカムへの影響は検討していない。

🧐 批判的吟味 — ジャーナルクラブでの論点

論点1：n=15 でどこまで言えるか サンプルサイズは検出力ではなく実施可能性で決められ、多重比較補正もない。したがって個々の p値は探索的である。しかし垂直方向の不均一性が15例全例（100%）で減少したという所見は、統計以前に方向性が揃っているという意味で説得力がある。JCでは「p値が支える主張」と「全例一致が支える主張」を区別して読みたい。

論点2：リクルートメント手技を毎回入れた設計の影響 仰臥位でも腹臥位でも、CT撮影前に 45 cmH2O のリクルートメント手技を行っている。これは肺容量履歴を揃えるための生理学的に正しい手順だが、通常の腹臥位には含まれない。本研究が測ったのは「腹臥位＋リクルートメント手技」の効果であり、純粋な体位変換の効果ではない点は明示しておくべきである。

論点3：60分という評価タイミング PROSEVA が示した生存改善は 16時間/日の腹臥位によるものである。60分後の形態が、16時間後の形態と同じである保証はない。むしろ「時間とともにさらにリクルートが進む」可能性も「背側が徐々に虚脱する」可能性も残る。

論点4：P/F 273 の1例を含めることの是非 軽症の1例は「CTで過膨張が見つかったから腹臥位にした」という、通常の適応外の症例である。過含気の変化が仰臥位過膨張とほぼ完全に相関する（rho −0.961）という所見は、こうした極端値に強く牽引されている可能性がある。感度解析としてこの1例を除いた解析があると良かった。

論点5：「COVIDは特殊か」論争への含意 2020年当時、COVID-19 の ARDS は「L型/H型」といった表現型論で他の ARDS と区別すべきだという議論があった。本研究は、少なくとも腹臥位に対する形態学的反応という一点においては、COVID も他の ARDS と同型であることを示した。表現型論は換気設定の話に限定して扱い、体位管理には持ち込まない、という整理が実務的である。

論点6：血流の不均一性という説明の検証可能性 「リクルートと酸素化が相関しないのは血流分布が不均一だから」という説明は説得的だが、本研究では検証されていない。造影CTを行ったのは15例中2例のみで、肺血栓は記録上0例だが、残りには未認識の灌流欠損があった可能性を著者ら自身が認めている。EIT（電気インピーダンストモグラフィ）で換気/血流を同時に見た研究（Perier ら、Fossali ら）と併読したい。

✅ Take home message

TAKE HOME

結論 COVID-19 の ARDS でも、腹臥位は虚脱（−82 ml）と過膨張（−28 ml）をともに減らし、垂直方向の含気の不均一性を全例（100%）で減らす。反応の型は非COVID ARDS と同じであり、COVID-19 でも腹臥位を行う病態生理学的根拠になる。 腹臥位の効果を酸素化で判定してはならない。P/F は 14例全員で改善したが、その改善量は虚脱の減少とまったく相関しない（rho −0.415, p=0.134）。 PEEPを上げると全例で過膨張が増えるが、腹臥位は過膨張も減らす。 リクルートの手段としてまず体位を選ぶ理由がここにある。 6 ml/kg・プラトー圧 23 cmH2O でも過膨張は起きている。低容量換気は過膨張がないことの保証ではない。
