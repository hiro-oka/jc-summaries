聖路加ICUでの実践

病棟プロトコルへの落とし込み

  • 動脈ラインは「血圧を測る道具」ではなく「波形から複数の情報を読む道具」として教育する。波形一本から、収縮期立ち上がりの傾き（dP/dt）、脈圧（一回拍出量と中心動脈コンプライアンス）、拡張期の下降脚（末梢血管抵抗）、陽圧換気に伴う脈圧変動（PPV）が読める。当院の研修医教育でここを標準項目にする価値がある。
  • 数値が合わないときは、まず物理系を疑う。ダンピング不良（オーバーダンプ／アンダーダンプ）は脈圧を過小／過大に見せる一方で、平均血圧（MAP）の精度は変えない。したがって、収縮期血圧だけがおかしいときは、気泡・血栓・半開のストップコック・カテーテルのキンクを先に潰す。
  • トランスデューサの高さは体位を変えるたびに合わせ直す。ゼロ点は左房レベルの静水圧に一致させる。患者が起き上がったのに高さを合わせないと血圧は人為的に低く出て、寝かせると逆に高く出る。当院でも体位変換・座位リハビリのたびに再ゼロを習慣にする。
  • 末梢で測るほど収縮期血圧は高く、拡張期血圧は低く出る（distal amplification）。橈骨動脈と大腿動脈の収縮期血圧が違っても、MAPが一致していれば異常ではない。昇圧薬の評価はMAPで行う。
  • PPV・SVVを使う前に適用条件を確認する。自発呼吸努力がないこと、一回換気量が十分（およそ 8 mL/kg）、肺コンプライアンスが低下していないこと、開胸中でないこと、不整脈がないこと。当院のARDS患者は低一回換気量で管理しているため、PPV・SVVはそのままでは使えない場面が多い。代わりに 受動的下肢挙上（PLR）・呼気終末閉塞試験・輸液チャレンジと組み合わせる。
  • 敗血症性ショックで血管作動薬を動かしている患者には、非校正型デバイス（FloTrac など）の心拍出量トレンドを信用しすぎない。血管緊張が大きく変わる場面で精度が落ちることが繰り返し示されており、ノルアドレナリンの用量変更に伴う心拍出量変化の追従性は特に悪い。この層では校正型（PiCCO、LiDCOplus、VolumeView/EV1000）を選ぶか、超音波でスポット評価する。
  • 校正型は「校正直後が最も正確で、時間とともに劣化する」。PiCCO では、1時間以上前の校正に基づく測定は体血管抵抗の変動により信頼できないとする報告がある。血行動態が大きく動いたら再校正する運用ルールを決める。
  • 大動脈弁閉鎖不全・大動脈弁狭窄・IABP 装着中は、非校正型の波形解析は原則使わない。

🧭 この論文の位置づけ（Known / Unknown / What's new）

補足

リサーチ・イン・コンテキスト

  • Known（既に分かっていたこと）：留置動脈カテーテルによる連続動脈圧測定は50年以上ルーチンに利用可能で、手術室・ICUで心血管系の破綻を迅速に診断し、低血圧・高血圧の帰結が現れる前に治療反応をモニターするために使われてきた。1990年時点で800万本以上の観血的動脈カテーテルが留置されていた。
  • Unknown（分かっていなかったこと）：肺動脈カテーテル（PAC）は複数のRCTで利益も害も示されず、合併症増加の報告もあり、心拍出量（CO）測定の主役の座を降りつつあった。その代替として動脈圧波形からCOを推定する低侵襲デバイスが多数登場したが、それぞれ異なるアルゴリズムを使っており、どの病態でどれが信頼できるのかが整理されていなかった。
  • What's new（本研究の新規性・意義）：動脈圧波形の物理（トランスデューサ・周波数応答・ゼロ点）から生理（波形の各成分が何を表すか）、そして各デバイスのアルゴリズムと限界までを一本の総説として橋渡しした。特に 校正型と非校正型の使い分け、および血管緊張が動く病態で非校正型の精度が落ちるという実務的な結論を明示した点が有用である。

📌 全体要約

要旨

ひとことで 動脈圧波形は血圧だけでなく、一回拍出量・心拍出量・血管抵抗・輸液反応性を連続的に読み取れる情報源であり、波形を見るだけでは不十分でデバイスが要るが、そのデバイスは病態によって信頼性が大きく変わる。

  • 波形の物理：カテーテル・チューブは硬い材質でなければ圧波を吸収してしまう。加圧バッグ（原文では通常 200 mmHg 超、Figure 1では約300 mmHg）で 2〜4 mL/h の持続フラッシュを行い、カテーテル先端の血栓形成を抑える。この流量は圧の読みに影響しない。
  • 周波数応答：動脈脈波の固有周波数は 1〜2.5 Hz。市販トランスデューサ単体は数百 Hz あるが、延長チューブ・微小気泡・先端血栓・半開のストップコックがシステム全体の周波数応答を落とす。オーバーダンプは脈圧を過小評価し、アンダーダンプは過大評価するが、MAPの精度は変わらない。
  • ゼロ点：ゼロ圧は左房レベルの静水圧にほぼ等しい isobestic point で定義する。体位が変わればトランスデューサも追随させる。
  • 末梢増幅（distal amplification）：大動脈基部から末梢へ行くほど収縮期圧は高く、拡張期圧は低くなり、脈圧は広がる。立ち上がりは急峻になり、切痕（dicrotic notch）は遅れて現れる。大動脈の立ち上がりと末梢の立ち上がりには 約60 ms の遅れがある。それでも MAPは動脈系を通じて著しく一定で、末梢でわずかに下がるのみ。
  • 波形から読めること：立ち上がりの傾き（dP/dt）＝収縮性の目安（ただし議論あり）、脈圧＝一回拍出量・収縮性・中心動脈コンプライアンスの関数、拡張期の下降脚＝末梢血管抵抗、陽圧換気下の脈圧変動（PPV）＝機能的循環血液量減少・輸液反応性。
  • デバイスの使い分け：校正型はトレンドの精度が高いが侵襲的（中心静脈カテーテルを要する）。血管作動薬を要する重症患者や敗血症性ショックのように血管緊張が不安定な患者に適する。非校正型は迅速・安価で、健常寄りの患者や周術期に向く。

📖 詳細

1. まず前提 — この技術の基礎（初めての人にも）🧩

要旨

5分で背景を掴む 動脈圧波形（arterial waveform） は、左室の収縮期駆出とそれに続く拡張期の一回拍出量の動脈内への拡散が作る圧の時間変化である。心電図が心臓の電気的収縮を表すのに対し、動脈波形は機械的収縮を表す。両者は不可分に結びついており、末梢動脈での収縮期立ち上がりは、心電図のR波から 120〜200 ms 遅れて現れる。これは電気的興奮の開始から心室が血液を駆出し、それがカテーテルとトランスデューサに到達するまでの時間を反映する。

波形の各成分は次のとおり（原著 Figure 4）。

  • A：収縮期の立ち上がり — 大動脈弁開放に伴う駆出。最低点から頂点へ急峻に上昇する。
  • B：収縮期ピーク
  • C：収縮期後半の圧下降 — 収縮終末から弛緩開始へ
  • D：切痕（dicrotic notch / incisura） — 下降脚を中断する切れ込みで、大動脈弁の閉鎖を表す。拡張期開始の直後に起こる。
  • E：拡張期 — 拡張終末に波形は最低点に達する

MAP（平均動脈圧） は、ある部位（大動脈弓、腹部大動脈、橈骨動脈など）で時間平均した圧。1心周期にわたる圧信号の積分（曲線下面積）であり、収縮期は拡張期より短いため、MAPは収縮期血圧と拡張期血圧の中点より低くなる。数式的には 拡張期血圧 ＋ (収縮期血圧 − 拡張期血圧) / 3 で推定できる。

一回拍出量（SV）と心拍出量（CO）：CO = SV × 心拍数。動脈圧波形からSVを推定するという発想は、1950年代に「SVは動脈波形の収縮期部分の曲線下面積に比例する」ことが示されたことに端を発する。

PPV（pulse pressure variation、脈圧変動）と SVV（stroke volume variation、一回拍出量変動）：陽圧換気では換気周期に伴い心臓への静脈還流が変動し、それが脈圧・一回拍出量の周期的変動として現れる。この変動の大きさは 前負荷予備能（preload reserve） を反映し、輸液反応性の指標となる。心室前負荷の静的指標（中心静脈圧など）よりも、輸液反応性の定義において特異的である。

2. 歴史と背景 📜

動脈血圧が直接測定されたのは1733年の Stephen Hales による。長いガラス管に柔軟な接続部（ガチョウの気管）を用い、大腿動脈と頸動脈で圧を測定した。その後 Daniel Bernoulli、そして Jean-Louis Poiseuille（1828年、水銀充填U字管で大動脈の複数点の圧を測定）らが改良した。臨床的に意味のある最初の動脈カテーテル留置は、1949年の Peterson らによる。彼らは「小さなプラスチックカテーテルを針を通して動脈に挿入し、針を抜いた後もカテーテルを動脈内に残す。容量型マノメーターに接続することで、不快感なく長時間の記録が可能となり、被験者は比較的自由に動ける」と記述した。その後 Peirce、そして Seldinger（1953年）が今日一般的な「ガイドワイヤー越しのカテーテル挿入」法を記述した。1990年時点で観血的動脈カテーテルは800万本以上留置されていた。

観血的動脈カテーテルの副次的利点として、ヘモグロビン・電解質などの採血が容易になり診断と管理が行いやすくなる点がある。医療技術の進歩に伴い、指や手首に装着したプレチスモグラフの原理を用いる非観血的連続動脈圧モニタ（CNAP、NexFin）も開発された。校正を要するものと要さないものがある。

PACの退潮。手術室とICUの血行動態モニタリングは、動脈圧モニタリングと肺動脈カテーテル（PAC）由来の指標（肺動脈圧、肺動脈閉塞圧、混合静脈血酸素飽和度、熱希釈法によるCO）の両輪で発展してきた。しかし、これら侵襲的手法によるCO推定が患者管理に有用だろうという直感に反し、PACの使用と非使用を比較した複数のRCTでは利益も害も示されず、一部の文献では肺動脈カテーテル法による合併症の増加が指摘された。著者はその理由として、CO値に基づいて蘇生を駆動する治療を使っていない研究がある、研究で用いられた治療自体が転帰改善を証明されていない、対象集団が不均一すぎて利益を検出できない、といった可能性を挙げている。

このPACへの関心低下が、低侵襲なCO推定への需要を生み、動脈圧波形解析への関心を高めた。動脈圧波形は多くの手術室・ICUで連続的に測定されており、単純なカテーテル挿入で、あるいは非観血的にも取得できる。利点は患者リスクを下げつつ動脈圧を連続測定できること。コストは数値計算を行うデバイスの購入費だが、専門スタッフの追加は不要である。

3. 圧モニタリングの技術的側面 🔧

侵襲的モニタリングは血管へのカテーテル挿入を要し、出血・血栓・感染という合併症リスクを常に伴う。動脈カテーテルを入れる判断は、常に一定のリスクを引き受ける判断であるという認識が前提になる。

トランスデューサ系。カテーテルと接続チューブは硬い材質でなければならない。柔らかいと圧波を吸収し、カテーテル先端からトランスデューサへの圧伝達が減る。標準的な系では、加圧した生理食塩水（またはヘパリン加生理食塩水）の緩徐持続注入を並列に組み込む。原文本文では加圧は通常 200 mmHg 超、Figure 1の凡例では 250 mL の生理食塩水バッグを約300 mmHg に加圧するとされ、2〜4 mL/h の持続フラッシュを行う。この流量は圧の読みに影響を与えず、カテーテル先端の血栓形成を抑える。

チューブ内の生理食塩水の圧は動脈圧の拍動とともに変化し、それに応じてトランスデューサのドーム隔膜が変形する。隔膜の変形は ホイートストンブリッジ型の電気回路の抵抗を比例的に変化させ、トランスデューサ電流の変化が圧の変化に正比例する（原著 Figure 2：隔膜に圧が加わると R1 と R3 が増加し、R2 と R4 が比例して減少する）。

周波数応答。動脈波形は複雑な波形であり、フーリエの定理により調和波の重ね合わせとして表現できる。圧変化を正しく報告するには、モニタリング系の周波数応答が動脈脈波の固有周波数（1〜2.5 Hz）を上回る必要がある。市販トランスデューサ単体は数百 Hz の応答を持つが、延長チューブ、チューブ内の微小気泡、カテーテル先端の血栓、半開のストップコックがシステム全体の周波数応答を低下させる。

状態波形の見え方脈圧への影響MAPへの影響
周波数応答が低すぎる（オーバーダンプ）鈍った、押しつぶされた波形過小評価影響なし
周波数応答が高すぎる（アンダーダンプ）鋭く振動的な波形過大評価影響なし

さらに hyperresonance（系内での圧波の反響によるアーチファクト）は、適切なダンピング係数で相殺し、正確な圧プロファイル解析ができるようにする必要がある。

ゼロ点と校正。ゼロ圧は 左房レベルの静水圧にほぼ等しい isobestic point で定義する。トランスデューサのゼロ較正用ストップコックをこの点で大気開放したときの値が、以後すべての圧測定のゼロとなる。ここが要注意で、ゼロ較正後にトランスデューサ高が変われば、すべての測定圧に系統誤差が生じる。

  • 患者が座位になったのにトランスデューサ高（床からの高さ）を変えなければ、人為的に低い動脈圧が報告される。
  • 座位でゼロ較正した後に患者を臥位に戻すと、静水圧の水柱が減った分だけ測定動脈圧は上昇する。
  • したがって、患者が動くたびにトランスデューサも追随し、常に左房レベルに置く。

ゼロ較正の後、既知の圧上昇（通常 100 mmHg）による電気出力変化と直接相関することが分かっている参照電気信号を回路に通す。ゼロがゼロを、100 mmHg の校正が 100 mmHg を示すように系の gain を調整する。これが完了して初めて、波形を臨床判断に使える。

4. 波形から何が読めるか 💓

収縮性（contractility）。動脈波形は圧の時間変化 dP/dt を反映し、立ち上がりの傾きがこれを表す。傾きが急峻なほど dP/dt が大きく収縮力が強く見え、傾きが浅いほど弱く見える。この情報は強心薬の調節に使われてきた。ただし著者は、動脈波形の dP/dt と左室収縮性の関係には議論があり、かなり複雑でありうると明記している。橈骨動脈波形が左室機能を予測しうるとする研究がある一方、橈骨波形は左室収縮機能の信頼できる指標ではないとする研究もある。dP/dt は収縮性だけでなく、大動脈拡張期圧、心室拡張終末圧、心室の興奮様式、収縮性の内因性調節にも影響される。大腿動脈での測定は左室 dP/dt を過小評価するが、左室への治療変更に伴う変化は正確に追従したとする研究がある。

中心動脈コンプライアンス。動脈脈圧は、左室一回拍出量、収縮性、中心動脈コンプライアンスの関数である。末梢血管の動脈硬化などで中心動脈が硬いほど脈圧は大きくなる。逆に、中心動脈が非常にコンプライアントな新生児では脈圧は小さい。また末梢の血管運動緊張が変われば、同じ一回拍出量でも脈圧は共変動し、動脈緊張の増加とともに増え、低下とともに減る。したがって動脈脈圧は、動脈圧プロファイルのなかで極めて多くを語るパラメータである。

末梢血管抵抗。動脈波形の下降脚（拡張期の runoff）は、左室から動脈系への駆出が止まった後に圧を維持する抵抗がどれだけあるかを示す。一回拍出量が安定または固定されていれば、血管抵抗の変化は下降脚の傾きの変化として現れる。下降脚が急峻に落ちるのは血管拡張薬や敗血症でよく見られ、血流への抵抗が小さいことを意味する。下降脚が浅いのは重症心不全でよく見られ、抵抗が高いことを示す。ただし著者は、この特徴は一回拍出量を先に知っている必要があるため臨床では使われていないと述べている。波形の形だけから一回拍出量と体血管抵抗を定量する試みは困難であることが判明している。

循環血液量減少（hypovolemia）。陽圧換気に伴って心臓への静脈還流が変動すると、動脈脈圧も変動する。この換気周期にわたる脈圧の変動が PPV であり、輸液反応性の代用指標として使える。PPVの増大は機能的な循環血液量減少の同定に使える。循環血液量が減少していると、正常血液量の状態に比べて収縮期圧・脈圧の変動が大きく増える。大きな収縮期圧変動やPPVは、胸腔内血液量と心室充満圧が低いことと相関する。著者は、これら機能的血行動態パラメータは、心室前負荷の静的指標よりも輸液反応性の定義において特異的であると結論している。

POINT

原著の Practice points（第1章）

  • 末梢増幅により、収縮期圧の読みは上がり、拡張期圧の読みは下がる。しかし動脈系全体を通じてMAPは同じである。
  • 動脈波形は動脈圧を測るだけでなく、SVV、循環血液量減少、収縮性、末梢血管抵抗の大きさの測定にも使える。これは輸液・強心薬・昇圧薬のどれが必要かという治療の方向づけに役立つ。

5. 心拍出量をどう測るか 📐

指示薬希釈法（indicator dilution）。COの測定法は複数ある。Fickの原理と電磁流量計は正確にCOを予測できるが、最も一般的なのは指示薬希釈法である。下流で検出できる指示薬なら何でもよく、冷温または加温ボーラスによる熱希釈、リチウム、インドシアニングリーンが使われる。静脈内にボーラス投与された指示薬は右室通過で混合され、肺動脈または動脈系で経時サンプリングすると、急峻な上昇に続く対数的減衰を示す。減衰部分の傾きは血流に反比例する。これらは Stewart–Hamilton の式に基づく。

PACによる熱希釈。中心静脈側から熱信号を与え、肺動脈で熱信号を測る。強みは CO測定にカテーテル1本で済むこと。弱みは、測定対象である肺動脈血流が換気周期を通じて大きく変動することである。そのためPACによるCO測定は、アーチファクトではないこの効果によって大きくばらつく。したがって通常 4〜5回の測定を行い平均する必要がある。

経肺熱希釈（transpulmonary thermodilution）。中心静脈カテーテル（指示薬注入）と動脈側の指示薬センサーという2つの侵襲デバイスを用いる。動脈側のサンプリング部位は橈骨・上腕・腋窩・大腿のいずれでもよい。PACによる肺動脈熱希釈と比べた信頼性と精度が検証されている。CO以外の利点が多い。

  1. 冷生理食塩水は安価で入手が容易
  2. 肺循環内での血液のバッファリングにより、呼吸性の血流変動によるCO推定のばらつきが小さい
  3. ベッドサイド管理に有用な他のパラメータが得られる — 血管外肺水分量（EVLW）、肺血管透過性、心収縮機能の指標である cardiac function index、心前負荷の指標である global end-diastolic volume

リチウム希釈。熱希釈と同様の安定性の利点を持ち、加えて血中に通常リチウムは存在しないため感度が高く、S/N比が熱希釈より優れる。ただしリチウムの注入と、通常は体外に置くリチウムセンサー（少量採血を要する）が必要になる。この種の指示薬希釈を用いるデバイスは、PACを要さないため「minimally invasive」ではなく 「less invasive」 と分類される。

Fickの原理。消費された酸素量は、動脈血と静脈血の酸素量の差に等しい。実測には酸素消費量と酸素含量が必要で、混合静脈血と動脈血の酸素レベルを測るためにやはりPACという侵襲的モニタが必要になる。

流量計と超音波。最も正確なCO測定は電磁流量計または超音波流量計による。大動脈に超音波を当てれば瞬時の拍動流が得られ、心周期の血流曲線が描ける。これを速度測定部位の大動脈径と組み合わせれば流量が定義され、曲線の積分が一回拍出量、それに心拍数を掛けたものがCOである。ただし連続測定には胸骨正中切開または開胸を要するため汎用的な解ではない。心臓手術中や左室補助装置の挿入時には、これらの計測を装置の校正に使える。より実用的な低侵襲アプローチは経食道心エコーとドプラ法で、左室流出路の断面積と左室流出路・大動脈弁での瞬時流速を測り、流速を時間積分して一回拍出量を得る。術者依存性があり、当てているときにしか推定できないが、経験ある術者の手では正確であり、著者は惜しむらくは過小利用されていると述べる。さらに簡便な形として USCOM（大動脈での血流速度を測る）があり、通常は大動脈径を測らないため流量は推定にとどまるが、使いやすさ・非侵襲性・再現性が利点である。

6. SVV・PPV の使いどころと限界 🚦

陽圧換気中の一回拍出量の経時的変動率が SVV であり、PPVと同様に前負荷予備能を定義する。PPVとSVVの変動が厳密には同一でないことを示す研究は複数あるが、SVVは輸液反応性の予測においてPPVと同程度に信頼できる。

ただし、SVVを輸液反応性の予測に使う際の限界はPPVと同じである。

  • 自発呼吸努力がないこと（自発努力があると使えない）
  • 静脈還流の変化を誘発するのに十分な一回換気量（およそ 8 mL/kg の換気）
  • 肺コンプライアンスの低下がないこと（拘束性疾患では使えない）
  • 開胸状態でないこと
  • 不整脈がないこと

動脈圧波形解析による一回拍出量・CO推定は、受動的下肢挙上（PLR）、呼気終末閉塞試験、輸液ボーラス負荷のような急速なCO変化を評価する場面で大きな助けになる。

7. アルゴリズムとモデル 🧮

MAPとCOの関係は複雑であり、中心動脈コンプライアンス・抵抗・インピーダンスに関する仮定に基づいて複数のアルゴリズムがCOを算出している。

  • 電気回路のアナロジー：体血管系が心臓の供給する電流（圧）に対する抵抗として働くと考え、オームの法則（V = IR） で流量を計算する。ただし動脈内の拍動流には正確でなく、時間平均した流れにしか当てはまらない。
  • Windkessel モデル：拍動流を考慮して圧と流量の関係を記述する、より正確なモデル。動脈は多量の血液を保持し、血管壁の性質上、容量変化に対する固有のインピーダンスを持つためキャパシタとして働く。
  • Liljestrand and Zander 法：動脈キャパシタンスが圧の関数として変化する（動脈圧が上がると動脈壁は硬くなりキャパシタンスが減る）と仮定する。
  • lumped parameter（集中定数）近似：これらモデルの最大の問題は、動脈系が多数の分枝に分かれており、インピーダンスと波の反射という効果を伴うことである。ほとんどのモデルと、市販されている全てのデバイスモデルは、抵抗・コンプライアンス・インピーダンスを集中定数として近似している。
  • Godje 非線形コンプライアンスモデル：Windkessel モデルに追加し、心臓を流量源ではなく圧源として扱う。動脈コンプライアンスを考慮する。
  • Wesseling Modelflow：血管系全体が非線形であることをさらに考慮する。ヒトの体動脈圧から大動脈血流を計算し、大動脈インピーダンスは動脈コンプライアンスの関数、コンプライアンスは圧の関数、抵抗は圧を流量で割ったものの関数であることを見出した。これにより、動脈圧波形の直接解析からCOをリアルタイムに正確に推定する式が作られた。
  • PulseCO（2001年）：動脈系の周波数解析に基づく新しいCO推定法。経肺熱希釈と比較してCOを正確に推定できることが示された。質量保存と仕事量保存の原理に基づき、一回拍出量が誘発する圧波形の拍動性変化の解析から一回拍出量を計算する。Modelflow に対する利点は、動脈圧波形輪郭のアーチファクト的変化、特に昇圧薬投与時やカテーテル先端の血栓形成時に、CO推定が影響を受けにくいことである。

臨床的に使えるデバイスが満たすべき3条件（著者の整理）。

  1. 動脈圧曲線の幾何学、特に収縮期部分を解析すること。一回拍出量は圧曲線の振幅に比例することを想起する。
  2. 動脈緊張を考慮しつつ動脈コンプライアンスを推定すること。動脈コンプライアンスに反比例する定数 k があり、k は圧曲線の振幅に比例する乗数として働く。加えて脈の増幅は動脈抵抗に依存する。
  3. 末梢の脈圧から大動脈圧を推定すること（前述の末梢増幅の概念を踏まえて）。

8. デバイス一覧と使い分け 🖥️

デバイスは 外部校正を要するもの（患者固有のコンプライアンスとインピーダンスを算出）と、非校正型（年齢・性・体格ごとの標準的なコンプライアンスとインピーダンスを仮定）に分かれる。一般に校正型は校正直後の精度が高いが、時間とともに精度が劣化する。非校正型が生理学的状態の変動を超えて経時的に精度を落とすかどうかは明らかでない。

LiDCOplus はリチウム経肺希釈で校正し、PulseCO アルゴリズムで動脈波形を解析する。熱希釈法との比較で信頼性が複数研究で確認されている。動脈波形の形態変化に加え、動脈カテーテル圧のダンピングにも影響されにくいとされる。

PiCCO は経肺熱希釈で校正し（そのため minimally invasive ではなく less invasive）、脈波輪郭を解析して動脈曲線の収縮期部分の面積を大動脈コンプライアンスで除することでCOを推定する。切痕を含む曲線の幾何学的性質が考慮される。動脈コンプライアンスと体血管抵抗（SVR、この手法では MAP ÷ CO と定義される）の推定には複数の独立したアルゴリズムを要する。生理学的状態が大きく変化したときには、外部校正型デバイスはいずれも再校正が必要になることが多い。この継続的な再評価により、患者のリアルタイムの血行動態に基づくCO推定へ適応できる。PACと比較したPiCCO plus のCO推定の妥当性は複数研究で確認されているが、ある研究では校正時期に近いほど測定が良好であり、同じ研究は校正から1時間以上経過している場合は、SVRの動的変化のため測定が信頼できないと指摘した。これがPiCCO plus の欠点として挙げられている。また低体温患者での使用を試みた研究はあるが、より確立した手法との検証が必要であり、低体温では温度が精度の指標として十分でない可能性から、温度・代謝に依存しない校正法が必要と示唆されている。超音波によるCOのスポット推定はこの要件を満たしうる。

VolumeView / EV1000 も経肺熱希釈による校正を要し、PiCCO と類似する。Langewouters 法に基づき、拍動性と、動脈抵抗・コンプライアンスを定量する定数 k から一回拍出量を推定する。高心拍出状態・血管麻痺状態の患者から記録した大規模な圧波形データベースに裏づけられ、近年の研究で信頼性が確認され、PiCCO と同等以上の精度が示された。

FloTrac / Vigileo は Langewouters 法に基づくアルゴリズムを持ち、標準的な動脈カテーテルと動脈ラインを専用の使い捨て圧トランスデューサ（FloTrac）に接続し、それを Vigileo に接続してCOを解析・表示する。非校正型デバイスの信頼性は校正型より議論が大きい。最初の非校正型である FloTrac / Vigileo は最も研究されており、PAC熱希釈と比較して良好な信頼性を示す研究が複数ある一方、正確でないとする研究も同数程度存在する。良好な信頼性は周術期で示されている。しかし、血管運動緊張が大きく変化する場面では信頼性が低下するとされ、具体的には重症患者や肝臓手術を受ける患者である。Monnet らは、FloTrac / Vigileo の新しいバージョンでも、ノルアドレナリンの用量変更で誘発したCO変化の追従性は、容量負荷で誘発した場合よりはるかに劣ることを示した。

⚠ 注意

臨床上の要注意ポイント

  • 一般に、非校正型の脈波輪郭解析デバイスは、動脈圧が修飾される状況で信頼性が低下する。具体的には 大動脈弁閉鎖不全、大動脈弁狭窄、大動脈内バルーンパンピング（IABP）、そして圧チューブ内の気泡やカテーテル・チューブのキンクによる単純なダンピングである。
  • 校正型でも「いつ校正したか」が精度を決める。血行動態が大きく動いた後は再校正する。
  • 低体温では熱希釈校正の精度に疑問がある。

LiDCOrapid は LiDCOplus と同じ PulseCO アルゴリズムを用い、患者の年齢・身長・体重から確立されたノモグラムを介して動脈コンプライアンスを推定する。校正は不要だが、独立した手法で測定したCOを入力できる。食道ドプラほどの信頼性はないとされるが、これが参照法の劣悪さによるのか、下行大動脈血流を総COの代用としたことによるのか、PulseCO 自体の誤差なのかは不明である。

ProAQT / Pulsioflex は身長・体重・年齢・MAP・心拍数を自社の自動校正アルゴリズムに取り込み、これらの値から企業固有かつ非公開の解析（前述の Windkessel モデルには基づかない）でCOを推定する。脈波輪郭解析は動脈波形を毎秒250回解析して行う。LiDCOrapid と同様、ドリフトを避けるため別法で測定したCOを入力できる。このデバイスはなお検証を要する。

MostCare は PRAM（pressure-recording analytical method） を用いる非校正型デバイスで、「ある血管において圧の変動が応答的な径方向の拡張を引き起こす」という原理に基づく。この過程には左室駆出の力、動脈のインピーダンスとコンプライアンス、末梢小血管抵抗が関与する。校正を一切要さず、患者のベースライン特性データにも依存しない唯一のデバイスである。心臓外科患者では許容できる信頼性を示す。LiDCO とは対照的に、ノルアドレナリンを投与されている重症敗血症患者においても、PACと比較して許容できる percentage error を示した。IABP 装着患者でも許容できる percentage error だったが、PRAM と PAC の推定COに大きな差があったとする研究も1つある。

Nexfin は完全に非侵襲的な方法で血行動態を測定する。指の中節骨に巻いた膨張式カフで患者と接続し、「拍動する指動脈を、動脈圧に等しい変動する対抗圧を加えることで一定容量にクランプする」— これが volume-clamp 法である。得られた上腕動脈波形をアルゴリズムで再構成し、それをCO測定の基礎とする。ここでも Windkessel モデルが用いられ、動脈圧・身長・体重・性別を血管特性として組み込む。動脈圧の測定については複数研究で妥当性が確認されている。COの推定については LiDCO と同様に結果が相反しており、肯定的な研究と否定的な研究の両方がある。四肢の灌流が悪い可能性のある重症患者、敗血症性ショックの患者では、上記の波形の正確な測定が妨げられうる。したがってこのデバイスは手術室や比較的健常な被験者に適している可能性がある。

結論としての使い分け（著者の総括）。校正型はトレンドデータの精度が高い傾向にあるが、より侵襲的である。したがって、昇圧薬を要する重症患者や、敗血症性ショックのように血管運動緊張が不安定な患者により適応がある。非校正型は素早くセットアップでき、安価な傾向があるため、手術室に来る比較的健常な被験者や周術期でより有用である。

POINT

原著の Practice points（デバイス章）

  • 動脈波形からCOを測定するシステムは複数あり、校正を要するものと要さないものがある。
  • 完全に非侵襲的なシステムは Nexfin ひとつである。
  • 校正を要するシステムは中心静脈カテーテル留置を要する。非校正型は侵襲が少ないが、校正型ほど正確・信頼できるとは限らない。
  • 校正型は最良の精度を保証するために複数回の再校正を要することがある。
  • 低侵襲・非侵襲デバイスの精度と信頼性は、患者の病態、治療内容、体温という文脈のなかで考える。
  • 動脈波形からCOを推定して治療を導けるが、動脈波形を見るだけでは不十分である。
  • デバイスの限界には、大動脈弁閉鎖不全下での精度低下があり、後負荷の大きな変化を考慮に入れなければならない。
  • 機器の校正は一般に、リチウムまたは既知温度の生理食塩水による熱希釈で行われる。
  • SVV とCO による治療には、臨床的に定義された目標値がある。

9. 今後の研究課題（原著の Research points）🔭

  • 血管運動緊張の文脈における MAP と CO / PPV / SVV の相互作用、すなわち敗血症患者に関するさらなる研究が必要である。
  • 異なる治療モードの相互作用と、蘇生の目標をどう定義するかについてさらなる研究が必要である。
  • 動脈波形が与える情報を使って、循環不安定の発症をいかに早期に認識し早期治療につなげるかについてさらなる研究が必要である。

結論 動脈ラインは血圧計ではなく、一回拍出量・心拍出量・血管抵抗・輸液反応性を連続的に読める血行動態モニタである。ただし波形を見るだけでは不十分で、デバイスが要り、そのデバイスは病態で信頼性が変わる。 血管緊張が不安定な患者（敗血症性ショック、昇圧薬使用中）は校正型を選ぶ。周術期の比較的安定した患者は非校正型で足りる。 数値がおかしいときは、まず ダンピング・ゼロ点・トランスデューサの高さという物理を疑う。
