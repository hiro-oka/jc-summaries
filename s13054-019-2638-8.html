🏥 聖路加ICUでの実践への示唆

聖路加ICUでの実践

病棟プロトコルへの落とし込み

  • 数値目標は2つだけ覚える：受動換気・胸壁が正常という前提で DP ≤15 cmH₂O、プラトー圧 ≤27 cmH₂O。ARDSNet の Pplat ≤30 cmH₂O より厳しい。当院で重症ARDSを診るときの一次目標として妥当
  • 順序を守る。設定をいじる前に「需要と脆弱性を下げる」（強い自発呼吸なら深鎮静・必要なら筋弛緩／重症例は腹臥位／発熱・興奮の抑制／原因疾患の治療）。回診でここを飛ばして呼吸器の画面から入るのが当院の典型的な失敗
  • 設定の優先順位を明文化する：①DPとPEEP → ②分時換気量（VE） → ③I:E比とフロープロファイル。この3段の順で触る
  • 呼吸数を下げる余地を毎回探す。PaCO₂ 60 mmHg程度までの高炭酸ガス血症を許容すれば、呼吸数・VE・パワーを同時に下げられる。パワーは呼吸数に比例するので、最も安く効く操作
  • PEEPは「全開の肺」を目指さない。段階的リクルートメント手技のあと漸減（decremental）で、リクルートと過膨張の釣り合う最小のPEEPを採る
  • 受動的な患者では定常フロー（VCV）を第一に検討する。圧制御の漸減フローをデフォルトにしている病棟では再考の材料になる
  • メカニカルパワーの数値に閾値運用を持ち込まない。著者自身が上限値を設定しておらず、体外CO₂除去の判断もパワー基準単独では行っていない
  • DPを読むときは総PEEP（auto-PEEP込み）で引く。本論文の略語表も DP＝プラトー圧−総PEEP と定義している（ドライビングプレッシャーではなくタイダルプレッシャーと呼べ — 吸気努力で過小・auto-PEEP無視で過大（Correspondence・RespirCare2019））

🧭 この論文の位置づけ（Known / Unknown / What's new）

補足

リサーチ・イン・コンテキスト

  • Known（既に分かっていたこと）：VILI予防の主要変数は長らく一回換気量と静的な気道内圧（プラトー圧・PEEP・その差であるドライビングプレッシャー）だった。しかし静的な圧は単独では損傷を起こせない。圧は容量変化と対になって初めてエネルギーを消費する
  • Unknown（分かっていなかったこと）：呼吸回数と曝露時間がVILIにどれだけ寄与するかは長く過小評価されてきた。またパワーの上限値をいくつに置くべきか、パワー基準だけで体外CO₂除去を始めてよいかについて、質の高い臨床研究による数値的指針が存在しない
  • What's new（本稿の意義）：パワーの生理を整理したうえで、著者自身が実際に何をどの順で操作しているかを公開した。数値目標（DP ≤15、Pplat ≤27、PaCO₂ ≤約60、I:E 1:1.5〜1:1）を示す一方で、パワー自体には上限値を設けないと明言するという、指標の使い方に対する慎重な立場を示した点が新しい

📌 全体要約

要旨

ひとことで 静的な圧だけでは肺は壊れない。壊すのは圧と容量変化の対（ストレス×ストレイン）が、どれだけの速さで、何回、どれだけの時間かけられたかである。だから見るべきは「パワー」だが、著者はパワーに数値の上限を置かず、DP ≤15・Pplat ≤27 という古典的な圧の目標から入る。

  • 損傷の起点は常に、肺に直接かかる圧（経肺圧＝ストレス）と、それに伴う肺容量変化（ストレイン）の組み合わせ。損傷はその頻度だけでなく、上皮と細胞外線維におけるストレス／ストレイン発生の速度にも依存するので、速いフローはVILIの危険を強める。
  • 「パワー」＝1呼吸あたりに与えるエネルギー × 換気回数を、その肺が許容できる容量で調整したもの。1分あたりの総エネルギー入力は、分時換気量とフロー抵抗成分・DP・PEEPの和の積として定義される。
  • ARDSの baby lung では、同じエネルギーが小さな「容器」に集中し、伸展力の大きさと速度の両方が増幅される。さらに閉じた単位と開いた単位の境界で応力が増幅する。
  • 同じパワー値になる頻度・一回換気量・圧の組み合わせが等しく危険とは考えにくい。まず1回ストレインの損傷閾値を超える必要があり、その閾値は健常肺で高く、肺疾患の重症度と逆相関する。
  • 3つの圧成分のうち、エネルギーとパワーのドライビングプレッシャー成分がVILIと最も直接的に関係する。
  • 実践は2段階。第1に脆弱性と換気需要を減らし（鎮静・筋弛緩・腹臥位・解熱・興奮抑制・原因治療）、第2に設定を①DPとPEEP ②VE ③I:E比とフロープロファイルの順で調整する。
  • 著者はパワーの上限値を設定せず、体外CO₂除去の開始判断もパワー基準単独では行わない。主要な判断基準は臨床経過の悪化。

📖 詳細

1. まず前提 — この病態・治療の基礎（初めての人にも）🧩

要旨

5分で背景を掴む VILI（ventilator-induced lung injury／人工呼吸器関連肺傷害）は、人工呼吸そのものが肺を傷つける現象を指す。従来の予防策は「圧を上げすぎない・容量を入れすぎない」だった。

ここで出てくる用語を先に定義する（略語は本論文末尾の Abbreviations に準拠）。

  • プラトー圧（Pplat）：吸気ホールド中の静的な気道内圧。肺胞にかかる圧の目安
  • PEEP：呼気終末陽圧。PEEPtot（総PEEP）＝設定PEEP＋auto-PEEP
  • DP（ドライビングプレッシャー）：プラトー圧 − 総PEEP。1回の呼吸で肺を膨らませるのに要した圧
  • F：平均吸気流量／R：気道＋組織の気流抵抗。両者の積 FR がフロー抵抗成分
  • VE：分時換気量／I:E：吸気呼気比
  • Cobs／Cpred：実測呼吸コンプライアンス／予測呼吸コンプライアンス

ストレスとストレイン：材料力学の言葉を肺に借りたもの。ストレス＝肺実質に直接かかる力（経肺圧）、ストレイン＝それによる変形（肺容量の変化率）。圧だけ、容量だけでは仕事にならない。両者が対になって初めてエネルギーが肺に入る、というのが本稿の出発点。

エネルギーとパワー：1回の呼吸で肺に入るエネルギー（単位 J）を、1分あたりに積み上げたものがパワー（単位 J/分）。同じ圧設定でも呼吸数が倍なら、肺が受け取るエネルギーは倍になる。ここが「静的な圧だけを見ていた時代」との違い。

baby lung：ARDSでは含気のある肺が健常の一部しか残らず、そこに全換気が集中する。容器が小さいのに同じ荷物を詰め込むので、単位組織あたりの負荷が跳ね上がる。

2. 背景と目的 🫁

  • 人工呼吸は本質的に動的な過程である。にもかかわらず、一回換気量と静的な気道内圧（プラトー圧・PEEP・その差であるDP）が、長らくVILI予防を導く主要変数の座を占めてきた。
  • 現在の実践での存在感にもかかわらず、このような非動的な圧は単独では損傷を与えられない。圧は容量変化と対になり、エネルギーを消費して初めて損傷の担い手になる。
  • より正確には、損傷の惹起因子はすべて、肺に直接かかる圧（経肺圧＝ストレス）と、それに伴う肺容量変化（ストレイン）を結びつけたものである。
  • 損傷はこの対の頻度だけに依存するのではなく、上皮を横切って、また肺の膨張に抗する個々の細胞外線維の内部で、1回換気ごとのストレス／ストレインがどれだけ速く発生するかにも依存する。したがって速いフローはVILIの危険を強める（引用文献1・2）。
  • 最近まで、呼吸回数と曝露時間はVILIへの寄与因子として過小に扱われてきた。実験データ（引用文献3）が示すように、いまや換気パワー、すなわち「1回換気あたりに送られるエネルギー × 換気回数を、その肺が耐えうる容量で調整したもの」により多くの注意を向けるべきである。
  • 非機械的因子もVILIへの脆弱性を高める：高い吸入酸素濃度（FiO₂）・体温上昇・肺血管圧の経肺胞勾配の増大（引用文献4）。

4. パワーの生理 — エネルギーはどこへ行くのか ⚡

  • 1呼吸の総膨張エネルギーは、フロー抵抗性の力と弾性の力（静的・動的の両方）を克服するために費やされる（引用文献5、Fig. 1）。
  • 1分あたりの総エネルギー入力、通常「パワー」と定義されるものは、分時換気量（VE）と、同じ3つの1回換気圧成分の和との積である。3成分とは、フロー抵抗成分（FR ＝ 流量 × 抵抗）・DP・PEEP。
  • 主たる強調は吸気側に置かれるのが正しいが、呼気も無視すべきではない。急な呼気（sudden tidal deflations）を許容するとVILIが強まりうる。おそらくは主として実質のエネルギーが急激に放出されるためである（引用文献6）。

5. ARDSの baby lung で何が増幅されるか 🫁

  • パワー仮説は魅力的だが、臨床実践でVILI回避を導くにはさらなる精緻化が必要である、と著者は明記する。
  • 例えばARDSの baby lung では、換気エネルギーとパワーが、容量が小さくガスを受け入れる気道も少ない「容器」の中に集中する（引用文献7）。
  • この空間的な集中が、1回換気の伸展力の大きさと速度の両方を増幅する。
  • さらに、機械的に不均一な環境が、閉じた単位と開いた単位の接合部で応力を増幅する（引用文献8・9）。1970年 Mead らの古典的モデルに遡る考え方。
  • ベッドサイドでの換気の相対的な容量（＝重症度を反映する）は、実測コンプライアンス／予測コンプライアンス比（Cobs/Cpred）でおおまかに近似できる（引用文献5）。

6. 同じパワー値でも等しく危険とは限らない ⚖️

  • 同じパワー値に合計される頻度・一回換気量・圧（フロー抵抗圧・DP・PEEP）の組み合わせのすべてが、ある肺に対して等しく危険であるとは考えにくい。
  • 仮説的にも実験的にも、損傷が始まるための1回ストレインの閾値を、どれほど不明瞭であれ、まず超えなければならない（引用文献10）。
  • その閾値の水準、すなわち実質のVILI感受性は、無傷の健常肺では高く、肺疾患の重症度と逆相関する（引用文献10）。
  • 3つの1回換気圧成分のうち、エネルギーとパワーのドライビングプレッシャー成分がVILIと最も直接的に関係する（引用文献5・11）。
  • PEEPの上昇は、パワーの式が示唆するその大きな寄与に比例してVILIに寄与するわけではないが、DPとプラトー圧に伴うストレインを損傷閾値に近づける。その閾値は肺の領域によって異なり（ある領域では他より低い）、VILIが進行するにつれて正のフィードバックの循環の中で低下する。
  • モードがフロー制御か圧制御かとは独立に、損傷を与えるストレイン閾値を超えている限り、呼吸回数と反復曝露の持続時間の両方がVILIに寄与する。

7. 有害なパワーを制御する優先順位 — 第1段階：脆弱性と需要を減らす 🛑

  • 支持療法の最も早い時期に採用する戦略が、高ストレスサイクルへの累積曝露を抑え、最終的な転帰を改善するうえで決定的である。
  • 著者の第一の優先事項は、VILIへの脆弱性と、身体の換気・酸素化・血流に対する需要を減らすこと。具体的には次のとおり。

8. 第2段階：人工呼吸器設定 — 重要度の降順で 🎛️

需要と脆弱性への共寄与因子を最小化したうえで、設定が最優先事項になる。重要度の降順は次のとおり。

  1. DP と PEEP
  2. VE（分時換気量）
  3. I:E比とフロープロファイル

一回換気量受動的膨張と正常な胸壁を仮定して、DP ≤15 cmH₂O、プラトー圧 ≤27 cmH₂O を保つように調節する前提条件（受動・正常胸壁）が本文に明記されている点が重要
I:E比圧と頻度を決めた後に吸気フローを調整し、I:E比を1:1.5〜1:1の間に保つ
フロープロファイル患者が受動的なとき、圧制御の漸減フローより制御された定常フロー（constant flow）を好む（引用文献11・14）
パワーの上限換気パワー自体に特定の上限値は設定しない損傷閾値が個々で異なり、質の高い臨床研究からの数値的指針が現時点で利用できないため
体外CO₂除去パワー基準だけを用いて開始することに自信を持てない主要な判断基準は臨床経過の悪化（deteriorating clinical trajectory）
再評価最後に、累積パワー曝露とVILIリスクを最小化するため、必要性と現在の呼吸補助の水準に関する自分の前提を頻繁に再評価する
  • 過剰なパワーがVILIリスクの中心にありうるため、著者はパワーの各決定因子を評価し、必要に応じて一つずつ下方調整しようと試みる。

9. 補助：メカニカルパワーの式を記号ごとに読む 🔢

⚠ 注意

ここからは論文本文ではない 以下の係数0.098・Gattinoniの簡略式・数値の代入例は、本論文本文には登場しない一般的な背景知識と補助的な例示である。本稿が示すのは、本文の「パワー＝VE ×（FR + DP + PEEP）」と、Fig.1脚注の「1呼吸のエネルギー＝FR + DP/2 + PEEPtot」という2つの表現だけである。

記号の定義と単位（本論文の Abbreviations に準拠、単位は一般的な表記）

記号読み定義単位
VT一回換気量1回の呼吸で出入りするガス量L
RR呼吸回数1分あたりの換気回数回/分
VE分時換気量VT × RRL/分
Ppeakピーク圧吸気中の最大気道内圧cmH₂O
Pplatプラトー圧吸気ホールド中の静的気道内圧cmH₂O
PEEPtot総PEEP設定PEEP ＋ auto-PEEPcmH₂O
DPドライビングプレッシャーPplat − PEEPtotcmH₂O
F平均吸気流量定常フローなら VT ÷ 吸気時間L/分
R抵抗気道＋組織の気流に対する抵抗cmH₂O/(L/秒)
FRフロー抵抗成分F × R。定常フローでは Ppeak − Pplat に等しいcmH₂O
0.098換算係数1 cmH₂O·L ＝ 0.098 J（圧×容積をジュールに直す）J/(cmH₂O·L)

Fig.1脚注の式（本論文にある形）

> 1呼吸の総膨張エネルギー ∝ FR + DP/2 + PEEPtot

これに VT を掛け、0.098 を掛けるとジュールになる。さらに RR を掛ければ1分あたりのパワー（J/分）になる。

Gattinoniの簡略式（本論文には無い。VCV定常フロー用。当院の メカニカルパワーと死亡率（ICM2018） に記載のある形）

> MP（J/分）＝ 0.098 × RR × VT ×（Ppeak − DP/2）

定常フローでは Ppeak − DP/2 ＝ FR + DP/2 + PEEPtot なので、この2つは同じものを別の測り方で書いたにすぎない。

計算例（補助的な例示。本論文の症例ではない）

前提：体重70 kg相当のPBWに 6 mL/kg の VT 0.42 L、RR 24回/分、Ppeak 30 cmH₂O、Pplat 25 cmH₂O、総PEEP 12 cmH₂O。したがって DP ＝ 25 − 12 ＝ 13 cmH₂O、FR ＝ 30 − 25 ＝ 5 cmH₂O。

  1. Fig.1の3成分：FR 5 ＋ DP/2 6.5 ＋ PEEPtot 12 ＝ 23.5 cmH₂O
  2. 1呼吸のエネルギー：0.42 L × 23.5 cmH₂O × 0.098 ＝ 0.968 J
  3. パワー：0.968 J × 24回/分 ＝ 23.2 J/分
  4. 簡略式で検算：0.098 × 24 × 0.42 ×（30 − 6.5）＝ 23.2 J/分（一致する）

この設定は Marini の目標（DP ≤15、Pplat ≤27）を満たしている。ここから呼吸数だけを24 → 18回/分に下げると、パワーは 0.098 × 18 × 0.42 × 23.5 ＝ 17.4 J/分 となり、25%減る。パワーは呼吸数に比例するので、圧を一切変えずに最も安く効く操作が呼吸数の低減であることが数字で見える。本文が「PaCO₂ ≤約60 mmHg までの高炭酸ガス血症を許容して呼吸回数・VE・換気パワーを下げる」と述べる意味はここにある。

参考までに、本文の「VE ×（FR + DP + PEEP）」をそのまま計算すると 10.08 L/分 × 30 cmH₂O × 0.098 ＝ 29.6 J/分 となり、Fig.1の式より 6.4 J/分（28%）大きい。前掲の警告のとおり、どちらの表現を採るかで数値が大きく変わる。

既存ノートとの整合

  • メカニカルパワーと死亡率（ICM2018）：Neto ら（PROVE Network）の観察研究では、MP 5 J/分の増加ごとに死亡オッズが MIMIC-III で OR 1.06（95%CI 1.01–1.11, p=0.021）、eICU で OR 1.10（1.02–1.18, p=0.010）だった。「MPは死亡と関連する」ことと「MPに上限値を設けて運用できる」ことは別であり、本論文の Marini は後者を明確に否定している。数値目標として使うのではなく、決定因子を一つずつ下げる対象として使う、という立場の違いを押さえる。
  • VILIの真犯人はメカニカルパワーではなく気道閉塞か（Correspondence・ICM2025）：MPの上昇は気道閉塞に二次的な現象であり、損傷はむしろエネルギーがほとんど届かない非換気領域で起きる、という反論。Marini が本稿で述べる「機械的に不均一な環境が閉じた単位と開いた単位の接合部で応力を増幅する」という記述は、この反論と矛盾せず、むしろ同じ現象を別の側から見ている。
  • ドライビングプレッシャーではなくタイダルプレッシャーと呼べ — 吸気努力で過小・auto-PEEP無視で過大（Correspondence・RespirCare2019）：DPを設定PEEPで引くと auto-PEEP のぶん過大評価になる。本論文の略語表も DP＝プラトー圧−総PEEP と定義しており、両者は整合する。
  • 私はPEEPをこう設定する — FiO2を固定しΔPと酸素化の反応だけで滴定する（エディトリアル・CritCare2019）：同じ Critical Care 2019 の "How I..." シリーズ。PEEPを漸減で最小有効値に決める発想は共通する。
  • 肥満患者の人工呼吸 i-STARアルゴリズム — Pplat目標を腹腔内圧で補正する（エディトリアル・CritCare2019）：本論文の Pplat ≤27 cmH₂O は「正常な胸壁を仮定して」の数値である。肥満・腹腔内圧上昇例ではこの前提が崩れるため、そのまま当てはめてはいけない。この2本は相互に補完関係にある。

旧版ノートからの訂正（PDF照合で判明）

  1. 旧版は「パワーの計算式そのものが複数存在し、本稿では概念（VE ×（FR + DP + PEEP））として示されるにとどまる」と書いていたが、Fig.1の脚注に明示的な式「FR + DP/2 + PEEPtot」がある。DPの係数1/2が抜けており、典型設定でエネルギーを約28%過大に見積もる形だった。本版では両方を併記し、食い違い自体を論点として扱う。
  2. 旧版は Fig.1 の重要な但し書き、「PEEP関連の弾性エネルギー（領域C）は吸気ストレス・ストレインの土台を持ち上げるが、蓄えられたその弾性エネルギーは呼気時に呼気弁と回路を通じて完全に散逸する」を落としていた。これは「PEEPがパワーの式ほどにはVILIに寄与しない」理由そのものであり、結論だけあって機序が欠けていた。
  3. 旧版は「2ページのエディトリアル全文に基づく」「Fig.1の内容は図脚注から転記した」と制約を記していたが、PDFは全3ページ（本文2ページ＋文献1ページ）であり、図そのものは本ノートに埋め込み可能だった。本版で原図を無改変で差し込んだ。
  4. 旧版の関連リンク ARDSの人工呼吸 低一回換気量と肺保護換気 と ARDSのリクルートメントとPEEP設定 はVault内に該当ノートが存在しない（リンク切れ）。実在ノートに差し替えた。
  5. 旧版 frontmatter に ジャーナルクラブ タグと updated が無かった。doi / journal / published / citation はいずれもPDF誌面と一致しており訂正不要だった。

批判的吟味（JCでの論点）

  • 式の内的不整合：前述のとおり、本文（DP）と図脚注（DP/2）で式が異なる。読者が本文だけを読むとパワーを過大評価する。査読・編集の見落としと考えられる。
  • 数値目標の根拠が示されていない：DP ≤15、Pplat ≤27、PaCO₂ ≤約60、I:E 1:1.5〜1:1 のいずれについても、本文中に出典も導出も無い。著者の実践としての提示であり、前向き検証はない。とくに Pplat ≤27 は ARDSNet の ≤30 より厳しいが、その3 cmH₂Oの差の根拠は書かれていない。
  • 「経肺」圧と言いながら測定法に触れていない：著者は「経肺プラトー圧と経肺ドライビングプレッシャーにまず注意を向ける」と書くが、食道内圧測定の実施可否・方法・閾値には一切言及がない。一方で数値目標（DP ≤15／Pplat ≤27）は「正常な胸壁を仮定して」の気道内圧として与えられており、経肺圧の話と数値目標の話が接続していない。
  • パワーの上限を置かないなら、何のためにパワーを見るのか：著者は「決定因子を一つずつ下方調整する」と答えているが、それは結局 DP・PEEP・VE・フローを個別に下げることであり、パワーという合成量を計算する実務上の追加価値は本文からは読み取れない。ここは反論の余地がある論点。
  • 腹臥位の適応が定性的：「難治性または悪化する低酸素血症、あるいは非常に低いコンプライアンス」とあるだけで、P/F比の閾値もコンプライアンスの数値も示されない（PROSEVA の P/F <150 のような基準への言及がない）。
  • エディトリアルであることの限界：著者は「パワー仮説は魅力的だが、臨床実践でVILI回避を導くにはさらなる精緻化が必要」「損傷閾値は個々で異なり、質の高い臨床研究からの数値的指針は現時点で利用できない」と、原文の慎重さを保って留保を明記している。この留保を落として数値だけを引用しないことがJCでの最大の注意点。

✅ Take home message

TAKE HOME

結論 静的な圧は単独では肺を壊さない。壊すのは「圧×容量変化」を、どれだけ速く・何回・どれだけの時間かけたかである。 だから第一に換気需要と脆弱性を下げ（鎮静・筋弛緩・腹臥位・解熱・原因治療）、次にDP ≤15 cmH₂O・プラトー圧 ≤27 cmH₂O（受動換気・正常胸壁が前提）を目標に設定を決め、PaCO₂ 60 mmHg までの高炭酸ガス血症を許容して呼吸数を落とす。メカニカルパワーには上限値を置かない。閾値の根拠となる臨床研究がまだ無いからである。
