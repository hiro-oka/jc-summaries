🏥 聖路加ICUでの実践への示唆

聖路加ICUでの実践

病棟プロトコルへの落とし込み

  • 「新しくICUに来た医師は全員 basic CCE ができること」を到達目標に置く。本レビューが提示するキーポイント8項目の第1位がこれ。basic CCE は4つの標準断面（傍胸骨長軸・傍胸骨短軸・心尖部四腔・肋骨下四腔）＋下大静脈と、4つの読影項目（左室サイズと収縮能／右室サイズと機能／心嚢液／IVC径と呼吸性変動）で構成される。当院の後期研修・フェロー教育に明示的なチェックリストとして組み込める形になっている。
  • 血行動態が不安定な患者には、少なくとも初期評価としてCCEを行う（キーポイント第2位）。「初期輸液蘇生後もショックが遷延する場合はCCEで心機能評価とタンポナーデ除外を行い、治療の効果判定として繰り返す」という16名の専門家ステートメントに沿った運用を、ショックのバンドルに明記する。
  • ICUに自前のTEEプローブを持つ（キーポイント第5位）。挿管・人工呼吸中の患者ではTTEの画質が不十分になりやすく、外傷患者の研究ではTTEの描出失敗が38%、そのすべてがTEEで解決した。TTE不良の危険因子は、入室時比10%超の体重増加、PEEP 15 cmH2O以上、胸腔ドレーンの存在。当院でも「挿管中・高PEEP・浮腫の強い患者でTTEが読めないとき」が最大のボトルネックであり、TEE運用（プローブの確保・洗浄動線・実施者の認定）を整備する意義が大きい。
  • シミュレーションを教育の標準にする（キーポイント第7位）。自己学習型の携帯シミュレータで初学者の画像取得・解釈能力が改善したという報告があり、TEEでの完全な血行動態評価の習得にも有効。実患者に頼らず立ち上げられる点で、症例数の限られる施設ほど価値がある。
  • 心臓外科術後とECMOはCCEが要になる（キーポイント第8位）。術後の限局性タンポナーデ（血腫による右心系圧排）はTTEでは見えにくくTEEが有利。VV/VA-ECMOでは導入前評価・カニュレーション誘導・維持中のトラブルシューティング・離脱判断のすべてでエコーが使われる。当院のECMO運用手順に、エコーの実施タイミングを段階別に書き込む素材として本レビューの表がそのまま使える。
  • 「使えるのに使っていない場面」を洗い出す。フランスのARDSコホートではCCEの使用率が54.5%→58.8%にとどまり、約40%の患者が恩恵を受けていなかった。FENICE研究では輸液の判断にエコー指標を使ったのはわずか2%、40%超は何の指標も使っていなかった。当院でも「ショック・ARDS患者で入室24時間以内にエコー評価が記録されている割合」を指標にできる。

🧭 この論文の位置づけ（Known / Unknown / What's new）

補足

リサーチ・イン・コンテキスト

  • Known（既に分かっていたこと）：2009年の米国胸部医学会（ACCP）と仏語圏蘇生学会（SRLF）の合同声明により、集中治療医が行う超音波は CCUS（critical care ultrasonography） を総称とし、その2大分枝として CCE（critical care echocardiography、心エコー） と GCCUS（一般集中治療超音波） が定義された。CCEは basic と advanced に分かれ、いずれも経胸壁（TTE）・経食道（TEE）のどちらのアプローチでも行いうる、という枠組みが確立していた。
  • Unknown（分かっていなかったこと）：この定義から10年で、CCEが実際にどこまで普及し、診断ツールとしてだけでなく血行動態モニタリングとしてどう位置づけられたのか。また、トレーニングと認定はどこまで整備されたのか。そして最も重要な点として、CCEの体系的な使用が患者アウトカムを改善するのかは未解決のままだった。
  • What's new（本研究の新規性・意義）：CCE定義から10年の到達点を、普及の実態（と使われていない領域）、basic／advancedの技能定義、TTEとTEEの使い分け、臨床応用場面（診断・血行動態モニタリング・敗血症性ショックの予後評価・心停止・呼吸不全・周術期・機械的循環補助）、教育とシミュレーション、世界の認定制度、将来技術（スペックルトラッキング、3D、ハンドヘルド機）まで横断的に整理した。さらに、CCUSの研究優先課題10項目と持続する不確実性10項目を明示し、報告の標準化プロジェクト「PRICES」も紹介している。

📌 全体要約

要旨

ひとことで クリティカルケア心エコー（CCE）は定義から10年で集中治療超音波の必須分枝となり、診断ツールとしても血行動態モニタリングとしても使用が著増した。近年の研究ではアウトカム改善の可能性も示唆されるが、体系的使用が予後を改善するかは依然として最優先の研究課題である。

  • 普及：米国の入院サンプル調査では心エコーの絶対件数が2001–2011年に年3.4%増。敗血症・うっ血性心不全の重症患者では肺動脈カテーテル（PAC）よりも心エコーが多く使われていた。ただし院内死亡例では依然として過少利用と結論された。
  • 未使用領域も大きい：フランスのARDS研究でCCE使用は 54.5%（2004–2006）→ 58.8%（2010–2012）。同期間にPAC使用は 10.4% → 7.4% に低下。
  • 欧州140 ICUの1日横断調査では入院患者の36%に計1,073件のGCCUS検査が実施され、大半は診断・治療調整目的の basic CCE。TEEは全体の10%未満。
  • 2つの習熟度：basic CCEは5断面の2D TTEで「重度左室機能低下があるか」「中等量以上の心嚢液があるか」といった二者択一の問いに答える。advanced CCEは全断面とドプラを駆使して心機能・血行動態をフル評価し、はるかに高度な認知的・技術的訓練を要する。
  • 敗血症での予後評価：8研究794例のメタ解析で、LVEFは死亡と関連しなかったが、GLS（global longitudinal strain）が悪い（負の値が小さい）ほど死亡が高かった。MIMIC-IIIの敗血症6,361例では、早期TTE実施群で28日死亡が有意に良好、初日の輸液量が多くドブタミン使用も多く、昇圧薬離脱も早い傾向だった。
  • 心停止：PEA（無脈性電気活動）11研究777例のシステマティックレビューで、超音波で心収縮活動がある患者はROSC（自己心拍再開）を得やすかった。
  • 認定制度：英仏の学会認定に加え、ESICMが2016年に EDEC（European Diploma in advanced critical care EchoCardiography）を開始。北米では2015年に主要学会がNBEと合意し、2019年1月に初回試験（508名が登録）を予定していた。

📖 詳細

1. まず前提 — この病態・治療の基礎（初めての人にも）🧩

要旨

5分で背景を掴む ベッドサイド超音波は、聴診器の延長として「身体所見の一部」になりつつある。用語を整理する。 POCUS（point-of-care ultrasonography）は、主治医が患者の目の前の疑問に答えるために行う目的指向型の検査を広く指す一般用語。集中治療領域では、2009年のACCP/SRLF声明により CCUS（critical care ultrasonography） が総称と定められ、その2分枝が CCE（心エコー） と GCCUS（肺・腹部・血管など心臓以外） である。 CCE は basic と advanced に分かれる。basic CCE は5断面の2D TTEで、心室径などの基本計測を（Mモードの有無を問わず）行うもので、Jensenらの初期の仕事から「FATE（focused assessed transthoracic echo）」という略称で普及した。答える問いは二者択一に近い。「重度の左室機能低下があるか」「中等量以上の心嚢液があるか」「右室は著明に拡大しているか」「輸液反応性がありそうか」。 advanced CCE は循環器内科医と同等の能力で心肺不全の病態生理を解明するもので、全2D断面とドプラ計測を用いる。左室では拡張能・局所壁運動異常・一回拍出量、右室では中隔運動・肺動脈圧推定・右室流出路ドプラ、心膜ではタンポナーデ生理まで踏み込む。感染性心内膜炎・大動脈解離・肺塞栓・心内シャント・心筋梗塞の合併症といった複雑な病態も守備範囲になる。 TTE（経胸壁）とTEE（経食道） はどちらも basic／advanced の双方に使える相補的なアプローチである。「basic＝TTE、advanced＝TEE」という理解は単純化しすぎ、と本レビューは明示的に釘を刺している。 その他の略語：IVC＝下大静脈、SVC＝上大静脈、VTI＝速度時間積分（大動脈血流の速度波形の面積。一回拍出量の代理）、PLR＝受動的下肢挙上、LVFAC＝左室面積変化率、GLS＝全体長軸ストレイン、PAC＝肺動脈カテーテル、TPT＝経肺熱希釈法。

2. 背景と目的 🫁

Cholleyらが2006年に「ICUで心エコーをもっと使おう」と呼びかけてから10年で、国際的なエビデンスに基づくガイドラインを出版できるだけの学術的蓄積が生まれた。この事実自体が、この分野の進歩の速さを示している。

本レビューはICM誌のCCUSシリーズの1編として、CCEに焦点を絞り、ACCP/SRLFによる公式な認知・定義から10年後の到達点を専門家グループがまとめたものである。CCEは救急外来での初期評価からICU入室・在室中、さらに手術室まで連続して使える「半連続的（semi-continuous）」なツールとして提示されている。

3. 方法（Methods）📐

  • デザイン：ナラティブレビュー（系統的レビューやメタ解析ではない）。
  • 執筆者：CCE分野の専門家グループ（フランス、カナダ、イタリア、スウェーデン、米国、オーストラリア、英国など）。
  • 構成：普及の現況と空白 → basic/advanced の2段階の習熟度 → TTEとTEEの比較 → 臨床応用（診断／血行動態モニタリング／敗血症の予後／心停止／呼吸不全／周術期／機械的循環補助） → 技能・教育・認定 → 将来。
  • 成果物：キーポイント8項目（Fig 1）、CCUSの研究優先課題10項目と持続する不確実性10項目（Table 1）、basic/advancedの対比（Fig 2）、CCEが有益な臨床シナリオ一覧（Table 2）、ECMOにおけるCCEの用途（Table 3）、教育カリキュラム10要素（Table 4）、世界の認定制度一覧（Table 5）。
  • 限界（レビューとしての性質）：文献の系統的検索・選択基準や、エビデンスの確実性評価（GRADE等）は行われていない。推奨はあくまで専門家の合意であり、記載される数値は引用元研究の値である。

4. CCEの普及 — 増えているが空白も大きい 📈

臨床疑問：CCEは実際どこまで使われており、どこで使われていないのか。

  • 米国 National Inpatient Sample に基づく報告では、心エコーの絶対件数が2001–2011年に年3.4%の割合で増加。ただしその多くは循環器医・技師によるもので、集中治療領域での使用率は過小評価されている可能性が高い。
  • 同研究では、敗血症の重症患者・うっ血性心不全患者で、心エコーはPACより多く使われていた。しかし入院中に死亡した患者ではなお過少利用と結論された。
  • フランスのARDS研究：CCE使用は 54.5%（2004–2006）→ 58.8%（2010–2012）。裏を返せば約40%は恩恵を受けていない。同期間にPACは 10.4% → 7.4% に低下。
  • 欧州140 ICUの1日横断研究（Zieleskiewicz ら）：入院患者の36%に 1,073件のGCCUS検査。大半は診断と治療調整のための basic CCE。TEEは10%未満で、TTEの手軽さが優位を裏づけた。
  • FENICE研究（輸液投与の実態調査）：2,213例中、輸液の判断にエコー指標を使ったのはわずか2%。40%超はいかなる指標も用いていなかった。
  • PACとの関係：中心静脈圧を直接測定していれば、PACで測った収縮期肺動脈圧とエコーで算出した値には臨床的に許容できる相関があることが確認された。ただし心臓外科術後ICUなど、一部の適応ではなおPACが好まれうる。

判断：CCEの使用にはばらつきが大きく、適応と使用の標準化が今後の主要目標である。

5. basic CCE と advanced CCE — 何が違うか 🔍

臨床疑問：どこまでが「短期研修で到達できる basic」で、どこからが「体系的訓練を要する advanced」か。

Table. basic CCE と advanced CCE の対比（原図2を日本語化）

評価対象basic CCE が答える問いadvanced CCE が答える問い
左室重度の左室収縮不全があるか拡張能と局所壁運動異常はどうか（左室充満圧は高そうか）
右室右室は著明に拡大しているか右室後負荷の急性上昇があるか

basic CCEの技能は「画像取得」「画像解釈」「臨床統合」の3層で整理される。画像取得は4断面（傍胸骨長軸・傍胸骨短軸・心尖部四腔・肋骨下四腔）＋肋骨下からのIVC。画像解釈は4項目（左室サイズと収縮能／右室サイズと機能／心嚢液／IVC径と呼吸性変動）。臨床統合は6つのシナリオ（重度循環血液量減少、左室不全、右室不全、心タンポナーデ、重度左心系弁逆流、心停止時の使用）。

臨床医が basic CCE を正確に実施できるよう訓練可能であることを示すデータは十分にある。とくに左室収縮能のPOCUS評価と心嚢液の有無についてはエビデンスが厚い。一方、右室機能評価（TAPSE、心室中隔位置など）と弁評価は、より複雑なためか検討が少ない。

6. TTE と TEE — 使い分けの実際 🩻

TTEの利点：非侵襲で患者リスクなし、準備時間が最小、ベッドサイドで即座に反復可能、プローブ洗浄が速く多数の患者を短時間で回れる、コンパクトでICU向けの小型機に適合する。三尖弁逆流速度・左室流出路狭窄速度・大動脈弁通過血流のドプラ計測ではTEEより角度が合いやすく、表在構造（心尖部血栓、前方心嚢腔）の描出も優れる。

TTEの弱点：体型、ドレッシング・ドレーン・デバイス、肺過膨張、体位変換困難といった患者要因で画質が不十分になる。外傷患者の研究ではTTE描出失敗が38%で、その全例がTEEで解決した。失敗の危険因子は入室時比10%超の体重増加、PEEP 15 cmH2O以上、胸腔ドレーン。習得期間はTEEより長く、術者依存性も高い。上大静脈の径・呼吸性変動、心内膜炎、大動脈解離、心臓外科術後の限局性血腫によるタンポナーデ、左房内血栓、ダブルルーメンECMOカニューレの挿入・位置決め、自己弁・人工弁の詳細な形態評価、急性肺性心の診断は苦手である。

TEEの位置づけ：習得期間はTTEより短く術者依存性も低い。画質が良く、上記の苦手領域を補える。合併症（食道損傷、下咽頭損傷、気管切開チューブの逸脱）はまれ〜きわめてまれで、報告の多くは自発呼吸下の覚醒患者。集中治療のTEEは人工呼吸中に行うことが多く、循環器領域の報告より合併症率は低い可能性がある。制約は、準備時間とプローブ洗浄、そして多くのICUチームが自前のプローブを持っていないこと（北米でより顕著だが欧州・アジアでも見られる）。

推奨：挿管されていない患者ではTTEが標準。まずTTEを「go-to」とし、明確なTEE適応があるとき、または挿管患者でTTEでは答えが得られないときにTEEへ進む。TEEはICUの標準ツールとして集中治療医が使える状態にすべき、というのが本レビューの立場である。

7. 血行動態モニタリングとしてのCCE 💧

臨床疑問：CCEはPACや経肺熱希釈法に代わる血行動態モニターになりうるか。

  • 16名の専門家によるステートメントは、初期輸液蘇生後もショックが続く場合にCCEを実施し、心機能評価とタンポナーデ除外を行い、治療の効果を評価するために必要に応じて反復することを推奨している。
  • 心拍出量（CO）は絶対値よりも変化の追跡に強い。大動脈VTIを一回拍出量に換算するには大動脈径の正確な計測が必要で誤差源になるが、VTIの変化は大動脈径に依存せず信頼して測れる。
  • 動的指標：陽圧換気による一回拍出量変動はVTI変動として、PLRに対するCO変化はPLR前後の瞬時・連続VTIの比較として評価できる。PAC由来の熱希釈法が数分単位で平均化するのとは対照的である。
  • TTEとTEEの最大の差は輸液反応性の評価法にある。TTEでは大動脈VTI変動、PLRに対するCO変化、IVC径（呼気終末径と呼吸性変動、ただし精度は限定的）。TEEではこれに加え上大静脈の呼吸性変動（∆SVC）が使える。∆SVCは輸液反応性の判定にきわめて良好な特異度と中等度の感度をもつと報告されている。これら動的指標はいずれも人工呼吸に同調した患者で検証されたものである点に注意。
  • 敗血症性ショックの多施設研究では、経肺熱希釈法（TPT）とCCEの血行動態測定値は中等度の一致にとどまり、28%の症例でTPT側に不正確さの可能性が示唆された。
  • 断続的ではあるものの、連続的な観血的血圧モニタリングと組み合わせた反復CCEで、大半の不安定患者は管理可能とされる。
  • CCEの独自性は、血行動態管理の個別化に加えて人工呼吸設定・戦略にも情報を与える点にある。ARDSなど肺動脈圧上昇を伴う病態での右室評価がとくに重要。
  • 長時間留置可能な小径TEEプローブなど新技術により、対象患者の幅は広がると期待される。

8. 診断ツールとしてのCCE、および場面別の応用 🚑

入院時・スクリーニング：病歴・身体所見にCCEを加えると診断精度が上がる。人工呼吸中の患者や原因不明の低血圧では、CCEの追加が診断収率を高め、治療方針を変えうる。

急性心不全：基本的な心臓＋肺エコーの組み合わせは、身体所見・胸部X線・血液検査といった従来ツールを上回る精度で急性非代償性心不全を診断できる。

拡張機能：advanced CCEは左室拡張能の評価を可能にするが、これは他のいかなる血行動態モニターにもできない。左室拡張障害は敗血症性ショックの死亡率上昇、および人工呼吸離脱失敗の増加と関連することが認識されつつある。

外傷：CCEの最初期のエビデンスは外傷領域から。穿通性心損傷での即時使用が心嚢液の検出を早め、手術までの時間を短縮し、生存を改善した。混合外傷集団の蘇生への超音波活用でも、循環血液量減少と左室機能低下の検出・是正が改善し、手術へのトリアージ時間が短縮、死亡率も低下傾向であった。

心停止：可逆的原因（心タンポナーデなど）の同定は管理を大きく変えうる。PEA 11研究777例のレビューでは、超音波で心収縮活動がある患者はROSCを得やすく、蘇生継続を後押しする所見となりうる。

敗血症性ショックの予後評価：CCEの結果で約半数の症例で管理方針が変わる。敗血症性心筋症の診断に有用だが、2D由来のLVEFの予後予測能は限定的で、むしろ心室・動脈のアンカップリング（ventriculo-arterial uncoupling）の方が示唆的。8研究794例のメタ解析ではLVEFは死亡と関連せず、GLSが悪いほど死亡が高かった。MIMIC-IIIの敗血症6,361例では、早期TTE群で28日死亡が有意に良好、初日の輸液投与量が多くドブタミン使用も多く、昇圧薬離脱も早い傾向。basic CCEを受けた患者では亜急性期の急性腎障害の発生も少なかった。

呼吸不全：右室機能に合わせて呼吸戦略を調整できるが、そのアプローチが予後を改善するかは未評価。肺塞栓では右室不全とショックが死亡の主要因であり、再灌流療法の適応判断を含むリスク層別にCCEが重要な役割を果たす。人工呼吸は右室機能に大きく影響する。吸気時・呼気終末の肺容量増加は胸腔内圧上昇を介して肺血管抵抗を上げ、過膨張は静脈還流を妨げ右室充満圧を下げる。過膨張で肺血管抵抗が上がった状態で輸液を行うと急性右室ストレイン（奇異性中隔運動、重症なら三尖弁逆流）が生じうる。

周術期：大手術で主要心血管・呼吸器イベントのリスクが高い患者では、術前・術中のエコーがモニタリング強化や術後管理レベルの決定（戦略的トリアージ）に役立つ。心臓外科では、術前エコーによるリスク層別、緊急時の大動脈解離・急性弁逆流の診断、術中エコーから術後スキャンへの連続的モニタリングが可能。血行動態不安定、低心拍出量症候群、心切開後の急性右室不全、人工弁機能不全、原因不明の重度低酸素血症、心タンポナーデの初期対応ツールとして確立している。限局性タンポナーデの診断ではTEEが好まれるが、TTEの実行可能性は術後1日目以降に改善する。使い捨ての72時間留置型TEEデバイスも探索されている。

機械的循環補助（ECMO）：TTE・TEEともVV/VA-ECMOの管理に必須。ダブルルーメンカニューレを用いる際の右房内での位置決め誘導、位置と機能の反復確認、右室・左室機能の継続評価、離脱検討時の心室機能の定量評価に使われる。

シミュレーションの役割：Skinnerらは、独立自己学習型・完全携帯型のシミュレータベースカリキュラムが、初学者レジデントの basic CCE の画像取得と解釈の訓練に有効であることを示した。同様のシミュレータ主導プログラムで認知的・精神運動的技能も改善する。シミュレータは、最大角度偏差、心構造に対する回転軸、胸壁上のプローブ位置を提示することで画像取得の正確さを可視化できる。シミュレーションで得た技能が臨床にどこまで転移するかのデータはなお乏しいが、basic CCEの学習曲線の改善、およびTEEによる完全な血行動態評価の実施能力の改善を報告した研究がある。

認定制度：英国とフランスは各国学会を通じてadvanced CCEのディプロマを確立。ESICMは2016年に EDEC を開始し、TTEとTEEの両方の能力を要求する（TEEをadvanced CCEの必須要素とみなすため）。英国のACCE（BSE）はTTEのみで、TEEは別ディプロマ。EDECは循環器系認定（EACVI/EACTAのTEE認定など）と異なり、詳細な弁評価ではなく重症患者の血行動態評価に焦点を置く。

北米では2015年に主要学会（ACCP、ATS、SCCM、麻酔科学会各団体、ACEP、ASE）が NBE（National Board of Echocardiography）とadvanced CCE認定の開発で合意。試験はNBMEと共同開発され、北米各地のテストセンターで実施される全日程の試験として年1回開催される。執筆時点で初回試験（2019年1月）に508名が登録。認定要件には、指導者の緊密な監督下でのTTE 150件以上の実施による画像取得能力の証明が含まれる予定で、TEEは画像解釈の能力は要求するが画像取得は要求しない（米国の集中治療医にTEEプローブが十分行き渡っていない現実を反映）。

10. 将来 — 新技術と標準化 🔭

スペックルトラッキング（ストレイン）は有望。3Dエコーも重症患者で記述されているが、なお大きな制約がある。いずれも、集中治療で広く使われている超音波装置がこれらの機能を持たないことが普及の障壁であり、機器の追加コストと複雑さも制限要因になる。

ハンドヘルド機：安価で使いやすく画質も良い小型機の登場は、basic CCE と CCUS の普及を大きく後押ししうる。スマートフォンと連携しインターネット接続を備えたモデルもある。ただし現時点でスペクトラルドプラを搭載した機種はなく、advanced CCE を完全には行えない。

⚠ 注意

臨床上の要注意ポイント 安価なポケットサイズ機が普及すると、十分な訓練を受けていない術者が使うリスクが生じ、患者への害とCCUS分野そのものの信用低下につながりうる。 機器の導入と訓練体制の整備は必ずセットで進める。CCEを行う医師は、TTE/TEEそれぞれの利点・落とし穴・限界を認識していなければならない（本レビューのキーポイント第6位）。画像の質が疾患ではなく術者によって決まってしまう、というのがこの分野の本質的な弱点である。

報告の標準化（PRICES）：CCE臨床研究のデータ報告の不均一性を受け、ESICMエコーワーキンググループの専門家パネルがCCE研究の報告ガイドラインを検討中（PROSPERO登録番号 CRD42018094450）。標準化された計測とデータ収集により、データ共有と大規模共同研究を可能にすることを目指す。
