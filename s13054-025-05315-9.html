🏥 聖路加ICUでの実践への示唆

聖路加ICUでの実践

明日からどうするか ① 「誰が診るかで決まる」を、当院のどの判断で許しているかを名指しする。 本論文の中核概念 system noise（システムノイズ＝本来同一であるべき判断のばらつき） は、「似た状況の患者が、担当が誰かというだけで違う扱いを受ける『くじ引き（lottery）効果』」として定義されている。当院ICUで「くじ引き」が起きている候補は明確に挙げられる。

② ノイズ監査（noise audit）を、当院で1回だけやってみる価値がある。 本論文のパイロット研究はICU臨床医20名に同一の患者ケース50例の死亡確率（0〜100%）を推定させ、うち症例3を「症例51」として気づかれないように再提示するだけの設計。特別な装置も倫理審査の重装備も要らない（原著でも低リスクとして審査免除）。当院で同じことをやれば、「うちの科の判断は、医師間でどれだけ、そして同一医師内でどれだけばらつくか」を数値で出せる。経営戦略会議やICU質指標（QI）の議論に、印象論ではなく分散の数字を持ち込める。

③ 重症度スコアは「予測精度」より先に「ノイズ除去装置」として売り込む。 本論文は APACHE を、(a) 全員が同じ妥当な変数を集める、(b) 同じ計算式で統合する、という二重の標準化装置として位置づけている。JIPAD で APACHE III-j / SOFA を日々入力している当院にとって、これは「学会提出のための入力作業」から「判断のばらつきを消す仕組み」への意味づけの転換になる。同時に本論文はGCSのような判断ベースの変数はスコア内に残るノイズ源だと明記しており、GCS・RASS の教育とダブルチェックが依然として効く理由にもなる。

④ 「独立した判断を平均する」を、多職種カンファの設計思想に入れる。 平均化はノイズを判断数の平方根に比例して縮める（4人なら1/2、9人なら1/3）。ただし条件は独立性で、先に部長や上級医が意見を言った時点で効果は大きく損なわれると原著は明言している。当院の朝カンファ・家族面談前カンファで、意見を「せーの」で同時に出す（付箋・チャット同時投稿・Formsでの事前入力）だけで、追加コストほぼゼロでノイズが下がる。岡本の立場（部長）は最も強い社会的影響源なので、自分が最後に話すルールが最も費用対効果が高い介入になる。

⑤ AI・予測モデルの院内導入では「バイアス」だけでなく「入力データのノイズ」を審査項目にする。 本論文は、一貫性のない専門家判断でラベル付けされたデータで学習したモデルは、そのノイズを取り込むと指摘する。バイタル自動収集や RRS の予測アラート、将来の院内AIを評価するとき、「精度が高いか」「差別的バイアスがないか」に加えて 「教師ラベルは誰がどれだけばらついて付けたか」 を必ず問う。

⑥ 「アルゴリズムに例外を作りすぎる」自分たちを疑う。 原著の最も反直感的な指摘は、人間はアルゴリズムに対して例外を作りすぎ（identify too many exceptions）、その結果ノイズを増やして精度をむしろ下げるという他分野の知見。当院で SBT プロトコル・輸液プロトコル・輸血トリガーから「この患者は特別だから」と外す判断を、外した理由を記録して後で見返す運用にすると、例外運用の妥当性が検証可能になる。

POINT

グロービス（MBA）の意思決定論との接続

  • 「バイアス vs ノイズ」は、平均のズレ vs 分散の大きさ。組織行動・オペレーションで扱う品質管理（正確度 accuracy と精密度 precision）と完全に同じ構造で、同じ幅だけ減らせば全体誤差への寄与は等価（原著の主張）。にもかかわらず経営でも医療でもバイアス（偏り）ばかりが議論され、ノイズ（ばらつき）は見えないまま残る。
  • アルゴリズム vs 専門家判断は、Meehl(1954) 以来の「臨床的予測 vs 統計的予測」論争そのもの。原著は Dawes の「improper linear model（単位重み・ランダム重みという『雑な』線形モデル）ですら専門家を上回りうる」という古典を引き、その理由を精度ではなく一貫性に帰している。これは採用面接・与信・人事評価の意思決定設計でそのまま使える論点。
  • holistic synthesis（アルゴリズム出力を1つの手がかりとして人間が統合する） をどこまで認めるかは、AIガバナンス・human-in-the-loop 設計の中心論点。原著は「有益と信じられているが検証されていない」と保留している。
  • 振り返り・レポートで使えるフレーム：「この判断は、誰がやっても同じになるべきものか？（→ノイズ削減の対象）／人によって違ってよいものか？（→価値判断の領域）」 の切り分け。

🧭 この論文の位置づけ（Known / Unknown / What's new）

内容
Known（すでに分かっていること）ICUの判断誤りは患者アウトカムに直結する。認知バイアス（アンカリング、利用可能性ヒューリスティック等）は集中治療領域でもスコーピングレビューで整理済み。AIモデルの差別的バイアスも近年大きく問題化。医師間の判断不一致は咽頭炎の診断・治療、尿沈渣の判読、画像読影など多くの領域で観察されてきた
Unknown（まだ分かっていないこと）ICUの判断誤りのうち、どれだけがノイズ（ランダム誤差）由来なのかは測られていない。アルゴリズム出力を「複数の手がかりの1つ」として人間が統合する holistic synthesis が、精度を上げるのか下げるのか。人間の判断のどの部分がモデルに価値を付加しているのか
What's new（この論文の新しさ）Kahneman らの noise（system noise ＝ level / stable pattern / occasion noise）の分類をICU臨床判断に体系的に持ち込んだこと。ICU臨床医20名の死亡確率推定パイロットで3種のノイズを実データとして可視化したこと。そして SICS の同一データ（827例）で 医師の院内死亡予測 AUC 0.68 に対し APACHE IV は AUC 0.83 と示し、「アルゴリズムの優位はノイズ除去で説明できる」と論じたこと

📌 全体要約

判断誤り（judgment error）＝「臨床医の予測と実際の転帰の差」は、バイアス（系統誤差）とノイズ（ランダム誤差）の2成分に分解できる。医学界は前者ばかり議論してきたが、同じ大きさだけ減らせば全体誤差への効果は等価である。

ICUは「臨床医は互換可能（interchangeable）」という前提で運営されているが、同一患者を評価しても判断は割れる。このsystem noise（システムノイズ）は3つに分解される。

  1. level noise（レベルノイズ）＝臨床医ごとの平均判断の高低（例：常に手術に前向きな医師／慎重な医師）
  2. stable pattern noise（安定パターンノイズ）＝特定の患者特性への反応の個人差（臨床医×患者特性の交互作用）
  3. occasion noise（機会ノイズ）＝同一臨床医内の場面依存のばらつき（気分・天候・疲労・時間帯）

対策は2つ。(a) アルゴリズム：変数選択と重み付けを固定し、不要な変数を無視できるため、人間が構造的に苦手な「一貫性」を保証する。(b) 独立した判断の平均化（wisdom of the crowd）：ランダム誤差が相殺され、ノイズは判断数の平方根に比例して減る。ただし平均化はノイズしか減らせずバイアスには無力で、かつ判断の独立性が崩れると効果は大幅に損なわれる。

アルゴリズム導入には条件がある。学習データ上の性能だけで有効性を仮定してはならず、誤ったモデルの出力提示はむしろ精度を下げる。ノイズの多い人間ラベルで学習すればモデルが誤差を取り込む。ハルシネーション・不整合・データ希少性への弱さなど固有の弱点もある。差別的なモデルは社会的不平等を強化しうる。一方で「アルゴリズムはブラックボックスだから信用できない」という不信には、人間の意思決定もブラックボックスであり、しかもアルゴリズムと違って実験的に検証できないと反論している。

3つのノイズが臨床にもたらす帰結（原著の論旨）

論点原著の主張
ICUの前提ICUは多様な患者を扱う「システム」で、臨床医は互換可能であると暗黙に仮定して運営されている
その前提の破綻同一患者を評価する臨床医間の不一致が、この仮定を繰り返し裏切る
帰結同じような状態の患者が、担当医が誰かというだけで異なる死亡予測と異なる治療を受ける＝システムに「くじ引き」の要素が入る
誤差の累積ノイズは個々の患者をまたいで打ち消し合うのではなく、蓄積していく（compounding）

ノイズ低減策①：アルゴリズム

論点原著の記述
なぜICUで直感的熟達が育ちにくいか直感的熟達（intuitive expertise）の成立条件は ①明確かつタイムリーなフィードバック、②予測因子と転帰の安定した関係、③その関係を学習する機会（Kahneman & Klein 2009）。ICUの患者は変動が大きく、これらが満たされないことがある
その傍証Cox らの研究で、経験豊富な医師のICU死亡予測は医学生より有意に正確とはいえなかった
アルゴリズムの利点(1)予測妥当性のある変数に適切な重みを与え、妥当性のない変数を無視できる。人間は無関係な変数を無視するのが苦手
アルゴリズムの利点(2)（原著が「より重要」とする点）全症例に同じ重み付けを一貫して適用する。人間は症例ごとに重み付けを変え、それが精度向上ではなくノイズを生む
一貫性の威力専門家の判断を模した線形モデル（judgmental bootstrapping）は元の専門家を上回る。単位重み・ランダム重みといった「improper」なモデルですら、一貫性ゆえに専門家を上回りうる
APACHE の位置づけAPACHE は (a) 全員が同じ妥当な変数を集め、(b) 一貫した式で統合することを保証する。よって複数の臨床医が同一患者に同一スコアを出せる＝システムノイズを最小化
APACHE に残るノイズ源測定機器の不正確さ、および GCS のような判断に依存する変数の不整合

ノイズ低減策②：独立した判断の平均化

論点原著の記述
原理「wisdom of the crowd（群衆の知恵）」。独立した判断はランダム誤差を含むが、平均すると誤差が相殺される
効果の大きさノイズは平均する判断数の平方根に比例して減少する
限界（重要）平均化はノイズを減らすがバイアスには効かない
個人内平均化同一臨床医が時間をおいて行った複数判断の平均も精度を上げうるが、非冗長（non-redundant）＝異なる視点・異なる情報に基づく場合に限られる
独立性の条件現実のICUで完全に独立した判断は常に可能とは限らない。社会的影響や集団力学で独立性が損なわれると、平均化によるノイズ低減効果は大きく削がれる
提案臨床医が独立に評価を行い、それを体系的に集約する仕組みを設計すべき

アルゴリズム導入で残る課題（Discussion の論点を全件）

#課題原著の記述
1性能の検証学習データ上の性能だけで有効性を仮定してはならない。誤ったモデルの出力を臨床医に提示すると判断精度が下がる（Jabbour, JAMA 2023）
2教師ラベルのノイズ一貫性のない専門家判断に由来する診断ラベルで学習すると、モデルに誤差が持ち込まれる（Sylolypavan, NPJ Digit Med 2023）
3アルゴリズム固有の弱点ハルシネーション、不整合（inconsistency）、faithlessness（出力が根拠に忠実でない）、データ希少性への弱さ、複雑性への対処困難
4意図せぬ帰結差別的なモデルは社会的不平等を強化しうる
5holistic synthesis臨床医はアルゴリズム出力をそのまま使わず、広い判断過程の1つの手がかりとして統合する。モデルに入っていない要因に気づける点で有利とされるが、他分野では「人間は例外を作りすぎ、ノイズを増やして精度を下げる」という反直感的知見がある。有利か不利かは要検証
6出力の無視・不採用アルゴリズム出力がそもそも使われないことがある。要因はモデルや予測因子定義の透明性の欠如による不信
7ブラックボックス論への反論人間の意思決定もブラックボックスである。臨床医を含め人は自分の意思決定過程を言語化できないことが多い。アルゴリズムは不透明でも厳密に検証・実験できるが、人間の意思決定でそれを行うのははるかに困難

著者が示した今後の研究課題

  • アルゴリズム出力を「holistic synthesis のための複数手がかりの1つ」として提示することは、そのまま適用する場合と比べて判断精度を上げるのか下げるのか
  • holistic synthesis が有益なら、臨床医の判断のどの側面が価値を付加しているのかを特定し、それをモデル側に確実に組み込む（model refinement）

  • 判断誤り＝バイアス（系統誤差）＋ノイズ（ランダム誤差）。同じ幅だけ減らせば全体誤差への効果は等価なのに、医学はバイアスばかり見てきた。
  • システムノイズ＝本来同一であるべき判断のばらつき。level（医師の平均水準の差）／stable pattern（患者特性への反応の個人差）／occasion（同一医師内の場面依存のばらつき）の3つに分かれる。
  • 結果として、似た患者が「誰が担当するか」というくじ引きで違う予後予測と違う治療を受ける。ノイズは相殺されず蓄積する。
  • 対策①アルゴリズム：一貫した変数選択と重み付けが最大の武器。improper な線形モデルでさえ一貫性ゆえに専門家を上回る。SICSの同一827例で医師 AUC 0.68 vs APACHE IV 0.83。
  • 対策②独立判断の平均化：ノイズは判断数の平方根で減る。ただしバイアスには無効、そして独立性が崩れれば効果も崩れる（＝上級医が先に話した時点で失われる）。
  • AI導入の落とし穴は「差別的バイアス」だけではない。誤ったモデルの提示は精度を下げ、ノイズの多い人間ラベルはモデルにノイズを移す。
  • 「アルゴリズムは不透明だから信用しない」への返答は、人間の判断も同じくらい不透明で、しかも検証できない。
