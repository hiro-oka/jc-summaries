🏥 聖路加ICUでの実践への示唆

聖路加ICUでの実践

病棟プロトコルへの落とし込み

  1. 「吸気努力だけ見る」運用をやめ、呼気筋の評価を1手順追加する。本総説の最大の主張はここにある。補助換気中の成人の2/3超で能動呼気が起きている（Akoumianaki 2024）にもかかわらず、当院を含め呼気筋はほぼ評価されていない。追加コストゼロで今日からできるのは ① 腹壁の視診・触診、② 呼気フロー波形の観察の2つ。呼気フローが指数関数的に減衰せず途中で増加する（上に凸の陥凹）／呼気終末にゼロへ戻らない場合は能動呼気を疑う。ただしきれいな指数関数的減衰でも能動呼気は否定できない。
  2. P0.1 と Pocc は「同じ呼気終末閉塞」から同時に読む。本総説も両者を並列に扱っており、当院の ベッドサイドで吸気ドライブと吸気努力をどう測るか — 13手法の使い分けと閾値（CritCare2025） 由来の運用（PS を触る前に P0.1 と ΔPocc を1回測る）と完全に整合する。低努力 P0.1 < 1.0 cmH₂O／高努力 P0.1 > 3.5–4.0 cmH₂O をそのまま維持してよい。
  3. 「高努力を拾う」目的では P0.1 より Pocc を信用する。本総説は de Vries 2023 を根拠に Pocc が高努力の同定で P0.1 を上回ったと明記。PDF の Fig. 2a の実例では 同一患者で P0.1 = 0.9 cmH₂O（＝低努力に見える）なのに Pocc = 21 cmH₂O（＝高努力） だった。「P0.1 が低いから大丈夫」は当院で最も危険な誤読（P0.1と生存の関連は非線形ではないか — 低すぎるP0.1も有害という指摘（AJRCCM2024） と同じ結論）。
  4. 推定 ΔP_L > 20 cmH₂O を「肺への負荷が高い」アラート値としてチームで共有する。Pocc から Predicted ΔP_L = (Ppeak − PEEP) − 2/3 × Pocc（Pocc は陰性値）で計算できる。電卓1回で出る。
  5. PMI は「安定プラトーが取れるか」自体を情報として使う。吸気終末ホールドで プラトー到達 < 800 ms・安定プラトー > 2 秒・変動 < 0.6 cmH₂O/s の基準を満たさない＝安定プラトーが取れないこと自体が高努力のサイン。「測れなかった」で終わらせない。
  6. PMI < 0 cmH₂O（Pplat < Ppeak）は過剰補助・過鎮静のサインとして鎮静／PS を減らす方向に動く。ただし高努力側の PMI 閾値は本総説でも未確立。
  7. 食道バルーンが入っているなら胃内圧（Pga）も同時に取る。ダブルバルーンで Pdi = Pga − Pes。呼気筋活動があると吸気努力と肺ストレスの両方を「過小にも過大にも」誤らせるため、Pga なしの Pes 単独評価は不完全。呼気中の ΔPga 1–2 cmH₂O 以上で能動呼気とみなす（本総説の著者らの reasoning、エビデンスに基づく確立閾値ではない）。
  8. Pga が使えないときは膀胱内圧（IAP）で代用する。尿道カテーテル経由の腹腔内圧測定は当院で日常的に実施可能であり、本総説も「呼気筋努力を同定し粗く定量する簡便な方法」と位置づけている。これは当院で明日から使える最も現実的な代替手段。
  9. ARDS で NMB を入れて酸素化が改善する現象を「呼気筋活動の消失」で説明する視点を持つ（Plens 2024）。逆に言えば、NMB を切った直後に酸素化が悪化する患者では呼気筋活動を疑う。
  10. 離脱評価に呼気筋活動を組み込む。呼気筋活動は離脱失敗のサインでありうる（Doorduin 2018、Pozzi 2022）。SBT 中の腹壁触診をルーチンに。

🧭 この論文の位置づけ（Known / Unknown / What's new）

補足

Known / Unknown / What's new

  • Known（既に分かっていたこと）：呼吸ドライブ（脳幹出力）と呼吸努力（筋が生む圧）は別物であり、過小・過大いずれの努力も横隔膜機能不全と関連する。過大な努力は pendelluft を介した局所の高い肺伸展圧と P-SILI をもたらしうる。食道内圧（Pes）が吸気努力の参照法であることは確立。P0.1・Pocc・PMI・sEMG といった非侵襲代替も個別に検証されてきた。
  • Unknown（分かっていなかったこと）：高努力が実際に横隔膜傷害・肺傷害を起こすという説得力ある証拠はまだ無い（本総説が明言）。また 呼気筋活動が吸気努力モニタリングの解釈をどう歪めるかが整理されていなかった。呼気筋努力を「強い／臨床的に意味がある」と層別化するための Pga データも存在しない。P0.1・Pocc の信頼性に呼気筋リクルートが与える影響も未検証。
  • What's new（本総説の新規性・意義）：吸気筋モニタリングを Table 1 の7手法に整理したうえで、従来の総説が扱わなかった「呼気筋」を対等の主題として組み込んだ点。「呼気筋を勘定に入れない呼吸筋努力の評価は不完全である（incomplete）」という結語がこの総説の立場を最も端的に表す。さらに機械学習による自動化（flow index、Pmus 推定アルゴリズム、深層学習によるフロースタベーション検出）を将来像として提示した。

📌 全体要約

要旨

結論 食道内圧（Pes）が吸気努力定量の参照標準であることは変わらないが、P0.1 と Pocc という2つの非侵襲な閉塞圧で「低すぎる／高すぎる努力」と「肺ストレス」をスクリーニングできる。とくに 高努力の検出では Pocc が P0.1 を上回る。一方、補助換気中の成人の2/3超で能動呼気が起きており、呼気筋活動は吸気努力と肺ストレスの解釈を歪める。呼気筋を評価しない呼吸筋モニタリングは不完全である。

  • 呼吸努力はドライブ（脳幹出力）→ 横隔神経 → 横隔膜収縮 → 力発生というカスケードの下流にある（Fig. 1）。横隔神経と横隔膜が健常なら高ドライブ＝高努力だが、呼吸筋機能不全があると高ドライブでも吸気努力は低い（＝呼吸困難の一因）。
  • 補助換気では一回換気量＝呼吸器の補助＋患者の努力であるため、呼吸器の波形だけを見ても実際の努力も高い肺伸展圧のリスクも分からない。
  • 吸気努力の評価法は7カテゴリ（Table 1）：臨床所見／P0.1／Pocc／PMI／(s)EMG／食道・胃内圧マノメトリ／波形の自動解析。
  • 呼気筋の評価は視診・触診 → 呼気フロー波形 → 腹壁エコー → Pga（最も簡便な定量法）→ 膀胱内圧（Pga 不可時）の順。
  • 将来像：機械学習による連続モニタリングの自動化。ただし現時点ではいずれも検証段階で、低努力／高努力の予測に使える参照値は未確立。

📖 詳細

1. 用語と生理の整理

図の解説

用語 呼吸ドライブ＝脳幹呼吸中枢の出力。呼吸努力＝その指令で呼吸筋が実際に生む圧。両者は密接だが別物。 ΔPes（Pes swing）＝吸気筋収縮による胸膜圧の低下量。Pmus＝吸気中に呼吸筋が生む総圧（胸壁を広げる圧を含む）。Pdi = Pga − Pes＝横隔膜特異的な努力指標。P_L（経肺圧）＝肺を伸展させる圧。

項目本総説の記載
吸気筋主役は横隔膜。運動・疾患時に 傍胸骨筋・外肋間筋・斜角筋・胸鎖乳突筋が動員される
呼気筋側腹壁筋群・内肋間筋。負荷が高いか吸気筋能力が低いときに動員
能動呼気の意義吸気筋努力だけでは到達できない一回換気量を稼ぐ重要な機序
胸壁エラスタンス（Ecw）能動呼吸中は正確に測れない。受動換気中の値を使うか、予測肺活量の 4% と概算する（Agostoni 1964）
Pmus 由来の派生指標WOB（一回換気量–圧曲線の面積）、PTP（圧×努力持続時間の積分）、pressure-rate product（圧振幅×呼吸数）。いずれも主に研究用途

能動呼気の頻度——補助換気中の成人の 2/3 超（Akoumianaki 2024, Soundoulounaki 2020）C：非同調性の吸気後負荷は全観察時間の 12.6%（厳格定義）／57%（鋭敏定義）測っている対象が違う（C は「非同調による吸気後負荷の時間割合」、本論文は「能動呼気を示した患者の割合」）。互いに矛盾せず補完的
⚠ 注意

依頼された食い違いへの回答 — P0.1 の低値側について本論文がどちらを採るか 本論文は「P0.1 < 1.0 cmH₂O」を採用している（Table 1「Low effort: P0.1 <1.0 cmH2O」、本文「P0.1 <1.0 cmH2O as a good screening tool for low respiratory drive」）。すなわち ベッドサイドで吸気ドライブと吸気努力をどう測るか — 13手法の使い分けと閾値（CritCare2025） の 1.0 と一致し、P0.1と生存の関連は非線形ではないか — 低すぎるP0.1も有害という指摘（AJRCCM2024） が引く Le Marec の 1.5 とは一致しない。 根拠文献が違う：本論文と 13手法総説はともに Telias ら（AJRCCM 2020）の生理学的検証研究を引いて 1.0 を採る。一方 1.5 は Le Marec ら（AJRCCM 2024）が予後解析のために設けた群分けの境界であって、生理学的な低努力閾値として提示されたものではない。 当院の運用結論：生理学的な「低努力／過剰補助」の判定閾値は 1.0 cmH₂O（2対1で多数、かつ根拠研究が生理学的検証）を正とする。1.5 cmH₂O は「予後の観点で注意を向け始めるライン」として二段構えで併用する（P0.1と生存の関連は非線形ではないか — 低すぎるP0.1も有害という指摘（AJRCCM2024） の結論を維持）。

5-1. 食道内圧（参照標準）

項目内容

5-2. 閉塞圧（P0.1 と Pocc）

項目P0.1Pocc

5-3. PMI（pressure muscle index）

項目内容
由来1997 年に Foti らが導入（AJRCCM 1997;156:1210-1216）
測り方補助換気中に吸気終末ホールドを行い、プラトー圧（Pplat）− 最高圧（Ppeak） を測る
原理吸気ホールドにより、呼吸器の補助に上乗せされた吸気筋の圧が露呈する：努力があると Pplat > Ppeak
検証小規模研究で PMI と Pes-time-product が中等度〜強い相関（Foti 1997、Bianchi 2022、Gao 2024）
PMI を目標にした補助調整実行可能（Gao 2024、Docci 2023）。Docci らは患者の反応を2群に分類：能動的に呼吸する患者は補助を下げると PMI が上昇（努力で代償）、"quasi-passive" 患者は補助を下げても PMI がほとんど上がらない → 吸気筋力低下 or 呼吸器の過剰補助のサイン
信頼できるプラトーの基準（Bianchi 2022）プラトー到達時間 < 800 ms／安定プラトーの持続 > 2 秒／プラトーの変動 < 0.6 cmH₂O/s
限界1高ドライブ・高努力の患者ほど安定プラトーが取りにくい／取れない。取れないこと自体が高努力の指標になりうる
限界2明瞭な安定プラトーがあっても呼気筋活動はしばしば存在する（Soundoulounaki 2020）。この場合、測定気道内圧は吸気終末の弾性リコイル圧と等しくならない
限界3PMI < 0 が受動吸気を示す以外、カットオフ値がない
派生同じ吸気ホールドから動的気道 driving pressure（ΔP,dyn = Pplat − PEEP）もモニタできる（Fig. 2c）

5-4. 表面筋電図（sEMG）

項目内容
参照法電極内蔵経鼻胃管（EAdi カテーテル）による EMGdi
非侵襲代替表面筋電図（sEMGdi）
核心的な問題EMGdi 振幅は努力と相関するが、被験者間・同一被験者内の記録間で変動が大きい（とくに sEMGdi）。振幅だけから努力は推定できない
解決策換算係数が必要：Pmus = k × EMGdi。k は神経力学的効率を表し、==呼気終末閉塞時に k = Pocc / 閉塞中の EMGdi 振幅として患者ごとに求められる==
進展運動方程式を用いた数理モデルで、平静呼吸中の sEMGdi から Pmus を正確に推定できる可能性（Petersen 2020、Grasshoff 2023）
注意Warnaar 2024 は sEMGdi 波形の品質基準を提案。換算係数（Pocc/sEMGdi）は適用 PEEP レベルに依存する

6. 呼気筋モニタリング（本総説の独自パート）

6-1. なぜ呼気筋を見るのか

観点内容
頻度補助換気中の成人の 2/3 超で能動呼気が起こりうる
良い面呼気流量と肺の空虚化を促進／横隔膜をより頭側に位置させ、次の吸気での張力発生に有利／呼気終末肺容量を減らし、弛緩時に吸気流量を生む
悪い面1肺容量低下により肺胞虚脱・周期的デリクルートメント・V/Q ミスマッチ・肺エラスタンスと driving pressure の悪化 → 肺傷害の増悪
悪い面2ARDS で神経筋遮断薬により酸素化が改善する機序の一つが、呼気筋活動の消失である可能性（Plens 2024、Zhang 2016）
悪い面3動的気道虚脱を起こしうる（Junhasavasdikul 2018）→ 肺の不均一性とガス交換障害
離脱呼気筋活動は離脱失敗のサインでありうる（Doorduin 2018、Pozzi 2022）

6-2. 呼気筋努力の評価法（段階的）

段階方法判定限界
① 臨床所見腹壁筋の視診・触診収縮の有無定性的
② 呼気フロー–時間波形波形観察（Fig. 3）初期ピークのあと、呼気流量が指数関数的に減衰せず逆に増加する（上向きの凹み）／呼気終末に流量がゼロへ戻らないことがある → 能動呼気を疑う典型的な指数関数的減衰でも能動呼気は否定できない
③ 腹壁エコー腹壁筋の厚み／厚み変化率健常者では腹筋の厚み増加が電気活動（McMeeken 2004）および圧発生（Misuri 1997、Schreiber 2021）と強く相関。ICU 患者でも圧発生との相関が確認されたが再現性は「中等度に許容できる」レベル定量には限界
④ 胃内圧（Pga）モニタリング現時点で呼気筋の力出力を測る最も簡便な方法呼気筋が活動すると呼気中に Pga（＝胸膜圧）が上昇し、吸気開始時の弛緩で急速に低下。ΔPga_exp（呼気時の Pga 上昇）と吸気開始時の Pga 低下の両方が検出に使われるが、ΔPga_exp の方が腹横筋 EMG との相関が良い（Parthasarathy 1998）。吸気初期の Pga 低下は「呼気筋の弛緩」と「吸気筋の収縮」のどちらでも起こるため胃バルーンの充填量・測定精度を較正する方法が存在しない（Pes とは対照的）。位置確認の最も正確な方法は X 線
⑤ PTPga_exp呼気 Pga 波形の曲線下面積（ベースライン＝安静呼気終末 Pga）呼気努力のエネルギー消費を推定—
⑥ 膀胱内圧（IAP）Pga が使えないとき、尿道カテーテル経由の腹腔内圧測定呼気筋努力を同定し粗く定量する簡便な方法精度は劣る
⚠ 注意

呼気筋努力の層別化はまだできない Pga に基づいて呼気筋努力を「強い」「臨床的に意味がある」と層別化するデータは現時点で存在しない。本総説は著者らの reasoning として ΔPga_exp 1–2 cmH₂O を能動呼気とみなすと述べているにすぎない。また、呼気筋努力の大きさを予測する非侵襲的方法はまだ開発されていない。

2Pplat の算出は吸気終末閉塞中の受動条件を前提とする。見かけ上平坦なプラトーでも呼気筋リクルートは否定できない（Soundoulounaki 2020）肺ストレスを過大評価
