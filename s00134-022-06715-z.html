# 肺リクルートメントとStress Index

🏥 聖路加ICUでの実践への示唆

聖路加ICUでの実践

病棟プロトコルへの落とし込み

  • PEEPは「上げれば必ず良い」ではない。開けるべき肺（リクルータブル）と、既に開いた肺の過膨張は別物で、同じPEEP上昇が患者ごとに真逆に働く。当院でも「酸素化が上がった＝リクルートできた」と短絡しないことを共有したい。酸素化改善は心拍出量低下によるシャント減少でも起こり、CTで測ったリクルートとの相関は弱い。
  • ベッドサイドでリクルータビリティを一手法に頼らない。この総説は「決定版の単一指標はまだ無い」と明言している。当院で実装しやすい順に、①VCV（従量式）でのStress Index、②PEEP段階を変えたPV曲線、③R/I比（15→5 cmH2Oの単回手技、人工呼吸器を選ばない）、④EIT が使えるなら decremental PEEP trial、を病態に応じて組み合わせる。
  • Stress Index を日常の一次スクリーニングに。VCVで気道圧−時間曲線の形を見るだけで、SI>1（上に凹＝過膨張）／SI<1（下に凸＝tidal recruitment）を推定できる。プラトー圧やドライビング圧と併せ、「このPEEP・この一回換気量で肺胞が過伸展していないか」を回診でチェックする材料にする。
  • PEEP設定の目的を個別化する。「最大リクルートを達成・維持することが肺傷害最小化に必須か」は本総説時点でも未解決。リクルータブルでない肺に高PEEPを当て続ける害（過膨張・血行動態）を意識し、リクルータビリティ評価の結果で高PEEP/低PEEPを使い分ける方向で運用する。

🧭 この論文の位置づけ（Known / Unknown / What's new）

補足

リサーチ・イン・コンテキスト

  • Known（既に分かっていたこと）：ARDSでは重力・鎮静による呼吸筋活動の消失・胸壁負荷で背側無気肺が生じ、その一部は再開通しうる「リクルータブル肺」である。リクルータビリティは疾患の原因（肺性/肺外性）より肺形態で大きく変動し、リクルートの手段としてリクルートメント手技・腹臥位・高PEEPがある。
  • Unknown（分かっていなかったこと）：ベッドサイドでリクルータビリティを正確・簡便に測る「万能な標準法」が無かった。これが、PEEPの効果を一貫して示す試験が出てこなかった一因と考えられる。
  • What's new（本研究の新規性・意義）：リクルートの測定法を「間接法（酸素化・コンプライアンス・Stress Index）」と「直接法（CT・PV曲線・EIT・肺エコー・R/I比）」に体系整理し、各手法が何を測り何を測れないか（例：CTは組織リクルート、PV曲線は気体リクルートで両者は相関しない）を明快に対比。近年登場したベッドサイド新技術が個々の患者でPEEPの利益と害を秤にかける道を開きうる、と展望する簡潔な総説。

📌 全体要約

要旨

ひとことで 肺リクルートメントとは「同じ圧に対する容量の増加」であり、その測定は間接法（酸素化・コンプライアンス・Stress Index）と直接法（CT・PV曲線・EIT・肺エコー・R/I比）に分かれる。単独で決定版と言える手法は無く、各手法の「何を測っているか」を理解して使い分けることが要点。

  • 定義：生理学的には「同じ圧に対する容量の増加」。臨床的には、無気肺化した背側の肺胞が再開通し一回換気に参加できるようになること。
  • リクルータビリティの規定因子：疾患の原因（肺性/肺外性）よりも肺形態が変動を説明する。中等症〜重症ARDSで、気道圧を5→45 cmH2Oに上げたときの再含気は平均で全肺重量の13 ± 11%と幅が広く、肺傷害の重症度と強く相関した。
  • 間接法の限界：酸素化改善は心拍出量低下によるシャント減少でも起こり、CTでのリクルートとの相関は弱い。コンプライアンス上昇は「既存肺胞の力学改善」と「新規リクルート」の両方を含み、リクルーターでも過膨張の併存で高PEEPでコンプライアンスが下がりうる。
  • Stress Index（SI）：定流量吸気時の気道圧−時間曲線の形を数式フィッティングで表す指標。SI=1（直線）で正常換気、SI<1（下に凸）でtidal recruitment、SI>1（上に凹）で過膨張を示唆する。SI由来のPEEPはCTのリクルータビリティとは別物。
  • 直接法の基準：CT（ボクセル単位、HU閾値で組織リクルートを定量）とPV曲線（開始肺容量/PEEPを変えた曲線の上方シフト＝リクルート、ヒステレシスに基づく）。両者は相関しない（CTは組織、PV曲線は気体を測る）。
  • ベッドサイド新技術：EIT（ピクセルコンプライアンスの変化でリクルート/過膨張を推定）、肺エコー（再含気スコアがPV曲線と相関、ただし過膨張は検出不可）、R/I比（15→5 cmH2Oの単回手技でリクルータビリティを算出）。
  • 臨床的含意：リクルータビリティを知ることは人工呼吸管理の最適化に不可欠。近年の手法がPEEPの利益・害を個別に秤にかける助けになると期待されるが、最大リクルートの達成・維持が肺傷害最小化に必須かは未解決。

📖 詳細

1. まず前提 — 肺リクルートメントとStress Indexの基礎（初めての人にも）🧩

要旨

5分で背景を掴む 肺リクルートメント（lung recruitment）とは、つぶれて（無気肺化して）ガスが入らなくなった肺胞を再び開かせ、一回換気に参加させることを指す。生理学的な定義は「同じ圧に対する容量の増加（increase in volume for the same pressure）」。ARDS（急性呼吸窮迫症候群：肺の広範な炎症・浮腫で酸素化が悪化する病態）では、重力・鎮静による自発呼吸の消失・（肥満患者では）胸壁の重みで、背側に無気肺が生じる。この背側の肺の一部は「開けられる肺＝リクルータブル肺」で、リクルートメント手技（一時的に高い圧をかけて開く）・腹臥位・高いPEEPで再開通・維持できる。 PEEP（呼気終末陽圧）は呼気の終わりに気道内を陽圧に保ち、開いた肺胞がつぶれ直すのを防ぐ設定。ただし高すぎるPEEPは、既に開いている肺胞を伸ばしすぎる「過膨張（overdistention）」を招き、かえってコンプライアンス（肺の膨らみやすさ）を下げ、肺傷害の原因にもなる。だから「どこまで開き、どこから伸ばしすぎか」を評価することが重要になる。 Stress Index（SI）は、その評価をベッドサイドで行う代表的な間接指標。VCV（従量式換気：一定の流量＝定流量でガスを送る設定）のとき、吸気中の気道圧が時間とともにどんな形で上がるかに注目する。肺が吸気の途中でさらに開いていく（tidal recruitment）なら、途中でコンプライアンスが上がるので圧の上がり方は鈍り、曲線は下に凸（convex）になる。逆に吸気の後半で肺胞が伸ばしすぎになる（過膨張）と、コンプライアンスが下がり圧が急に上がって、曲線は上に凹（concave）になる。この気道圧−時間曲線の「形」を数式フィッティングで1つの数値にしたのがSIである。SI=1（直線）＝過膨張のない正常な換気／SI<1＝tidal recruitmentが進行中／SI>1＝過膨張、と読む。

2. 背景と目的 🫁

本総説は、リクルートの意味を臨床像で説明することから始める。細菌性肺炎を例にとると、ある肺葉での感染は細菌と炎症細胞が固まった硬化巣（consolidation）を作り、この部分はガスが到達できず、リクルートもできない。一方、残りの肺は急速に炎症を起こしても、なおガスが到達可能なことがある。この後者に対して、重力の影響、鎮静された患者での呼吸筋活動の欠如、肥満患者での胸壁による負荷が主に背側無気肺を生む（ただし肺内部の強い不均一性も存在しうる）。この部分こそがリクルータブル肺であり、リクルートメント手技・腹臥位・より高いPEEPといった異なるアプローチで再開通・維持できる。

患者間でのリクルータビリティの大きなばらつきは、肺傷害の原因（肺外性か肺性か）よりも、肺形態（lung morphology）によって説明されうる、と述べる。

目的は「リクルートをどう測るか」を体系立てて示すこと。リクルータビリティを知ることは人工呼吸管理の最適化に決定的に重要であり、これまで満足のいく万能なベッドサイド法が無かったことが、PEEPの一貫した効果を示す試験が出てこなかった理由かもしれない、という問題意識が背景にある。

3. 方法（Methods）📐

  • デザイン：原著研究ではなく、Intensive Care Medicine の "Lasting Legacy in Intensive Care Medicine" シリーズに掲載された簡潔なナラティブ総説（mini-review）。全3ページ、図は1枚（哺乳類肺のPV曲線ヒステレシス）。したがってPICO・n数・統計解析は該当しない。
  • 対象領域：中等症〜重症ARDSを中心とした、機械換気下でのリクルータビリティ評価。
  • 構成：リクルートの測定法を「間接法（酸素化・コンプライアンス・Stress Index）」と「直接法（CT・PV曲線・EIT・肺エコー・R/I比）」に大別し、各手法が測っているもの・長所・限界・ベッドサイドでの実行可能性を対比して整理する。
  • 引用の性格：CTの再含気量（13 ± 11%）などの具体的数値は先行研究（Gattinoni 2006・Chiumello 2016 ほか）からの引用であり、本総説がデータを新たに取得したものではない。

4. 間接的評価法 — 酸素化・コンプライアンス・Stress Index 💧

臨床疑問：ベッドサイドで得やすい生理指標（酸素化・コンプライアンス・気道圧波形）から、リクルートをどこまで推定できるか。

生理学的には、より多くの肺胞が一回換気に参加すればガス交換と呼吸メカニクスは改善するはずである。しかし「機能的（functional）」リクルートの測定の要注意点は、ガス交換や呼吸メカニクスの変化がリクルートだけを反映しているわけではないことにある。

  • 酸素化：酸素化の改善は、心拍出量の低下による肺内シャント減少からも生じうる。実際、酸素化はCTで測ったリクルートとは弱い相関しか示さず、シャントは心内・血管性の要因（卵円孔開存など）でも説明されうる。
  • コンプライアンス：高い圧でのコンプライアンス改善は、「既に開いている肺単位の力学的性質の改善」と「以前虚脱していた肺胞の新規リクルート」の両方を表しうる。さらに、リクルーターであっても過膨張の同時併存により、高PEEPでコンプライアンスがむしろ低下することがある。
  • Stress Index（SI）：tidal recruitment は SI で推定できる。SIは定流量吸気時の気道圧−時間曲線の形を数式フィッティングで表したパラメータである。
  • SI=1（圧の直線的上昇）：過膨張のない正常換気肺胞のtidal inflationを示唆。
  • SI<1（下に凸＝convexity、吸気中にコンプライアンスが増加）：tidal recruitmentを示唆。
  • SI>1（上に凹＝concavity、吸気中にコンプライアンスが低下）：過膨張を示唆。
  • PEEPに伴うSIの変化は、そのPEEPレベルでtidal inflationがtidal recruitmentを起こしているのか、tidal hyperinflation（過伸展）を起こしているのかを示す。したがってSI由来のPEEPはCTスキャンのリクルータビリティとは同一ではない。
⚠ 注意

臨床上の要注意ポイント 間接指標（酸素化・コンプライアンス）の改善を「リクルートできた」と即断しない。酸素化改善は心拍出量低下によるシャント減少でも起こり、高PEEPでコンプライアンスが下がっても、それは過膨張の併存であってリクルート不能とは限らない。単一指標での判断は誤りやすい。

5. 直接的評価法 — 基準法（CTスキャンとPV曲線）🫁

臨床疑問：リクルートを「直接」測る基準法は何を測っており、互いにどう違うのか。

  • CTスキャン：ボクセル単位の解析に基づく。含気ボクセルの密度閾値（例：−100または−200 Hounsfield単位）に応じ、ある圧で非含気だった組織が高い圧で再含気する量として組織リクルートを定量する。しばしば「含気が回復した組織のグラム数」や「全肺重量に対する再含気画分」で表す。この方法での再含気量は、中等症〜重症ARDSで気道圧を5→45 cmH2Oに上げたとき平均で全肺重量の13 ± 11%と幅広く、肺傷害の重症度と強く相関した。CTは搬送・被曝・時間の面でルーチン使用には不向きで、被曝はスキャンプロトコルで低減すべきである。
  • PV曲線（圧−容量曲線）：異なる呼気終末肺容量またはPEEPレベルから始めた2本以上のPV曲線を重ねたとき、高PEEPでのPV曲線の垂直方向の上方シフトがリクルートを意味する（Fig 1）。これは肺のヒステレシス様の挙動に基づく。PV曲線は定流量の緩徐吸気法で得られ、鎮静（±筋弛緩）を要する。
  • 両者は相関しない：興味深いことにPV曲線法はCTベースのリクルートと相関しなかった。CTは組織リクルート（解剖学的）を測るのに対し、PV曲線は再開通した気体（recruited gas）を検出するためである（低換気領域を考慮する別のCT解析とは相関した）。CT上で組織リクルートが無くても、肺組織の性質が容量で変わることにより気体リクルートが存在しうるが、その逆は成り立たない。

6. 直接的評価法 — ベッドサイド新技術（EIT・肺エコー・R/I比）💧

  • 電気インピーダンス断層撮影（EIT）：ベッドサイド非侵襲肺画像として普及しつつある。CTのような含気の画像は与えず、換気の動的情報（人工呼吸器設定変化に伴う全体・局所の肺容量変化）を提供する。リクルータブルな肺胞虚脱の割合は、ピクセルコンプライアンスの相対変化を測って推定できる。高PEEPでの「基準」値と、広いPEEP範囲（しばしば24→6 cmH2O）でのdecremental PEEP trialが必要で、PEEPを下げたときのピクセルコンプライアンス低下は虚脱を、PEEPを上げたときの低下は過膨張を示唆する。ピクセルコンプライアンス変化とリクルート容量推定の両方を含む定量法は開発中（NCT04460859）。
  • 肺エコー（LUS）：もう一つの普及したベッドサイド非侵襲モダリティ。LUS再含気スコアはPV曲線で定量したPEEP誘発リクルートと相関した。高PEEPで再含気する硬化組織の局所評価はできるが、肺の過膨張は予測できない。
  • R/I比（recruitment-to-inflation ratio）：どの人工呼吸器でも行える簡略化した単回呼吸手技で得る。まず気道閉塞の有無と対応する気道開放圧を確認する。次に、急なPEEP低下（しばしば15→5 cmH2O）の間に測った呼出容量から算出する。この呼出容量は、高PEEPでの呼出一回換気量、予測されるPEEP誘発膨張容量（＝ΔPEEP×低PEEPでのコンプライアンス）、そしてリクルート容量から成る。リクルータビリティは、リクルートされた肺のコンプライアンスと低PEEPでの「ベビーラング（baby lung）」コンプライアンスの比として定義される。手技中は、以前リクルートされた開放肺単位を十分に空にするため呼吸回数を6〜8回/分に下げる。R/I比は酸素化（反応）・肺胞死腔・血行動態反応と相関し、リクルーターと非リクルーターの区別に使われることが増えている。高/低PEEP設定にR/I比を用いることが研究されている（NCT03963622）。

7. 臨床的含意と残された課題 🧩

リクルータビリティを知ることは人工呼吸管理の最適化に決定的に重要である。最近まで満足のいく万能なベッドサイド法が無く、これがPEEPの一貫した効果を示す試験が出てこなかった一因かもしれない。近年導入された手法が、PEEPの潜在的な有益・有害効果について臨床医により良い情報を与え、個々の患者でPEEPの利益とリスクを秤にかけることを可能にすると期待される。ただし、最大の肺胞リクルートを達成・維持することが肺傷害を最小化し肺の治癒を促すために必要か否かは、依然として不明のままである。

結論

  • 肺リクルートメントは「同じ圧に対する容量の増加」。その評価に決定版の単一指標は無く、各手法が「組織」を測るのか「気体」を測るのか（CTとPV曲線は相関しない）を理解して使い分ける。
  • Stress Index は VCV での気道圧−時間曲線の形。==SI=1で正常、SI<1（下に凸）でtidal recruitment、SI>1（上に凹）で過膨張==。ベッドサイドの一次スクリーニングに使える。
  • 酸素化やコンプライアンスの改善を「リクルートできた」と即断しない。心拍出量低下や過膨張の併存で誤読しうる。
  • ベッドサイドではR/I比・EIT・肺エコーが実装しやすい。最大リクルートの達成・維持が肺傷害最小化に必須かは未解決で、リクルータブルでない肺への高PEEP固執の害を意識する。
