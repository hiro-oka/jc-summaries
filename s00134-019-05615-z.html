🏥 聖路加ICUでの実践への示唆

聖路加ICUでの実践

病棟プロトコルへの落とし込み

  • AKIだからといって蛋白を絞らない。RRT非施行のAKIでも、一般ICU患者と同じく 1.3 g/kg/日 へ段階的に増量する。RRT導入を遅らせる目的の蛋白制限は本論文の推奨ではない。
  • 初期は低カロリーで始める。発症早期は消費エネルギー（EE）の 70%を超えない。day 3以降に 80〜100%へ上げる。「AKIだから」でカロリー目標を変える根拠はない。
  • CRRT中はクエン酸のカロリーを栄養計算に算入する。局所クエン酸抗凝固（RCA）を回している患者では、これを無視すると容易に過剰栄養になる。
  • CRRT患者では微量栄養素（水溶性ビタミン・微量元素）の補充を既定にする。ただし種類・量・期間は未確立で、専門家意見レベル。
  • 経路の順番を守る：可能なら経口 → 不十分なら 24〜48時間以内に経腸 → 経腸が禁忌なら 3〜7日以内に経静脈。早期の補助的静脈栄養（早期PN）は、特にAKI患者で害の報告がある（EPaNIC）。
  • グルタミン・抗酸化物質の常用は行わない。多臓器不全＋AKI例で害が示されている（REDOXS post hoc）。
  • 栄養評価は AKI 専用の妥当性検証済みツールが存在しない。ICU入室前の体重減少、身体所見、体組成・筋量・筋力の評価で代替する。

🧭 この論文の位置づけ（Known / Unknown / What's new）

補足

リサーチ・イン・コンテキスト

  • Known（既に分かっていたこと）：AKIは重症患者の高頻度合併症で、炎症・不動・筋崩壊により低栄養を来しやすい。RRT（特にCRRT）ではアミノ酸・微量元素・グルコース・水溶性ビタミンが除去される（CRRTでアミノ酸損失 10〜15 g/日 の報告）。一般ICU集団では、過小栄養も過剰栄養も回復遅延・死亡増加と関連する。
  • Unknown（分かっていなかったこと）：AKI患者を対象とした栄養のRCTは 1本も存在しない。AKI特異的な栄養スクリーニングツールも未検証。CRRT中の微量栄養素ルーチン補充の役割も不明。
  • What's new（本研究の新規性・意義）：エビデンスの空白を明示したうえで、AKI患者・一般ICU患者それぞれのカロリー／蛋白／微量栄養素の推奨を エビデンスレベル付きで1枚の表に集約（Table 1）。AKI推奨の大半が Level 5（専門家意見）である事実を可視化した点が本質的な貢献。

📌 全体要約

要旨

ひとことで AKIの栄養にはRCTが存在せず、推奨のほとんどが専門家意見である。実務上は「AKIだから特別」ではなく 一般ICU患者の原則（早期は低カロリー、蛋白は 1.3 g/kg/日 へ漸増、経腸優先）を適用し、RRT特有の損失（アミノ酸・微量栄養素）とクエン酸カロリーを上乗せ補正するのが現時点の最善解。

  • AKIの低栄養の主因は 重症病態そのもの（全身炎症・不動・筋崩壊）と 入院前からの低栄養。尿毒素・中分子・アミノ酸パターン異常・体液貯留も寄与する。
  • CRRT患者の 80% が、チアミン／ピリドキシン／アスコルビン酸／葉酸／亜鉛／銅のうち 少なくとも1つで正常下限を下回っていた（後ろ向き研究）。
  • ただし血中濃度低下＝フィルタ除去とは限らない。Story らの検討では、CRRT患者は健常者より有意に低値だったが、CRRTあり／なしの重症患者間では差がなかった → 急性病態そのものの寄与がCRRTより大きい。
  • ESPEN 2019：早期は EEの70%を超えない低カロリー、day 3以降 80〜100% へ。蛋白は 1.3 g/kg/日へ漸進的に。
  • AKI患者のカロリー目標を RRT の有無で変える根拠はない。ただし CRRTのクエン酸はカロリー源として算入する。
  • 高用量グルタミン、および第1週の早期補助的PNは、多臓器不全・AKI例で 害（尿素産生増加によるRRT需要増、オートファジー抑制、異化抑制の失敗、死亡増加）。
  • 進行中RCT：NCT03292237、NCT03573739（カロリー／蛋白の低用量 vs 高用量）。

📖 詳細

1. まず前提 — この病態・治療の基礎（初めての人にも）🧩

要旨

5分で背景を掴む AKI（急性腎障害） は敗血症・多臓器不全・大手術・外傷を背景に起こる急性の腎機能低下で、それ自体が「炎症性の病態」と捉えられている。腎が悪いと言うと反射的に「蛋白を絞る」と考えがちだが、ICUのAKIでは事情が違う。重症病態では筋肉からアミノ酸が動員され、糖新生と炎症性メディエータ産生に使われる。この 異化（カタボリズム）は栄養では止められない ——栄養ができるのは蛋白・エネルギー収支の改善と、おそらく蛋白合成の下支えまでである。 RRT（腎代替療法） を回すと話がさらに複雑になる。CRRT（持続的腎代替療法） は連続的に血液を濾過するため、老廃物だけでなくアミノ酸・水溶性ビタミン・微量元素・グルコースも一緒に抜ける。逆に、抗凝固に使うクエン酸（citrate）は代謝されてカロリーになるため、気づかないうちに 過剰栄養 の側に振れることもある。 EE（energy expenditure、エネルギー消費量） の測定には間接熱量計（indirect calorimetry）が理想だが普及していない。推算式はAKIで妥当性検証されておらず信頼できない。つまり「いくら入れるか」の土台自体が脆い、というのが本論文の出発点である。

2. 背景と目的 🫁

本稿の目的は明快で、著者ら自身が "Our aim is to highlight the lack of high-quality data related to nutrition in AKI."（AKIの栄養に関する質の高いデータの欠如を強調すること）と述べている。

低栄養はWHO定義で「エネルギーおよび／または栄養素の摂取における不足・過剰・不均衡」。AKIでは高頻度で、蛋白分解亢進、脂肪分解の障害、インスリン抵抗性、ホルモン調節の変化が報告されている。

RRT施行中はアミノ酸・微量元素・グルコース・水溶性ビタミンの除去が栄養状態に影響する。除去量はモダリティ・線量・期間・血中濃度に依存し、CRRTではアミノ酸損失 10〜15 g/日 の報告がある。ただし多くは小規模・古く、現在の診療を必ずしも反映しない。

3. 方法（Methods）📐

  • デザイン：Intensive Care Medicine の "What's new in intensive care" 枠のナラティブレビュー（3ページの短報）。系統的レビューでもRCTでもなく、エビデンス統合の方法論は記載されていない。
  • 対象：重症AKI患者（RRT施行例・非施行例の双方）。
  • 中心となる成果物：既存ガイドライン（ESPEN 2019、KDIGO 2012、ASPEN/SCCM 2016、DGIIN/ÖGIAIN/DIVI 2018、A.S.P.E.N. 2010）の推奨を、Oxford CEBM のエビデンスレベル付きで対比した Table 1。
  • 限界（著者自身の記載）：AKI患者に特化した栄養のRCTは存在しない。一般ICU集団（AKI患者を含む）の知見を外挿している。
⚠ 注意

臨床上の要注意ポイント

  • AKI患者の栄養推奨は、その大半が Level 5（専門家意見）である。表の数値を「エビデンス」として扱わないこと。
  • 早期のフル栄養は過剰栄養になりうる。測定できない内因性エネルギー産生を抑制できないためで、筋異化も反転させず、リフィーディングを誘発しうる。
  • 早期補助的PN・高用量グルタミンは、多臓器不全＋AKIで害。尿素産生増加により RRT 必要性が増える可能性がある。
  • CRRT中の血中微量栄養素低値を見たとき、「フィルタで抜けたから」と即断しない。急性病態そのものの寄与のほうが大きい可能性がある。

4. 栄養評価（Nutritional assessment）📐

すべての重症患者は一般的な栄養状態評価を受けるべきだが、AKI患者の栄養必要量を評価する妥当性検証済みスクリーニングツールは存在しない。間接熱量測定は広く利用できず、安静時エネルギー必要量の推算式は信頼性が低くAKIでの検証もない。

専用ツールが検証されるまでの代替として推奨されるのは以下：

  • ICU入室前の体重減少の聴取
  • 身体診察
  • 体組成・筋量・筋力の評価

5. 栄養サポート（Nutritional support）💧

臨床疑問：重症AKI患者に、どのタイミングで／どの経路で／どれだけのカロリーと蛋白を投与すべきか。

POINT

実務上の推奨（本文＋ESPEN 2019）

  • 個別化：異化の重症度、原疾患、併存症、RRTの要否、入院前の栄養状態に合わせる（コンセンサス）
  • カロリー：早期は EE の 70%以下、day 3以降に 80〜100% へ（overfeedingもunderfeedingも有害）
  • 蛋白：1.3 g/kg/日 へ 漸進的に増量（急に目標へ持っていかない）
  • 経路：経口 → 経腸（24〜48時間以内）→ 経静脈（経腸禁忌なら 3〜7日以内）
  • ボーラス vs 持続の経腸：限られたデータでは同等の目標達成が可能
  • AKI × RRT の有無でカロリー目標を変える根拠はない（ただしクエン酸のカロリーは算入する）

エビデンス

  • 微量栄養素：CRRT患者の 80% が、チアミン・ピリドキシン・アスコルビン酸・葉酸・亜鉛・銅のいずれか1つ以上で正常下限未満（Kamel 2018、後ろ向き）。
  • CRRTか病態か：Story らはビタミンC・E、セレン、亜鉛、クロム、銅を測定し、CRRT患者は健常対照より有意に低値だったが、重症患者コホート間（CRRTあり／なし）には差がなかった。
  • 蛋白の観察データ：一般ICU集団で高蛋白投与は低死亡と関連するが、day 3〜5にかけて緩徐に目標へ近づけるほうが有益な可能性（Weijs 2014、Zusman 2016、Bendavid 2019）。
  • 早期PNの害：EPaNIC（Casaer 2011、NEJM）— 第1週の早期補助的PNは害。
  • グルタミンの害：REDOXS post hoc（Heyland 2015）— 多臓器不全、特にAKIで高用量グルタミンは有害。
  • 進行中：ClinicalTrials.gov NCT03292237、NCT03573739。
⚠ 注意

ガイドライン間の食い違い（本ノートで採用した立場） 蛋白目標はガイドラインによって割れている。ASPEN/SCCM 2016 は古い報告に基づき より高い蛋白量（25–30 kcal/kg/日のカロリーと併せ）を推奨する一方、本論文の著者は 最新のESPEN 2019 に沿った 1.3 g/kg/日 の漸進的投与 を支持している。本ノートは 著者の立場（ESPEN 2019 準拠）を採用 した。理由は、より高用量を支持する根拠が古く、かつ早期PN・高用量グルタミンで害が示されているためである。

6. 未充足のニーズと今後の研究 🔬

著者らの結論：AKIの栄養は研究が不足している領域（under-researched area）である。

  • AKI患者を対象とした栄養のRCTは存在しない。
  • CRRT患者における微量栄養素ルーチン補充の正確な役割は不明。
  • 特に「異なる蛋白目標 × 低カロリー栄養 × 微量栄養素補充」の組み合わせがアウトカムを改善するかを検証する、良質なRCTが急務。

✅ Take home message

TAKE HOME

結論 AKIの栄養に特化したRCTは存在しない。だから「AKIだから蛋白を絞る」ではなく、一般ICUの原則をそのまま適用する — 早期は低カロリー（EEの70%以下）、day 3以降に80〜100%、蛋白は 1.3 g/kg/日 へ漸増、経腸を優先。そのうえで CRRT特有の補正（微量栄養素の補充、クエン酸カロリーの算入）を上乗せする。早期補助的PNと高用量グルタミンは、AKIでは害。
